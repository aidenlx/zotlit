I'm not from the Obsidian team, but just to share a recent experience...
For the Tasks plugin, after a report of a "Remote Code Execution" vulnerability, made possible by the execution of user-supplied JavaScript, I was advised by the Obsidian team to turn off JS execution by default, storing the option locally (not sync-able via data.json).
In the end, I was convinced of the value and importance of this, for various reasons - resulting in these:
PR: fix!!: For security, JS search features now disabled by default, with setting to enable
A breaking release (8.0.0)
New docs page: JavaScript in Tasks Queries
I have to say it was a very, very stressful few weeks
first receiving the user report
and then having to wait a while to hear back from the Obsidian team...
and then having to implement and document the change.
