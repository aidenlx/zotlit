An update refreshes what comes from Zotero. It keeps your three sections, the `course` and `week` you type once, and the `status` you set. Zotero tags add to the tag list, so a tag you remove in Zotero stays in the note until you delete it there. A Zotero tag with a comma or a `#` needs a manual fix in Obsidian.

To sort weeks in number order, give `week` its type once: select the icon beside `week`, then **Property type** > **Number**.

If another look already takes the item, ZotLit uses that look; then run **Switch literature note profile** on the note. A switched note does not get the three sections.
