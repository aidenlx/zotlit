The line names the item's main creators: the authors for most items, or the main role for the item type, such as the person interviewed for an interview. When an item has none of these, the line names its editors, then its directors, then its contributors. When it has no creators at all, the partial writes nothing.

To write "and" instead of "&", or "等" instead of "et al.", replace that text in the last line of the partial.
