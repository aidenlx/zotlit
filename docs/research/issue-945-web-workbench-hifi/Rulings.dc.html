ZotLit
Rulings · web Workbench, revision 2

The job

Change what my literature notes look like, see it, keep it. Three concepts and no more: this is my note; the orange {{ fields }} fill in from Zotero, I add one from the list; Save keeps it.

Composition

  • One header row: name, the paper shown, ···, Save.
  • Three columns: From this paper · Your note · The note you get.
  • The note is the only open pane; Properties and Name and folder are two links under it.
  • Fields print as {{ Title }}, the field's human name in the Liquid braces, as a live preview over the source; selecting one reveals its code, {{ zt.title }}, in place (one buffer, one undo, ADR 0032). Advanced shows the whole file as plain source, with no field preview.
  • The kept-up-to-date part is a tinted band; the highlight format is a dashed box inside it.
  • Empty states are hidden: no Problems line when there are none, no connection line when connected.
  • Advanced, Download, and Undo sit behind ···.
  • Under 780px, the note fills the screen with a tab for the result and a bottom "Add a field" button.

Final section on every board

  • The file ends with the required highlight section.
  • The first place highlights render is where it is edited; later places link back.
  • A file without it shows one calm strip with "Add the highlight format".
  • Advanced shows the header line as text.
