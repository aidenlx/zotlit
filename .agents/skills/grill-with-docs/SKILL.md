Before round one, settle every prerequisite exploration can resolve: dispatch sub-agents for the facts the design tree will need (codebase, `CONTEXT.md`/ADRs, prior research docs) and wait for them to report back. Don't open the frontier until exploration is settled — unlike plain `/grilling`, which asks around a running exploration, this session blocks on it first.

Run a `/grilling` session, using the `/domain-modeling` skill.
