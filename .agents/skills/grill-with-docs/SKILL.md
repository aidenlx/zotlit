Before round one, settle every prerequisite exploration can resolve: dispatch subagents for the facts the design tree will need (codebase, `GLOSSARY.md`/ADRs, prior research docs) and wait for them to report back. Open the frontier after exploration is settled; unlike plain `/grilling`, which asks around a running exploration, this session blocks on it first.

Call the Skill tool twice, for "grilling" and "domain-modeling".
