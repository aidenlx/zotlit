# Chinese documentation

## Locale files

The site uses native Fumadocs localization and Paraglide messages. English URLs have no prefix. Simplified Chinese URLs use `/zh-CN`, as in V1.

A `.zh-CN.mdx` or `.zh-CN.md` file supplies the Chinese edition. When that file is absent, Fumadocs serves the English file at the same Chinese URL. The fallback notice uses the requested UI locale and offers an explicit “Read in English” link. That link preserves the query and fragment. The site does not redirect the reader automatically.

The Chinese edition includes content imported from [PR #1448](https://github.com/aidenlx/zotlit/pull/1448), source commit `f8bd34ec1be87cc57efa6b3e2016ac886ce5942e`:

- 88 `.zh-CN.mdx` files: 85 pages and 3 included partials
- 7 `meta.zh-CN.json` files for navigation, with 6 translated section labels
- 101 updated `docs_*` values in the root Chinese catalog; all 110 current docs keys are retained
- 46 translated Fumadocs dictionary values in `i18n/zh-CN.json`

All non-docs catalog values remain unchanged. The newer `docs_read_in_english` key is absent from the imported work and still says “Read in English”. The template-data reference retains the missing, already-authored sections from [PR #1447](https://github.com/aidenlx/zotlit/pull/1447), source `675c8b3265c8e2d20cb424180f7fe00864a189e4`. Many other supplied MDX pages still contain English headings and passages, including reference commands/settings, template syntax, and later blog sections. These counts describe the supplied files and values, not a complete translation-quality review.

## Editing Chinese content

1. Edit the matching locale file under `content/docs`, `content/blog`, or `content/changelog`. Include the title, description, body, and image text. Keep code, API names, stable anchors, and links intact.
2. Edit the included Chinese partials. Their include paths already name the `.zh-CN.mdx` files.
3. Edit navigation labels in `meta.zh-CN.json`, keeping page order and identifiers.
4. Edit site messages in [the Chinese catalog](../../../messages/zh-CN.json), using [the English catalog](../../../messages/en.json) as the source. Site copy uses `docs_*`; shared Workbench copy uses `workbench_*`.
5. Edit `fumadocs` values in [`i18n/zh-CN.json`](../i18n/zh-CN.json). Keep the dictionary keys and interpolation tokens, such as `{url}`, unchanged.

These files take effect on the next build. There are no translation approval flags or readiness commands. File presence selects the locale edition; the site does not detect the language or quality of its text.

The generated template-data reference also renders prose from the shared English contract data. Translate that surface as well as the MDX and partials before publishing Chinese documentation.

## Metadata and fallback

The build reads the actual locale files through the existing [content scan](../src/lib/content-scan.ts). A loader result that uses English fallback does not count as a native Chinese file.

- An existing Chinese file has Chinese locale metadata, a Chinese canonical URL, reciprocal English/Chinese alternate links, and a Chinese sitemap entry.
- A missing Chinese file has English content language and canonical URL. Its Chinese fallback URL uses `noindex, follow`, has no Chinese alternate link, and stays out of the sitemap.
- Home, community, Workbench, blog listings, and changelog listings use the locale catalogs. A missing individual post does not disable its section listing.
- Workbench keeps its deliberate `noindex` and stays out of the sitemap in both locales.

See [locale state](../src/lib/locale-state.ts) and [page SEO](../src/lib/seo.ts). Chinese files count as Chinese editions immediately, so review the remaining English copy before production publication.

## Adding an English-only page

A new `content/docs/how-to/new-feature.mdx` can omit its Chinese counterpart. `/zh-CN/docs/how-to/new-feature` then shows its English body and the fallback notice without changing the requested URL. Chinese navigation and docs search can include it with English text and Chinese URLs. Sidebar inclusion follows normal metadata ordering; use `...` or list the page explicitly.

Add the matching `.zh-CN.mdx` file to enable its Chinese edition on the next build. Ordinary tests and builds permit missing counterparts.

## Existing links and dates

Known V1 Chinese permalinks have permanent `308` redirects to their corresponding Chinese V2 pages. V1-only items continue to point at the legacy site. The [redirect table](../src/lib/v1-redirects.ts) owns this behavior. Complete the Chinese text before production publication.

Visible publication dates use the requested locale. Shared English OG cards keep their existing English date formatting. Review the native Fumadocs dictionary when upgrading that package.
