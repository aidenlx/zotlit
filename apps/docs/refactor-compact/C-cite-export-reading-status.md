## how-to/insert-citations.mdx
- Title: Insert citations | Description: Insert Markdown citations while typing or from the command palette, as the main citation or the alternate citation.
- Archetype (judged from content): Mixed(How-to + Reference: citation-text table + citekey-conflict explanation)
- Purpose: Insert Markdown citations (main/alt variant) via inline suggester or command palette, optionally as Literature Note wikilink citation.
- Prerequisites stated: Zotero items need citation keys (Zotero native citation key field; Better BibTeX recommended, not required). Wikilink form needs Wikilink citations source on.
- Product facts asserted:
  - Two entry points: Citation Suggester (inline), command palette picker. Both search all libraries in library scope at once, one relevance order; suggestion names its library only when >1 library can contribute; label omitted with one library in scope.
  - Before typing a search: papers already cited in current note listed first; each group ordered by Last Activity newest first; same order as Recent in Library View. Once typing: all results ranked by relevance.
  - Paper already cited in note shows "cited in note" label (m.citation_suggester_cited_in_note), with or without search.
  - Insertion independent of Document Citation Set / In-text Citation Rendering; works with both source settings off and Show formatted citations off.
  - Citation key read from Zotero native citation key field; Better BibTeX writes its keys into that field; in an uneditable group library BBT keeps keys to itself, ZotLit sees only keys already in the field.
  - Better BibTeX: recommended once citing; stable keys from pattern; can keep bibliography file updated via automatic exports for native Pandoc export; ZotLit does not require it.
  - Suggester opens on `[@` or `【@`. Opt-in "@ trigger" setting: bare `@` at word boundary (line start, after space, after opening bracket or quote) opens it; mid-word `@` (email) ignored.
  - Enter inserts main citation; built-in renders `[@citationKey]`. Alt renders `@citationKey`. Insert ends with trailing space; cursor placed after; an existing following space is reused, not doubled.
  - `@` query ends at first space; use `_` for space (`@machine_learning` finds "machine learning"). `[@` queries accept real spaces.
  - Alt via trailing `/` in query before Enter, or Shift+Enter. Instruction row in suggester shows shortcuts. Trailing `/` wins without Shift and `/` is stripped from the search.
  - Command palette picker: Enter = main, Shift+Enter = alt; no trailing-`/` shortcut there.
  - Item with no key: nothing inserted; notice "Selected item has no citation key: `{key}`."
  - Suggester settings (all on Citations settings page): Citation suggester (default on); At-trigger (default off, visible only while suggester on); Show citekey (default off, shows key beside title in list).
  - Wikilink-citation form: enable Wikilink citations; type `[[`, pick the Literature Note, keep unaliased; optional Citation Fragment e.g. `[[Doe 2020#cite:locator=33]]`. Link must resolve to ZotLit Literature Note; aliases, embeds, heading/block fragments, unresolved targets, malformed Citation Fragments stay outside Document Citation Set.
  - `[[@doe2024]]` is not a citation key; counts only if a note with that exact name is the item's Literature Note; use `[@doe2024]` for literal key.
  - Ambiguous key (twins in one library or across two in-scope libraries): insert refused from either entry point; message "Citation key `@{key}` matches multiple Zotero items. Change it in Zotero before inserting a citation." Fix: distinct key on one item, or narrow library scope. Existing keys in notes stay readable.
  - Citation text: one template document renders every insert; receives `zt.variant` = `main`|`alt`. Built-in table (main / alt): one key `[@smith2024]` / `@smith2024`; two keys `[@a2020; @b2021]` / first item in text, rest in brackets; locator 62 `[@smith2024, {p. 62}]` / `@smith2024 [{p. 62}]`; suppressed author `[-@smith2024]` / `[-@smith2024]`; prefix `[see @smith2024]` / bracketed cluster fallback.
  - Alt asks Pandoc to prefer author-in-text; falls back to bracketed cluster for prefix or suppressed author, so variants can render same text. Item with no key dropped from output.
  - Rendered citation normalized to one line: trim, whitespace run containing newline collapses to one space.
  - Formatted citations in Live Preview/reading view need Pandoc citations + Show formatted citations on, Pandoc engine and selected style. Open Literature Note from citation: click in Live Preview, Ctrl/Cmd-click in Source mode (needs Pandoc citations + Open as links on).
- Steps: (Typing) 1 type `[@` (or bare `@` with opt-in); list appears 2 filter, select, Enter 3 optional alt via trailing `/` or Shift+Enter. (Palette) 1 run Insert citation command; picker opens 2 search, Enter=main, Shift+Enter=alt. (Wikilink) 1 enable Wikilink citations 2 type `[[`, select Literature Note, unaliased 3 add `#cite:` fragment if needed, replace `Doe 2020` with exact target.

## concepts/how-citekey-links-work.mdx
- Title: How in-text citation rendering and navigation work | Description: How ZotLit selects, formats, lists, and opens citations in the active note.
- Archetype (judged from content): Explanation
- Purpose: Explain the Document Citation Set, citation syntax, resolution, ambiguity, formatted display, references and navigation.
- Prerequisites stated: none
- Product facts asserted:
  - One ordered set (Document Citation Set) drives formatting, numbering of references, and navigation. It holds Citation Occurrences of active note, each with source position and citation details.
  - Source settings (Citations page): Pandoc citations default On (literal `@doe2024`, `[@doe2024]`); Wikilink citations default Off (eligible wikilinks to Literature Notes). Both off => References Sidebar, formatted in-text citations, numeric numbering, Citekey Navigation get an empty set.
  - Eligible wikilink: unaliased, points to Literature Note, no fragment or valid Citation Fragment (`#cite:locator=33`). Excluded: aliases, embeds, unresolved targets, heading fragments, block fragments, malformed Citation Fragments. Sidebar reports malformed fragment as Reference Error while Wikilink citations on.
  - Set keeps source order; numeric styles number from complete note, not one visible section.
  - Citation Index: internal vault-wide record of Citation Occurrences, always active, tracks both source types independent of settings. Document Citation Set applies source settings when a feature asks; changing either setting recomputes without rescanning vault.
  - Insertion and built-in export use their own membership rules; turning a source off does not disable insertion or remove it from export.
  - Pandoc syntax: `@key` author-in-text; `-@key` suppress author; `[@key]`, `[@key, p. 3]` Citation Clusters; `[see @a, p. 3; @b]` multi-work cluster; `@{https://example.com/paper}` braced key. Trailing punctuation outside key. Email addresses and URLs with `@` stay text. Citation-like text excluded in code, math, `%%` comments, frontmatter, URLs.
  - Resolution: against Zotero native citation key field across every library in library scope; NOT the `citekey` frontmatter field. Item can be cited before it has a Literature Note; opening creates note then opens. Unresolved key stays in native source and shows as Reference Error in sidebar. Resolution data refreshes when Zotero database changes; re-keyed item updates after next refresh.
  - Ambiguous key (two items same library, or one each in two in-scope libraries): ZotLit never picks; editor, reading view, popover, sidebar all report same ambiguous state; key adopts no candidate item, contributes no bibliography entry. Cluster holding both an ambiguous key and an unmatched key reports the unresolved one (stronger failure). Fix: distinct key in Zotero, or narrow library scope.
  - Wikilink citations represent the item of that Literature Note; Citation Fragment adds prefix, locator, suffix, author-suppression mode. Example: `[[Doe 2020#cite:locator=33]]` = Pandoc `[@doe2020, p. 33]` when key is doe2020. Wikilinks keep Obsidian native link target, click and drag; Source mode always shows raw wikilink.
  - Formatted display: Show formatted citations default On; applies selected references style in Live Preview and reading view; Source mode always Markdown. ZotLit asks Pandoc engine to format whole set; swaps whole document only after full render finishes. In Live Preview, source returns only for citation touched by cursor/selection. Native source stays if no complete formatted result. Cluster with any unresolved item stays entirely unchanged; its resolved items still affect later numeric numbering and sidebar. Turning off leaves native presentation; does not change membership, navigation, insertion, export.
  - References Sidebar: one entry per resolved item; formatted list follows style's bibliography order and Entry Markers; without formatted output, minimal list in first-occurrence order. Reference Error keeps its exact source occurrence, contributes no entry.
  - Citekey Navigation: Open as links setting controls navigation for literal Pandoc citations and wikilinks shown as citations; independent of formatted display and hover. Single-item citation opens/creates Literature Note; multi-item requires item choice; ambiguous key requires candidate choice. Citation Popover shows every cited item's full bibliography entry in citation order; unresolved/ambiguous shown as own state.
  - Theme hooks: public CSS classes only on sources in the Document Citation Set where ZotLit supplies rendering or navigation; excluded sources, or sources with both applicable features inactive, get none.
- Steps (if procedural): n/a
- UI labels / commands / settings named: Pandoc citations (m.settings_citation_pandoc_citations_name); Wikilink citations (m.settings_citation_wikilink_citations_name); Library scope (m.settings_library_scope_name); Show formatted citations (m.settings_citation_show_formatted_name); Citations and references style (m.settings_citation_references_style_name); Open as links (m.settings_citation_open_as_links_name); SettingsPath Citations (m.settings_page_citations). Glossary terms: Document Citation Set, Citation Occurrence, Citation Index, Citation Cluster, Citation Fragment, Reference Error, Entry Markers, Citekey Navigation, Citation Popover, References Sidebar.
- Anchors defined: [#ambiguous-key] A key that matches several items; [#theme-hooks] Theme hooks.
- Outbound links: /docs/reference/settings#library-scope (library scope); /docs/how-to/review-copy-troubleshoot-references (references how-to, x2 inline + card); /docs/reference/commands (commands reference, open-under-cursor commands); /docs/reference/theme-hooks (Theme hooks); #ambiguous-key (internal). Cards: /docs/how-to/insert-citations, /docs/how-to/create-and-open-notes, /docs/how-to/review-copy-troubleshoot-references, /docs/how-to/export-note-with-citations, /docs/reference/settings.

## how-to/export-note-with-citations.mdx
- Title: Export a note with citations | Description: Export an active Markdown note with citations and a bibliography to DOCX or HTML.
- Archetype (judged from content): Mixed(How-to + Reference: membership rules + error table)
- Purpose: Run ZotLit built-in export of the active note to DOCX/HTML with formatted citations and bibliography; understand membership and fix errors.
- Prerequisites stated: Obsidian Desktop with Markdown note open; Pandoc engine installed (Citations settings, references heading); Zotero running.
- Product facts asserted:
  - Data source: Better BibTeX when available, else Zotero local API.
  - Export modal fields: Format (starts DOCX; HTML option); Style (starts with style the note uses in Obsidian; line below names source: note's own `zotlit-csl` property / Imported Note's profile selects style (example profile "Research") / vault Citations and references style); Destination (starts with source note's path and filename stem).   - Confirm: resolves citations, retrieves bibliography data, converts complete note. Output `.docx` or `.html` with formatted citations + bibliography. Notice names file and style (e.g. "Draft.docx", "APA Style 7th edition").
