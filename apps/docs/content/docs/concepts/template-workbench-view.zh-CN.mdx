模板工作台视图（Template Workbench View）用于编辑单份模板文档，并直接对照来自您 Zotero 文献库的数据呈现渲染效果。

## 一个视图，支持三类文档 [#kinds]

该视图支持打开全部[三类模板文档](/docs/concepts/how-templates-work#kinds)。文档类型决定了展示的标签页、标签页标题以及预览区域所渲染的内容。

| 文档类型 | 标签页标题                                               | 标签页组成                                                | 预览呈现内容                 |
| -------- | -------------------------------------------------------- | --------------------------------------------------------- | ---------------------------- |
| 配置方案 | 配置方案名称，加 `Profile`                               | 六个标签页                                                | 某篇论文的文献笔记整体预览   |
| 引文文本 | <UiLabel name={m.template_workbench_title_citation()} /> | 单个标签页：<UiLabel name={m.workbench_tab_citation()} /> | 单条插入引文的格式化效果     |
| 共享片段 | 片段名称，加 `Partial`                                   | 单个标签页：<UiLabel name={m.workbench_tab_partial()} />  | 供某模板调用时的片段渲染效果 |

您键入的任何字符都会即时同步到预览中，即使尚未执行文件保存。编辑过程使用 Obsidian 的自动保存机制，并支持完整的撤销（Undo）与重做（Redo）。含有语法错误的文档依然可以正常编辑并保存，编辑器内会直观展示对应的诊断报错。

Obsidian 原生的 Markdown 视图依然可以打开同一个文件。选择 <UiLabel name={m.template_workbench_open_markdown()} /> 可以以纯 Markdown 形式查看文档；在文件列表中右键选择模板文档可直接点击 <UiLabel name={m.template_workbench_open()} />。

## 配置方案文档的编辑 [#profile]

配置方案负责控制文献笔记的文件名、存放目录、frontmatter 属性以及正文结构。它还定义了单条标注的显示格式，以及哪些 Zotero 条目会自动套用该配置方案。

工作台视图将这些部分组织为六个标签页：

- <UiLabel name={m.workbench_tab_note()} />
  ：编辑文献笔记的正文结构。
- <UiLabel name={m.workbench_tab_properties()} />
  ：编辑由 ZotLit 托管的 YAML frontmatter 属性。
- <UiLabel name={m.workbench_tab_annotation()} />
  ：编辑单条标注的渲染格式。
- <UiLabel name={m.workbench_tab_name_and_folder()} />
  ：编辑笔记路径、引文格式、导入笔记选项以及模板语言引擎。
  <UiLabel name={m.workbench_name_path_heading()} />
  组合了文献笔记文件夹与笔记名称模板，并实时预览生成的完整路径。
- <UiLabel name={m.workbench_tab_match()} />
  ：声明让条目自动套用此自定义配置方案的匹配条件。
- <UiLabel name={m.workbench_tab_profile()} />
  ：编辑配置方案自身的显示名称、描述与版本信息。

<UiLabel name={m.workbench_advanced()} />
是视图标题栏中的切换按钮。点击它可在标签页界面与完整的配置方案 Markdown
原始源码之间自由切换。引文文本和共享片段因为自身只占一个标签页，因此仅对配置方案文档提供此源码模式切换。

### 预览数据来源 [#preview-data]

预览可以使用您文献库中的实际条目或内置的示例数据。从文献笔记中打开工作台视图会自动关联该笔记所对应的文献条目。面板菜单中提供了 <UiLabel name={m.workbench_choose_item()} /> 用于切换预览条目，以及 <UiLabel name={m.template_workbench_open_layout()} /> 可将编辑器、可用字段列表与渲染预览并排展开。

预览会随着您的键入即时刷新。虽然数据库连接或引文样式的警告可能会临时限制部分预览渲染，但您仍可继续顺畅地编辑配置方案。

### 保存更改 [#saving]

内置默认配置方案为只读。无需创建文档，您就可以查看和选择其中的值。选择 <UiLabel name={m.template_workbench_customize()} /> 会先在配置的模板文件夹中创建文档，再开放编辑；如果已有自定义文档，则直接打开它。

如果创建失败，您仍可查看内置值，界面中的错误提示会提供重试操作。即使关闭前未作任何修改，已经创建的自定义文档也会保留。

现有文献笔记会保留当前内容。运行 <Command name={m.command_update_note_name()} />，即可将修改后的配置方案应用到当前活动笔记。

<Callout type="info" title="编辑 Markdown 文档">
  选择 <UiLabel name={m.template_workbench_open_markdown()} />
  ，可以将现有配置方案文档作为 Markdown
  打开。自定义内置默认配置方案时，会先创建文档，再开放编辑。
</Callout>

## 引文文本 [#citation]

引文文本在单个 <UiLabel name={m.workbench_tab_citation()} /> 标签页中打开，其标签页标题固定为 <UiLabel name={m.template_workbench_title_citation()} />。

以 <UiLabel name={m.workbench_citation_result_heading()} /> 为标题的预览区域会渲染一条引文。说明文字标明当前预览的变体：<UiLabel name={m.workbench_citation_variant_main()} /> 或 <UiLabel name={m.workbench_citation_variant_alt()} />。可在预览面板菜单中选择变体，并通过 <UiLabel name={m.template_workbench_use_example()} /> 选用内置引文示例，或通过 <UiLabel name={m.workbench_choose_item()} /> 选择您自己的 Zotero 条目。

每个面板分别保存其变体和示例，Obsidian 会随面板记住这些选择。操作步骤请参阅[自定义引文文本](/docs/how-to/customize-a-template#citation-text)。

## 共享片段 [#partial]

共享片段在单个 <UiLabel name={m.workbench_tab_partial()} /> 标签页中打开。标签页标题由共享片段名称及其后的 `Partial` 组成。

共享片段本身没有数据，而是使用调用它的模板的数据进行渲染。因此，以 <UiLabel name={m.workbench_partial_result_heading()} /> 为标题的预览区域会让您选择按哪种调用方进行渲染。面板菜单提供 <UiLabel name={m.template_workbench_preview_as_note()} />、<UiLabel name={m.template_workbench_preview_as_annotation()} /> 和 <UiLabel name={m.template_workbench_preview_as_citation()} />。默认按笔记预览，并为每个文件记住您的选择。ZotLit 不会根据调用共享片段的模板猜测调用方。

当仓库中存在默认配置方案以外的配置方案时，面板菜单还会提供 <UiLabel name={m.template_workbench_use_profile()} />，以便用该方案的数据预览。保存共享片段后，所有使用它的已打开预览都会重新渲染。

## 文档语言 [#language]

引文文本或共享片段的编辑器上方会显示文档的语言：<UiLabel name={m.workbench_name_language_liquid()} /> 或 <UiLabel name={m.workbench_name_language_eta()} />。这段文字仅用于说明，不能切换语言。

面板菜单中的 <UiLabel name={m.template_workbench_change_language()} /> 可以在两种语言间切换。ZotLit 只改写 manifest 中的配置键，不会转换源码。请参阅[模板工作原理](/docs/concepts/how-templates-work#manifest)。

配置方案文档则在 <UiLabel name={m.workbench_tab_name_and_folder()} /> 标签页的 <UiLabel name={m.workbench_name_language_heading()} /> 下设置语言。

## 打开视图 [#open]

每个视图编辑一份模板文档。不同类型的文档从各自所在的位置打开：

- 配置方案：从 <SettingsPath page={m.settings_page_profiles()} /> 中对应的行，或 <SettingsPath /> 中的 <UiLabel name={m.settings_profile_document_name()} /> 行打开。
- 引文文本：从 <SettingsPath page={m.settings_page_citations()} /> 中的 <UiLabel name={m.settings_citation_text_name()} /> 行打开。
- 共享片段：从 <SettingsPath page={m.settings_page_profiles()} /> 中 <UiLabel name={m.settings_partials_heading()} /> 下对应的行打开。

文献笔记当前使用的配置方案可以从该笔记中打开。

每一行都提供相应的控件。[自定义模板](/docs/how-to/customize-a-template)列出了控件名称和操作步骤。
