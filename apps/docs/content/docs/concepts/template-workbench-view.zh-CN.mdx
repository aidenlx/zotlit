模板工作台视图（Template Workbench View）用于编辑单份模板文档，并直接对照来自您 Zotero 文献库的数据呈现渲染效果。

## 一个视图，支持三类文档 [#kinds]

该视图支持打开全部[三类模板文档](/docs/concepts/how-templates-work#kinds)。文档类型决定了展示的标签页、标签页标题以及预览区域所渲染的内容。

| 文档类型 | 标签页标题                                               | 标签页组成                                                | 预览呈现内容                 |
| -------- | -------------------------------------------------------- | --------------------------------------------------------- | ---------------------------- |
| 配置方案 | 配置方案名称，加 `Profile`                               | 六个标签页                                                | 某篇论文的文献笔记整体预览   |
| 引文文本 | <UiLabel name={m.template_workbench_title_citation()} /> | 单个标签页：<UiLabel name={m.workbench_tab_citation()} /> | 单条插入引文的格式化效果     |
| 共享片段 | 片段名称，加 `Partial`                                   | 单个标签页：<UiLabel name={m.workbench_tab_partial()} />  | 供某模板调用时的片段渲染效果 |

您键入的任何字符都会即时同步到预览中，即使尚未执行文件保存。编辑过程使用 Obsidian 的自动保存机制，并支持完整的撤销（Undo）与重做（Redo）。含有语法错误的文档依然可以正常编辑并保存，编辑器内会直观展示对应的诊断报错。

Obsidian 原生的 Markdown 视图依然可以打开同一个文件。选择 <UiLabel name={m.template_workbench_open_markdown()} /> 可以以纯 Markdown 形式查看文档；在文件列表中右键选择模板文档可直接点击 <UiLabel name={m.template_workbench_open()} />。

## 配置方案文档的编辑 [#profile]

配置方案负责控制文献笔记的文件名、存放目录、frontmatter 属性以及正文结构。它还定义了单条标注的显示格式，以及哪些 Zotero 条目会自动套用该配置方案。

工作台视图将这些部分组织为六个标签页：

- <UiLabel name={m.workbench_tab_note()} />
  ：编辑文献笔记的正文结构。
- <UiLabel name={m.workbench_tab_properties()} />
  ：编辑由 ZotLit 托管的 YAML frontmatter 属性。
- <UiLabel name={m.workbench_tab_annotation()} />
  ：编辑单条标注的渲染格式。
- <UiLabel name={m.workbench_tab_name_and_folder()} />
  ：编辑笔记路径、引文格式、导入笔记选项以及模板语言引擎。
  <UiLabel name={m.workbench_name_path_heading()} />
  组合了文献笔记文件夹与笔记名称模板，并实时预览生成的完整路径。
- <UiLabel name={m.workbench_tab_match()} />
  ：声明让条目自动套用此自定义配置方案的匹配条件。
- <UiLabel name={m.workbench_tab_profile()} />
  ：编辑配置方案自身的显示名称、描述与版本信息。

<UiLabel name={m.workbench_advanced()} />
是视图标题栏中的切换按钮。点击它可在标签页界面与完整的配置方案 Markdown
原始源码之间自由切换。引文文本和共享片段因为自身只占一个标签页，因此仅对配置方案文档提供此源码模式切换。

### 预览数据来源 [#preview-data]

预览可以使用您文献库中的实际条目或内置的示例数据。从文献笔记中打开工作台视图会自动关联该笔记所对应的文献条目。面板菜单中提供了 <UiLabel name={m.workbench_choose_item()} /> 用于切换预览条目，以及 <UiLabel name={m.template_workbench_open_layout()} /> 可将编辑器、可用字段列表与渲染预览并排展开。

预览会随着您的键入即时刷新。虽然数据库连接或引文样式的警告可能会临时限制部分预览渲染，但您仍可继续顺畅地编辑配置方案。

### Saving changes [#saving]

The built-in Default profile is read-only. You can read and select its values without creating a document. <UiLabel name={m.template_workbench_customize()} /> creates its document in the configured template folder before editing becomes available, or opens the existing custom document.

If creation fails, the built-in values remain readable and an inline error offers a retry. Closing an untouched customization keeps the created document.

Existing literature notes keep their current content. Run <Command name={m.command_update_note_name()} /> to apply the edited profile to the active note.

<Callout type="info" title="Edit the Markdown document">
  Select <UiLabel name={m.template_workbench_open_markdown()} /> to open an
  existing profile document as Markdown. Customizing the built-in Default
  creates its document before editing becomes available.
</Callout>

## The citation text [#citation]

The citation text opens on one <UiLabel name={m.workbench_tab_citation()} /> tab. Its tab title is the fixed <UiLabel name={m.template_workbench_title_citation()} />.

The preview, headed <UiLabel name={m.workbench_citation_result_heading()} />, renders one citation. Its caption names the variant being previewed, <UiLabel name={m.workbench_citation_variant_main()} /> or <UiLabel name={m.workbench_citation_variant_alt()} />. The preview pane menu picks that variant, and offers <UiLabel name={m.template_workbench_use_example()} /> for a set of built-in citation shapes or <UiLabel name={m.workbench_choose_item()} /> for one of your own Zotero items.

Each pane keeps its own variant and example, and Obsidian remembers them with the pane. See [Customize the citation text](/docs/how-to/customize-a-template#citation-text) for the steps.

## A partial [#partial]

A partial opens on one <UiLabel name={m.workbench_tab_partial()} /> tab. Its tab title is the partial's name, then `Partial`.

A partial has no data of its own: it renders with the data of whichever template calls it. So its preview, headed <UiLabel name={m.workbench_partial_result_heading()} />, asks you which caller to render as. The pane menu offers <UiLabel name={m.template_workbench_preview_as_note()} />, <UiLabel name={m.template_workbench_preview_as_annotation()} />, and <UiLabel name={m.template_workbench_preview_as_citation()} />. It opens on Note, and remembers your choice per file. ZotLit never guesses the caller from the templates that call the partial.

While your vault holds a profile besides Default, the pane menu also offers <UiLabel name={m.template_workbench_use_profile()} /> to preview against that profile's data. Saving a partial re-renders every open preview that uses it.

## The document's language [#language]

Above the editor of a citation text or a partial, a caption names the document's language, <UiLabel name={m.workbench_name_language_liquid()} /> or <UiLabel name={m.workbench_name_language_eta()} />. The caption reports; it does not switch.

The pane menu carries <UiLabel name={m.template_workbench_change_language()} />, the switch between the two languages. ZotLit rewrites the manifest key alone and translates no source. See [How templates work](/docs/concepts/how-templates-work#manifest).

A profile document sets its language on the <UiLabel name={m.workbench_tab_name_and_folder()} /> tab instead, under <UiLabel name={m.workbench_name_language_heading()} />.

## Open the view [#open]

A view edits one template document, and each kind opens from the place that holds it:

- A profile, from its row at <SettingsPath page={m.settings_page_profiles()} />, or from the <UiLabel name={m.settings_profile_document_name()} /> row at <SettingsPath />.
- The citation text, from the <UiLabel name={m.settings_citation_text_name()} /> row at <SettingsPath page={m.settings_page_citations()} />.
- A partial, from its row under <UiLabel name={m.settings_partials_heading()} /> at <SettingsPath page={m.settings_page_profiles()} />.

The profile a literature note already uses opens from that note.

Each of those rows carries its own control, and [Customize a template](/docs/how-to/customize-a-template) names it and walks the steps.
