The Profile Editor changes a literature note profile and shows its output against a paper from your Zotero library.

## What a profile controls

A profile controls the name, folder, properties, and body of a literature note. It can also define how annotations appear and which Zotero items use the profile automatically.

The Profile Editor groups these parts into five tabs:

- <UiLabel name={m.workbench_tab_note()} /> edits the literature note body.
- <UiLabel name={m.workbench_tab_properties()} /> edits the YAML properties that
  ZotLit manages.
- <UiLabel name={m.workbench_tab_annotation()} /> edits the format of one
  annotation.
- <UiLabel name={m.workbench_tab_match()} /> selects the Zotero items that use
  an added profile automatically.
- <UiLabel name={m.workbench_tab_name_and_folder()} /> edits the profile
  details, note name, folders, citation style, and template language.

Select <UiLabel name={m.workbench_advanced()} /> to edit the complete profile document as Markdown.

## Preview data

The editor uses a paper from your Zotero library to render its preview. Opening it from a literature note selects that note's paper. Select <UiLabel name={m.profile_editor_choose_paper()} /> to use another paper.

The preview changes as you edit. A database or citation-style warning can limit the preview, but you can continue editing the profile.

## Saving changes

The Profile Editor saves changes to the profile document automatically. A document with an error stays on disk and shows its diagnostics in the editor. The built-in Default profile has no document until you edit it. Your first edit creates a custom Default profile in the configured template folder.

Existing literature notes keep their current content. Run <Command name={m.command_update_note_name()} /> to apply the edited profile to the active note.

<Callout type="info" title="Edit the Markdown document">
  Select <UiLabel name={m.profile_editor_open_markdown()} /> to open an existing
  profile document as Markdown. The built-in Default profile gets a document
  after your first edit.
</Callout>

## Open the editor

Select <UiLabel name={m.settings_template_customize()} /> on the <UiLabel name={m.settings_profile_document_name()} /> row at <SettingsPath />.

To edit the profile used by an existing literature note, open that note and run <Command name={m.command_customize_note_template_name()} />. ZotLit opens the profile with the note's paper selected for the preview.

See [Customize a template](/docs/how-to/customize-a-template) for complete steps.
