- [创建并打开文献笔记](/docs/how-to/create-and-open-notes) — 通过快速切换器或 Zotero 打开或创建文献笔记。
- [保持笔记最新](/docs/how-to/keep-notes-updated) — 在 Zotero 数据发生变化时更新笔记，同时保留自己撰写的内容。
- [导入 Zotero 笔记](/docs/how-to/import-zotero-notes) — 将在 Zotero 中撰写的笔记作为 Markdown 文件导入仓库。
