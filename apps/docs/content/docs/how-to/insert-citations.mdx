1. In your note, type `[@`. A list of papers from your Zotero library opens.
2. Type a few words of the title or author, select the paper, and press `Enter`. ZotLit inserts `[@citationKey]` and a space, so you can keep typing.
3. For the author-in-text form `@citationKey`, press `Shift+Enter` instead.

## Insert while typing

1. Type `[@` in the note (`【@` also works). A list of papers from your Zotero library opens under your cursor. Before you type a search term, the papers this note already cites appear first, each marked <UiLabel name={m.citation_suggester_cited_in_note()} />.

   ![A thesis chapter with "[@" typed at the end of a paragraph, and the citation suggester below it listing the two papers the chapter already cites, each marked "Cited in this note"](/img/how-to/citation-suggester-cited-in-note.webp)

2. Keep typing words from the title or author to narrow the list. The list ranks papers by how well they match, and any paper the note already cites keeps its <UiLabel name={m.citation_suggester_cited_in_note()} /> mark.
3. Select the paper and press `Enter`. The citation appears in your note (for example, `[@smith2024]`), followed by a space, with your cursor placed after the space.
4. For the author-in-text form, press `Shift+Enter` instead of `Enter`, or end your search with `/` and press `Enter`. The note receives `@smith2024`. The hint row at the bottom of the list confirms `↵` <UiLabel name={m.instruction_insert_citation()} />, and `/ ↵` and `⇧↵` <UiLabel name={m.instruction_insert_alternate_citation()} />.

<Accordion title="From the command palette" id="command-palette">

Open the command palette (`Ctrl+P` on Windows and Linux, `Cmd+P` on macOS) and run <Command inline name={m.command_insert_citation_name()} />. A picker showing your Zotero library opens. Search for the paper, then press `Enter` to insert the main citation or `Shift+Enter` for the alternate citation. A trailing `/` does not trigger the alternate form here; use `Shift+Enter`.

</Accordion>
<Accordion title="Give your papers citation keys" id="citation-keys">

A citation names a paper by its citation key, such as `smith2024`. ZotLit reads this value from Zotero's own **Citation Key** field.

Install [Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/), a Zotero add-on, to cite as you write: it fills that field for every paper with stable keys generated from a pattern. A paper with an empty field cannot be cited. In a group library where you lack edit permissions, Better BibTeX keeps generated keys local; ZotLit can only read keys that already exist in the item's field.

</Accordion>
<Accordion title="What each form looks like" id="citation-text">

| You press                                   | You get        | With page 62            |
| ------------------------------------------- | -------------- | ----------------------- |
| `Enter` (main citation)                     | `[@smith2024]` | `[@smith2024, {p. 62}]` |
| `Shift+Enter` or a trailing `/` (alternate) | `@smith2024`   | `@smith2024 [{p. 62}]`  |

One template, <UiLabel name={m.settings_citation_text_name()} />, formats both outputs. To modify how they appear, run <Command inline name={m.command_customize_citation_text_name()} /> (see [Change the text a citation inserts](/docs/how-to/customize-a-template#citation-text)). The full rendering table is in the [Citation text](/docs/reference/templates/defaults#citation-text) reference.

Inserting citations works even if all display toggles are off; it does not require <UiLabel name={m.settings_citation_pandoc_citations_name()} /> or <UiLabel name={m.settings_citation_show_formatted_name()} />. When both are enabled (the default), both forms can render as formatted text in Live Preview and reading view if you have configured the <UiLabel name={m.settings_citation_engine_name()} /> and a style.

</Accordion>
<Accordion title="Cite with a link to the literature note" id="wikilink-citations">

Use this format when the citation must function as an Obsidian link to the paper's literature note.

1. Open <SettingsPath page={m.settings_page_citations()} /> and enable <UiLabel name={m.settings_citation_wikilink_citations_name()} />.
2. Type `[[` in your text, select the literature note, and keep the link without an alias: `This finding follows the earlier analysis [[Doe 2020]].`
3. To cite a specific page, add it to the link: `[[Doe 2020#cite:locator=33]]`. Replace `Doe 2020` with the literature note's exact file name.

`[[@doe2024]]` is not treated as a citation unless a literature note is named exactly that; write `[@doe2024]` to reference a citation key.

</Accordion>

## If you see something else

- **Nothing happens when I type `@` alone:** A bare `@` opens the suggester only when <UiLabel name={m.settings_citation_at_trigger_name()} /> is turned on in <SettingsPath page={m.settings_page_citations()} /> (off by default). Type `[@` instead, or turn that setting on.
- **No list opens at all, even for `[@`:** <UiLabel name={m.settings_citation_suggester_name()} /> is turned off. Open <SettingsPath page={m.settings_page_citations()} /> and turn it back on.
- **My search stops at the first space after `@`:** When using a bare `@`, type `_` instead of a space (for example, `@machine_learning` matches "machine learning"). Normal spaces work as expected after `[@`.
- **Notice: "Selected item has no citation key: \{key\}."** The paper has an empty Citation Key field in Zotero. Add a citation key to the item in Zotero, then insert it again.
- **Notice: "Citation key @\{citekey\} matches multiple Zotero items. Change it in Zotero before inserting a citation."** Two items share the same citation key, in one library or in two libraries ZotLit reads. Give one paper a distinct key in Zotero, or narrow your <UiLabel name={m.settings_library_scope_name()} /> to the intended library. For details, see [A key that matches several items](/docs/reference/citation-links#ambiguous-key).
- **A citation already in my note shows as a problem, and the References sidebar says "@\{citekey\} matches multiple items in your Zotero library."** Two items share the same citation key. Change one key in Zotero or narrow your <UiLabel name={m.settings_library_scope_name()} />; until resolved, ZotLit leaves the raw key in place and omits it from the reference list.
- **Each paper in the list names a library:** ZotLit is currently searching more than one library. The label indicates which library contains that item; when only one library is active in scope, the label is omitted.
