1. Open a literature note and run <Command inline name={m.command_open_template_data_explorer_name()} /> from the command palette.
2. Type part of a field name, such as `title`, in the search box.
3. Right-click the field's row and select <UiLabel name={m.workbench_explorer_menu_copy_output()} />.
4. Paste the snippet, for example `{{ zt.title }}`, into your template.

A template reads everything about a paper from one name, `zt`: `zt.title` is the title, `zt.authors` the authors. You paste what you copy here into your **profile**, the document that writes your literature notes, which you edit in the Template Workbench View (see [How templates work](/docs/reference/templates/how-templates-work)).

## Find a field and copy it

1. Open a literature note, open the command palette, and run <Command inline name={m.command_open_template_data_explorer_name()} />. A pane opens that lists that note's paper's fields under section headings, with a title ending in <UiLabel name={m.workbench_view_fields()} />. With no literature note active, it shows a list of papers to choose from instead.
2. If asked, choose a paper under <UiLabel name={m.workbench_recently_updated()} /> or select <UiLabel name={m.workbench_search_zotero()} /> (or choose one of the built-in examples: journal article, conference paper, book, or thesis). The list is replaced by that paper's fields, starting with <UiLabel name={m.workbench_explorer_section_common()} />.
3. Type in the <UiLabel name={m.workbench_fields_search_note()} /> box to match field names, keys, or values. Matching rows open along with the rows that hold them.
4. Right-click the row, or open its <UiLabel name={m.workbench_explorer_row_actions()} /> menu, and select <UiLabel name={m.workbench_explorer_menu_copy_output()} />. The notice <UiLabel name={m.workbench_field_copy_done()} /> appears, and your clipboard holds the snippet (for example, `{{ zt.title }}`).

Browsing here changes no template and touches nothing in your Zotero library; what you copy is plain text. To insert fields directly at your cursor while editing a template, use <UiLabel name={m.workbench_view_fields()} /> inside the Template Workbench View instead. For a complete list of every available field, see the [Data reference](/docs/reference/templates/data).

<Accordion title="Copy a Zotero key" id="indexed-key">

A Zotero key identifies one item, attachment, annotation, or note. Copy one when a tool asks which item to work on:

- In Obsidian, on the active literature note: run <Command inline name={m.command_copy_item_key_name()} />, or select it from the file menu. A literature note also records this in its `zotero-key` property.
- On an annotation row: open the more-options menu and select <UiLabel name={m.indexed_key_menu_copy_annotation()} />.
- In the explorer's pane menu: select <UiLabel name={m.command_copy_item_key_name()} /> or <UiLabel name={m.indexed_key_menu_copy_annotation()} />.
- In Zotero (with ZotLit Companion): right-click rows and select <UiLabel name={m["zotero.menu_submenu.label"]()} /> > <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "item" })} /> or <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "attachment" })} /> (selecting several rows copies one key per line). In the PDF reader, right-click an annotation and select <UiLabel name={m["zotero.menu_reader_annot_copy_key"]()} />.

</Accordion>
<Accordion title="Fields of one highlight" id="annotation-fields">

The fields an annotation template reads belong to an individual highlight rather than the paper. Select <UiLabel name={m.workbench_choose_annotation()} /> to choose from the paper's annotations or six built-in examples (highlight, underline, note, text, image, ink). Alternatively, under `zt.annotations`, open a row's more-options menu and select <UiLabel name={m.workbench_explorer_menu_explore_annotation()} />. A breadcrumb labelled <UiLabel name={m.template_data_explorer_note_root()} /> appears; click its back button (<UiLabel name={m.template_data_explorer_back_to_note_root()} />) to return to the paper's fields.

## If you see something else

- **A list of papers instead of fields** — no literature note was active when you ran the command. Pick a paper from the list, or open a literature note and run the command again.
- <UiLabel name={m.workbench_fields_no_matches()} /> — shorten or clear the text
  in the search box.
- <UiLabel name={m.workbench_field_copy_failed()} /> — select the snippet text
  displayed on screen and copy it manually.
- **The snippet items are in two submenus, Liquid and Eta** — choose the language your template uses. If you are starting fresh, choose Liquid.
- **Zotero asks for confirmation each time it opens Obsidian** — follow [Suppress the Zotero security prompt](/docs/how-to/suppress-zotero-security-prompt).
- **The values look out of date** — data updates automatically, but you can select <UiLabel name={m.workbench_refresh_item()} /> from the pane menu to refresh it immediately.
- **A template rendered the wrong thing and you want to report it** — follow [Template data](/docs/how-to/collect-debug-logs#template-data) in Collect debug logs.
