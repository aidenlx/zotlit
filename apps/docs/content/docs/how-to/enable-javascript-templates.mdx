<UiLabel name={m.settings_template_js_enable_name()} /> is a per-device gate
that lets JavaScript run inside your templates. It is disabled by default.

In ZotLit 2.1 the language lived in the file name: `zotlit-note.eta.md` was an
Eta template and `zotlit-note.liquid.md` was a Liquid one. A 2.2 template
document declares its language in its own manifest instead, with the key
`language: eta`.

A managed frontmatter entry declares its language with its value member: `expr`
(Liquid), `value` (JSON-e), or `js` (JavaScript). See
[Profile document](/docs/reference/templates/profile-document) for the manifest
keys and the three entry members.

## What the gate covers

- **Eta template documents.** A profile document, a citation text, or a partial whose manifest sets `language: eta`.
- **`js` frontmatter entries.** A managed frontmatter entry whose value member is `js`.

The `expr` and `value` members stay active whether the gate is on or off. While
the gate is off, an Eta document is never compiled and a `js` entry never
evaluates.

<Callout type="info" title="Understand the implications first">
  Eta templates run JavaScript with the same access as ZotLit itself: they can
  read and modify your vault, connect to the internet, and on desktop, access
  your system. Read [JavaScript templates](/docs/concepts/javascript-templates)
  for the full explanation before opting in.
</Callout>

## Turn on

<Steps>
  <Step>
    ### Open the template engine settings

    In Obsidian, open <SettingsPath page={m.settings_page_advanced()} />. Locate the <UiLabel name={m.settings_advanced_template_engine_heading()} /> group and its <UiLabel name={m.settings_template_js_enable_name()} /> row.

  </Step>
  <Step>
    ### Click Turn on

    Click the <UiLabel name={m.settings_template_js_turn_on()} /> button. A confirmation modal titled <UiLabel name={m.settings_template_js_confirm_title()} /> appears with the following warning:

    > <UiLabel name={m.settings_template_js_confirm_body()} />

    Click <UiLabel name={m.settings_template_js_confirm_action()} /> to confirm.

  </Step>
</Steps>

The gate takes effect immediately. ZotLit recompiles the template folder in place. No plugin reload is needed.

## Turn off

In the same <UiLabel name={m.settings_template_js_enable_name()} /> group, click <UiLabel name={m.settings_template_js_turn_off()} />. The gate disables immediately with no confirmation modal. Every template document that declares `language: eta` becomes inert, and every managed frontmatter entry declared with `js` stops evaluating until you turn the gate back on.

## Per-device scope

The setting is stored locally on the device, outside the synced plugin data. Enabling it on one device does not enable it on another. Each device where you want Eta documents and `js` entries to run requires its own opt-in.
