import { Steps, Step } from "fumadocs-ui/components/steps";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Command } from "@/components/command";
import { SettingsPath } from "@/components/settings-path";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

配置方案决定了文献笔记的名称、存放目录、frontmatter 属性以及正文结构。当图书、论文或某个单独的文献分类需要使用专属的笔记格式时，即可为其添加配置方案。

## 添加配置方案

<Steps>
  <Step>
    ### 打开配置方案设置页面

    在 Obsidian 中，打开 <SettingsPath page={m.settings_page_profiles()} />。在 <UiLabel name={m.settings_profile_other_heading()} /> 列表标题中，选择 <UiLabel name={m.settings_profile_add()} />。

  </Step>
  <Step>
    ### 命名并指定存放目录

    输入 <UiLabel name={m.settings_profile_name_name()} />。只需输入名称即可创建配置方案。若希望将其生成的笔记存放在独立目录中，还可输入 <UiLabel name={m.settings_profile_folder_name()} />；留空则默认使用默认配置方案的目录。对话框提示为 <UiLabel name={m.settings_profile_destination_desc()} />。点击 <UiLabel name={m.settings_profile_add()} /> 创建配置方案。

    ZotLit 会在 <UiLabel name={m.settings_template_folder_name()} /> 所指定的文件夹中生成 `zotlit-profile.<slug>.md` 文件，并在模板工作台视图中将其打开。您输入的名称是列表中展示的标签；配置方案的实际身份由文件内部的独立 ID 标识，因此重命名文件不会产生破坏。关于文档承载的内容，请参阅[配置方案](/docs/concepts/profiles)。

  </Step>
  <Step>
    ### 编辑笔记模板源码与属性

    选择 <UiLabel name={m.workbench_tab_note()} /> 并编辑笔记模板源码：即由该配置方案生成的每篇笔记的开头文本。选择 <UiLabel name={m.workbench_tab_properties()} /> 并设置 ZotLit 写入每篇笔记顶部的 YAML 属性。

    编辑器旁的预览区域会实时将您的修改渲染并对照 Zotero 条目进行呈现。随时可切换其他条目以验证不同的数据情况。

  </Step>
  <Step>
    ### 设置自动匹配条件

    选择 <UiLabel name={m.workbench_tab_match()} /> 标签页。该页面说明为 <UiLabel name={m.workbench_match_conditions_desc()} />。

    点击 <UiLabel name={m.workbench_match_add_condition()} /> 添加第一条条件，然后选取判断类型：<UiLabel name={m.workbench_match_condition_item_type()} />、<UiLabel name={m.workbench_match_condition_collection()} />、<UiLabel name={m.workbench_match_condition_tag()} /> 或 <UiLabel name={m.workbench_match_condition_library()} />。当满足 <UiLabel name={m.workbench_match_match_all()} /> 或满足 <UiLabel name={m.workbench_match_match_any()} /> 时即可命中配置方案。可在条件上方切换这两者。

    有关完整的匹配语言说明（包含表达式书写形式），请参阅[配置方案匹配规则](/docs/reference/templates/profile-match)。

  </Step>
  <Step>
    ### 对照条目核验匹配条件

    点击 <UiLabel name={m.workbench_choose_match_item()} /> 并选择一个条目。标签页会即时报告针对该条目的匹配结果：<UiLabel name={m.workbench_match_result_yes()} /> 或 <UiLabel name={m.workbench_match_result_no()} />。

    在 ZotLit 能够正常计算该条件期间，设置页面中的该配置方案所在行会展示状态标签 <UiLabel name={m.settings_profile_match_status({ state: "evaluable" })} />。

  </Step>
  <Step>
    ### 使用该配置方案创建笔记

运行 <Command name={m.command_open_lit_note_name()} />，并选择符合该配置方案条件的条目。ZotLit 会使用该配置方案创建笔记，并报告匹配结果。笔记会在 `zotlit-profile` 属性中记录配置方案。

  </Step>
</Steps>

现有笔记会继续使用创建它的配置方案。要将某篇笔记转到此配置方案，请在该笔记中运行 <Command inline name={m.command_switch_literature_note_profile_name()} />。

## 两个配置方案同时匹配时 [#overlap]

两个配置方案可能同时匹配同一个条目，此时 ZotLit 不会替您选择。选择器会打开并显示 <UiLabel name={m.modal_profile_problem_overlap({ profiles: "…" })} />。其搜索框提示为 <UiLabel name={m.modal_profile_overlap_placeholder()} />，每个匹配该条目的候选方案都会带有 <UiLabel name={m.modal_profile_match_candidate()} /> 标记。

选择您要使用的配置方案，或关闭选择器以取消创建笔记。若要从根本上消除重叠，请在 <UiLabel name={m.workbench_tab_match()} /> 标签页中收窄匹配条件。

## 手动选择配置方案时 [#manual]

为当前操作手动选择的配置方案优先于自动匹配，无论匹配条件如何设置。ZotLit 选择配置方案时的优先顺序见[配置方案](/docs/concepts/profiles)。

您的选择仅适用于这一次操作。笔记会记录创建它的配置方案，后续更新读取该记录，而不会重新检查匹配条件。

## 以单个文件分享配置方案 [#share]

配置方案是一份独立文档，您可以通过一个文件将其移至另一个仓库，它调用的共享片段会一并包含在文件内。[配置方案文档](/docs/reference/templates/profile-document)参考介绍了用于分享的文档及其中的每个配置键。

<Steps>
  <Step>
    ### 分享配置方案 [#share-the-profile]

    在配置方案所在行打开 <UiLabel name={m.workbench_more_actions()} />，然后选择 <UiLabel name={m.settings_profile_share()} />。分享对话框会收集该文档及检测到它可能调用的共享片段。

  </Step>
  <Step>
    ### 选择文件包含的内容 [#choose-what-the-file-carries]

    在 <UiLabel name={m.profile_share_partials()} /> 下，取消选中您不想分享的共享片段；检测到配置方案可能调用的片段已默认选中。<UiLabel name={m.profile_share_include_match()} /> 会将配置方案匹配规则带到接收方仓库，<UiLabel name={m.profile_share_folders()} /> 则将您的笔记文件夹设置加入文件。

  </Step>
  <Step>
    ### 复制或保存文件 [#copy-it-or-save-it]

    选择 <UiLabel name={m.profile_share_copy()} /> 将文件内容放入剪贴板，或选择 <UiLabel name={m.profile_share_save()} /> 将其写入您指定的文件夹。两种方式生成相同的单一文档。

  </Step>
  <Step>
    ### 在接收方仓库中导入 [#import-it-in-the-receiving-vault]

    运行 <Command inline name={m.command_import_profile_name()} />，或选择 <UiLabel name={m.settings_profile_other_heading()} /> 列表标题栏中的导入按钮。ZotLit 随后会询问文件来源：<UiLabel name={m.profile_import_clipboard()} /> 或 <UiLabel name={m.profile_import_file()} />。

  </Step>
  <Step>
    ### 查看导入对话框的说明 [#read-what-the-import-dialog-reports]

    对话框会预览将解包到模板文件夹的共享片段、引文样式，以及用文字描述的传入配置方案匹配规则。<UiLabel name={m.profile_import_include_match()} /> 会随配置方案导入匹配规则，使它也能在此仓库中自动选择笔记；关闭此项可将该方案仅用于手动选择。如果分享的配置方案不包含匹配规则，对话框会显示 <UiLabel name={m.profile_match_absent()} /> 并隐藏开关。选择 <UiLabel name={m.profile_import_confirm()} /> 写入配置方案。

  </Step>
</Steps>
