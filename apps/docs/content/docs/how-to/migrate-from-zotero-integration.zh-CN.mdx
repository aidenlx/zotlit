如果你当前正在使用 mgmeyers 的 **Zotero Integration** 插件并希望切换到 ZotLit，请参考本指南。

<Callout type="info" title="主要变化">

- 你的 Zotero 文库和文献引用标识保持不变。
- 仓库中现有的文献笔记仍将作为常规 Markdown 文件保留。
- 模板需要转换：Zotero Integration 使用 Nunjucks；ZotLit 使用 [Liquid](/docs/reference/templates/syntax)（或 [Eta](/docs/reference/templates/eta-syntax)）。
- 不再需要 Better BibTeX。ZotLit 直接读取 Zotero 的数据库。建议保留 Better BibTeX 的安装，以便使用其文献引用标识格式。
- `{% persist %}` 块模型转变为[托管区域](/docs/reference/literature-notes)模型。这两种模型恰好相反：Zotero Integration 标记要保留的内容；ZotLit 标记要替换的内容。

</Callout>

## 安装 ZotLit [#install]

<Steps>
  <Step>
    ### 禁用 Zotero Integration [#disable-zotero-integration]

    在 Obsidian 中，打开**设置 > 第三方插件**（Settings > Community plugins）。禁用（或卸载）**Zotero Integration**。这两个插件具有不同的插件 ID，可以共存以供测试，但同时运行可能会与 Zotero 连接产生冲突。

  </Step>
  <Step>
    ### 安装 ZotLit [#install-zotlit]

    在**设置 > 第三方插件**中，搜索 **ZotLit** 并安装。安装后启用该插件。

  </Step>
  <Step>
    ### 连接你的 Zotero 文库 [#connect-your-zotero-library]

    打开 <SettingsPath page={m.settings_page_zotero()} />。ZotLit 会连接到你的本地 Zotero 数据库。建立连接无需安装额外的 Zotero 插件。

  </Step>
</Steps>

## 现有笔记 [#existing-notes]

Zotero Integration 的笔记是普通的 Markdown 文件。切换后，它们仍会保留在你的仓库中并保持可读。

ZotLit 通过 `zotero-key` 属性来识别文献笔记。如果你的 Zotero Integration 笔记在属性中已包含 Zotero 标识符（且 ZotLit 能够解析它），ZotLit 就会识别它们。如果没有，请将其视为独立笔记，并通过 ZotLit 创建全新的文献笔记。

ZotLit 不会读取 Zotero Integration 的 `%% begin notes %%` / `%% end notes %%` 持久化标记。这些标记将作为普通注释保留在文件中。

## 转换模板 [#translate-templates]

<Callout type="info" title="使用默认设置？">

如果你从未自定义过 Zotero Integration 模板，可以跳过本节。ZotLit 的内置默认配置会生成结构相当的文献笔记。

</Callout>

### 语法差异 [#syntax]

Zotero Integration 使用 Nunjucks。ZotLit 默认使用 Liquid。下表将常见的 Nunjucks 结构映射到其对应的 Liquid 语法。

| Nunjucks (Zotero Integration)                        | Liquid (ZotLit)                                                   |
| ---------------------------------------------------- | ----------------------------------------------------------------- |
| `{{ title }}`                                        | `{{ zt.title }}`                                                  |
| `{% set x = value %}`                                | `{% assign x = value %}`                                          |
| `{% for item in array %}`                            | `{% for item in array %}`                                         |
| `{% include "[[file]]" %}`                           | `{% render "partial-name" with zt as zt %}`                       |
| `loop.index`                                         | `forloop.index`                                                   |
| `loop.first` / `loop.last`                           | `forloop.first` / `forloop.last`                                  |
| `{{ date \| format("YYYY-MM-DD") }}`                 | `{{ zt.date \| date: "%Y-%m-%d" }}`                               |
| `{{ array \| filterby("prop", "startswith", "x") }}` | 模板逻辑或 [Eta JavaScript](/docs/reference/templates/eta-syntax) |
| `{{ obj \| setAttribute("key", "val") }}`            | `{% assign key = val %}`                                          |

### 数据路径变更 [#data-paths]

ZotLit 中的所有模板数据都位于 `zt` 变量下。下表将 Zotero Integration 变量映射到其对应的 ZotLit 变量。

| Zotero Integration                 | ZotLit                                   | 说明                                                                                   |
| ---------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------------------- |
| `title`                            | `zt.title`                               | 所有条目字段均移至 `zt.` 下                                                            |
| `citekey`                          | `zt.citationKey`                         |                                                                                        |
| `desktopURI`                       | `zt.backlink`                            | `zotero://select` URI                                                                  |
| `authors` (comma-separated string) | `zt.creators` (array of creator objects) | 使用 `{% for c in zt.creators %}` 进行遍历；每个对象包含 `family`、`given`、`fullName` |
| `annotation.annotatedText`         | `zt.text`                                | 位于配置方案的标注分节内                                                               |
| `annotation.colorCategory`         | `zt.colorName`                           | 解析后的调色板名称（`"yellow"`、`"red"` 等）                                           |
| `annotation.imageRelativePath`     | `zt.imgLink`                             | 链接辅助方法；调用 `{{ zt.imgLink }}` 获取 Markdown 链接                               |
| `annotation.comment`               | `zt.comment`                             | 纯文本评论                                                                             |

[模板数据浏览器](/docs/how-to/explore-template-data)显示了实时 Zotero 条目的所有可用字段。你可以用它来查找任何 Zotero Integration 变量在 ZotLit 中的对应项。

### 从 persist 到托管区域的转变 [#persist-vs-managed]

这是两个插件之间最重要的概念差异。

- 在 Zotero Integration 中，`{% persist "id" %}` 标记在重新导入时要**保留**的内容。持久化块之外的所有内容都会被重新渲染。
- 在 ZotLit 中，`{% managed %}...{% endmanaged %}` 标记在更新时要**重新渲染**的内容。托管区域之外的所有内容都会被保留。

这两种模型恰好相反。Zotero Integration 标记要保留的内容；ZotLit 标记要替换的内容。

在 Zotero Integration 中，你可能会有多个 persist 块。而在 ZotLit 中，每篇笔记只有一个托管区域。

**Zotero Integration 模板**：

```text
# {{ title }}
Authors: {{ authors }}

{% persist "notes" %}
{% if isFirstImport %}
- [ ] Read this paper
{% endif %}
{% endpersist %}

{% persist "annotations" %}
{% set newAnnots = annotations | filterby("date", "dateafter", lastImportDate) %}
{% for a in newAnnots %}
> {{ a.annotatedText }}
{% endfor %}
{% endpersist %}
```

**ZotLit 对应项（配置方案笔记源码）**：

笔记正文包含一个用于放置生成内容的托管区域。个人笔记写在区域外部。

```liquid
# {{ zt.title }}
Authors: {% for c in zt.creators %}{{ c.fullName }}{% unless forloop.last %}, {% endunless %}{% endfor %}

{% managed %}
(Annotations and generated content go here. Re-rendered on every update.)
{% endmanaged %}

## My notes
(This section is never touched by updates. Write freely here.)
- [ ] Read this paper
```

标注分节是配置方案文档中的独立部分（位于 `--- zotlit:annotation ---` 标头之后）。它控制单条标注的格式：

```liquid
> {{ zt.text }}
```

要点：

- 之前位于 `{% persist "notes" %}` 中的个人笔记移至托管区域**外部**。
- 标注循环移至配置方案的[标注分节](/docs/reference/templates/profile-document)中。ZotLit 会自动遍历所有标注。
- `isFirstImport` 和 `lastImportDate` 没有对应项。托管区域在每次更新时都会重新渲染全部内容。
- 每次都会渲染全部标注。过期的标注会被自动移除。

### 模板包含（include） [#includes]

Zotero Integration 的 `{% include "[[file]]" %}` 变成了 ZotLit 的共享片段。在[模板文件夹](/docs/reference/templates/how-templates-work#template-folder)中创建一个 `zotlit-partial.<name>.md` 文件，然后使用 `{% render "<name>" with zt as zt %}` 引用它。

有关具体步骤，请参阅[自定义模板](/docs/how-to/customize-a-template)。

### 引文格式 [#citation-formats]

Zotero Integration 为每种引文格式注册了一个命令。ZotLit 则通过引文模板渲染每条引用，因此格式只是该文档内的一个过滤器选择：

| Zotero Integration 格式 | 引文模板                                     |
| ----------------------- | -------------------------------------------- |
| `pandoc`                | `{{ zt.citations \| pandoc_cite }}`          |
| `latex`                 | `{{ zt.citations \| tex_cite }}`             |
| `biblatex`              | `{{ zt.citations \| tex_cite: "autocite" }}` |
| `template`              | 引文模板本身                                 |

请参阅 [`tex_cite`](/docs/reference/templates/syntax#tex-cite) 了解前缀与后缀规则，以及 LaTeX 中没有对应位置的输入项。

引文模板通过读取 `zt.variant` 来渲染两种形式：建议器在按下 Enter 时插入 `main`，在按下 Shift+Enter 时插入 `alt`。因此，单个模板可以同时提供这两种格式，而在 Zotero Integration 中每种格式都需要单独的命令。

`formatted-citation` 和 `formatted-bibliography` 通过 CSL 样式而非模板进行渲染。ZotLit 在[导出带引文的笔记](/docs/how-to/export-note-with-citations)时会生成该输出。

## 没有直接对应项的功能 [#no-equivalent]

| Zotero Integration 功能            | ZotLit 中的替代方法                                                           |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| `{% persist %}`（多个块）          | 将个人内容放置在单个托管区域之外                                              |
| `isFirstImport` / `lastImportDate` | 托管区域每次都会重新渲染全部内容                                              |
| 标注拼接（`+` 前缀）               | 在 Zotero 的标注编辑器中合并文本                                              |
| `pdfannots2json`（外部标注提取器） | 使用 Zotero 内置的 PDF 阅读器                                                 |
| 图片 DPI / 格式 / 质量 / OCR 设置  | ZotLit 按需生成[摘录图片](/docs/reference/excerpt-images)；这些设置没有对应项 |
| `runImport()` 公共 API             | 使用 [ZotLit 协议链接](/docs/reference/protocol-links)                        |

## 你获得的新功能 [#features-you-gain]

- **无需依赖 Better BibTeX**：ZotLit 以更高性能的方式直接读取 Zotero 数据库。
- **模板工作台**：在编辑模板时支持实时预览，笔记预览位于编辑器旁，模板字段一键即可插入。
- **配置方案匹配**：按条目类型、标签或分类自动选择模板。
- **图谱引用**：引用连线会显示在 Obsidian 的关系图谱视图中。
- **托管区域**：无需特殊语法，托管区域之外的编辑在每次更新后都会保留。
- **切换配置方案**：创建笔记后仍可更改其模板。
