Read a Zotero item's PDF in an Obsidian tab instead of switching to Zotero.

ZotLit opens the PDF in Obsidian's own PDF reader, whether the file sits inside your vault or in Zotero's storage folder. Only PDF attachments open this way; EPUBs, web snapshots, and other file types stay in Zotero.

You need Obsidian 1.14.5 or later, which ZotLit 2.2 requires.

## From a literature note

With the literature note open in Obsidian:

- Open the command palette and run <Command inline name={m.command_open_pdf_name()} />.
- Or right-click the note's tab and choose <UiLabel name={m.command_open_pdf_name()} /> from the **zotlit** section of the file menu.

## From the annotation view

Open the view's pane menu and choose <UiLabel name={m.command_open_pdf_name()} />. This opens the attachment the view shows. The menu leaves the entry out while the view follows that PDF's tab in Obsidian.

## From the Library View

In the [Library View](/docs/how-to/use-library-view), double-click a paper's row, or select it and press `Shift+Enter`. To keep the library in view, right-click the row and choose <UiLabel name={m.library_view_menu_open_pdf_right()} />. The Reading Card's <UiLabel name={m.library_view_menu_open_pdf()} /> button opens it too.

## From the quick switcher

Run <Command inline name={m.command_open_lit_note_name()} />, search for the item, and press `Shift+Enter` on the result. The PDF opens without the literature note. See [Use the quick switcher](/docs/how-to/create-and-open-notes#quick-switcher) for every chord a result takes.

## From Zotero

These entry points need ZotLit Companion, the Zotero add-on, at the version released with ZotLit 2.2. [Install ZotLit Companion](/docs/install-companion) has the current version.

- In the library, select one PDF attachment, or one item that has a PDF, and choose <UiLabel name={m["zotero.menu_item_open_pdf.label"]()} /> from the top-level context menu.
- While reading a PDF in Zotero, right-click inside the page and choose <UiLabel name={m["zotero.menu_reader_page_open_pdf"]()} />. This opens the PDF you are reading.

## From a link in a note [#file-links]

Each annotation ZotLit writes into a note links back to Zotero with a durable link. Click one and the PDF opens in Obsidian, with that annotation selected and scrolled into view. The link works on every computer: when this one does not hold the PDF, Zotero opens the annotation instead. An annotation Zotero no longer has still opens the PDF on its page. See [Zotero open links](/docs/reference/protocol-links#zotero-open-links) for every case.

A literature note's `fileLink` writes a link straight to the attachment file, and a click opens that PDF in Obsidian. Notes from an earlier ZotLit link each annotation to the file as well. Those links keep opening in Obsidian on the annotation.

File links work for any link in your vault that points at a PDF in your Zotero library, however the link got there. A link to any other file — an EPUB, a web snapshot, a PDF Zotero does not know about — opens in your system app as before.

To open one link in your system app anyway, right-click it and choose **Open in default browser**. An annotation link then opens in Zotero. To turn the whole behavior off, clear <UiLabel name={m.settings_reader_open_file_links_name()} /> in **Settings → ZotLit → Reader**.

To send annotation links alone to Zotero, clear <SettingsPath page={m.settings_page_reader()} setting={m.settings_reader_open_annotation_links_name()} />. Hovering an annotation link still shows the annotation.

Hover over an annotation link in Live Preview, Source mode, or Reading view to see a popover preview. It shows the quoted text, your comment, the page number, and the highlight color. For an image or ink annotation, it displays the visual excerpt. Below the annotation, the popover shows the bibliography entry of the annotation's item, with the same actions as a citation popover. An annotation on a standalone PDF has no item, so its popover shows the annotation alone. The preview shows on every hover, whatever the citation hover settings are.

## What you get

When the item has one PDF, it opens straight away. When it has several, ZotLit asks which one to open; the picker lists them by file name and its search box reads <UiLabel name={m.modal_select_pdf_placeholder()} />.

When the item has no PDF, ZotLit shows <UiLabel name={m.notice_no_pdf_attachment()} /> When the file is no longer on disk, it shows <UiLabel name={m.notice_pdf_file_missing()} /> In neither case does ZotLit open the file in Zotero instead.

The annotation view comes forward in the sidebar with the PDF, so the item's highlights appear beside it. While the view is in <UiLabel name={m.annot_view_mode_active_tab()} /> mode, it follows the PDF tab.

To keep your sidebar as it is, turn off <SettingsPath page={m.settings_page_reader()} setting={m.settings_reader_focus_annot_view_name()} />. See [Settings](/docs/reference/settings#reader).

## Keep the read time in Zotero [#recently-read]

If you already granted Write Authorization with <UiLabel name={m.capability_enable_editing()} /> and **Always Allow**, reading a PDF from My Library in Obsidian updates its last-read time in Zotero. The paper then appears in Zotero's Recently Read list, and the read time syncs through Zotero.

ZotLit does not ask for Write Authorization while you read. Without it, with
Zotero closed, or if the update fails, the read still counts on this device and
no notice appears. Reads of group-library PDFs in Obsidian also stay on this
device.
