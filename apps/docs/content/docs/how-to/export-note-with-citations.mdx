Export the active Markdown note as a Word document or web page with formatted citations and a bibliography.

For a guided comparison with native Pandoc, follow [Build a Pandoc citation workflow](/docs/tutorial/pandoc-citation-workflow).

## Before you start

You need:

- Obsidian Desktop with a Markdown note open.
- The **{m.settings_citation_engine_name()}** installed under **Settings > ZotLit > {m.settings_page_citations()} > {m.settings_citation_references_heading()}**.
- Zotero running so ZotLit can collect bibliography data.

ZotLit uses Better BibTeX when it is available. Otherwise, it uses the Zotero local API.

## Export the note

<Steps>
  <Step>
    ### Open the export modal

    Open the command palette and run:

    <Command name={m.command_pandoc_export_name()} />

  </Step>
  <Step>
    ### Select the output

    Review these fields:

    - **{m.pandoc_export_format_name()}** starts with **{m.pandoc_export_format_docx()}**. Select **{m.pandoc_export_format_html()}** for HTML output.
    - **{m.pandoc_export_style_name()}** starts with your current **{m.settings_citation_references_style_name()}**.
    - **{m.pandoc_export_destination_name()}** starts with the source note's path and filename stem.

    Change the format, style, or destination as needed.

  </Step>
  <Step>
    ### Run the export

    Select **{m.pandoc_export_confirm()}**. ZotLit resolves the citations, retrieves bibliography data, and converts the complete note.

  </Step>
</Steps>

The destination contains a `.docx` Word document or an `.html` web page. The output includes formatted citations and a bibliography.

Export leaves the source note unchanged. The bibliography is generated in the exported document; your Markdown keeps the citations it was generated from. To place a bibliography elsewhere, [copy it from the References Sidebar](/docs/how-to/review-copy-troubleshoot-references#copy-references).

## Which citations are exported

Built-in export uses its own citation membership. The following settings do not change export content:

- **{m.settings_citation_pandoc_citations_name()}**
- **{m.settings_citation_wikilink_citations_name()}**
- **{m.settings_citation_show_formatted_name()}**
- **{m.settings_citation_open_as_links_name()}**

All wikilinks to Literature Notes are export members. A valid Citation Fragment such as `#cite:locator=33` adds its citation details.

Literal Pandoc keys such as `@doe2024` also work. Each key must exist in the bibliography data that Zotero supplies.

<Callout type="info">
  Export is all-or-nothing. ZotLit writes the destination only after citation
  resolution, bibliography retrieval, and Pandoc conversion all succeed.
</Callout>

## Fix an export error

| Symptom                                                                                                       | Recovery                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| ZotLit asks you to install the Pandoc engine                                                                  | Open **Settings > ZotLit > {m.settings_page_citations()} > {m.settings_citation_references_heading()}**, then install the engine. |
| A `#cite:` fragment is malformed, points to a note that is not a Literature Note, or has an unresolved target | Correct the fragment or link target.                                                                                              |
| ZotLit cannot read the Zotero database                                                                        | Check the **{m.settings_page_database()}** settings, then run the export again.                                                   |
| Zotero holds no item for a Literature Note                                                                    | Restore the missing item or update the Literature Note's `zotero-key`.                                                            |
| Better BibTeX holds no citation key for a Literature Note                                                     | Assign a citation key in Better BibTeX, then run the export again.                                                                |
| ZotLit asks you to start Zotero                                                                               | Start Zotero and keep it running during export.                                                                                   |
| The Zotero local API is disabled                                                                              | In Zotero, open **Settings > Advanced** and enable **Allow other applications on this computer to communicate with Zotero**.      |
| Better BibTeX or the Zotero local API refuses the request                                                     | Check the named source in the error, then retry after it responds normally.                                                       |
| Pandoc stops the conversion                                                                                   | Correct the source or style problem named in the error, then run the export again.                                                |
| ZotLit cannot write the exported document                                                                     | Select a writable destination and run the export again.                                                                           |

Each failure stops the complete export. ZotLit does not write a document with a partial bibliography.

For conversion with a user-installed Pandoc CLI, see [Native Pandoc workflow](/docs/reference/settings#native-pandoc). That workflow uses the {m.settings_citation_pandoc_files_name()} instead of this command.
