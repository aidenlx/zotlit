本指南将协助您在当前活动笔记中审阅参考文献，并纠正 ZotLit 无法正确解析或格式化的引文条目。

## 审阅参考文献

<Steps>
  <Step>
    ### 打开参考文献侧边栏

    打开您希望审阅的 Markdown 笔记。运行命令：

    <Command name={m.command_open_references_view_name()} />

    侧边栏会自动跟随当前处于活动状态的笔记。排版后的列表严格依循所选 CSL 样式以及参考文献规范排序。

  </Step>
  <Step>
    ### 依次定位跳转换读各处引用

    点击条目右侧的箭头展开图标。ZotLit 会立即将编辑器光标滚动并定位到该条目的下一个出现位置。

    再次点击可在后续出现位置间循环跳转。在遍历完最后一处引用后，再次点击会重新回到第一处。

  </Step>
  <Step>
    ### 打开关联项

    将鼠标悬停在条目上，或通过键盘将焦点移动到该条目，即可唤出其行内操作按钮：

    - <UiLabel name={m.references_open_note()} />：打开对应的文献笔记。若该 Zotero 条目尚未创建文献笔记，ZotLit 会自动先行为其创建。
    - <UiLabel name={m.references_open_in_zotero()} />：在 Zotero 中高亮选中该条目。
    - <UiLabel name={m.references_open_attachment()} />：打开其关联附件。当存在多个附件时，ZotLit 会弹出选择菜单。

    附件操作按钮仅在该条目确实包含可打开附件时才会显示。

  </Step>
  <Step>
    ### 在编辑器中直接预览引文详情

    在 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_hover_heading()} /> 下，将 <UiLabel name={m.settings_citation_hover_action_name()} /> 设置为 <UiLabel name={m.settings_citation_hover_action_popover()} />。

    将鼠标悬停在格式化引文上。弹出的浮窗将展示所引条目的完整参考文献列表内容，并附带文献笔记、Zotero 定位及附件快捷操作按钮。

    使用 <UiLabel name={m.settings_citation_hover_mod_page_name()} /> 可针对 <UiLabel name={m.settings_citation_hover_mod_source_name()} />、<UiLabel name={m.settings_citation_hover_mod_live_preview_name()} /> 以及阅读视图分别精细控制悬停按键行为。

  </Step>
</Steps>

## 更改单篇笔记的显示方式 [#change-one-notes-presentation]

打开笔记，然后运行：

<Command name={m.command_set_citation_presentation_name()} />

您也可以从当前活动笔记的 **More options** 菜单中选择 <UiLabel name={m.command_set_citation_presentation_name()} />。

1. 选择一个已安装在 Zotero 中的 <UiLabel name={m.citation_presentation_style_name()} />，或继续使用仓库样式。
2. 输入 <UiLabel name={m.citation_presentation_language_name()} />，例如 `en-US`、`de` 或 `zh-CN`。
3. 选择 <UiLabel name={m.citation_presentation_confirm()} />。

该样式会应用于此笔记的文内引文、<UiLabel name={m.references_view_name()} /> 侧边栏、<UiLabel name={m.settings_citation_hover_action_popover()} />、复制的参考文献、内置导出，以及[原生 Pandoc](/docs/how-to/export-with-native-pandoc) 导出。<UiLabel name={m.citation_presentation_language_name()} /> 设置的是整篇导出文档的 Pandoc `lang`，不仅影响引文。

选择 <UiLabel name={m.citation_presentation_language_name()} /> 旁的重置按钮，其提示为 <UiLabel name={m.citation_presentation_language_reset()} />。这会移除笔记中的 `lang`，使引文格式化改用仓库的 <UiLabel name={m.settings_citation_locale_name()} />。

## 复制参考文献 [#copy-references]

### 复制完整参考文献列表 [#copy-the-complete-bibliography]

在 <UiLabel name={m.references_view_name()} /> 侧边栏工具栏中选择 <UiLabel name={m.references_copy_bibliography()} />。ZotLit 会按参考文献顺序复制格式化条目，不包含标题。

剪贴板同时包含富文本和纯文本。纯文本条目之间留有一空行。

### 复制单个条目 [#copy-one-entry]

在侧边栏中选中一个条目的文本，然后使用操作系统通常的复制快捷键。

选择条目行的箭头会跳转到引文出现位置，不会复制该条目。

## 排查 <UiLabel name={m.references_copy_bibliography()} /> 操作不可用的问题 [#fix-a-disabled-copy-bibliography-action]

将鼠标悬停在不可用的操作上，查看当前原因。

| 提示                                                         | 处理方法                                 |
| ------------------------------------------------------------ | ---------------------------------------- |
| <UiLabel name={m.references_copy_blocked_no_note()} />       | 打开需要复制参考文献的 Markdown 笔记。   |
| <UiLabel name={m.references_copy_blocked_no_references()} /> | 在当前活动笔记中添加可识别的引文。       |
| <UiLabel name={m.references_copy_blocked_pending()} />       | 等待当前格式化过程完成。                 |
| <UiLabel name={m.references_copy_blocked_unavailable()} />   | 安装或恢复 Pandoc 引擎及可用的样式。     |
| <UiLabel name={m.references_copy_blocked_failed()} />        | 检查引擎和所选样式，在侧边栏刷新后重试。 |
| <UiLabel name={m.references_copy_blocked_errors()} />        | 修正侧边栏中列出的所有参考文献错误。     |

当前活动笔记、样式、语言区域或 Zotero 数据发生变化时，此操作也会暂时不可用。请等待新的参考文献列表完成格式化。

## 修复参考文献错误 [#fix-reference-errors]

每个参考文献错误都对应准确的源码位置。使用条目行的箭头可打开该位置。

| 侧边栏状态                                                               | 原因                                                                              | 修复方法                                                                                          |
| ------------------------------------------------------------------------ | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| <UiLabel name={m.references_citekey_unresolved({ citekey: "key" })} />   | <UiLabel name={m.settings_library_scope_name()} /> 中没有条目使用该文献引用标识。 | 修正标识，将对应的文献库加入作用域，或将该标识分配给目标条目。                                    |
| <UiLabel name={m.references_citekey_ambiguous({ citekey: "key" })} />    | 作用域内的多个条目使用同一个文献引用标识。                                        | 为每个条目分配不同标识，或收窄 <UiLabel name={m.settings_library_scope_name()} />，直到标识唯一。 |
| <UiLabel name={m.references_citation_fragment_invalid()} />              | 文献笔记链接的 `#cite:` 片段格式错误。                                            | 修正片段。如需引用页码，可使用 `#cite:locator=33`。                                               |
| <UiLabel name={m.references_item_missing({ linkpath: "{linkpath}" })} /> | 文献笔记的 `zotero-key` 已无法解析到条目。                                        | 恢复 Zotero 条目，或修正文献笔记的身份标识。                                                      |

有歧义的条目行会列出所有匹配条目及其文献库和条目键。在文献引用标识能唯一确定一个条目之前，<UiLabel name={m.references_open_note()} /> 保持不可用。

## 修复显示错误 [#fix-presentation-errors]

| 提示横幅                                                         | 修复方法                                                                                                                                                                          |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <UiLabel name={m.references_document_style_failed_title()} />    | 修正笔记的 `zotlit-csl`，在 Zotero 中安装该样式，或改用仓库样式。                                                                                                                 |
| <UiLabel name={m.references_document_language_failed_title()} /> | 将 `lang` 设置为 `de-DE` 等语言标签，或移除此属性。                                                                                                                               |
| <UiLabel name={m.references_format_failed_title()} />            | 在 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} /> 下检查所选样式和 <UiLabel name={m.settings_citation_engine_name()} />。 |
| <UiLabel name={m.references_engine_failed_title()} />            | 打开同一个设置页面，修复或重新安装引擎。                                                                                                                                          |

格式化输出不可用时，侧边栏会显示简化列表。在 ZotLit 生成不含参考文献错误的完整列表前，复制操作保持禁用。
