本指南将协助您在当前活动笔记中审阅参考文献，并纠正 ZotLit 无法正确解析或格式化的引文条目。

## 审阅参考文献

<Steps>
  <Step>
    ### 打开参考文献侧边栏

    打开您希望审阅的 Markdown 笔记。运行命令：

    <Command name={m.command_open_references_view_name()} />

    侧边栏会自动跟随当前处于活动状态的笔记。排版后的列表严格依循所选 CSL 样式以及参考文献规范排序。

  </Step>
  <Step>
    ### 依次定位跳转换读各处引用

    点击条目右侧的箭头展开图标。ZotLit 会立即将编辑器光标滚动并定位到该条目的下一个出现位置。

    再次点击可在后续出现位置间循环跳转。在遍历完最后一处引用后，再次点击会重新回到第一处。

  </Step>
  <Step>
    ### 打开关联项

    将鼠标悬停在条目上，或通过键盘将焦点移动到该条目，即可唤出其行内操作按钮：

    - <UiLabel name={m.references_open_note()} />：打开对应的文献笔记。若该 Zotero 条目尚未创建文献笔记，ZotLit 会自动先行为其创建。
    - <UiLabel name={m.references_open_in_zotero()} />：在 Zotero 中高亮选中该条目。
    - <UiLabel name={m.references_open_attachment()} />：打开其关联附件。当存在多个附件时，ZotLit 会弹出选择菜单。

    附件操作按钮仅在该条目确实包含可打开附件时才会显示。

  </Step>
  <Step>
    ### 在编辑器中直接预览引文详情

    在 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_hover_heading()} /> 下，将 <UiLabel name={m.settings_citation_hover_action_name()} /> 设置为 <UiLabel name={m.settings_citation_hover_action_popover()} />。

    将鼠标悬停在格式化引文上。弹出的浮窗将展示所引条目的完整参考文献列表内容，并附带文献笔记、Zotero 定位及附件快捷操作按钮。

    使用 <UiLabel name={m.settings_citation_hover_mod_page_name()} /> 可针对 <UiLabel name={m.settings_citation_hover_mod_source_name()} />、<UiLabel name={m.settings_citation_hover_mod_live_preview_name()} /> 以及阅读视图分别精细控制悬停按键行为。

  </Step>
</Steps>

## Change one note's presentation

Open the note, then run:

<Command name={m.command_set_citation_presentation_name()} />

You can also select <UiLabel name={m.command_set_citation_presentation_name()} /> from the active note's **More options** menu.

1. Select a <UiLabel name={m.citation_presentation_style_name()} /> installed in Zotero, or keep the vault style.
2. Enter a <UiLabel name={m.citation_presentation_language_name()} />, such as `en-US`, `de`, or `zh-CN`.
3. Select <UiLabel name={m.citation_presentation_confirm()} />.

The style applies to this note's in-text citations, <UiLabel name={m.references_view_name()} /> Sidebar, <UiLabel name={m.settings_citation_hover_action_popover()} />, copied bibliography, built-in export, and [native Pandoc](/docs/how-to/export-with-native-pandoc) runs. <UiLabel name={m.citation_presentation_language_name()} /> sets Pandoc `lang` for the complete exported document, not only its citations.

Select the reset button beside <UiLabel name={m.citation_presentation_language_name()} />. Its tooltip is <UiLabel name={m.citation_presentation_language_reset()} />. This removes `lang` from the note, so citation formatting uses the vault <UiLabel name={m.settings_citation_locale_name()} />.

## Copy references [#copy-references]

### Copy the complete bibliography

Select <UiLabel name={m.references_copy_bibliography()} /> in the <UiLabel name={m.references_view_name()} /> Sidebar toolbar. ZotLit copies the formatted entries in bibliography order, without a heading.

The clipboard contains rich text and plain text. Plain-text entries have a blank line between them.

### Copy one entry

Select the text of one entry in the sidebar. Use your operating system's normal copy shortcut.

Selecting the row's chevron navigates to citation occurrences. It does not copy the entry.

## Fix a disabled Copy bibliography action

Hover the disabled action to see its current reason.

| Tooltip                                                      | What to do                                                                   |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| <UiLabel name={m.references_copy_blocked_no_note()} />       | Open the Markdown note whose bibliography you need.                          |
| <UiLabel name={m.references_copy_blocked_no_references()} /> | Add a recognized citation to the active note.                                |
| <UiLabel name={m.references_copy_blocked_pending()} />       | Wait for the current formatting pass to finish.                              |
| <UiLabel name={m.references_copy_blocked_unavailable()} />   | Install or restore the Pandoc engine and an available style.                 |
| <UiLabel name={m.references_copy_blocked_failed()} />        | Check the engine and selected style, then retry after the sidebar refreshes. |
| <UiLabel name={m.references_copy_blocked_errors()} />        | Correct every Reference Error listed in the sidebar.                         |

The action also becomes temporarily unavailable when the active note, style, locale, or Zotero data changes. Wait for the new bibliography to finish formatting.

## Fix Reference Errors

Each Reference Error stays tied to its exact source occurrence. Use the row's chevron to open that occurrence.

| Sidebar state                                                            | Cause                                                                                | Recovery                                                                                                             |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `@key matches no item in your Zotero library.`                           | No item in <UiLabel name={m.settings_library_scope_name()} /> has that citation key. | Correct the key, add the matching library to the scope, or assign the key to the intended item.                      |
| `@key matches multiple items in your Zotero library.`                    | Several in-scope items have the same citation key.                                   | Give each item a distinct key, or narrow <UiLabel name={m.settings_library_scope_name()} /> until the key is unique. |
| `This link has an invalid citation fragment.`                            | A Literature Note link has a malformed `#cite:` fragment.                            | Correct the fragment. For a page locator, use `#cite:locator=33`.                                                    |
| `{linkpath} points to an item that is no longer in your Zotero library.` | The Literature Note's `zotero-key` no longer resolves to an item.                    | Restore the Zotero item or correct the Literature Note identity.                                                     |

An ambiguous row lists every matching item with its library and item key. <UiLabel name={m.references_open_note()} /> stays unavailable until the citation key identifies one item.

## Fix presentation errors

| Banner                                                       | Recovery                                                                                                                                                                                        |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **This note's citation and references style is unavailable** | Correct the note's `zotlit-csl`, install that style in Zotero, or use the vault style.                                                                                                          |
| **This note's document language is invalid**                 | Set `lang` to a language tag such as `de-DE`, or remove the property.                                                                                                                           |
| **ZotLit could not format these references**                 | Check the selected style and <UiLabel name={m.settings_citation_engine_name()} /> under <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} />. |
| **The Pandoc engine is unavailable**                         | Open the same settings page and repair or reinstall the engine.                                                                                                                                 |

The sidebar shows a minimal list when formatted output is unavailable. Copy remains disabled until ZotLit produces a complete bibliography without Reference Errors.
