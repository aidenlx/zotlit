查询文件可以在标签页或笔记中实时显示来自 Zotero 文库的标注、文件或文献。本页介绍如何创建查询文件、更改其视图以及进行嵌入。[查询文件与查询块](/docs/reference/how-queries-work)解释了背后的核心概念。

## 创建查询文件 [#create]

可以使用以下任一方式：

- 打开命令面板（Command palette）并运行 <Command inline name={m.command_new_query_file_name()} />。该文件会存放在 Obsidian 存放新笔记的文件夹中。
- 在文件列表（file explorer）中，右键点击某个文件夹（或该文件夹中的文件），然后选择 <UiLabel name={m.query_file_new()} />。

ZotLit 会创建一个名为 `Untitled.zotquery` 的文件并在标签页中打开。在选择菜单项时按住 `Ctrl`（Windows 和 Linux）或 `Command`（macOS）可在新标签页中打开。重命名该文件的方式与重命名普通笔记完全相同。

新文件包含两个视图：

- <UiLabel name={m.query_file_items_view_name()} />
  是默认视图。它是一个以表格形式展示整个文库文献的视图，按修改日期降序排列（最新在前），一次最多显示
  100 条。它包含 <UiLabel name={m.query_view_property_title()} />、
  <UiLabel name={m.query_view_property_creators()} />、
  <UiLabel name={m.query_view_property_year()} /> 以及
  <UiLabel name={m.query_view_table_literature_note()} /> 列。
- <UiLabel name={m.query_file_annotations_view_name()} />
  显示整个文库的标注，按文献分组，一次最多显示 100 条。

想要查看标注，请打开视图菜单并选择 <UiLabel name={m.query_file_annotations_view_name()} />。详见[切换、添加和排列视图](#view-menu)。

## 使用视图 [#views]

文件顶部的工具栏包含以下控件（从左到右）：

| 控件                                         | 作用                                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------------------ |
| 视图菜单                                     | 显示当前屏幕上的视图。在此切换、添加和配置视图。                                     |
| 结果计数                                     | 显示匹配的记录数量。点击可打开 <UiLabel name={m.query_view_results_menu()} /> 菜单。 |
| <UiLabel name={m.query_view_filter()} />     | 选择视图中显示的记录。                                                               |
| <UiLabel name={m.query_view_sort()} />       | 设置行的排序方式。                                                                   |
| <UiLabel name={m.query_view_group()} />      | 将各行归类在标题下。                                                                 |
| <UiLabel name={m.query_view_properties()} /> | 选择每行显示的属性值。                                                               |
| <UiLabel name={m.query_view_search()} />     | 在当前屏幕显示的行中查找文本。                                                       |

在较窄的窗格中，工具栏仅显示图标而不显示文字标签。

### 切换、添加和排列视图 [#view-menu]

选择视图菜单即可查看该文件的所有视图。在 <UiLabel name={m.query_view_search_views()} /> 中输入内容可按名称查找视图，然后选择它。

- 要添加视图，请选择 <UiLabel name={m.query_view_add_view()} />。ZotLit 会打开 <UiLabel name={m.query_view_configure_view()} /> 供你命名。
- 要调整视图的顺序，请在列表中拖动视图。
- 要将某个视图设为默认视图，请打开其 <UiLabel name={m.query_view_configure_view()} /> 页面，选择 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_default_view()} />。默认视图会移至列表顶部。未指定视图名称的嵌入内容将显示该视图。
- 要复制或删除视图，请打开其 <UiLabel name={m.query_view_configure_view()} /> 页面，选择 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_duplicate_view()} /> 或 <UiLabel name={m.query_view_delete_view()} />。

### 配置视图 [#configure]

选择视图菜单。在视图所在行上，选择提示为 <UiLabel name={m.query_view_configure_view()} /> 的箭头按钮。你也可以右键点击该行，或者右键点击视图菜单按钮来配置当前显示的视图。<UiLabel name={m.query_view_configure_view()} /> 页面会在同一个菜单中打开。每项修改都会立即保存。视图名称在离开输入框时保存。

| 设置项                                      | 作用                                                     |
| ------------------------------------------- | -------------------------------------------------------- |
| <UiLabel name={m.query_view_view_name()} /> | 在视图菜单中以及嵌入语法中 `#` 后面显示的名称。          |
| <UiLabel name={m.query_view_dataset()} />   | 每行所代表的内容：一条标注、一个附件或一个条目。         |
| <UiLabel name={m.query_view_layout()} />    | 视图呈现各行的方式。列表中仅提供能够展示所选记录的布局。 |

更改行数据类型时，排序、分组和属性设置仍会保留在文件中。新数据类型中不存在的属性会被视图忽略。<UiLabel name={m.query_view_sort()} />、<UiLabel name={m.query_view_group()} /> 和 <UiLabel name={m.query_view_properties()} /> 会将其标记为 <UiLabel name={m.query_view_not_used()} />，工具栏下方的提示也会列出它们。当切回包含这些属性的数据类型时，视图会重新启用它们。

每种布局都带有专属选项：

| 布局                                                 | 选项                                                                                                                                                                                   |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <UiLabel name={m.query_view_layout_annotations()} /> | <UiLabel name={m.query_view_card_width()} />、<UiLabel name={m.query_view_show_comment()} />、<UiLabel name={m.query_view_show_tags()} />、<UiLabel name={m.query_view_show_page()} /> |
| <UiLabel name={m.query_view_layout_list()} />        | <UiLabel name={m.query_view_list_markers()} />、<UiLabel name={m.query_view_list_indent_properties()} />、<UiLabel name={m.query_view_list_property_separator()} />                    |
| <UiLabel name={m.query_view_layout_cards()} />       | <UiLabel name={m.query_view_card_size()} />                                                                                                                                            |
| <UiLabel name={m.query_view_layout_table()} />       | 列顺序和列宽直接在表头中调整（参见[使用表格布局](#table)）。                                                                                                                           |

## 筛选行 [#filter]

选择 <UiLabel name={m.query_view_filter()} />。筛选器编辑器包含两部分：

- <UiLabel name={m.query_view_filter_all_views()} />
  ：应用于该文件中与第一个视图展示相同类型数据的所有视图的条件。
- <UiLabel name={m.query_view_filter_this_view()} />
  ：仅应用于当前屏幕上视图的条件。

<Steps>
  <Step>
    ### 添加条件 [#add-a-condition]

    选择 <UiLabel name={m.workbench_match_add_condition()} />。新添加的行显示为 <UiLabel name={m.workbench_match_value_empty()} />，在填入具体值之前不会执行任何筛选。选择一个属性、一个运算符以及一个值。例如，选择 <UiLabel name={m.workbench_filter_field_color()} />、<UiLabel name={m.workbench_filter_op_is()} /> 和 <UiLabel name={m.workbench_filter_color_yellow()} /> 可查找重点高亮。在条目视图中，选择 <UiLabel name={m.workbench_filter_field_year()} />、<UiLabel name={m.workbench_filter_op_on_or_after()} /> 并输入 `2020` 可查找近期的出版物。

    属性列表包含了视图记录中所有的 Zotero 字段，常用字段排在前面。要查找某个属性，可在列表的搜索框中输入内容。使用中英文常用词也可以查找到属性：输入 `journal` 或 `期刊` 可以找到“出版物”字段，输入 `summary` 可以找到摘要。这些词仅用于帮助你查找属性，筛选器实际保存的是属性本身的名称（例如 `publicationTitle`）。

  </Step>
  <Step>
    ### 组合条件 [#combine-conditions]

    选择 <UiLabel name={m.workbench_match_match_all()} /> 显示满足所有条件的记录，选择 <UiLabel name={m.workbench_match_match_any()} /> 显示满足至少一个条件的记录，或选择 <UiLabel name={m.workbench_match_match_none()} /> 隐藏满足该分组中任一条件的记录。选择 <UiLabel name={m.workbench_match_add_group()} /> 可以在另一个分组中嵌套条件分组（例如，查找既是黄色高亮且同时带有 `#theory` 或 `#method` 标签的高亮）。

  </Step>
  <Step>
    ### 排列条件 [#arrange-conditions]

    拖动任意条件或分组上的手柄（<UiLabel name={m.workbench_drag_to_reorder()} />）即可上下移动。你可以在同一分组内拖动条件，将其拖入嵌套分组，或拖出到父级分组。你也可以选中手柄并按 `Alt+Arrow Up` 或 `Alt+Arrow Down` 移动该行。

    要移除条件，请删除对应的行。删除嵌套分组中的最后一行时，该分组也会被一并删除。删除筛选器中的最后一行时，该筛选器也会被移除。

  </Step>
  <Step>
    ### 检查结果 [#check-the-result]

    视图会在你编辑时实时刷新。结果计数会显示新的记录数量。

  </Step>
</Steps>

可用属性取决于视图展示的记录类型。标注视图提供每条标注的颜色、标签、评论、文本、页码以及日期。所有视图均提供文献的标题、创建者、第一作者、年份、条目类型、分类以及文库。标注和附件视图还提供文件的标题和文件类型。条目视图还提供文献笔记的属性，如[在查询视图中跟踪阅读状态](/docs/how-to/track-reading-status#filter)中所示。

要将条件编写为[筛选表达式](/docs/reference/how-queries-work#steps)，请在其所在行选择 <UiLabel name={m.workbench_match_edit_as_expression()} />。筛选表达式编辑器会对字段名、函数、数字和字符串进行语法着色。在输入时，自动补全会提示可用字段和函数（按 `Tab` 或 `Enter` 插入），参数提示会显示预期参数，波浪下划线会立即标出语法错误。选择 <UiLabel name={m.workbench_match_edit_visually()} /> 可切回可视化条件行。

当条件存在错误时，所在行会显示具体原因。视图将保留上次显示的各行，并显示 <UiLabel name={m.query_view_filter_error()} />。

## 排序与分组行 [#sort-group]

### 排序 [#sort]

选择 <UiLabel name={m.query_view_sort()} />，然后选择 <UiLabel name={m.query_view_sort_add()} />。选择一个属性和排序方向（例如针对日期选择 <UiLabel name={m.query_view_sort_new_old()} />）。添加更多属性可在出现相同值时继续排序。拖动属性可调整其优先级：第一个属性优先排序。

可用属性取决于视图展示的记录类型：

| 数据类型 | 排序属性                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 标注     | 在文件中的位置、页码、日期、颜色、标注类型，以及文献的标题、第一作者和日期，文件的标题和添加日期             |
| 附件     | 标题、日期，以及文献的标题、第一作者和日期                                                                   |
| 条目     | 标题、第一作者、日期、添加和修改日期、条目类型，以及[文献笔记](/docs/how-to/track-reading-status#sort)的属性 |

### 分组 [#group]

选择 <UiLabel name={m.query_view_group()} />，然后在 <UiLabel name={m.query_view_group_by()} /> 中选择一个属性：

| 数据类型 | 分组属性                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标注     | <UiLabel name={m.query_view_property_item()} />、<UiLabel name={m.query_view_property_attachment()} />、<UiLabel name={m.query_view_property_color()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} /> |
| 附件     | <UiLabel name={m.query_view_property_item()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} />                                                                                                          |
| 条目     | <UiLabel name={m.query_view_property_item_type()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} />                                                                                                     |

然后选择分组的排列顺序：

- <UiLabel name={m.query_view_sort_az()} /> 或
  <UiLabel name={m.query_view_sort_za()} />
  ：按分组的值排序。
- <UiLabel name={m.query_view_group_manual()} />
  ：列出各个分组。勾选或取消勾选分组的复选框可显示或隐藏该分组，拖动分组可调整其位置。例如，针对某项写作任务仅显示黄色和红色的分组。

拥有多个标签或分类的记录会出现在其所属的每个分组中。没有值的记录会显示在 <UiLabel name={m.query_view_group_none()} /> 下。在标注、列表和卡片布局中，点击分组标题可以折叠其下的行。

## 选择属性 [#properties]

选择 <UiLabel name={m.query_view_properties()} />。勾选或取消勾选属性的复选框可显示或隐藏该属性，拖动属性可调整其顺序。在 <UiLabel name={m.query_view_properties_search()} /> 中输入内容可查找属性。要添加列表中没有的属性，请输入其路径（例如 `item.citationKey`），然后选择添加该属性的行。在条目视图中，菜单还支持添加文献笔记的属性。参见[在查询视图中跟踪阅读状态](/docs/how-to/track-reading-status#add-column)。

点击任意属性行上的箭头按钮（或按右方向键）可打开其设置页面，在此可以设置[显示名称](#display-names)或编辑[公式](#formulas)。

表格、列表和卡片布局会按此顺序显示这些属性。复制和 CSV 导出也会将它们用作各列。

## 添加公式 [#formulas]

公式是 ZotLit 根据其他属性为每一行计算出的属性。它使用与筛选条件相同的[筛选表达式](/docs/reference/how-queries-work#steps)语言。例如，公式可以显示每篇文献的年份，或其作者的数量。

要在条目视图中显示每篇文献的年份：

<Steps>
  <Step>
    ### 打开公式页面 [#open-the-formula-page]

    选择 <UiLabel name={m.query_view_properties()} />，然后选择 <UiLabel name={m.query_view_formula_add()} />。新公式页面会在同一个菜单中打开。

  </Step>
  <Step>
    ### 命名公式 [#name-the-formula]

    在 <UiLabel name={m.query_view_formula_name()} /> 中输入 `year`。名称由字母、数字和下划线组成，且必须以字母或下划线开头。名称区分大小写。视图会将该属性命名为 `formula.year`。

  </Step>
  <Step>
    ### 编写表达式 [#write-the-expression]

    在 <UiLabel name={m.query_view_formula_expression()} /> 中输入 `date.year`。标签旁的对勾表示文本没有语法错误。若存在语法错误，该位置会显示警告图标，并在字段下方显示原因。

  </Step>
  <Step>
    ### 保存 [#save]

    选择 <UiLabel name={m.query_view_formula_save()} />。视图会在其他属性之后显示这个新属性，并列出每篇文献的年份。页面随后会切换到该新公式的设置页面。

  </Step>
</Steps>

文件会将公式保存在其顶层的 `formulas` 键下，该文件中的所有视图均可显示该公式。若要按公式进行筛选，可在筛选器编辑器中的某个条件上选择 <UiLabel name={m.workbench_match_edit_as_expression()} />，然后输入例如 `formula.year >= 2020`。一个公式也可以引用另一个公式，例如 `formula.year + 1`。

要修改公式，请选择 <UiLabel name={m.query_view_properties()} />。在对应的行上，点击提示为 <UiLabel name={m.query_view_property_edit()} /> 的箭头按钮，或按右方向键。公式页面会在同一菜单中打开。修改 <UiLabel name={m.query_view_formula_expression()} /> 中的文本即可。在没有语法错误的情况下，停止输入片刻后文本会自动保存。公式名称保持不变：若要更改名称，请删除该公式并重新添加。选择 <UiLabel name={m.query_view_back()} /> 可返回列表。

要移除公式，请打开其页面，选择 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_formula_remove()} />。ZotLit 会从该文件的所有视图中移除该公式并返回列表。仍在使用该公式的筛选条件会报错，直到你进行修改。

### 当公式存在错误时 [#formula-errors]

如果公式无法被 ZotLit Query 执行（例如 `title * 2`），其在 <UiLabel name={m.query_view_properties()} /> 中的所在行以及表格布局的列标头处会显示警告图标。悬停在图标上可查看原因。视图中的其他属性仍会正常显示。引用了错误公式的公式会显示出错公式的名称。如果视图的筛选条件引用了错误的公式，视图将显示错误信息且不展示任何行，直到你将其修正。

公式可能在大多数行上正常运行，却在某一行出错。例如，`number(volume)` 在卷号为文本（如“Spring”）的文献上会计算失败。该行的单元格中会显示警告图标，并在工具提示中显示原因。复制和 CSV 导出操作会在该单元格中写入 `Error: ` 以及错误原因。没有卷号的文献则显示为空单元格。[错误值](/docs/reference/how-queries-work#error-values)解释了二者的区别。

## 重命名属性 [#display-names]

显示名称可以在视图中替代属性的路径。例如，属性 `formula.year` 可以显示为“Year of source”。

<Steps>
  <Step>
    ### 打开属性页面 [#open-the-property-page]

    选择 <UiLabel name={m.query_view_properties()} />。在 `formula.year` 所在行上，点击提示为 <UiLabel name={m.query_view_property_edit()} /> 的箭头按钮。

  </Step>
  <Step>
    ### 输入名称 [#type-the-name]

    在 <UiLabel name={m.query_view_display_name()} /> 中输入 `Year of source`。离开输入框、按 `Enter`、选择 <UiLabel name={m.query_view_back()} /> 或关闭菜单时，名称都会自动保存。

  </Step>
</Steps>

表格表头、卡片标签、<UiLabel name={m.query_view_properties()} /> 中的各行以及复制和 CSV 导出的表头行都会显示为“Year of source”。显示名称适用于该文件的所有视图。对于新建公式，你也可以在添加公式时直接在 <UiLabel name={m.query_view_display_name()} /> 中进行设置。

要恢复默认名称，请清空该输入框。没有显示名称时，属性将显示其字段名称（例如标题）或其路径。

## 限制、复制和导出结果 [#results]

点击结果计数可打开 <UiLabel name={m.query_view_results_menu()} /> 菜单：

- <UiLabel name={m.query_view_limit()} />
  ：设置显示的最大行数。清空输入框或选择
  <UiLabel name={m.query_view_show_all({ count: 250 })} /> 可显示所有匹配项。
  当匹配记录数超过视图显示数量时，结果计数会同时显示两个数字，例如
  <UiLabel name={m.query_view_results_limited({ count: 250, shown: 100 })} />。
- <UiLabel name={m.query_view_copy()} />
  ：将所显示行的可见列作为表格复制到剪贴板。可以将其作为 Markdown 表格粘贴到
  Obsidian 笔记中，或粘贴到 Microsoft Excel、Google Sheets、Apple Numbers
  等电子表格软件中。
- <UiLabel name={m.query_view_export_csv()} />
  ：将所显示行的可见列保存为 CSV 文件。该文件采用带 BOM 的 UTF-8 编码，以便
  Excel 以及 R 或 SPSS 等统计软件能够正常显示多语言标题和作者姓名。

复制和 CSV 导出都仅包含视图中显示的属性，并按照可见顺序排列。界面按钮（例如 <UiLabel name={m.query_view_table_literature_note()} /> 列）会被自动忽略。

## 搜索行 [#search]

选择 <UiLabel name={m.query_view_search()} /> 并输入关键词。视图将仅显示当前屏幕中包含该文本的行。搜索不会修改文件。清空输入框即可重新查看所有行。

## 使用表格布局 [#table]

表格布局以网格形式展示文献，类似于 Zotero 中的主条目列表。若要使用该布局，请在 <UiLabel name={m.query_view_configure_view()} /> 中将数据行设置为条目，然后选择 <UiLabel name={m.query_view_layout_table()} />。

### 查看文件、笔记和标注 [#table-expand]

点击任意文献上的 <UiLabel name={m.query_view_table_expand()} /> 可展开其附件文件、子笔记和标注。展开某个附件可以查看其单条标注。

表格单元格中的附件标题和标注文本均为可点击的链接：

- 点击 PDF 附件可在 Obsidian 内置的 PDF 查看器中打开该文件。
- 点击标注可直接打开 PDF 至对应页面并高亮显示该标注。
- 点击其他任何文件类型可在 Zotero 中打开。

点击链接时按住 `Ctrl`（Windows 和 Linux）或 `Command`（macOS）可在新标签页中打开。

### 排列与调整列宽 [#table-columns]

你可以直接在视图中调整表格各列：

- 左右拖动表头可更改列顺序。
- 拖动两列表头之间的边界可调整列宽。
- 双击两列表头之间的边界可将该列恢复为自动宽度。
- 右键点击任意表头可打开其菜单（移动端点击表头即可）。菜单提供 <UiLabel name={m.query_view_table_move_column_left()} />、<UiLabel name={m.query_view_table_move_column_right()} /> 和 <UiLabel name={m.query_view_table_reset_column_width()} /> 选项。

该菜单还可以对该列对应的属性进行操作，与 Obsidian base 类似：

- <UiLabel name={m.query_view_table_hide_column()} />
  ：从视图中移除该列。
- <UiLabel name={m.query_view_table_group_by()} />
  ：按该列对行进行分组（适用于支持分组的属性）。
- <UiLabel name={m.query_view_table_sort_az()} /> 和
  <UiLabel name={m.query_view_table_sort_za()} />
  将该列设为视图的首选排序依据并保留其他排序条件。
  <UiLabel name={m.query_view_table_clear_sort()} /> 可清除该列的排序。
- <UiLabel name={m.query_view_table_edit_property()} />
  会在表头旁打开属性的显示名称设置。对于公式，该选项显示为
  <UiLabel name={m.query_view_table_edit_formula()} />
  ，同时还会打开公式表达式编辑器。

点击表头可按该列排序，就像在 Obsidian base 中一样。每次点击会在“A 到 Z”、“Z 到 A”和“不按该列排序”之间切换；视图原有的其他排序条件会排在其后。每个参与排序的列在表头末尾都会显示一个小箭头：向上代表 A 到 Z，向下代表 Z 到 A。ZotLit 无法对其排序的列（例如文献笔记列）将忽略点击。

调整后的列宽会自动保存在查询文件中。

### 文献笔记列 [#table-literature-note]

<UiLabel name={m.query_view_table_literature_note()} /> 列可在 Obsidian
中打开该文献的文献笔记。若该文献尚未创建文献笔记，点击
<UiLabel name={m.query_view_table_create_note()} /> 即可创建。

该列的行为与任何其他属性相同：你可以在 <UiLabel name={m.query_view_properties()} /> 中显示、隐藏、移动或重命名它。复制和 CSV 导出操作会自动排除此列。

## 在笔记中嵌入查询文件 [#embed]

在任意笔记中输入嵌入链接：

```md
![[Figures.zotquery]]
```

嵌入内容默认显示默认视图。若要显示其他视图，请在 `#` 后加上其名称：

```md
![[Figures.zotquery#Yellow highlights]]
```

嵌入视图拥有与标签页完全相同的工具栏。在嵌入视图中所做的修改会保存到查询文件中，因此所有嵌入了该文件的笔记都会同步体现。选择 <UiLabel name={m.query_view_open_file()} /> 可在标签页中打开该文件。嵌入视图支持阅读视图（Reading view）、实时预览（Live Preview）以及悬停浮窗。

要显示当前笔记自身对应文献的标注，可以在视图的筛选器中使用 `this.item`：

```yaml
filters: item == this.item
```

在文献笔记中，`this.item` 代表笔记属性 `zotero-key` 所指定的文献。如果该文献所属的文库超出了你的 <UiLabel name={m.settings_library_scope_name()} /> 设置范围，嵌入内容将显示 <UiLabel name={m.query_view_warning_outside_library_scope()} />。详见 [`this`：笔记所属文献](/docs/reference/how-queries-work#this)。

当视图使用了 `this.item` 或 `this.attachment` 但缺少有效上下文时（例如在独立的查询文件标签页或未关联文献的普通笔记中），视图会显示提示说明应在何处打开它。

## 在笔记中添加查询块 [#block]

查询块无需创建独立文件，即可将实时视图直接嵌入在单篇笔记中。输入语言为 `zotquery` 的代码块：

````md
```zotquery
views:
  - type: annotations
    name: Yellow highlights
    from: annotations
    filters: item == this.item && colorName == "yellow"
```
````

该代码块会渲染出视图及其工具栏。在工具栏中进行的任何修改（例如更改排序、添加筛选或选择属性）都会自动更新笔记中的代码块文本。当代码块通过章节嵌入或悬停浮窗显示时同样有效。如果在此期间笔记文本发生了变动，代码块会显示 <UiLabel name={m.query_block_save_failed()} />。此时重新打开笔记即可刷新视图。

[查询文件格式](/docs/reference/query-file-format)列出了所有可配置的字段键名。

### 文献笔记中的查询块 [#literature-note-block]

默认文献笔记模板会在 Annotations 标题下方放置一个查询块。该查询块会显示该笔记对应文献的标注。使用较早版本创建的文献笔记将在下次更新时获得该查询块。处于 Zotero 回收站中的文献不会在其中显示标注。参见[默认模板](/docs/reference/templates/defaults#content-template)。

## 将标注侧边栏另存为查询文件 [#save-sidebar]

侧边栏的 <UiLabel name={m.annot_view_name()} /> 在其 <UiLabel name={m.annot_view_more_tooltip()} /> 菜单（⋮）中提供了更多视图控件：

| 菜单项                                               | 作用                                                                                   |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------- |
| <UiLabel name={m.annot_view_sort()} />               | 按标注的某个属性对卡片进行正向或反向排序。                                             |
| <UiLabel name={m.annot_view_group_by()} />           | 按颜色或标签对卡片进行分组，或者选择 <UiLabel name={m.annot_view_group_by_none()} />。 |
| <UiLabel name={m.annot_view_filter()} />             | 打开侧边栏的筛选器编辑器。                                                             |
| <UiLabel name={m.annot_view_save_as_query_file()} /> | 将侧边栏当前显示的内容另存为新的查询文件。在侧边栏显示条目时可用。                     |

要将侧边栏的筛选状态保存为文件：

<Steps>
  <Step>
    ### 打开对话框 [#open-the-dialog]

    在侧边栏中，打开 <UiLabel name={m.annot_view_more_tooltip()} /> 并选择 <UiLabel name={m.annot_view_save_as_query_file()} />。

  </Step>
  <Step>
    ### 命名文件 [#name-the-file]

    输入 <UiLabel name={m.annot_view_save_name_label()} /> 并选择 <UiLabel name={m.annot_view_save_folder_label()} />。

  </Step>
  <Step>
    ### 选择文件中显示的标注 [#choose-which-annotations-the-file-shows]

    在 <UiLabel name={m.annot_view_save_records_label()} /> 下选择一项：

    - <UiLabel name={m.annot_view_save_records_this_item()} />：显示侧边栏当前展示的附件的标注。如果侧边栏显示的是条目且未选择附件，则该文件显示该条目的标注。
    - <UiLabel name={m.annot_view_save_records_note_item()} />：显示嵌入该文件的各篇笔记所对应文献的标注。适用于需要嵌入到多篇文献笔记中的查询文件。

  </Step>
  <Step>
    ### 保存 [#save-1]

    选择 <UiLabel name={m.annot_view_save_action()} />。ZotLit 会创建该文件并在标签页中打开。该文件会保留侧边栏中的排序、分组和筛选设置，包括你在侧边栏中选择的颜色、标签以及搜索文本。

  </Step>
</Steps>
