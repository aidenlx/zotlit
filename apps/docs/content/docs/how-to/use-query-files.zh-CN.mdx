要追踪阅读进度，请参阅 <LessonLink slug="track-papers-you-have-read" />。要对比多篇文献，请先参阅 <LessonLink slug="literature-review-table-from-zotero" />。

查询文件可以在标签页或笔记中实时显示 Zotero 文库中的标注、文件或文献。本页介绍如何创建查询文件、更改其视图以及进行嵌入。[查询文件与查询块](/docs/reference/how-queries-work)解释了背后的核心概念。

## 创建查询文件 [#create]

可以通过以下任一方式创建：

- 打开命令面板并运行 <Command inline name={m.command_new_query_file_name()} />。文件会存放在 Obsidian 保存新笔记的文件夹中。
- 在文件列表中右键点击某个文件夹（或该文件夹中的文件），然后选择 <UiLabel name={m.query_file_new()} />。

ZotLit 会创建一个名为 `Untitled.zotquery` 的文件并在标签页中打开。在选择菜单项时按住 `Ctrl`（Windows 和 Linux）或 `Command`（macOS）可在新标签页中打开。重命名该文件的方式与重命名普通笔记相同。

新建的文件包含两个视图：

- <UiLabel name={m.query_file_items_view_name()} />
  是默认视图。它以表格形式列出整个文库中的文献，按修改日期降序排列（最新的排在最前），每次最多显示
  100 条。它包含
  <UiLabel name={m.query_view_property_title()} />、
  <UiLabel name={m.query_view_property_creators()} />、
  <UiLabel name={m.query_view_property_year()} /> 和
  <UiLabel name={m.query_view_table_literature_note()} /> 列。
- <UiLabel name={m.query_file_annotations_view_name()} />
  显示整个文库的标注，按文献分组，每次最多显示 100 条。

要查看标注，请打开视图菜单并选择 <UiLabel name={m.query_file_annotations_view_name()} />。请参阅[切换、添加和排列视图](#view-menu)。

## 管理视图 [#views]

文件顶部的工具栏从左到右包含以下控件：

| 控件                                         | 说明                                                                         |
| -------------------------------------------- | ---------------------------------------------------------------------------- |
| 视图菜单                                     | 显示当前视图。在此切换、添加和配置视图。                                     |
| 结果数量                                     | 显示匹配的记录数。打开 <UiLabel name={m.query_view_results_menu()} /> 菜单。 |
| <UiLabel name={m.query_view_filter()} />     | 选择视图显示的记录。                                                         |
| <UiLabel name={m.query_view_sort()} />       | 设置各行的排序方式。                                                         |
| <UiLabel name={m.query_view_group()} />      | 将各行归集到不同分组标题下。                                                 |
| <UiLabel name={m.query_view_properties()} /> | 选择每行显示的属性值。                                                       |
| <UiLabel name={m.query_view_search()} />     | 在当前屏幕显示的各行中查找文本。                                             |

在较窄的面板中，工具栏仅显示图标而不显示文本标签。

### 切换、添加和排列视图 [#view-menu]

点击视图菜单可以查看文件中的所有视图。在 <UiLabel name={m.query_view_search_views()} /> 中输入内容可按名称查找视图，然后点击选择。

- 要添加视图，请选择 <UiLabel name={m.query_view_add_view()} />。ZotLit 会打开 <UiLabel name={m.query_view_configure_view()} /> 页面以便为其命名。
- 要更改视图顺序，请在列表中拖动视图。
- 要将某个视图设为默认视图，请打开其 <UiLabel name={m.query_view_configure_view()} /> 页面，点击 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_default_view()} />。默认视图会移至列表顶部。未指定视图名称的嵌入内容将默认显示此视图。
- 要复制或删除视图，请打开其 <UiLabel name={m.query_view_configure_view()} /> 页面，点击 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_duplicate_view()} /> 或 <UiLabel name={m.query_view_delete_view()} />。

### 配置视图 [#configure]

打开视图菜单。在某个视图对应的行上，点击带有提示文本 <UiLabel name={m.query_view_configure_view()} /> 的箭头按钮。你也可以右键点击该行，或者右键点击工具栏上的视图菜单按钮来配置当前显示的视图。<UiLabel name={m.query_view_configure_view()} /> 页面会在同一菜单中打开。每项更改都会即时保存。离开输入框时会自动保存视图名称。

| 设置项                                      | 说明                                                     |
| ------------------------------------------- | -------------------------------------------------------- |
| <UiLabel name={m.query_view_view_name()} /> | 在视图菜单中以及嵌入语法中 `#` 后面显示的名称。          |
| <UiLabel name={m.query_view_dataset()} />   | 每行代表的数据类型：单条标注、单个附件或单个条目。       |
| <UiLabel name={m.query_view_layout()} />    | 视图呈现各行的方式。列表中仅提供支持所选记录类型的布局。 |

更改记录类型时，原有的排序、分组和属性配置仍会保留在文件中。新记录类型中不存在的配置会被视图忽略。<UiLabel name={m.query_view_sort()} />、<UiLabel name={m.query_view_group()} /> 和 <UiLabel name={m.query_view_properties()} /> 会将它们标记为 <UiLabel name={m.query_view_not_used()} />，工具栏下方也会显示提示列出这些配置项。当切回支持它们的记录类型时，视图会重新应用这些配置。

每种布局都提供独立的选项：

| 布局                                                 | 选项                                                                                                                                                                                   |
| ---------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <UiLabel name={m.query_view_layout_annotations()} /> | <UiLabel name={m.query_view_card_width()} />、<UiLabel name={m.query_view_show_comment()} />、<UiLabel name={m.query_view_show_tags()} />、<UiLabel name={m.query_view_show_page()} /> |
| <UiLabel name={m.query_view_layout_list()} />        | <UiLabel name={m.query_view_list_markers()} />、<UiLabel name={m.query_view_list_indent_properties()} />、<UiLabel name={m.query_view_list_property_separator()} />                    |
| <UiLabel name={m.query_view_layout_cards()} />       | <UiLabel name={m.query_view_card_size()} />                                                                                                                                            |
| <UiLabel name={m.query_view_layout_table()} />       | 列顺序和列宽可直接在表头上调整（参见[使用表格布局](#table)）。                                                                                                                         |

## 筛选记录 [#filter]

点击 <UiLabel name={m.query_view_filter()} />。筛选编辑器分为两部分：

- <UiLabel name={m.query_view_filter_all_views()} />
  ：应用于该文件中与首个视图显示相同记录类型的所有视图。
- <UiLabel name={m.query_view_filter_this_view()} />
  ：仅应用于当前屏幕上显示的视图。

<Steps>
  <Step>
    ### 添加条件 [#add-a-condition]

    点击 <UiLabel name={m.workbench_match_add_condition()} />。新添加的一行显示为 <UiLabel name={m.workbench_match_value_empty()} />，在填入值之前不会产生筛选效果。选择一个属性、运算符和取值。例如，选择 <UiLabel name={m.workbench_filter_field_color()} />、<UiLabel name={m.workbench_filter_op_is()} /> 和 <UiLabel name={m.workbench_filter_color_yellow()} /> 可以找出关键高亮。在条目视图中，选择 <UiLabel name={m.workbench_filter_field_year()} />、<UiLabel name={m.workbench_filter_op_on_or_after()} /> 并输入 `2020` 可以找出近年出版的文献。

    属性列表中包含了该视图记录的所有 Zotero 字段，常用字段排在最前。在列表的搜索框中输入即可查找属性。输入英文或中文常用词也能检索到属性：输入 `journal` 或 `期刊` 可以找到出版物字段，输入 `summary` 可以找到摘要。这些词仅用于辅助查找属性。筛选器最终保存的是属性本身的名称，例如 `publicationTitle`。

  </Step>
  <Step>
    ### 组合条件 [#combine-conditions]

    选择 <UiLabel name={m.workbench_match_match_all()} /> 显示匹配全部条件的记录，选择 <UiLabel name={m.workbench_match_match_any()} /> 显示至少匹配一项的记录，或者选择 <UiLabel name={m.workbench_match_match_none()} /> 隐藏匹配该组中任意条件的记录。点击 <UiLabel name={m.workbench_match_add_group()} /> 可以在已有分组中嵌套新的条件分组（例如：找出黄色高亮，且同时带有 `#theory` 或 `#method` 标签的记录）。

  </Step>
  <Step>
    ### 调整条件顺序 [#arrange-conditions]

    拖动任意条件或分组上的手柄（<UiLabel name={m.workbench_drag_to_reorder()} />）即可上下移动。你可以在分组内拖动条件、拖入嵌套分组或拖出到父级分组。你也可以选中手柄并按 `Alt+Arrow Up` 或 `Alt+Arrow Down` 移动该行。

    要移除条件，删除对应的行即可。删除嵌套分组中的最后一行时，该分组也会一并被移除。删除筛选器中的最后一行时，整个筛选器也会被移除。

  </Step>
  <Step>
    ### 查看结果 [#check-the-result]

    视图会在编辑时实时刷新。结果数量会显示最新的匹配记录数。

  </Step>
</Steps>

可用属性取决于视图的记录类型。标注视图提供每条标注的颜色、标签、评论、文本、页码和日期。所有视图都提供文献的标题、创建者、第一作者、年份、条目类型、分类和文库。标注和附件视图还提供文件的标题和文件类型。条目视图还提供文献笔记的属性，如[追踪阅读状态](/docs/how-to/track-reading-status#filter)中所示。

要将条件编写为[筛选表达式](/docs/reference/how-queries-work#steps)，请在该行上点击 <UiLabel name={m.workbench_match_edit_as_expression()} />。筛选表达式编辑器会对字段名、函数、数字和字符串应用语法高亮。输入时，自动补全会提示可用字段和函数（按 `Tab` 或 `Enter` 插入），参数提示会显示预期的参数，波浪线会立即标出语法错误。点击 <UiLabel name={m.workbench_match_edit_visually()} /> 可返回可视化条件行。

## 排序与分组 [#sort-group]

### 排序 [#sort]

点击 <UiLabel name={m.query_view_sort()} />，然后点击 <UiLabel name={m.query_view_sort_add()} />。选择一个属性和排序方向，例如日期的 <UiLabel name={m.query_view_sort_new_old()} />。可以添加多个属性以解决并列情况。拖动属性可调整优先级：排在前面的属性优先排序。

可用属性取决于视图的记录类型：

| 记录类型 | 排序属性                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| 标注     | 在文件中的位置、页码、日期、颜色、标注类型，以及文献标题、第一作者、日期，还有文件标题和添加日期             |
| 附件     | 标题、日期，以及文献标题、第一作者和日期                                                                     |
| 条目     | 标题、第一作者、日期、添加和修改日期、条目类型，以及[文献笔记](/docs/how-to/track-reading-status#sort)的属性 |

### 分组 [#group]

点击 <UiLabel name={m.query_view_group()} />，然后在 <UiLabel name={m.query_view_group_by()} /> 中选择一个属性：

| 记录类型 | 分组属性                                                                                                                                                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标注     | <UiLabel name={m.query_view_property_item()} />、<UiLabel name={m.query_view_property_attachment()} />、<UiLabel name={m.query_view_property_color()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} /> |
| 附件     | <UiLabel name={m.query_view_property_item()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} />                                                                                                          |
| 条目     | <UiLabel name={m.query_view_property_item_type()} />、<UiLabel name={m.query_view_property_tag()} />、<UiLabel name={m.query_view_property_collection()} />                                                                                                     |

然后选择分组的排列顺序：

- <UiLabel name={m.query_view_sort_az()} /> 或
  <UiLabel name={m.query_view_sort_za()} /> 按属性值对各分组排序。
- <UiLabel name={m.query_view_group_manual()} />
  会列出所有分组。勾选或取消勾选分组的复选框可以显示或隐藏该分组，拖动分组可以调整显示位置。例如，可以仅显示黄色和红色分组以专注文写作任务。

带有多个标签或分类的记录会出现在其所属的每个分组中。没有属性值的记录会显示在 <UiLabel name={m.query_view_group_none()} /> 下。在标注、列表和卡片布局中，点击分组标题可以折叠其下的各行。

## 选择属性 [#properties]

点击 <UiLabel name={m.query_view_properties()} />。勾选或取消勾选属性复选框可以显示或隐藏该属性，拖动属性可以调整其显示位置。在 <UiLabel name={m.query_view_properties_search()} /> 中输入内容可以查找属性。若要添加列表中未包含的属性，请输入其路径（例如 `item.citationKey`），然后点击新增该属性的行。在条目视图中，菜单还支持添加文献笔记的属性。请参阅[追踪阅读状态](/docs/how-to/track-reading-status#add-column)。

点击任意属性行上的箭头按钮（或按向右箭头键）可以打开其设置页面，在此处可以设置[显示名称](#display-names)或编辑[公式](#formulas)。

表格、列表和卡片布局会按此顺序显示这些属性。复制和导出 CSV 时也会将它们作为各列输出。

## 添加公式 [#formulas]

公式是由 ZotLit 根据其他属性为每一行计算得出的一种属性。它采用与筛选条件相同的[筛选表达式](/docs/reference/how-queries-work#steps)语言。例如，公式可以显示每篇文献的年份，或者其作者的人数。

若要在条目视图中显示每篇文献的年份：

<Steps>
  <Step>
    ### 打开公式页面 [#open-the-formula-page]

    点击 <UiLabel name={m.query_view_properties()} />，然后点击 <UiLabel name={m.query_view_formula_add()} />。新建公式页面会在同一菜单中打开。

  </Step>
  <Step>
    ### 为公式命名 [#name-the-formula]

    在 <UiLabel name={m.query_view_formula_name()} /> 中输入 `year`。名称由字母、数字和下划线组成，且必须以字母或下划线开头。名称区分大小写。视图会将该属性命名为 `formula.year`。

  </Step>
  <Step>
    ### 编写表达式 [#write-the-expression]

    在 <UiLabel name={m.query_view_formula_expression()} /> 中输入 `date.year`。标签旁边的勾选标记表示文本没有语法错误。当存在语法错误时，相应位置会显示警告图标，输入框下方会显示错误原因。

  </Step>
  <Step>
    ### 保存 [#save]

    点击 <UiLabel name={m.query_view_formula_save()} />。视图会在其他属性之后显示这个新属性，并列出每篇文献的年份。页面会切换至该新公式的设置页面。

  </Step>
</Steps>

文件会将公式保存在顶层的 `formulas` 键下，文件中的每个视图都可以显示它。若要按公式进行筛选，请在筛选编辑器中的某个条件上点击 <UiLabel name={m.workbench_match_edit_as_expression()} />，然后输入例如 `formula.year >= 2020`。一个公式也可以引用另一个公式，例如 `formula.year + 1`。

若要修改公式，请点击 <UiLabel name={m.query_view_properties()} />。在对应的行上，点击带有提示文本 <UiLabel name={m.query_view_property_edit()} /> 的箭头按钮，或按向右箭头键。公式页面会在同一菜单中打开。在 <UiLabel name={m.query_view_formula_expression()} /> 中修改表达式。在停止输入且无语法错误后，内容很快会自动保存。公式名称保持不变：若要使用新名称，请删除该公式并重新添加。点击 <UiLabel name={m.query_view_back()} /> 可返回列表。

若要删除公式，请打开其页面，点击 <UiLabel name={m.query_view_more_options()} />（…），然后选择 <UiLabel name={m.query_view_formula_remove()} />。ZotLit 会从该文件的所有视图中移除该公式并返回列表。仍在使用该公式的筛选条件会报错，直到你进行修改。

### 当公式存在错误时 [#formula-errors]

无法被 ZotLit Query 运行的公式（例如 `title * 2`）会在 <UiLabel name={m.query_view_properties()} /> 的对应行以及表格布局的列头上显示警告图标。悬停在图标上可查看具体原因。视图中的其他属性仍会正常显示。如果某个公式引用了错误的公式，它会显示出错公式的名称。当视图的筛选条件引用了错误的公式时，视图会显示错误且不显示任何行，直到你将其修正。

公式可能对大多数行有效，但对某一行失败。例如，对于期刊卷号为文本（如 "Spring"）的文献，`number(volume)` 计算会失败。该行会在其单元格中显示警告图标，并在悬停提示中显示原因。复制和导出 CSV 时会在该单元格中写入 `Error: ` 及具体原因。没有卷号的文献则显示为空白单元格。[错误值](/docs/reference/how-queries-work#error-values)解释了这两者的区别。

## 重命名属性 [#display-names]

显示名称用于在视图中替换属性的路径。例如，属性 `formula.year` 可以显示为“Year of source”。

<Steps>
  <Step>
    ### 打开属性页面 [#open-the-property-page]

    点击 <UiLabel name={m.query_view_properties()} />。在 `formula.year` 所在行上，点击带有提示文本 <UiLabel name={m.query_view_property_edit()} /> 的箭头按钮。

  </Step>
  <Step>
    ### 输入名称 [#type-the-name]

    在 <UiLabel name={m.query_view_display_name()} /> 中输入 `Year of source`。离开输入框、按 `Enter`、点击 <UiLabel name={m.query_view_back()} /> 或关闭菜单时，名称会自动保存。

  </Step>
</Steps>

表格表头、卡片标签、<UiLabel name={m.query_view_properties()} /> 中的各行，以及复制和 CSV 导出的表头行都会显示为“Year of source”。显示名称适用于该文件中的所有视图。添加新公式时，你也可以在 <UiLabel name={m.query_view_display_name()} /> 中直接设置它。

若要恢复默认名称，清空该输入框即可。在没有设置显示名称时，属性会显示其字段名称（例如标题）或其路径。

## 限制、复制和导出结果 [#results]

点击结果数量可打开 <UiLabel name={m.query_view_results_menu()} /> 菜单：

- <UiLabel name={m.query_view_limit()} />
  ：设置显示的最大行数。清空输入框或选择
  <UiLabel name={m.query_view_show_all({ count: 250 })} /> 可显示全部匹配项。
  当匹配的记录数超过视图显示数量时，结果计数会同时显示两个数字，例如
  <UiLabel name={m.query_view_results_limited({ count: 250, shown: 100 })} />。
- <UiLabel name={m.query_view_copy()} />
  ：以表格形式将当前显示的各行中可见的列复制到剪贴板。 可将其作为 Markdown
  表格粘贴到 Obsidian 笔记中，或粘贴到 Microsoft Excel、Google Sheets 或 Apple
  Numbers 等电子表格软件中。
- <UiLabel name={m.query_view_export_csv()} />
  ：将当前显示的各行中可见的列保存为 CSV 文件。
  该文件采用带有字节顺序标记（BOM）的 UTF-8 编码，以便 Excel 以及 R 或 SPSS
  等统计软件能够正常显示多语言标题与作者姓名。

复制和 CSV 导出均仅包含视图中显示的属性，并保持其可见顺序。界面按钮（如 <UiLabel name={m.query_view_table_literature_note()} /> 列）会被自动忽略。

## 搜索记录 [#search]

点击 <UiLabel name={m.query_view_search()} /> 并输入文本。视图会仅显示当前屏幕中包含该文本的行。搜索不会修改文件内容。清空输入框即可重新查看所有行。

## 使用表格布局 [#table]

表格布局在网格中展示文献，类似于 Zotero 的主条目列表。若要使用该布局，请在 <UiLabel name={m.query_view_configure_view()} /> 中将记录类型设置为条目，然后选择 <UiLabel name={m.query_view_layout_table()} />。

### 查看文件、笔记和标注 [#table-expand]

在任意文献上点击 <UiLabel name={m.query_view_table_expand()} /> 即可展开其附加文件、子笔记和标注。展开某个附件可查看其具体标注。

表格单元格中的附件标题和标注文本均可点击：

- 点击 PDF 附件可在 Obsidian 的 PDF 阅读器中打开该文件。
- 点击标注可直接打开 PDF 跳转至对应页面并高亮该标记。
- 点击其他任意文件类型可在 Zotero 中打开。

点击链接时按住 `Ctrl`（Windows 和 Linux）或 `Command`（macOS）可在新标签页中打开。

### 排列和调整列宽 [#table-columns]

可以直接在视图中调整表格列：

- 左右拖动表头可更改列顺序。
- 拖动两个表头之间的边框可调整列宽。
- 双击两个表头之间的边框可恢复该列的自动宽度。
- 点击或右键点击任意表头可打开其菜单。菜单提供 <UiLabel name={m.query_view_table_move_column_left()} />、<UiLabel name={m.query_view_table_move_column_right()} /> 和 <UiLabel name={m.query_view_table_reset_column_width()} />。

调整后的列宽会自动保存在查询文件中。

### 文献笔记列 [#table-literature-note]

<UiLabel name={m.query_view_table_literature_note()} /> 列用于在 Obsidian
中打开文献对应的文献笔记。当文献尚未创建文献笔记时，点击
<UiLabel name={m.query_view_table_create_note()} /> 即可新建。

该列的表现与普通属性一致：你可以在 <UiLabel name={m.query_view_properties()} /> 中对其进行显示、隐藏、移动或重命名。复制和导出 CSV 时会自动忽略该列。

## 在笔记中嵌入查询文件 [#embed]

在任意笔记中输入嵌入链接：

```md
![[Figures.zotquery]]
```

嵌入内容会显示默认视图。若要显示其他视图，请在 `#` 后加上其名称：

```md
![[Figures.zotquery#Yellow highlights]]
```

嵌入内容拥有与独立标签页相同的工具栏。在嵌入视图中所做的更改会直接保存到查询文件中，因此嵌入该文件的所有笔记都会同步显示。点击 <UiLabel name={m.query_view_open_file()} /> 可在标签页中打开该文件。嵌入功能支持在阅读视图、实时预览以及悬停预览框中使用。

若要仅显示笔记所属文献的标注，请在视图筛选器中使用 `this.item`：

```yaml
filters: item == this.item
```

在文献笔记中，`this.item` 指代笔记的 `zotero-key` 属性所指定的文献。当该文献所属的文库超出你的 <UiLabel name={m.settings_library_scope_name()} /> 设置范围时，嵌入视图会显示 <UiLabel name={m.query_view_warning_outside_library_scope()} />。请参阅 [`this`：笔记所属文献](/docs/reference/how-queries-work#this)。

当视图在没有活动上下文的情况下使用 `this.item` 或 `this.attachment` 时（例如在独立的查询文件标签页或未关联文献的笔记中），视图会显示提示说明应在何处打开它。

## 在笔记中添加查询块 [#block]

查询块可以在单篇笔记内保持实时视图，而无需创建独立文件。输入语言为 `zotquery` 的代码块：

````md
```zotquery
views:
  - type: annotations
    name: Yellow highlights
    from: annotations
    filters: item == this.item && colorName == "yellow"
```
````

该代码块会呈现视图及其工具栏。在工具栏中进行的任何更改（如更改排序顺序、添加筛选条件或选择属性），都会自动重写笔记中的代码块文本。当代码块通过分节嵌入或悬停预览框显示时同样有效。如果在此期间笔记文本发生了变化，代码块会显示 <UiLabel name={m.query_block_save_failed()} />。重新打开笔记即可刷新视图。

[查询文件格式](/docs/reference/query-file-format)列出了所有可配置的键名。

### 文献笔记中的查询块 [#literature-note-block]

默认文献笔记模板会在标注标题下方放置一个查询块。该查询块显示当前笔记所属文献的标注。使用较早版本创建的文献笔记在下次更新时会获得该查询块。Zotero 回收站中的文献在此处不会显示标注。请参阅[默认模板](/docs/reference/templates/defaults#content-template)。

## 将标注侧边栏另存为查询文件 [#save-sidebar]

侧边栏 <UiLabel name={m.annot_view_name()} /> 的 <UiLabel name={m.annot_view_more_tooltip()} /> 菜单（⋮）中提供了更多视图控件：

| 菜单项                                               | 说明                                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------- |
| <UiLabel name={m.annot_view_sort()} />               | 按标注的某个属性以升序或降序对卡片排序。                                           |
| <UiLabel name={m.annot_view_group_by()} />           | 按颜色或标签对卡片分组，或者选择 <UiLabel name={m.annot_view_group_by_none()} />。 |
| <UiLabel name={m.annot_view_filter()} />             | 打开侧边栏的筛选编辑器。                                                           |
| <UiLabel name={m.annot_view_save_as_query_file()} /> | 将侧边栏当前显示的内容另存为新的查询文件。在侧边栏显示条目时可用。                 |

若要将侧边栏的筛选保留为文件：

<Steps>
  <Step>
    ### 打开对话框 [#open-the-dialog]

    在侧边栏中打开 <UiLabel name={m.annot_view_more_tooltip()} />，然后选择 <UiLabel name={m.annot_view_save_as_query_file()} />。

  </Step>
  <Step>
    ### 命名文件 [#name-the-file]

    输入 <UiLabel name={m.annot_view_save_name_label()} /> 并选择 <UiLabel name={m.annot_view_save_folder_label()} />。

  </Step>
  <Step>
    ### 选择文件显示的标注 [#choose-which-annotations-the-file-shows]

    在 <UiLabel name={m.annot_view_save_records_label()} /> 下，选择以下一项：

    - <UiLabel name={m.annot_view_save_records_this_item()} />：侧边栏当前显示的附件的标注。当侧边栏显示未选择附件的条目时，文件会显示该条目的标注。
    - <UiLabel name={m.annot_view_save_records_note_item()} />：嵌入该文件的每篇笔记所属文献的标注。如果要将文件嵌入到多个文献笔记中，请使用此选项。

  </Step>
  <Step>
    ### 保存 [#save-1]

    点击 <UiLabel name={m.annot_view_save_action()} />。ZotLit 会创建该文件并在标签页中打开。该文件会保留侧边栏的排序、分组和筛选器，包括在侧边栏中选择的颜色、标签和搜索文本。

  </Step>
</Steps>
