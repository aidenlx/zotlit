## Open a note with the quick switcher [#quick-switcher]

1. Open the command palette (`Ctrl+P` on Windows and Linux, `Cmd+P` on macOS) and run <Command inline name={m.command_open_lit_note_name()} />. A search box opens over a list of papers. With nothing typed, the list shows papers by last activity, newest first. When the search covers more than one Zotero library, each row names its library.
2. Type to search your library, then move to the paper with the arrow keys. The list narrows to matching papers.
3. Press `Enter`. The paper's literature note opens. If the paper had no note, ZotLit writes it first: a short notice reads <UiLabel name={m.notice_creating_note()} />, followed by <UiLabel name={m.notice_created_note()} />

Pressing `Ctrl+Enter` (`Cmd+Enter` on macOS) opens the note in a new pane, `Shift+Enter` opens the paper's PDF instead, and `Esc` closes the switcher. The full list of shortcuts is in the [Quick switcher reference](/docs/reference/commands#quick-switcher).

A literature note is written only when the paper has none; opening an existing note leaves your text intact. What you write in the note stays yours: with the current default template, updating a note later refreshes its properties and leaves your body text alone, while the annotations section updates automatically.

<Accordion title="ZotLit asks which profile to use" id="choose-profile">

This prompt appears only when you have created additional note profiles. With only the Default profile, ZotLit writes the note immediately without asking.

- **One profile matches the paper:** ZotLit writes the note with that profile; the notice names the match.
- **Several match, or none match:** A picker opens. Select the profile to use for this note, or close the picker to cancel without creating a note.

Inside the picker, a matching profile displays the badge <UiLabel name={m.modal_profile_match_candidate()} />. When no profile matches, **Default** is preselected. When multiple profiles match, the search box displays <UiLabel name={m.modal_profile_overlap_placeholder()} />.

To create a profile and configure when it applies, see [Use different templates](/docs/how-to/use-different-templates). Details on how a profile is chosen are in the [Profile match reference](/docs/reference/settings#profile-match).

<Accordion title="From a citation in your draft" id="from-citation">

A Pandoc citation in your draft looks like `@key` or `[@key]` (as well as `[@key, p. 3]` or `[@a; @b]`).

To open notes directly from citations, go to <SettingsPath page={m.settings_page_citations()} /> and turn on <UiLabel name={m.settings_citation_open_as_links_name()} /> (off by default). Ensure <UiLabel name={m.settings_citation_pandoc_citations_name()} /> is also enabled (on by default).

| View         | What to do                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| Live Preview | Click the citation.                                                                                   |
| Source mode  | `Ctrl`-click the citation key (`Cmd`-click on macOS). A plain click places the cursor.                |
| Reading view | Click the citation. One paper opens its note; a citation with multiple papers opens a selection menu. |

The note opens immediately, or ZotLit creates it first if no note exists yet. Alternatively, place the cursor on any citation key and run <Command inline name={m.command_open_citekey_name()} />.

ZotLit resolves the key against Zotero's Citation Key field across all libraries chosen in your [<UiLabel name={m.settings_library_scope_name()} />](/docs/reference/settings#library-scope). See [Citation links](/docs/reference/citation-links) for supported syntax and lookup rules.

</Accordion>

<Accordion title="Several papers at once" id="bulk">

Creating notes in bulk from Zotero requires the ZotLit Companion add-on. The Obsidian command requires no extra setup.

| Which papers                        | What to do                                                                                                                                                                                                                                                       |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Papers you select in Zotero         | Right-click the selection → <UiLabel name={m["zotero.menu_submenu.label"]()} /> → <UiLabel name={m["zotero.menu_item_update.label"]({ count: 2 })} /> (with one paper selected, this reads <UiLabel name={m["zotero.menu_item_update.label"]({ count: 1 })} />). |
| One collection                      | In Zotero, right-click the collection → <UiLabel name={m["zotero.menu_submenu.label"]()} /> → <UiLabel name={m["zotero.menu_collection_update_all.label"]()} />. All subcollections are included.                                                                |
| A whole Zotero library              | In Zotero, right-click **My Library** or a group library → <UiLabel name={m["zotero.menu_submenu.label"]()} /> → <UiLabel name={m["zotero.menu_collection_update_all.label"]()} />. Covers that library regardless of your library scope.                        |
| Every library in your library scope | In Obsidian, run <Command inline name={m.command_update_all_notes_name()} />.                                                                                                                                                                                    |

In each case, Obsidian opens a confirmation dialog showing which notes will be created and which will be updated. Review the list and confirm to proceed.

When you have multiple profiles configured, the confirmation window includes a profile selector for newly created notes (see [Batch profiles](/docs/reference/settings#batch-profiles)). To see how existing notes are affected, see [Keep notes updated](/docs/how-to/keep-notes-updated).

## If you see something else

- **A notice: <UiLabel name={m.notice_citekey_not_found({ citekey: "key" })} />** No item in your library scope has this key in Zotero's Citation Key field. Verify which libraries are active under [<UiLabel name={m.settings_library_scope_name()} />](/docs/reference/settings#library-scope).
- **A notice: <UiLabel name={m.notice_citekey_db_unavailable({ citekey: "key" })} />** ZotLit cannot access the Zotero database file. See [Database unavailable](/docs/reference/settings#database-unavailable) to restore the connection.
- **Clicking a citation only puts the cursor in it.** <UiLabel name={m.settings_citation_open_as_links_name()} /> is disabled. Enable it under <SettingsPath page={m.settings_page_citations()} />, or use `Ctrl`-click (`Cmd`-click on macOS) on the key.
- **A list asks which paper you mean.** More than one item shares that citation key. Each row shows its library and item key; select the correct entry to open its note. See [Ambiguous citation keys](/docs/reference/citation-links#ambiguous-key).
- **A picker of profiles opens.** You have configured multiple profiles and ZotLit cannot pick one automatically. Select a profile from the list, or review the [profile selection fold-out](#choose-profile) above.
- **Zotero says the selection is too large, or asks to enable a server.** Large batches transfer to Obsidian through ZotLit's local server. In Obsidian, go to <SettingsPath page={m.settings_page_advanced()} /> and turn on the server in the <UiLabel name={m.settings_advanced_local_server_heading()} /> group, or select fewer papers at once. See [Set up live updates](/docs/how-to/set-up-live-updates).
- **Zotero asks for confirmation each time it opens Obsidian.** This prompt is Zotero's default security check for opening `obsidian://` links. See [Suppress Zotero security prompt](/docs/how-to/suppress-zotero-security-prompt).
