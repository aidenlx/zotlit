## Migrate the workflow

Your existing citations stay as written: nothing in your notes has to change except `[[@citekey]]` links and some note properties. Keep your original notes or a backup copy until you check a note at the end.

1. In Zotero, check that every paper you cite has a citation key in its **Citation Key** field. Each cited paper shows a key. Choose your key format before migrating notes, and keep existing keys after the move.
2. Open <SettingsPath page={m.settings_page_zotero()} />. Check that <UiLabel name={m.settings_db_file_name()} /> points to the Zotero profile that holds your cited papers. The database path is the one with your library.
3. On the same page, under <UiLabel name={m.settings_zotero_libraries_heading()} />, set <UiLabel name={m.settings_library_scope_name()} /> to <UiLabel name={m.settings_library_scope_all()} />, or choose <UiLabel name={m.settings_library_scope_selected()} /> and add the personal and group libraries you used before. ZotLit searches all of those libraries at once.
4. Open <SettingsPath page={m.settings_page_citations()} />. Keep <UiLabel name={m.settings_citation_pandoc_citations_name()} /> and <UiLabel name={m.settings_citation_show_formatted_name()} /> on. Under <UiLabel name={m.settings_citation_references_heading()} />, install the <UiLabel name={m.settings_citation_engine_name()} />. The engine is installed.
5. Install your former CSL style in Zotero. Then open <SettingsPath /> and select that style under <UiLabel name={m.settings_citation_references_style_name()} />. Citations in Live Preview use that style.
6. Back in <SettingsPath page={m.settings_page_citations()} />, under <UiLabel name={m.settings_citation_references_heading()} />, set <UiLabel name={m.settings_citation_locale_name()} /> to your language, or leave it empty to keep <UiLabel name={m.settings_citation_locale_default()} />. Citation terms and dates follow that language.
7. If you used citation-key tooltips, set <UiLabel name={m.settings_citation_hover_action_name()} /> to <UiLabel name={m.settings_citation_hover_action_popover()} />. Hovering a citation shows its reference entry.
8. Search the vault for `[[@`. Change each one by hand. No `[[@` link is left that you did not mean.
9. In **Settings > Community plugins**, turn off Pandoc Reference List. Keep a record of its settings first. Only ZotLit changes how citations look.
10. Open a note that uses your citations and note properties. Check that its citations show formatted in Live Preview. Run <Command inline name={m.command_open_references_view_name()} />, then select <UiLabel name={m.references_copy_bibliography()} /> in the <UiLabel name={m.references_view_name()} /> sidebar. The sidebar lists each cited paper, and the reference list is on your clipboard.

<Accordion title="Citation-key links ([[@citekey]])" id="citation-key-links">

Pandoc Reference List can treat `[[@doe2024]]` as a citation. ZotLit counts a `[[...]]` link as a citation only when it points to the paper's literature note.

For each link, choose:

- If it is only a citation: replace it with `[@doe2024]`.
- If it is a citation that should also open the paper's literature note: replace it with a link to that note without an alias, such as `[[Doe 2020]]` (only when `Doe 2020.md` is that paper's literature note). For a page locator, use `[[Doe 2020#cite:locator=33]]`.

After the links are updated, turn on <UiLabel name={m.settings_citation_wikilink_citations_name()} /> in <SettingsPath page={m.settings_page_citations()} />. Do this one by one: the intent and the note names differ for each link, so a vault-wide find-and-replace gets some of them wrong.

</Accordion>
<Accordion title="Note properties (bibliography, csl, lang)" id="note-properties">

| Property                  | What to do                                                                                                                                                                             |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bibliography`            | Keep it only for native Pandoc. ZotLit gets reference data directly from Zotero.                                                                                                       |
| `csl` or `citation-style` | Keep one for a style that Pandoc owns. Do not add `zotlit-csl` to the same note.                                                                                                       |
| `zotlit-csl`              | Use it when ZotLit should use a style installed in Zotero. Remove `csl` and `citation-style` first.                                                                                    |
| `lang`                    | Keep it when it is a valid document language such as `en-US`, `de`, or `zh-CN`. ZotLit uses it for that note's citations too.                                                          |
| `citation-language`       | Change it to `lang` only when the value is the language of the whole document. Otherwise set <UiLabel name={m.settings_citation_locale_name()} /> in settings and remove the property. |

To set a Zotero style and the document language together, run <Command inline name={m.command_set_citation_presentation_name()} />; it is also in the note's **More options** menu. Its <UiLabel name={m.citation_presentation_language_name()} /> becomes Pandoc `lang` for the exported document. Keep one style family per note: the ZotLit filter reports `csl-ambiguous` when a note has both `csl` and `zotlit-csl`. For details, see [Per-note citation presentation](/docs/reference/settings#citation-style).

## If you see something else

- **The References sidebar shows a Reference Error** → fix every Reference Error before you go on; see [Review, copy, and troubleshoot references](/docs/how-to/review-copy-troubleshoot-references).
- **The sidebar says "@\{citekey\} matches multiple items in your Zotero library."** → two papers share that key, in one library or in two libraries in your scope. ZotLit does not pick one by library order. Give one paper a different key in Zotero, or narrow <UiLabel name={m.settings_library_scope_name()} />; see [Ambiguous citation keys](/docs/reference/citation-links#ambiguous-key).
- **Both plugins change how the citations look** → Pandoc Reference List is still on. Turn it off in **Settings > Community plugins** and test with only ZotLit.
- **The ZotLit filter reports `csl-ambiguous`** → the note has both `csl` and `zotlit-csl`. Keep only one of them.
