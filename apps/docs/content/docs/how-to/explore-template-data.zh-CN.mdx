模板数据浏览器（Template Data Explorer）直观展示了模板在面对某篇 Zotero 条目、标注、笔记名称或引文时实际接收到的全部强类型字段。借助它，您可以快速查找字段路径、读取真实取值并将开箱即用的代码片段直接复制到模板中。

## 打开数据浏览器

数据浏览器既可以作为侧边栏面板独立呈现，也可与模板工作台视图并排展示。您可以通过多种途径打开它：

### 通过命令面板

<Steps>
  <Step>
    ### 运行命令

    打开命令面板并运行：

    <Command name={m.command_open_template_data_explorer_name()} />

    如果编辑器当前正打开着某篇文献笔记，数据浏览器将直接使用该笔记对应的 Zotero 条目。如果未处于文献笔记中，则会展示条目选取列表。

  </Step>
</Steps>

### 从文献笔记打开

在文件列表或标签页中右键单击某篇文献笔记（或点击三点菜单），选择 <UiLabel name={m.template_data_explorer_menu_explore()} />。数据浏览器将以该笔记绑定的条目为数据源直接打开。

### 从标注视图打开

在标注侧边栏中，打开任意标注卡片上的更多操作菜单，选择 <UiLabel name={m.template_data_explorer_menu_explore()} />。数据浏览器将以该条标注为根节点锚点打开。

### 从 Zotero 打开（条目）

ZotLit Companion（Zotero 配套插件）在 Zotero 中注入了这些入口。右键单击单个条目，展开 <UiLabel name={m["zotero.menu_submenu.label"]()} /> 子菜单，选择 <UiLabel name={m.template_data_explorer_menu_explore()} />。Zotero 会通过协议链接在 Obsidian 中呼出数据浏览器。

### 从 Zotero 打开（标注）

在 Zotero PDF 阅读器中，右键单击某条批注并选择由 Companion 提供的 <UiLabel name={m["zotero.menu_reader_annot_explore"]()} />。数据浏览器将在 Obsidian 中以此标注为锚点直接打开。

## 选取数据

您可以直接选择内置的期刊文章、会议论文、图书或学位论文等示例数据，或在 <UiLabel name={m.workbench_recently_updated()} /> 下选择最近更新的条目。选择 <UiLabel name={m.workbench_search_zotero()} /> 可在 Zotero 文献库中直接搜索。选中条目后，其所有字段将被完整列出。

使用 <UiLabel name={m.workbench_choose_item()} /> 可以切换条目。对于标注字段，使用 <UiLabel name={m.workbench_choose_annotation()} />。标注选取器既可从选定条目中挑选标注，也可体验高亮、下划线、笔记、文本、区域图片或手写墨迹等六个内置示例。

数据选择会联动更新其他面板。标注字段与预览采用选定的标注及其自身的父级条目数据；笔记预览则使用选定的条目。

面板标题开头展示选定的数据名称，末尾为 <UiLabel name={m.workbench_view_fields()} />。标注标题会标明类型、页码和简短摘录。全功能面板在标题栏中提供了选择操作项；侧边栏则在数据附近提供紧凑的选择控件。若要将编辑器、字段列表与预览界面并排展开，可在模板工作台视图的面板菜单中选择 <UiLabel name={m.template_workbench_open_layout()} />。

预览使用的数据会自动更新。如需重新加载，可在面板菜单中选择 <UiLabel name={m.workbench_refresh_item()} />。在 <UiLabel name={m.workbench_preview_on_demand()} /> 模式下，点击 <UiLabel name={m.workbench_preview_run()} /> 可手动触发渲染预览。

## 复制 Zotero 标识符 [#indexed-key]

Zotero 标识符（Zotero key）唯一指代一个对象：包含条目、附件、标注或笔记。当工具需要您指定操作对象时，可直接复制此标识符。

在 Obsidian 中：

- 对于当前活动的文献笔记，运行 <Command inline name={m.command_copy_item_key_name()} />，或从文件菜单中选择 <UiLabel name={m.command_copy_item_key_name()} />。
- 在标注卡片上，打开更多操作菜单并选择 <UiLabel name={m.indexed_key_menu_copy_annotation()} />。
- 在数据浏览器中，打开面板菜单并选择 <UiLabel name={m.command_copy_item_key_name()} /> 或 <UiLabel name={m.indexed_key_menu_copy_annotation()} />。标签文本会随当前面板所列的根节点类型自适应调整。

If a literature note is already open, you can also copy its `zotero-key` frontmatter value by hand.

In Zotero, the Companion adds two more entry points:

- Right-click one or more library rows and open the <UiLabel name={m["zotero.menu_submenu.label"]()} /> submenu. The entry names the kind you selected, such as <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "item" })} /> or <UiLabel name={m["zotero.menu_item_copy_key.label"]({ count: 1, kind: "attachment" })} />. Multiple rows copy one key per line.
- In the PDF reader, right-click an annotation and select <UiLabel name={m["zotero.menu_reader_annot_copy_key"]()} />.

One key is always enough. The root the pane lists decides which object it names: the note root copies the item key, the annotation root the annotation key.

## Browse the fields

The pane lists the fields of one root, grouped under section headings.

### The root the pane lists

The pane header names the root it reads: <UiLabel name={m.workbench_fields_root_note()} />, <UiLabel name={m.workbench_fields_root_annotation()} />, <UiLabel name={m.workbench_fields_root_filename()} />, or <UiLabel name={m.workbench_fields_root_citation()} />.

The root follows the part of the profile you are editing: the note body and its properties list the note root, the Annotation Section lists the annotation root, the manifest's `filename` value lists the note name root, and the Citation text lists the citation root.

The standalone explorer takes its root from the Template Workbench View beside it. When it is anchored at an annotation, a breadcrumb above the list reads <UiLabel name={m.template_data_explorer_note_root()} />, and its back button, tooltipped <UiLabel name={m.template_data_explorer_back_to_note_root()} />, returns the list to the note root.

To read one annotation's own fields from the note root, open the more-options menu on its row under `zt.annotations` and select <UiLabel name={m.workbench_explorer_menu_explore_annotation()} />.

### Sections

<UiLabel name={m.workbench_explorer_section_common()} /> leads every root and
holds the fields most templates use. A note root and a note name root group the
remaining fields under
<UiLabel name={m.workbench_explorer_section_reference()} />,
<UiLabel name={m.workbench_explorer_section_identifiers()} />,
<UiLabel name={m.workbench_explorer_section_content()} />,
<UiLabel name={m.workbench_explorer_section_organization()} />,
<UiLabel name={m.workbench_explorer_section_links()} />, and
<UiLabel name={m.workbench_explorer_section_record()} />. An annotation root
groups them under <UiLabel name={m.workbench_explorer_section_annotation()} />,
<UiLabel name={m.workbench_explorer_section_source()} />,
<UiLabel name={m.workbench_explorer_section_organization()} />,
<UiLabel name={m.workbench_explorer_section_links()} />, and
<UiLabel name={m.workbench_explorer_section_record()} />. A citation root has no
other section yet.

Select a section heading to open or close that section. The button beside the pane's selection control opens every section or closes every one, tooltipped <UiLabel name={m.workbench_explorer_expand_all()} /> or <UiLabel name={m.workbench_explorer_collapse_all()} />. The pane menu carries the same action.

Each top-level row shows a name a reader knows, and its raw path stays in the tooltip and in <UiLabel name={m.workbench_explorer_menu_copy_path()} />. Expand a row that holds an object or an array to read its members. A long value collapses to its first line until you select <UiLabel name={m.workbench_explorer_show_more()} />; <UiLabel name={m.workbench_explorer_show_less()} /> folds it back.

### Filter fields

Type in the search box to narrow the list. The box names the root it searches: <UiLabel name={m.workbench_fields_search_note()} />, <UiLabel name={m.workbench_fields_search_annotation()} />, <UiLabel name={m.workbench_fields_search_filename()} />, or <UiLabel name={m.workbench_fields_search_citation()} />.

A query matches field names, keys, and values by case-insensitive substring. Matching rows and their ancestor chains open automatically. When nothing matches, the list reads <UiLabel name={m.workbench_fields_no_matches()} />.

## Copy paths and snippets

Every row carries a menu. Open it from the row's action cluster, labelled <UiLabel name={m.workbench_explorer_row_actions()} />, or right-click the row.

### Copy path

Select <UiLabel name={m.workbench_explorer_menu_copy_path()} /> to copy the engine-neutral property path, such as `zt.creators[0].lastName`.

### Copy value

Select <UiLabel name={m.workbench_explorer_menu_copy_value()} /> to copy the row's current value. Primitives copy verbatim; objects and arrays copy as JSON. The item is unavailable while the row holds no value.

### Copy template snippets

The same menu offers ready-to-use snippets in the syntax of your template:

- <UiLabel name={m.workbench_explorer_menu_copy_output()} /> renders the value, for example `{{ zt.title }}`.
- <UiLabel name={m.workbench_explorer_menu_copy_if_present()} /> wraps the value
  in a conditional block.
- <UiLabel name={m.workbench_explorer_menu_copy_loop()} /> iterates over an
  array node.
- <UiLabel name={m.workbench_explorer_menu_copy_joined()} /> joins an array into
  a delimiter-separated string.

An array node offers <UiLabel name={m.workbench_explorer_menu_copy_loop()} />, and <UiLabel name={m.workbench_explorer_menu_copy_joined()} /> where its elements join into text. Every other node offers <UiLabel name={m.workbench_explorer_menu_copy_output()} /> and <UiLabel name={m.workbench_explorer_menu_copy_if_present()} />.

With <UiLabel name={m.settings_template_js_enable_name()} /> on, the snippet items sit in two submenus, captioned "Liquid" and "Eta", so you can pick the syntax your template uses. With the gate off, the Liquid items appear directly in the menu.

A successful copy shows the notice <UiLabel name={m.workbench_field_copy_done()} />. A failed copy shows <UiLabel name={m.workbench_field_copy_failed()} />.
