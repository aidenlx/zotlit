Use this guide when Zotero changes do not appear after you update a literature note in Obsidian.

## Restore current Zotero data

<Steps>
  <Step>
    ### Install or update ZotLit Companion

    ZotLit Companion, the Zotero add-on, keeps recent Zotero changes available to ZotLit. [Install the latest Companion](/docs/install-companion), or update your current installation in Zotero.

  </Step>
  <Step>
    ### Confirm the Companion setting

    In Zotero, open **Edit → Settings** on Windows or Linux. On macOS, open **Zotero → Settings**. Select the **ZotLit** pane.

    Under **Database**, enable **Keep the database file up to date for Obsidian**. New Companion installations enable this setting by default.

  </Step>
  <Step>
    ### Make recent changes available

    In Zotero's item pane, select **Database Status** beside **Locate**. If **Write Changes to Database File Now** is available, select it.

    This makes recent Zotero changes available immediately.

  </Step>
  <Step>
    ### Update the literature note

    Return to the literature note in Obsidian. Run <Command inline name={m.command_update_note_name()} />.

    The missing Zotero change should now appear in the note.

  </Step>
  <Step>
    ### Refresh ZotLit

    If the note still shows old data, run <Command inline name={m.command_refresh_db_name()} />. Then update the literature note again.

  </Step>
</Steps>

## Advanced: Use Full copy as a last resort [#read-mode]

If the problem continues, open <SettingsPath page={m.settings_page_database()} />. Set <UiLabel name={m.settings_db_read_mode_name()} /> to <UiLabel name={m.settings_db_read_mode_copy()} />, refresh the database, and update the literature note again.

<UiLabel name={m.settings_db_read_mode_copy()} /> copies the entire database on
every refresh. Large Zotero libraries take longer to refresh and use more disk
space.

## Report a remaining problem

If <UiLabel name={m.settings_db_read_mode_copy()} /> also fails, [collect debug logs](/docs/how-to/collect-debug-logs). Then [file a bug report](https://github.com/aidenlx/zotlit/discussions/new?category=bug-reports) with your ZotLit version, operating system, and reproduction steps.
