Use this guide when Zotero changes do not appear after you update a literature note in Obsidian.

## Restore current Zotero data

<Steps>
  <Step>
    ### Install or update the companion

    [Install the latest ZotLit companion](/docs/install-companion), or update your existing installation in Zotero.

    The companion keeps Zotero's main database file current so ZotLit can read recent changes.

  </Step>
  <Step>
    ### Confirm the database setting

    In Zotero, open **Edit > Settings** on Windows or Linux. On macOS, open **Zotero > Settings**. Select the **ZotLit** pane.

    Under **Database**, enable **Keep the database file up to date for Obsidian**. New companion installations enable this setting by default.

  </Step>
  <Step>
    ### Check Database Status in Zotero

    In Zotero's item-pane sidenav, select **Database Status** beside **Locate**. If **Write Changes to Database File Now** is available, select it to make recent changes available immediately. If the menu says the database does not use a write-ahead log, continue to the next step.

    The menu also reports the last write. If it reports a failure, [collect Zotero debug logs](/docs/how-to/collect-debug-logs) before you continue.

  </Step>
  <Step>
    ### Check the literature note

    Make a small edit to an item in Zotero, then switch to Obsidian. Run <Command inline>ZotLit: Update literature note</Command> for that item.

    The updated value should now appear in the literature note.

  </Step>
  <Step>
    ### Refresh the database manually

    If the note still shows old data, run <Command inline>ZotLit: Refresh Zotero database</Command>. Then update the literature note again.

  </Step>
  <Step>
    ### Use Full copy as a last resort [#read-mode]

    If the problem continues, open **Settings > ZotLit > Zotero database**. Set **Read mode** to **Full copy**, refresh the database, and update the literature note again.

    <Callout type="warn" title="Full copy is expensive">
      **Full copy** captures the current database state, but it copies the
      entire database on every refresh. Large Zotero libraries take longer to
      refresh and use more disk space.
    </Callout>

  </Step>
  <Step>
    ### Report a remaining problem

    If Full copy also fails, [collect debug logs](/docs/how-to/collect-debug-logs). Then [file a bug report](https://github.com/aidenlx/zotlit/discussions/new?category=bug-reports) with your ZotLit version, operating system, and reproduction steps.

  </Step>
</Steps>
