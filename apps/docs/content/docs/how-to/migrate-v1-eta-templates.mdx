If you never changed the v1 templates, do nothing: v2 ships new defaults. Otherwise:

1. Rename each `zt-` template file to `zotlit-`; `zt-annots.eta.md` becomes `zotlit-content.eta.md`.
2. In the templates, replace `it.` with `zt.`.
3. Turn on <UiLabel name={m.settings_template_js_enable_name()} /> on each device.
4. Fix the few fields that changed, then run <Command inline name={m.command_overwrite_note_name()} /> on old notes when you are ready.

## Bring your Eta templates to v2

1. **Rename the files** in your template folder:

   | v1 file                                | Rename to                     |
   | -------------------------------------- | ----------------------------- |
   | `zt-note.eta.md`                       | `zotlit-note.eta.md`          |
   | `zt-annots.eta.md`                     | `zotlit-content.eta.md`       |
   | `zt-annot.eta.md`                      | `zotlit-annotation.eta.md`    |
   | `zt-cite*.eta.md` (two citation files) | same `zt-` → `zotlit-` rename |

   ZotLit loads and renders them under these names once step 4 is done. Renaming files changes nothing in your Zotero library.

2. **Delete two files** if you have them in your folder: `zt-field.eta.md` (properties now live in the profile) and `zt-colored.eta.md` (colour styling is now handled automatically during note import).
3. **Replace `it.` with `zt.`** inside template tags, such as `it.title` → `zt.title` and `it.creators` → `zt.creators`. Leave `comment`, `tags`, `collections`, `date`, and `notes` for step 5.
4. **Turn on JavaScript templates.** Open <SettingsPath page={m.settings_page_advanced()} />. In the <UiLabel name={m.settings_advanced_template_engine_heading()} /> group, on the <UiLabel name={m.settings_template_js_enable_name()} /> row, select <UiLabel name={m.settings_template_js_turn_on()} />. In the <UiLabel name={m.settings_template_js_confirm_title()} /> dialog, select <UiLabel name={m.settings_template_js_confirm_action()} />. ZotLit recompiles the templates at once. This setting is per device; turn it on on each computer you use.
5. **Fix the fields that changed.** The common ones:

   | v1                                         | v2                                           |
   | ------------------------------------------ | -------------------------------------------- |
   | `it.citekey`                               | `zt.citationKey` (`zt.citekey` also works)   |
   | `it.date` used as a year                   | `zt.date?.year`                              |
   | `it.abstractNote`                          | `zt.abstract` (`zt.abstractNote` also works) |
   | `it.textExcerpt`                           | `zt.text`                                    |
   | `it.commentMd`                             | `zt.comment`                                 |
   | `<%~ include("annots", it.annotations) %>` | `<%~ include("content", zt) %>`              |

   Tags, collections, and authors are now objects that still print as their name in text, so expressions like `zt.tags.join(", ")` keep working. For every other change, see [v1 to v2 field changes](/docs/reference/templates/eta-syntax#v1-changes).

6. **Rebuild an old note when you are ready.** Open the note, run <Command inline name={m.command_overwrite_note_name()} />, and select <UiLabel name={m.modal_overwrite_note_confirm()} />. ZotLit rebuilds the whole note body from the renamed templates and inserts the managed-region markers (`%%zt-managed%%` … `%%/zt-managed%%`). After that, <Command inline name={m.command_update_note_name()} /> refreshes the note. Notes you have not overwritten keep their body while their properties refresh.

## If you see something else

- **Your notes look like the v2 defaults, not your templates** → The files still start with `zt-`; v2 reads only `zotlit-` files. Rename them (step 1).
- **"The Eta template at … is inactive because JavaScript templates are disabled on this device."** → Turn on <UiLabel name={m.settings_template_js_enable_name()} /> on this device (step 4).
- **"These frontmatter fields are inactive because JavaScript templates are disabled: …"** → Turn on <UiLabel name={m.settings_template_js_enable_name()} /> on this device (step 4).
- **Extra blank lines in the note** → v1 trimmed one newline after each `%>`; v2 keeps all whitespace. Write `-%>` where you want the old trim behavior.
- **A year shows as a full date** → `it.date` printed only a year in v1; write `zt.date?.year`.
- <UiLabel name={m.notice_updated_note_no_region()} /> after
  <Command inline name={m.command_update_note_name()} /> on a v1 note → v1 notes
  lack managed-region markers. Run
  <Command inline name={m.command_overwrite_note_name()} /> on the note (step
  6).
- **Your files are named like `zotlit-note.liquid.md`** → Those are 2.1 templates. Follow [Migrate from 2.1 templates](/docs/how-to/migrate-from-2.1-templates).
