在修改模板前，若想先创建一篇文献笔记，请从 <LessonLink slug="connect-zotero-to-obsidian" /> 开始。

1. 打开 <SettingsPath />。在 <UiLabel name={m.settings_profile_document_name()} /> 行上，点击铅笔按钮 <UiLabel name={m.settings_profile_edit()} />。
2. 通过 <UiLabel name={m.workbench_choose_item()} /> 选择一篇文献进行预览。
3. 在各个标签页中进行编辑，并在 <UiLabel name={m.workbench_result_heading()} /> 中查看效果。
4. 修改会自动保存并应用到新笔记。对现有笔记运行 <Command inline name={m.command_update_note_name()} /> 即可更新其属性。

你所编辑的是一个**配置方案**：它是模板文件夹（默认为 `templates`）中的一个文件，用于生成同类文献笔记。默认配置方案的文件是 `zotlit-profile.default.md`；ZotLit 会在你第一次点击 <UiLabel name={m.settings_profile_edit()} /> 时自动创建它。参见[模板工作原理](/docs/reference/templates/how-templates-work)。

## 编辑文献笔记配置方案 [#edit-a-literature-note-profile]

![Rougier 等人 (2014)《Ten Simple Rules for Better Figures》的模板工作台：左侧编辑器显示 Reading notes 配置方案的笔记模板，中间是笔记预览并显示渲染后的属性、标题和标注，右侧边缘展开字段弹出面板并按类别列出该文献的字段](/img/how-to/template-workbench-layout.webp)

1. **打开配置方案**。 在 Obsidian 中，打开 <SettingsPath />。在 <UiLabel name={m.settings_profile_document_name()} /> 行上，点击铅笔按钮，提示为 <UiLabel name={m.settings_profile_edit()} />。
   模板工作台视图将在独立窗口中打开并显示预览面板；如果模板文件夹中尚不存在 `zotlit-profile.default.md`，则会自动创建该文件。
2. **选择用于预览的文献**。 点击面板上方一行的 <UiLabel name={m.workbench_choose_item()} />，然后在 <UiLabel name={m.workbench_recently_updated()} /> 下选择文献、点击 <UiLabel name={m.workbench_search_zotero()} />，或选择内置示例。
   编辑器标签页、预览面板和字段面板均会显示该文献的数据。
3. **编辑标签页**。 选择要编辑的标签页：<UiLabel name={m.workbench_tab_note()} />（笔记正文）、<UiLabel name={m.workbench_tab_properties()} />、<UiLabel name={m.workbench_tab_annotation()} />（单条高亮的呈现方式）、<UiLabel name={m.workbench_tab_name_and_folder()} /> 或 <UiLabel name={m.workbench_tab_match()} />。
   预览面板中的 <UiLabel name={m.workbench_result_heading()} /> 会随着你的输入实时更新。
4. **添加文献中的字段**。 将光标置于模板中。点击视图标头中的 <UiLabel name={m.workbench_view_fields()} />，然后点击字段所在行的插入按钮，或在行菜单中选择 <UiLabel name={m.workbench_fields_put_in_note()} />。
   该字段将插入到光标所在位置，弹出框随即关闭。（按住 Shift 键的同时点击插入按钮可保持弹出框打开。）
5. **等待自动保存**。 更改会在操作时自动保存，并支持 Obsidian 的撤销与重做。
   新笔记将使用你编辑后的配置方案。现有笔记保持不变；运行 <Command inline name={m.command_update_note_name()} /> 可以刷新它们的属性，而运行 <Command inline name={m.command_overwrite_note_name()} /> 则会在确认后替换整个正文。

有关此视图中每个面板、固定按钮和设置的完整指南，请参阅[模板工作台视图参考](/docs/reference/template-workbench-view)。

</Accordion>
<Accordion title="在多个配置方案之间复用文本" id="share-a-partial">

- **片段**（partial）是一个可复用的模板文件（`zotlit-partial.<name>.md`），任何配置方案或引文模板都可以按名称调用它。
- 如需创建片段，请打开 <SettingsPath page={m.settings_page_profiles()} setting={m.settings_partials_heading()} /> 并选择 <UiLabel name={m.settings_partial_add()} />。或者，在工作台编辑器中选中文本，右键点击并选择 <UiLabel name={m.template_workbench_extract_partial()} />。
- 在 Liquid 中使用 `{% render "authors" with zt as zt %}` 调用片段（输入 `{% render "` 会列出你的片段并自动补全参数）。在 Eta 中，使用 `<%~ include("authors", zt) %>` 调用。
- 有关命名和参数的详细信息，请参阅[调用片段](/docs/reference/templates/syntax#calling-a-partial)。

</Accordion>

## 常见问题排查 [#if-you-see-something-else]

- **首次创建文档时报错** → 点击错误提示旁的重试操作。
- **预览为空或未显示文献** → 点击 <UiLabel name={m.workbench_choose_item()} />，从你的文库中选择一篇文献或选择一个内置示例。
- **预览失败** → 重试预览，或使用 <UiLabel name={m.workbench_choose_item()} /> 选择另一篇文献。你可以继续编辑。
- **编辑正文后笔记未发生变化** → 运行 <Command inline name={m.command_update_note_name()} /> 以刷新属性。如果你的配置方案没有受管块（managed block），ZotLit 会提示 <UiLabel name={m.notice_updated_note_no_managed_block()} />。正文编辑会自动应用到新笔记；若要重建现有笔记的正文，请运行 <Command inline name={m.command_overwrite_note_name()} />，该命令将在确认后替换正文。
- **Eta 模板没有任何效果** → Eta 模板需要开启 <UiLabel name={m.settings_template_js_enable_name()} /> 设置。如果未开启，Eta 模板将无法执行，且不会回退到内置文本。参见[启用 JavaScript 模板](/docs/how-to/enable-javascript-templates)。
- **片段调用处标记为** <UiLabel name={m.workbench_partial_missing()} /> → 片段已被重命名或删除。请修改模板调用处的片段名称，或重新创建该片段文件。
- **片段字段输出为空** → Liquid 调用中缺少数据参数；请写为 `{% render "name" with zt as zt %}`。
