When you sync an Obsidian vault between computers, each computer may have Zotero installed in a different location. ZotLit stores the Zotero profile path and data directory path per device, so one machine's path never overwrites another's through vault sync.

## Default installs: nothing to configure

On a computer where Zotero is installed in its default location, ZotLit auto-detects the profile (from Zotero's `profiles.ini`) and data directory. A freshly synced vault connects to Zotero with no manual setup.

If every computer uses the default Zotero location, you are done. No per-device configuration is needed.

## Point a device at a non-default Zotero location

If Zotero's profile or data directory is in a custom location on one of your computers, tell ZotLit where to find it on that device.

<Steps>
  <Step>
    ### Open the Zotero database settings

    On the device that needs a custom path, open **Settings > Community plugins > ZotLit > {m.settings_page_database()}**.

  </Step>
  <Step>
    ### Set the Zotero profile

    Use the **{m.settings_db_profile_dir_name()}** picker to select the correct profile directory for this machine. If you only need to change the data directory, skip this step.

  </Step>
  <Step>
    ### Set the data directory override (if needed)

    If the Zotero data directory is also non-default, expand the **{m.settings_db_advanced()}** group and use the **{m.settings_db_data_dir_name()}** picker to select the correct path.

  </Step>
</Steps>

The chosen paths apply to this device only. Other devices that sync the same vault keep their own paths (or continue using auto-detection).

<Callout type="info" title="Clearing a Device Override">
  To return a device to auto-detection, reset the profile or data directory
  picker to its default value. ZotLit resumes auto-detecting on that device.
</Callout>

## When a new device cannot find Zotero

If you sync a vault to a computer where Zotero is not in the default location and no Device Override is set, ZotLit cannot locate the database. At launch, it shows a notice:

> Zotero wasn't found on this device

The notice includes a **{m.notice_db_not_found_action()}** action that opens the Welcome View. The first quick-start step displays live connection status and a locate action to pick the correct path. The notice reappears on each launch while the connection is unresolved; it does not appear when auto-detection succeeds or a working Device Override is in place.

You can also set the path directly from **Settings > Community plugins > ZotLit > {m.settings_page_database()}**, as described above.
