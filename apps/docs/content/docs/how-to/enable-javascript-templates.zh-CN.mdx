<UiLabel name={m.settings_template_js_enable_name()} />
是一项单设备独立的权限开关，允许在您的模板内部执行完整的 JavaScript
代码。该设置项默认处于禁用状态。

在 ZotLit 2.1 中，模板语言直接体现在文件名中：`zotlit-note.eta.md` 代表 Eta 模板，而 `zotlit-note.liquid.md` 则代表 Liquid 模板。在 2.2 中，模板文档改为在其自身的 manifest 元数据区中显式声明语言：`language: eta`。

受管 frontmatter 配置项则通过其值计算成员声明语言：`expr`（Liquid 表达式）、`value`（JSON-e 模板）或 `js`（JavaScript 表达式）。有关 manifest 配置键与三类成员项的详细说明，请参阅[配置方案文档](/docs/reference/templates/profile-document)。

## 该权限开关管控的范围

- **Eta 模板文档：** 在 manifest 中显式声明了 `language: eta` 的配置方案文档、引文文本文档或共享片段文档。
- **`js` frontmatter 配置项：** 声明了 `js` 表达式作为值计算方式的受管 frontmatter 配置项。

无论该开关处于开启还是关闭状态，`expr` 与 `value` 成员均始终保持正常可用。在开关关闭期间，Eta 文档绝不会被编译，`js` 表达式也绝不会被执行求值。

<Callout type="info" title="请先了解安全影响">
  Eta 模板运行 JavaScript 时拥有与 ZotLit
  插件自身完全同等级别的系统权限：它可以直接读取并修改您的仓库、发起网络外发连接，在桌面端甚至能够直接访问操作系统底层。在开启授权之前，请仔细阅读[JavaScript
  模板核心概念](/docs/concepts/javascript-templates)。
</Callout>

## 开启步骤

<Steps>
  <Step>
    ### 打开模板引擎设置

    在 Obsidian 中，打开 <SettingsPath page={m.settings_page_advanced()} />。找到 <UiLabel name={m.settings_advanced_template_engine_heading()} /> 选项组及其中的 <UiLabel name={m.settings_template_js_enable_name()} /> 所在行。

  </Step>
  <Step>
    ### 点击开启

    点击 <UiLabel name={m.settings_template_js_turn_on()} /> 按钮。界面将弹出一个标题为 <UiLabel name={m.settings_template_js_confirm_title()} /> 的二次确认窗口，附带如下警示说明：

    > <UiLabel name={m.settings_template_js_confirm_body()} />

    点击 <UiLabel name={m.settings_template_js_confirm_action()} /> 进行确认。

  </Step>
</Steps>

开关立即生效。ZotLit 会就地重新编译模板文件夹，无需重新加载插件。

## 关闭 [#turn-off]

在同一个 <UiLabel name={m.settings_template_js_enable_name()} /> 选项组中，选择 <UiLabel name={m.settings_template_js_turn_off()} />。开关会立即关闭，不再弹出确认窗口。所有声明了 `language: eta` 的模板文档都会停止运行，所有以 `js` 声明的受管 frontmatter 配置项都会停止求值，直到您重新开启此开关。

## 按设备独立设置 [#per-device-scope]

此设置保存在当前设备本地，不属于同步的插件数据。在一台设备上启用它，不会同时在其他设备上启用。每台需要运行 Eta 文档与 `js` 配置项的设备都必须单独授权。
