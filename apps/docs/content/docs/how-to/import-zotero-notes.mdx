## Import a paper's notes

In Zotero, notes attached to an item are called child notes, while notes placed directly in a collection are standalone notes.

1. Open the literature note of the paper whose Zotero notes you want. The literature note is now the active tab.
2. Open the command palette and run <Command inline name={m.command_import_child_notes_name()} />. You can also right-click the literature note's file in the file explorer and select the same command. The <UiLabel name={m.batch_import_child_title()} /> dialog opens, showing how many notes will be imported and listing any notes you have already imported.
3. Select <UiLabel name={m.batch_import_confirm_button()} />. Each Zotero note becomes a Markdown file in the folder set by <UiLabel name={m.settings_note_import_folder_name()} /> (by default, `zotero_notes`), which ZotLit creates if it does not yet exist. Each file name ends in a short random suffix so every note keeps its own file. The literature note links to these files whenever its template uses `noteLink`; until a note is imported, that link opens the note in Zotero. Creating, updating, or overwriting a literature note never imports or changes these files; only an import or re-import writes them.

<Accordion title={<>Show highlight colours with <code>==</code> marks</>} id="colored-highlights" value="colored-highlights">

1. Turn on <UiLabel name={m.settings_note_import_colored_highlights_name()} /> under <SettingsPath page={m.settings_page_note_import()} />. This setting is off by default.
2. Optional: open <UiLabel name={m.settings_note_import_highlight_mappings_name()} /> to choose how each Zotero colour renders: <UiLabel name={m.settings_note_import_highlight_mark()} />, a circle emoji, or <UiLabel name={m.settings_note_import_highlight_custom()} /> with an emoji of your own.
3. Import or re-import the note.

A highlight in the imported note now renders as `==🔵Highlighted text==`. If the highlight comes from an annotation, it retains its Zotero link: `[==🔵Highlighted text==](zotero://...)`.

By default, red, orange, yellow, green, blue, and purple map to matching circle emoji; magenta, gray, and plum use HTML marks. Your theme or another plugin must support the emoji to display the colour. Files imported before enabling this setting change only when re-imported. For complete rules, see [Colored highlight syntax](/docs/reference/settings#colored-highlights).

## If you see something else

- **I edited the note in Zotero, but the file in Obsidian did not change** — Imported files are created once and do not sync automatically. Open the file in Obsidian and run <Command inline name={m.command_reimport_note_name()} />, or select the note in Zotero and click <UiLabel name={m["zotero.menu_submenu.label"]()} /> → <UiLabel name={m["zotero.menu_item_import_notes.label"]({ count: 2 })} />.
- **A notice <UiLabel name={m.notice_attachment_sources_skipped({ count: 1 })} /> or <UiLabel name={m.notice_attachment_sources_skipped({ count: 2 })} /> with <UiLabel name={m.notice_attachment_sources_skipped_folders({ count: 1 })} /> or <UiLabel name={m.notice_attachment_sources_skipped_folders({ count: 2 })} />** — The attachment is a Zotero [linked file](https://www.zotero.org/support/attaching_files#adding_linked_files) in a folder outside ZotLit's allowed locations. Select <UiLabel name={m.notice_attachment_sources_skipped_action()} />, navigate to <SettingsPath page={m.settings_page_attachments()} setting={m.settings_attachment_approved_name()} />, add the folder if you trust it, and re-import the note. Approving a folder does not alter earlier imports.
- **The batch lists a note under <UiLabel name={m.batch_import_group_up_to_date({ count: "…" })} />, but an annotation in it changed** — Batch imports check only the modification timestamp of the Zotero note itself, not individual annotations. Open that note file in Obsidian and run <Command inline name={m.command_reimport_note_name()} />.
- **A citation in the imported note reads like `-@ABC123?`** — ZotLit found no citation key for that paper in your Zotero library or in the note. The trailing `?` lets you search your vault for unresolved citations. When no cited paper in a citation resolves, ZotLit preserves the original text so nothing is lost.
- **A notice: <UiLabel name={m.notice_imported_note_profile_unknown({ stamp: "…", target: "…" })} />** — The profile originally used to import this note has been removed. Select <UiLabel name={m.profile_switch_recovery()} /> and choose an existing profile.
- **An image in the imported note reads <UiLabel name={m.excerpt_image_unavailable()} /> with a source link** — The image could not be generated and the note had no previous image to retain. Other annotations and text in the note still imported. See [Import outcomes](/docs/reference/excerpt-images#import-outcomes).
- **A notice starting "Excerpt images: …"** — This notice appears once per batch or import to report images that were not freshly generated. "Kept from the note and not refreshed" means an existing image in the note was preserved. See [Import outcomes](/docs/reference/excerpt-images#import-outcomes).
- **An image reads <UiLabel name={m.excerpt_image_import_disabled()} />** — <UiLabel name={m.settings_attachment_import_name()} /> is turned off under <SettingsPath page={m.settings_page_attachments()} />, which prevents ZotLit from writing image files. Turn the setting on, then re-import the note.
- **A notice: <UiLabel name={m.batch_all_no_library_in_scope()} />** — None of the libraries in your library scope are in the Zotero database, so the import dialog cannot open. See [Library scope](/docs/reference/settings#library-scope).
- **Zotero says the selection is too large, or asks to enable a server** — Enable ZotLit's local HTTP server in Obsidian settings, or select fewer notes at a time. See [Set up live updates](/docs/how-to/set-up-live-updates).
- **Zotero asks for confirmation each time it opens Obsidian** — Follow [Suppress the Zotero security prompt](/docs/how-to/suppress-zotero-security-prompt) to disable the confirmation dialog.
