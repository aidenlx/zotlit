ZotLit Companion, the Zotero add-on, can push changes to Obsidian as you read and annotate in Zotero. The annotation view's reader-following mode and automatic database refreshes both depend on this optional connection.

<Callout type="info" title="When you do not need this">
  Basic Companion actions (opening items and their PDFs, updating notes,
  importing notes from the Zotero context menu) work through protocol links with
  no server. You only need live updates for real-time push (reader-following,
  instant database refresh when Zotero data changes).
</Callout>

## Enable the ZotLit server

<Steps>
  <Step>
    ### Open the sync settings

    In Obsidian, open <SettingsPath page={m.settings_page_zotero()} /> and find the <UiLabel name={m.settings_zotero_sync_heading()} /> group. Keep <UiLabel name={m.settings_live_updates_enabled_name()} /> on.

  </Step>
  <Step>
    ### Turn on the listener

    On the <UiLabel name={m.settings_advanced_local_server_heading()} /> row, select <UiLabel name={m.settings_zotero_local_server_open()} />. This opens the <UiLabel name={m.settings_advanced_local_server_heading()} /> group on <SettingsPath page={m.settings_page_advanced()} />.

    Enable <UiLabel name={m.settings_local_server_enabled_name()} />. Keep the default hostname, `127.0.0.1`, to accept connections from this computer only.

    The configured port defaults to **9091**. Check <UiLabel name={m.settings_local_server_active_port_name()} /> for the port actually used: ZotLit tries a higher port if the configured one is busy.

  </Step>
</Steps>

## Enable the Companion's notify preference

<Steps>
  <Step>
    ### Open Zotero preferences

    In Zotero, open **Edit > Settings** (Windows/Linux) or **Zotero > Settings** (macOS). Select the <UiLabel name={m["zotero.prefs_pane_label"]()} /> pane.

  </Step>
  <Step>
    ### Enable notifications

    Under the <UiLabel name={m["zotero.prefs_notify_section"]()} /> section, check <UiLabel name={m["zotero.prefs_notify_enable.label"]()} />.

  </Step>
  <Step>
    ### Set the Notify URL

    Set the <UiLabel name={m["zotero.prefs_notify_url"]()} /> to point at the ZotLit server. The default value is `http://localhost:9091`, which matches the default port.

    Use the port shown by <UiLabel name={m.settings_local_server_active_port_name()} /> in Obsidian (for example, `http://localhost:9092`). Each vault can use a different port.

  </Step>
</Steps>

## Verify the connection

After enabling both sides, open the annotation view in Obsidian and switch it to <UiLabel name={m.annot_view_mode_zotero_reader()} /> mode. The view starts in <UiLabel name={m.annot_view_mode_active_tab()} /> mode and keeps the mode you last chose. Then open an item in the Zotero PDF reader. The annotation view updates to show that item's annotations. If it does not update, check that both the port and hostname match between the ZotLit server settings and the Companion's Notify URL.

## Source ID filtering

The ZotLit server accepts requests only from the Zotero install whose profile and data directory match the connected source. Requests from other Zotero installs are silently ignored. The source identifier is displayed read-only as <UiLabel name={m.settings_db_source_id_name()} /> under <SettingsPath page={m.settings_page_zotero()} setting={m.settings_page_zotero_location()} />.
