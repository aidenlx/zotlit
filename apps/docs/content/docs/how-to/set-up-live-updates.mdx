ZotLit Companion, the Zotero add-on, can push changes to Obsidian as you read and annotate in Zotero. The annotation view's reader-following mode and automatic database refreshes both depend on this optional connection.

<Callout type="info" title="When you do not need this">
  Basic Companion actions (opening items, updating notes, importing notes from
  the Zotero context menu) work through protocol links with no server. You only
  need live updates for real-time push (reader-following, instant database
  refresh when Zotero data changes).
</Callout>

## Enable the ZotLit server

<Steps>
  <Step>
    ### Open the live updates settings

    In Obsidian, open <SettingsPath page={m.settings_page_advanced()} /> and find the <UiLabel name={m.settings_advanced_local_server_heading()} /> group.

  </Step>
  <Step>
    ### Turn on the listener

    Enable <UiLabel name={m.settings_local_server_enabled_name()} />, then keep <UiLabel name={m.settings_live_updates_enabled_name()} /> on. Keep the default hostname, `127.0.0.1`, to accept connections from this computer only.

    The configured port defaults to **9091**. Check <UiLabel name={m.settings_local_server_active_port_name()} /> for the port actually used: ZotLit tries a higher port if the configured one is busy.

  </Step>
</Steps>

## Enable the Companion's notify preference

<Steps>
  <Step>
    ### Open Zotero preferences

    In Zotero, open **Edit > Settings** (Windows/Linux) or **Zotero > Settings** (macOS). Select the <UiLabel name={m["zotero.prefs_pane_label"]()} /> pane.

  </Step>
  <Step>
    ### Enable notifications

    Under the <UiLabel name={m["zotero.prefs_notify_section"]()} /> section, check <UiLabel name={m["zotero.prefs_notify_enable.label"]()} />.

  </Step>
  <Step>
    ### Set the Notify URL

    Set the <UiLabel name={m["zotero.prefs_notify_url"]()} /> to point at the ZotLit server. The default value is `http://localhost:9091`, which matches the default port.

    Use the port shown by <UiLabel name={m.settings_local_server_active_port_name()} /> in Obsidian (for example, `http://localhost:9092`). Each vault can use a different port.

  </Step>
</Steps>

## Verify the connection

After enabling both sides, open an item in the Zotero PDF reader with the annotation view open in Obsidian. If reader-following is active, the annotation view updates to show that item's annotations. If it does not update, check that both the port and hostname match between the ZotLit server settings and the Companion's Notify URL.

## Source ID filtering

The ZotLit server accepts requests only from the Zotero install whose profile and data directory match the connected source. Requests from other Zotero installs are silently ignored. The source identifiers are displayed read-only under <SettingsPath page={m.settings_page_zotero()} />.
