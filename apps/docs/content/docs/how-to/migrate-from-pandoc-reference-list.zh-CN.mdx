本指南帮助您将引文工作流迁移至 ZotLit，但请勿假定两者功能完全相同。

完成迁移后，可参阅[搭建 Pandoc 引文工作流](/docs/tutorial/pandoc-citation-workflow)，通过单篇笔记实操比对内置导出与原生 Pandoc 导出。

[Pandoc Reference List 代码仓库](https://github.com/community-archive/obsidian-pandoc-reference-list)由 [Obsidian Community Archive](https://github.com/community-archive/.github) 组织归档维护。

## 梳理各项功能的迁移归宿

| 分类判定                 | 原有功能行为                                                                                            | ZotLit 中的对应处理方式                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 保持原样直接可用         | 字面量引文语法，如 `@doe2024`、`[@doe2024]` 及 `[@doe2024, p. 33]`                                      | 完整保留 Markdown 源码不变。开启 <UiLabel name={m.settings_citation_pandoc_citations_name()} /> 即可。 |
| 需调整设置或语法         | Zotero 文献库选择、实时格式化渲染、建议弹窗、提示工具条、CSL 样式选择、引文语言以及 `[[@citekey]]` 链接 | 配置 ZotLit 对应项，并对受影响的属性字段及链接进行核对。                                               |
| 继续通过原生 Pandoc 使用 | `bibliography`、参考文献库文件、多源文献库输入以及标准的 `csl` 或 `citation-style` 路径/URL             | 在[原生 Pandoc 工作流](/docs/how-to/export-with-native-pandoc)中继续保留这些参数输入。                 |
| ZotLit 中无直接等价物    | 应用内直接基于独立参考文献文件驱动、浮窗延迟控制、参考文献中的隐藏链接以及点击单条复制                  | 改用下文介绍的由 Zotero 数据库原生支撑的 ZotLit 控制方案。                                             |

ZotLit 的应用内引文功能直接读取 Zotero 文献条目。导出的参考文献库文件在原生 Pandoc 中依然十分重要，但它不再作为应用内<UiLabel name={m.references_view_name()} />侧边栏的数据源。

## 工作流迁移步骤

<Steps>
  <Step>
    ### 记录当前的配置

    记录现有的参考文献文件来源、选定的文献库、CSL 引文样式、语言以及渲染设置。

    在整个仓库中检索以下笔记属性与引文书写形式：

    - `bibliography`
    - `csl` 或 `citation-style`
    - `lang` 或 `citation-language`
    - `[[@`

    在完成全部验证步骤之前，请妥善保留原始笔记。

  </Step>
  <Step>
    ### 在 Zotero 中确认文献引用标识（citation key） [#在-zotero-中确认文献引用标识]

    确认每篇被引用的 Zotero 条目均已设置文献引用标识。ZotLit 会依据 Zotero 原生的 **Citation Key** 字段解析字面量文献引用标识。

    推荐安装 [Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/) 来生成并维护稳定的文献引用标识。如果原生字段中已具备合规的标识键，ZotLit 并不强制依赖 Better BibTeX。

    在批量迁移笔记之前，请先确定您理想的标识命名格式，避免在迁移完成后频繁改动现有标识。

  </Step>
  <Step>
    ### 连接 Zotero 数据库

打开 <SettingsPath page={m.settings_page_zotero()} />。确认 <UiLabel name={m.settings_db_file_name()} /> 指向包含被引条目的 Zotero 配置文件。

    在同一页面的 <UiLabel name={m.settings_zotero_libraries_heading()} /> 下，将 <UiLabel name={m.settings_library_scope_name()} /> 设置为 <UiLabel name={m.settings_library_scope_all()} />，或选择 <UiLabel name={m.settings_library_scope_selected()} /> 并添加您之前使用的个人和群组文献库。

    ZotLit 会同时搜索整个作用域。一个文献引用标识匹配多个条目时，ZotLit 会报告标识存在歧义，不会按文献库顺序选择某个条目。

  </Step>
  <Step>
    ### 配置应用内格式化 [#configure-in-app-formatting]

    打开 <SettingsPath page={m.settings_page_citations()} />。

    1. 保持 <UiLabel name={m.settings_citation_pandoc_citations_name()} /> 开启。
    2. 保持 <UiLabel name={m.settings_citation_show_formatted_name()} /> 开启。
    3. 在 <UiLabel name={m.settings_citation_references_heading()} /> 下安装 <UiLabel name={m.settings_citation_engine_name()} />。
    4. 在 Zotero 中安装您之前使用的 CSL 样式。
    5. 在 <UiLabel name={m.settings_citation_references_style_name()} /> 下选择该样式。
    6. 设置 <UiLabel name={m.settings_citation_locale_name()} />，或保持为 <UiLabel name={m.settings_citation_locale_default()} />。

    如果您之前使用文献引用标识的悬停提示，请将 <UiLabel name={m.settings_citation_hover_action_name()} /> 设置为 <UiLabel name={m.settings_citation_hover_action_popover()} />。ZotLit 可为每种编辑模式设置所需的修饰键，但没有悬停提示延迟设置。

  </Step>
  <Step>
    ### 迁移笔记元数据 [#migrate-note-metadata]

    对每篇受影响的笔记应用以下规则：

    | 属性 | 迁移规则 |
    | --- | --- |
    | `bibliography` | 仅为原生 Pandoc 保留此属性。ZotLit 的应用内功能和内置导出均从 Zotero 获取参考文献数据。 |
    | `csl` 或 `citation-style` | 若样式由 Pandoc 管理，保留其中一个属性。同一篇笔记中不要再添加 `zotlit-csl`。 |
    | `zotlit-csl` | 若需由 ZotLit 解析安装在 Zotero 中的样式，改用此属性。请先移除 `csl` 和 `citation-style`。 |
    | `lang` | 如果其值为有效的文档语言，例如 `en-US`、`de` 或 `zh-CN`，则保留。ZotLit 也会将其用于该笔记的引文。 |
    | `citation-language` | 只有当该值描述整篇文档的语言时，才将其转换为 `lang`。否则，请设置仓库的 <UiLabel name={m.settings_citation_locale_name()} /> 并移除此属性。 |

    要同时设置 Zotero 中已安装的样式和文档语言，请运行：

    <Command name={m.command_set_citation_presentation_name()} />

    当前活动笔记的 **More options** 菜单中也提供此操作。其中的 <UiLabel name={m.citation_presentation_language_name()} /> 值会成为整篇导出文档的 Pandoc `lang`。

    <Callout type="warn" title="选择一个样式管理方">
      原生 Pandoc 文档可以使用标准的 `csl` 或 `citation-style`，也可以由 ZotLit 解析 `zotlit-csl`。请只保留其中一类。文档同时包含 `csl` 和 `zotlit-csl` 时，ZotLit 过滤器会报告 `csl-ambiguous`。
    </Callout>

  </Step>
  <Step>
    ### 逐一检查文献引用标识链接 [#audit-citekey-links-one-at-a-time]

    Pandoc Reference List 可以将 `[[@doe2024]]` 视为引文。ZotLit 的 <UiLabel name={m.settings_citation_wikilink_citations_name()} /> 设置采用不同规则。

    请逐一检查每处 `[[@citekey]]`，按其用途选择处理方式：

    - 如果仅用作引文，将其替换为 `[@citekey]`。
    - 如果需要引用并打开对应笔记，将其替换为指向正确 ZotLit 文献笔记的不带别名的链接。

    例如，只有当 `Doe 2020.md` 确实是该条目的文献笔记时，才使用 `[[Doe 2020]]`。如果链接需要指定引用位置，请添加 `#cite:locator=33`：`[[Doe 2020#cite:locator=33]]`。

    确认文献笔记链接有效后，再开启 <UiLabel name={m.settings_citation_wikilink_citations_name()} />。不要批量替换，因为各处链接的用途和笔记名称可能不同。

  </Step>
  <Step>
    ### 测试时禁用 Pandoc Reference List [#disable-pandoc-reference-list-for-the-test]

    保留已记录的设置，然后在 **Settings > Community plugins** 中禁用 Pandoc Reference List。

    只启用 ZotLit 来测试引文渲染，避免两个插件同时改变同一处引文的显示。

  </Step>
  <Step>
    ### 验证一篇有代表性的笔记 [#verify-one-representative-note]

    打开一篇包含已迁移语法和元数据的笔记。

    1. 确认字面形式的引文在实时预览中得到格式化。
    2. 运行 <Command inline name={m.command_open_references_view_name()} />。
    3. 将鼠标悬停在引文上，检查 <UiLabel name={m.settings_citation_hover_action_popover()} />。
    4. 打开对应的文献笔记、Zotero 条目和可用的附件。
    5. 在 <UiLabel name={m.references_view_name()} /> 侧边栏中选择 <UiLabel name={m.references_copy_bibliography()} />。

    解决所有参考文献错误后再继续。尤其当文献引用标识存在歧义时，请修改重复标识，或收窄 <UiLabel name={m.settings_library_scope_name()} />。

  </Step>
  <Step>
    ### 选择导出工作流 [#choose-an-export-workflow]

    使用 <Command inline name={m.command_pandoc_export_name()} /> 进行 ZotLit 内置的 DOCX 或 HTML 导出。

    如果需要参考文献文件、多个输入文件、标准 CSL 路径或 URL，或其他 Pandoc 选项，请继续使用[原生 Pandoc](/docs/how-to/export-with-native-pandoc)。

  </Step>
</Steps>

## 没有直接对应功能的行为 [#behaviors-without-a-direct-equivalent]

- **通过参考文献文件提供应用内参考文献：**改为将 ZotLit 连接到对应的 Zotero 数据库。
- **在 Obsidian 中使用任意 CSL 路径或 URL：**将样式安装到 Zotero 中。如有需要，可为原生 Pandoc 保留路径或 URL。
- **悬停提示延迟：**选择 <UiLabel name={m.settings_citation_hover_action_popover()} />、<UiLabel name={m.settings_citation_hover_action_page_preview()} /> 或 <UiLabel name={m.settings_citation_hover_action_off()} />，并按编辑模式配置所需的修饰键。
- **隐藏参考文献中的链接：**ZotLit 没有对应的引文设置。
- **点击一条参考文献进行复制：**选中条目文本并使用通常的复制快捷键。点击条目行用于引文导航和条目操作。
