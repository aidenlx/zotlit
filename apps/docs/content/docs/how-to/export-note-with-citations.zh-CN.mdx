将当前处于活动状态的 Markdown 笔记导出为包含格式化引文与文末参考文献列表的 Word 文档或网页。

如需查看与原生 Pandoc 的分步对照实践，请参阅[搭建 Pandoc 引文工作流](/docs/tutorial/pandoc-citation-workflow)。

## 准备工作

您需要：

- 打开了某篇 Markdown 笔记的 Obsidian 桌面端。
- 在 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} /> 下安装好 <UiLabel name={m.settings_citation_engine_name()} />。
- 保持 Zotero 处于运行状态，以便 ZotLit 能够读取参考文献数据。

ZotLit 会优先使用 Better BibTeX 接口（若可用）；若未安装，则自动回退至 Zotero 本地 API。

## 导出笔记步骤

  <Step>
    ### 打开导出对话框

    打开命令面板并运行：

    <Command name={m.command_pandoc_export_name()} />

  </Step>
  <Step>
    ### 选择输出格式与选项

    检查以下各项设置：

    - <UiLabel name={m.pandoc_export_format_name()} />：默认为 <UiLabel name={m.pandoc_export_format_docx()} />。如需导出网页格式，请选择 <UiLabel name={m.pandoc_export_format_html()} />。
    - <UiLabel name={m.pandoc_export_style_name()} />：默认采用笔记在 Obsidian 中当前使用的引文样式。选择器下方的文字标明了该样式的来源依据：
      - <UiLabel name={m.pandoc_export_style_from_note()} />：笔记自身声明了 `zotlit-csl` 属性。
      - <UiLabel name={m.pandoc_export_style_from_profile({ profile: "Research" })} />：该笔记为导入笔记，其所属配置方案绑定了该样式。
      - <UiLabel name={m.pandoc_export_style_from_vault()} />：笔记沿用仓库全局的 <UiLabel name={m.settings_citation_references_style_name()} />。
    - <UiLabel name={m.pandoc_export_destination_name()} />：默认以源笔记所在路径和文件名为基准。

    按需调整输出格式、引文样式或保存目标路径。当您在弹窗中选取其他样式时，提示文字会显示 <UiLabel name={m.pandoc_export_style_changed({ style: "APA Style 7th edition" })} />。该对话框中的微调绝不会修改笔记本体。

  </Step>
  <Step>
    ### 执行导出

    点击 <UiLabel name={m.pandoc_export_confirm()} />。ZotLit 将自动解析各处引文、拉取参考文献数据并完成整篇笔记的格式化转换。

  </Step>

The destination contains a `.docx` Word document or an `.html` web page. The output includes formatted citations and a bibliography. The notice names the file and the style, for example <UiLabel name={m.notice_pandoc_export_done({ file: "Draft.docx", style: "APA Style 7th edition" })} />

Export leaves the source note unchanged. The bibliography is generated in the exported document; your Markdown keeps the citations it was generated from. To place a bibliography elsewhere, [copy it from the References Sidebar](/docs/how-to/review-copy-troubleshoot-references#copy-references).

## Which citations are exported

Built-in export uses its own citation membership. The following settings do not change export content:

- <UiLabel name={m.settings_citation_pandoc_citations_name()} />
- <UiLabel name={m.settings_citation_wikilink_citations_name()} />
- <UiLabel name={m.settings_citation_show_formatted_name()} />
- <UiLabel name={m.settings_citation_open_as_links_name()} />

All wikilinks to Literature Notes are export members. A valid Citation Fragment such as `#cite:locator=33` adds its citation details.

Literal Pandoc citations are export members in every form Pandoc reads: `[@doe2024]`, `[@doe2024, p. 12]`, `[-@doe2024]`, and the in-text `@doe2024`. A work cited both by a wikilink and by a literal key takes one bibliography entry.

Each citation key must name one Zotero item in the <UiLabel name={m.settings_library_scope_name()} />. A key that matches no item, or several, stops the export and names the keys. See [Fix an export error](#fix-an-export-error).

A `nocite` property in the note's frontmatter adds its item to the bibliography without citing it in the text.

Pandoc reads the note, so text it treats as ordinary (a key inside code or behind a `\` escape) is no citation of the export.

<Callout type="info">
  Export is all-or-nothing. ZotLit writes the destination only after citation
  resolution, bibliography retrieval, and Pandoc conversion all succeed.
</Callout>

## Fix an export error

| Symptom                                                                                                       | Recovery                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| ZotLit asks you to install the Pandoc engine                                                                  | Open <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} />, then install the engine. |
| A `#cite:` fragment is malformed, points to a note that is not a Literature Note, or has an unresolved target | Correct the fragment or link target.                                                                                                  |
| ZotLit cannot read the Zotero database                                                                        | Check the <UiLabel name={m.settings_page_zotero()} /> settings, then run the export again.                                            |
| Zotero holds no item for a Literature Note                                                                    | Restore the missing item or update the Literature Note's `zotero-key`.                                                                |
| Better BibTeX holds no citation key for a Literature Note                                                     | Assign a citation key in Better BibTeX, then run the export again.                                                                    |
| No Zotero item matches a literal citation key                                                                 | Check the spelling of the key, or widen the <UiLabel name={m.settings_library_scope_name()} />.                                       |
| A literal citation key matches multiple Zotero items                                                          | Change one of the keys in Zotero, or narrow the <UiLabel name={m.settings_library_scope_name()} />.                                   |
| ZotLit asks you to start Zotero                                                                               | Start Zotero and keep it running during export.                                                                                       |
| The Zotero local API is disabled                                                                              | In Zotero, open **Settings > Advanced** and enable **Allow other applications on this computer to communicate with Zotero**.          |
| Better BibTeX or the Zotero local API refuses the request                                                     | Check the named source in the error, then retry after it responds normally.                                                           |
| Zotero cannot supply the chosen style                                                                         | Install the style in Zotero, or choose another style in the dialog. ZotLit does not export with a different style.                    |
| Pandoc stops the conversion                                                                                   | Correct the source or style problem named in the error, then run the export again.                                                    |
| ZotLit cannot write the exported document                                                                     | Select a writable destination and run the export again.                                                                               |

Each failure stops the complete export. ZotLit does not write a document with a partial bibliography.

For conversion with a user-installed Pandoc CLI, see [Native Pandoc workflow](/docs/reference/settings#native-pandoc). That workflow uses the <UiLabel name={m.settings_citation_pandoc_files_name()} /> instead of this command.
