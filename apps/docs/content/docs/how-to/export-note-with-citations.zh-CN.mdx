将当前处于活动状态的 Markdown 笔记导出为包含格式化引文与文末参考文献列表的 Word 文档或网页。

如需查看与原生 Pandoc 的分步对照实践，请参阅[搭建 Pandoc 引文工作流](/docs/tutorial/pandoc-citation-workflow)。

## 准备工作

您需要：

- 打开了某篇 Markdown 笔记的 Obsidian 桌面端。
- 在 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} /> 下安装好 <UiLabel name={m.settings_citation_engine_name()} />。
- 保持 Zotero 处于运行状态，以便 ZotLit 能够读取参考文献数据。

ZotLit 会优先使用 Better BibTeX 接口（若可用）；若不可用，则自动回退至 Zotero 本地 API。

## 导出笔记步骤

<Steps>
  <Step>
    ### 打开导出对话框

    打开命令面板并运行：

    <Command name={m.command_pandoc_export_name()} />

  </Step>
  <Step>
    ### 选择输出格式与选项

    检查以下各项设置：

    - <UiLabel name={m.pandoc_export_format_name()} />：默认为 <UiLabel name={m.pandoc_export_format_docx()} />。如需导出网页格式，请选择 <UiLabel name={m.pandoc_export_format_html()} />。
    - <UiLabel name={m.pandoc_export_style_name()} />：默认采用笔记在 Obsidian 中当前使用的引文样式。选择器下方的文字标明了该样式的来源依据：
      - <UiLabel name={m.pandoc_export_style_from_note()} />：笔记自身声明了 `zotlit-csl` 属性。
      - <UiLabel name={m.pandoc_export_style_from_profile({ profile: "Research" })} />：该笔记为导入笔记，其所属配置方案绑定了该样式。
      - <UiLabel name={m.pandoc_export_style_from_vault()} />：笔记沿用仓库全局的 <UiLabel name={m.settings_citation_references_style_name()} />。
    - <UiLabel name={m.pandoc_export_destination_name()} />：默认以源笔记所在路径和文件名为基准。

    按需调整输出格式、引文样式或保存目标路径。当您在弹窗中选取其他样式时，提示文字会显示 <UiLabel name={m.pandoc_export_style_changed({ style: "APA Style 7th edition" })} />。该对话框中的微调绝不会修改笔记本体。

  </Step>
  <Step>
    ### 执行导出

    点击 <UiLabel name={m.pandoc_export_confirm()} />。ZotLit 将自动解析各处引文、拉取参考文献数据并完成整篇笔记的格式化转换。

  </Step>
</Steps>

目标位置会生成 `.docx` Word 文档或 `.html` 网页，包含格式化引文与参考文献列表。通知会说明文件名和采用的样式，例如 <UiLabel name={m.notice_pandoc_export_done({ file: "Draft.docx", style: "APA Style 7th edition" })} />。

导出不会修改源笔记。参考文献列表生成在导出的文档中，Markdown 源文件保留原有引文。如需将参考文献列表放到其他位置，可[从参考文献侧边栏复制](/docs/how-to/review-copy-troubleshoot-references#copy-references)。

## 哪些引文会被导出 [#which-citations-are-exported]

内置导出使用独立的引文纳入规则。以下设置不会改变导出内容：

- <UiLabel name={m.settings_citation_pandoc_citations_name()} />
- <UiLabel name={m.settings_citation_wikilink_citations_name()} />
- <UiLabel name={m.settings_citation_show_formatted_name()} />
- <UiLabel name={m.settings_citation_open_as_links_name()} />

所有指向文献笔记的双链都会被纳入导出。有效的引文片段（例如 `#cite:locator=33`）会补充对应的引文细节。

所有 Pandoc 可读取的字面量引文形式都会被纳入导出：`[@doe2024]`、`[@doe2024, p. 12]`、`[-@doe2024]`，以及正文中的 `@doe2024`。同一文献即使同时通过双链和字面量标识被引用，也只生成一条参考文献条目。

每个文献引用标识必须在 <UiLabel name={m.settings_library_scope_name()} /> 中唯一对应一个 Zotero 条目。若找不到条目或匹配了多个条目，导出会停止，并列出相关标识。请参阅[解决导出错误](#fix-an-export-error)。

笔记 frontmatter 中的 `nocite` 属性可以将对应条目加入参考文献列表，而不在正文中引用它。

Pandoc 会解析笔记，因此它视为普通文本的内容（例如代码内的标识或经过 `\` 转义的标识）不会成为导出引文。

<Callout type="info">
  导出必须全部成功才会写入结果。只有引文解析、参考文献获取和 Pandoc
  转换均成功后， ZotLit 才会写入目标文件。
</Callout>

## 解决导出错误 [#fix-an-export-error]

| 现象                                                | 解决方法                                                                                                                    |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| ZotLit 提示安装 Pandoc 引擎                         | 打开 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} />，然后安装引擎。 |
| `#cite:` 片段格式错误、指向非文献笔记或目标无法解析 | 修正片段或链接目标。                                                                                                        |
| ZotLit 无法读取 Zotero 数据库                       | 检查 <UiLabel name={m.settings_page_zotero()} /> 设置，然后重新导出。                                                       |
| Zotero 中没有文献笔记对应的条目                     | 恢复缺失条目，或更新文献笔记的 `zotero-key`。                                                                               |
| Better BibTeX 中没有文献笔记对应的文献引用标识      | 在 Better BibTeX 中设置文献引用标识，然后重新导出。                                                                         |
| 字面量文献引用标识未匹配任何 Zotero 条目            | 检查标识拼写，或扩大 <UiLabel name={m.settings_library_scope_name()} />。                                                   |
| 字面量文献引用标识匹配多个 Zotero 条目              | 在 Zotero 中修改其中一个标识，或缩小 <UiLabel name={m.settings_library_scope_name()} />。                                   |
| ZotLit 提示启动 Zotero                              | 启动 Zotero，并在导出期间保持运行。                                                                                         |
| Zotero 本地 API 已禁用                              | 在 Zotero 中打开 **Settings > Advanced**，开启 **Allow other applications on this computer to communicate with Zotero**。   |
| Better BibTeX 或 Zotero 本地 API 拒绝请求           | 检查错误中指出的数据源，待其恢复正常响应后重试。                                                                            |
| Zotero 无法提供所选样式                             | 在 Zotero 中安装该样式，或在对话框中选择其他样式。ZotLit 不会擅自改用其他样式导出。                                         |
| Pandoc 停止转换                                     | 修正错误中指出的源文件或样式问题，然后重新导出。                                                                            |
| ZotLit 无法写入导出文档                             | 选择可写入的目标位置，然后重新导出。                                                                                        |

任何一项失败都会停止整个导出。ZotLit 不会生成仅包含部分参考文献的文档。

如需使用自行安装的 Pandoc CLI 转换，请参阅[原生 Pandoc 工作流](/docs/reference/settings#native-pandoc)。该工作流使用 <UiLabel name={m.settings_citation_pandoc_files_name()} />，不使用此命令。
