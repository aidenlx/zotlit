---
title: "撰写并导出包含引文的笔记"
description: "插入引文、检查参考文献，并导出一份附带格式化参考文献列表的 Word 文档。"
---

import { Steps, Step } from "fumadocs-ui/components/steps";
import { Card, Cards } from "fumadocs-ui/components/card";
import { Callout } from "@/components/callout";
import { Command } from "@/components/command";
import { SettingsPath } from "@/components/settings-path";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

本教程将引导您从单个 Zotero 条目出发，生成一份带有引文的 Word 文档。

您将插入类似 `[@doe2024]` 这样的字面量 Pandoc 引文。ZotLit 将对其进行格式化，且无需改动您的 Markdown 源码。

## 准备工作

请完成 [ZotLit 安装](/docs/install-zotlit)。您还需要安装 Zotero 端的必备插件 ZotLit Companion。[安装 Companion](/docs/install-companion)，并在本教程进行期间保持 Zotero 处于打开状态。

推荐安装 [Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/) 以生成并维护稳定的文献引用标识（citation key），它还将在导出时提供参考文献列表数据。如果您未使用该插件，请打开 **Zotero 设置 → 高级**并启用**允许本计算机上的其他应用程序与 Zotero 通信**，以便 ZotLit 可以使用 Zotero 本地 API。

<Steps>
  <Step>
    ### 准备一个 Zotero 条目

    在 Zotero 中选择一个条目，确认其 **Citation Key** 字段已有对应取值。

    如果您使用的是 Better BibTeX，请按照其[文献引用标识指南](https://retorque.re/zotero-better-bibtex/citing/)生成并检查该标识。保持生成的标识与 Zotero 中一致。

  </Step>
  <Step>
    ### 安装 Pandoc 引擎

    在 Obsidian 中，打开 <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} />。找到 <UiLabel name={m.settings_citation_engine_name()} />，然后选择 <UiLabel name={m.settings_citation_engine_install()} />。

    等待该行状态提示 Pandoc 已安装完成。该引擎负责格式化引文、参考文献列表以及导出的文档。

  </Step>
  <Step>
    ### 插入引文

    在实时预览模式下打开一篇 Markdown 笔记。键入 `[@`，然后输入条目标题或文献引用标识的一部分。光标下方将弹出匹配的 Zotero 条目建议列表。

    ![在 Obsidian 论文段落末尾输入“[@ten”，下方建议列表显示 Rougier et al. (2014) 的“Ten Simple Rules for Better Figures”](/img/tutorial/write-and-export-insert-citation.webp)

    选择该条目并按 `Enter`。ZotLit 将插入如下引文：

    ```md
    Recent work reaches a similar conclusion [@doe2024].
    ```

    将光标移开引文。在实时预览模式下，ZotLit 会将源码显示替换为格式化后的引文呈现。

  </Step>
  <Step>
    ### 查看参考文献

    打开命令面板并运行：

    <Command name={m.command_open_references_view_name()} />

    <UiLabel name={m.references_view_name()} />侧边栏将显示该引文的格式化参考文献条目。

    ![该段落末尾现在显示格式化引文“(Rougier et al. 2014)”，右侧的参考文献侧边栏列出了该论文的完整参考文献条目](/img/tutorial/write-and-export-references-sidebar.webp)

  </Step>
  <Step>
    ### 预览引文

    在实时预览模式下将鼠标悬停在格式化引文上。<UiLabel name={m.settings_citation_hover_action_popover()} />将显示完整的参考文献条目内容。

    ![引文“(Rougier et al. 2014)”下方的浮窗显示了 Ten Simple Rules for Better Figures 的完整参考文献条目](/img/tutorial/write-and-export-citation-popover.webp)

    在实时预览模式下，默认的悬停设置无需按下修饰键即可直接展示此悬浮窗。

  </Step>
  <Step>
    ### 复制参考文献列表

    在<UiLabel name={m.references_view_name()} />侧边栏工具栏中，选择 <UiLabel name={m.references_copy_bibliography()} />。将其粘贴至文本编辑器或文字处理软件中。

    ZotLit 会将富文本和纯文本一并写入剪贴板。目标程序将采用其所支持的呈现格式。

  </Step>
  <Step>
    ### 导出 Word 文档

    保持当前笔记处于活动状态。打开命令面板并运行：

    <Command name={m.command_pandoc_export_name()} />

    保持 <UiLabel name={m.pandoc_export_format_name()} /> 设置为 <UiLabel name={m.pandoc_export_format_docx()} />。<UiLabel name={m.pandoc_export_style_name()} />所在行显示了 ZotLit 将使用的样式。下方的说明标明了该样式的来源。保持该样式设置不变。

    <UiLabel name={m.pandoc_export_destination_name()} />默认位于当前笔记所在目录。如需保存到其他位置，请选择 <UiLabel name={m.pandoc_export_destination_browse()} />。随后选择 <UiLabel name={m.pandoc_export_confirm()} />。

    ![设置为 Word 文档的“导出附带引文”对话框，引文样式为默认（芝加哥作者-年份格式），提示文本为“您的仓库设置指定了此样式。”](/img/tutorial/write-and-export-export-dialog.webp)

    当导出完成时，通知会提示导出的文件名和所使用的引文样式。打开生成的 `.docx` 文件，其中已包含格式化后的正文引文和文末参考文献列表。

  </Step>
</Steps>

现在，您拥有了一份既能在 Obsidian 中无缝查看、又能直接导出为规范引用 Word 文档的 Markdown 源码。

<Callout type="info" title="保持 Markdown 源文件的可移植性">
  ZotLit 会将 `[@doe2024]`
  留在笔记中。实时预览负责将其格式化以便阅读，而导出流程则负责在输出文件中生成参考文献列表。
</Callout>
