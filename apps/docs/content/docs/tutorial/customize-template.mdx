Change the annotation callouts in your first literature note with the Template Workbench View in Obsidian. This tutorial continues from [Create your first literature note](/docs/tutorial/first-note).

<Callout type="info" title="Before you start">
  Use the literature note from [the first tutorial](/docs/tutorial/first-note).
  It needs at least one annotation from a Zotero PDF. If it has none, add a
  highlight in Zotero and update the literature note before you continue.
</Callout>

## Change the callout type

The built-in annotation format uses `[!note]` as the Obsidian callout type. You will change it to `[!quote]`.

<Steps>
  <Step>
    ### Open the Template Workbench View

    Open the literature note in Obsidian. Run <Command name={m.command_customize_note_template_name()} />. If ZotLit asks where to edit, select <UiLabel name={m.modal_workbench_launch_native()} />, then <UiLabel name={m.modal_workbench_launch_open()} />.

    ZotLit opens the template document used by this note and selects its paper for the preview. Read the shared-template guidance above the editor: other notes can use this template too. Check that your note's name appears beside <UiLabel name={m.template_workbench_update_this_note()} />.

  </Step>
  <Step>
    ### Open the annotation format

    Select the <UiLabel name={m.workbench_tab_annotation()} /> tab. The editor shows the format used for one annotation. Choose an annotation from your paper and find its highlighted text in the preview.

    For a short explanation of the format, you can open <UiLabel name={m.workbench_help()} /> beside the annotation instructions.

  </Step>
  <Step>
    ### Change the callout type

    Find `[!note]` in the annotation format and change it to `[!quote]`.

    ZotLit saves the template document automatically. Check that the same annotation now appears in a quote callout in the preview. Your literature note keeps its previous content until you update it.

  </Step>
  <Step>
    ### Update the literature note

    In the Workbench, select <UiLabel name={m.template_workbench_update_this_note()} /> beside your note's name. Wait for the notice that names the updated note, then open that note.

    Its annotations now use quote callouts. Your writing outside the managed region stays unchanged.

  </Step>
</Steps>

## Add the highlight color

Template fields insert data from Zotero. You will add the annotation's `colorName` field to the callout title.

<Steps>
  <Step>
    ### Return to the annotation format

    Run <Command name={m.command_customize_note_template_name()} /> from the literature note. Select the <UiLabel name={m.workbench_tab_annotation()} /> tab.

  </Step>
  <Step>
    ### Insert the color field

    Place the cursor after `{{ zt.pageLabel }}` in the callout title. Add a comma and a space, then type `{{` to open the template field list.

    Select <UiLabel name={m.workbench_field_color_name()} />. The line now contains:

    ```liquid
    [!quote] Page {{ zt.pageLabel }}, {{ zt.colorName }}
    ```

  </Step>
  <Step>
    ### Check the preview

    The annotation preview shows the selected annotation's highlight color. Select a different example in the <UiLabel name={m.workbench_tab_annotation()} /> tab to check another annotation.

  </Step>
  <Step>
    ### Update the note again

    Select <UiLabel name={m.template_workbench_update_this_note()} /> beside your note's name. After ZotLit reports the update, open the note. Each annotation callout title now includes its highlight color, such as `Page 12, yellow`.

  </Step>
</Steps>

## Restore the built-in profile

To remove these changes from the Default profile, open <SettingsPath />. Select <UiLabel name={m.settings_profile_document_restore()} /> on the <UiLabel name={m.settings_profile_document_name()} /> row.

ZotLit moves the custom profile document to Obsidian's configured trash. Update the literature note again to render it with the built-in profile.
