This tutorial picks up where [Create your first literature note](/docs/tutorial/first-note) left off. You will change how annotation callouts look in that note by editing a template file, then use the <UiLabel name={m.template_data_explorer_view_name()} /> to find new data you can add.

<Callout type="info" title="Before you start">
  You need the literature note you created in [the first
  tutorial](/docs/tutorial/first-note). It should contain at least one
  annotation callout (a highlight or note from the Zotero PDF reader). If your
  note has no annotations, open a PDF in Zotero, highlight a passage, then come
  back here.
</Callout>

## Change the callout type

Each annotation in your note renders as a callout block. The built-in template uses `[!note]` as the callout type. In this section you will switch it to `[!quote]` by editing the annotation template file.

<Steps>
  <Step>
    ### Create the editable template file

    Open ZotLit's settings in Obsidian (**Settings > ZotLit**) and go to the <UiLabel name={m.settings_page_templates()} /> sub-page. Under the <UiLabel name={m.settings_template_files_heading()} /> group, find the row labeled <UiLabel name={m.settings_template_name_annotation()} />.

    Click the pen icon button to the right of the row. Its tooltip reads "<UiLabel name={m.settings_template_eject()} />."

    A notice confirms the file was saved: **Template saved to templates/zotlit-annotation.liquid.md** (the exact path depends on your template folder setting).

  </Step>
  <Step>
    ### Edit the template

    Open the file `templates/zotlit-annotation.liquid.md` in your vault. It contains the default annotation template:

    ```liquid
    {% bq %}
    [!note] Page {{ zt.pageLabel }}

    {{ zt.imgLink | embed }}{{ zt.text }}
    {% if zt.comment %}

    {{ zt.comment }}
    {% endif %}
    {% endbq %}
    ```

    Change `[!note]` to `[!quote]` on the second line:

    ```liquid
    [!quote] Page {{ zt.pageLabel }}
    ```

    Save the file. ZotLit picks up template changes as soon as you save. No restart is required.

  </Step>
  <Step>
    ### Update the note

    Open the command palette and run:

    <Command name={m.command_update_note_name()} />

    The managed region re-renders with your new template. Every annotation callout in the note now shows `[!quote]` instead of `[!note]`. You will see a notice: "Literature note updated." Your own writing above or below the managed region stays untouched.

    <Callout type="warn" title="Use the right command">
      A similarly named <Command inline name={m.command_update_note_metadata_name()} /> refreshes frontmatter only. It does not re-render annotation callouts. If your callouts did not change, check that you ran <Command inline name={m.command_update_note_name()} /> (without "metadata").
    </Callout>

  </Step>
</Steps>

## Add annotation color to the title

The annotation template has access to data from each annotation in your Zotero library. One useful property is `colorName`, which holds the highlight color as a word (such as "yellow", "red", or "green"). You can discover properties like this in the <UiLabel name={m.template_data_explorer_view_name()} />.

<Steps>
  <Step>
    ### Open the explorer

    With your literature note open, run the command palette and choose:

    <Command name={m.command_open_template_data_explorer_name()} />

    A panel opens showing the data tree for the current note.

  </Step>
  <Step>
    ### Find the color property

    In the explorer, expand the **annotations** list and find an annotation entry. Right-click that annotation row and choose <UiLabel name={m.template_data_explorer_menu_explore_annotation()} />. This re-roots the tree so that each property's path matches what you write in the annotation template.

    Look for the `colorName` row. Right-click it and choose <UiLabel name={m.template_data_explorer_menu_copy_output()} />. The clipboard now contains `{{ zt.colorName }}`, ready to paste into your template.

  </Step>
  <Step>
    ### Add color to the callout title

    Go back to `templates/zotlit-annotation.liquid.md`. On the callout title line, add a comma after `{{ zt.pageLabel }}` and paste what you copied:

    ```liquid
    [!quote] Page {{ zt.pageLabel }}, {{ zt.colorName }}
    ```

    Save the file.

  </Step>
  <Step>
    ### Update again

    Run <Command inline name={m.command_update_note_name()} /> once more. Each callout title now includes the annotation's highlight color, such as "Page 12, yellow."

  </Step>
</Steps>

## Restoring the default template

If you want to undo your changes, delete the `templates/zotlit-annotation.liquid.md` file from your vault. The next time you run <UiLabel name={m.command_update_note_name()} />, ZotLit renders annotations with the original built-in template.
