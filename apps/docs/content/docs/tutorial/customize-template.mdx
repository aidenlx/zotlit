This tutorial continues from [Create your first literature note](/docs/tutorial/first-note). You will change the annotation callouts in that note with the Template Workbench View.

<Callout type="info" title="Before you start">
  Use the literature note from [the first tutorial](/docs/tutorial/first-note).
  It needs at least one annotation from a Zotero PDF. If it has none, add a
  highlight in Zotero and update the literature note before you continue.
</Callout>

## Change the callout type

The built-in annotation format uses `[!note]` as the Obsidian callout type. You will change it to `[!quote]`.

<Steps>
  <Step>
    ### Open the Template Workbench View

    Open the literature note in Obsidian. Run <Command name={m.command_customize_note_template_name()} />.

    ZotLit opens the profile used by this note. The note's paper is selected for the preview.

  </Step>
  <Step>
    ### Open the annotation format

    Select the <UiLabel name={m.workbench_tab_annotation()} /> tab. The editor shows the format used for one annotation and a preview from the selected paper.

  </Step>
  <Step>
    ### Change the callout type

    Find `[!note]` in the annotation format and change it to `[!quote]`.

    ZotLit saves the profile automatically. The annotation preview now uses a quote callout.

  </Step>
  <Step>
    ### Update the literature note

    Return to the literature note and run <Command name={m.command_update_note_name()} />.

    ZotLit renders the managed region with the updated profile. Your writing outside the managed region stays unchanged.

  </Step>
</Steps>

## Add the highlight color

Template fields insert data from Zotero. You will add the annotation's `colorName` field to the callout title.

<Steps>
  <Step>
    ### Return to the annotation format

    Run <Command name={m.command_customize_note_template_name()} /> from the literature note. Select the <UiLabel name={m.workbench_tab_annotation()} /> tab.

  </Step>
  <Step>
    ### Insert the color field

    Place the cursor after `{{ zt.pageLabel }}` in the callout title. Add a comma and a space, then type `{{` to open the template field list.

    Select <UiLabel name={m.workbench_field_color_name()} />. The line now contains:

    ```liquid
    [!quote] Page {{ zt.pageLabel }}, {{ zt.colorName }}
    ```

  </Step>
  <Step>
    ### Check the preview

    The annotation preview shows the selected annotation's highlight color. Select a different example in the <UiLabel name={m.workbench_tab_annotation()} /> tab to check another annotation.

  </Step>
  <Step>
    ### Update the note again

    Return to the literature note and run <Command name={m.command_update_note_name()} />. Each annotation callout title now includes its highlight color, such as `Page 12, yellow`.

  </Step>
</Steps>

## Restore the built-in profile

To remove these changes from the Default profile, open <SettingsPath />. Select <UiLabel name={m.settings_profile_document_restore()} /> on the <UiLabel name={m.settings_profile_document_name()} /> row.

ZotLit moves the custom profile document to Obsidian's configured trash. Update the literature note again to render it with the built-in profile.
