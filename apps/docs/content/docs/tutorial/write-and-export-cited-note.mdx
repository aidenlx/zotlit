This tutorial takes you from one Zotero item to a cited Word document.

You will insert a literal Pandoc citation such as `[@doe2024]`. ZotLit will format it without changing your Markdown.

## Before you start

Complete the [ZotLit installation](/docs/install-zotlit). You also need ZotLit Companion, the Zotero add-on. [Install the Companion](/docs/install-companion), then keep Zotero open during the tutorial.

[Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/) is recommended for generating and maintaining stable citation keys. It also supplies bibliography data during export. If you do not use it, open **Zotero Settings > Advanced** and enable **Allow other applications on this computer to communicate with Zotero** so ZotLit can use the Zotero local API instead.

<Steps>
  <Step>
    ### Prepare one Zotero item

    Select an item in Zotero and confirm that its **Citation Key** field has a value.

    If you use Better BibTeX, follow its [citation key guide](https://retorque.re/zotero-better-bibtex/citing/) to generate and inspect the key. Keep the generated key as it appears in Zotero.

  </Step>
  <Step>
    ### Install the Pandoc engine

    In Obsidian, open <SettingsPath page={m.settings_page_citations()} setting={m.settings_citation_references_heading()} />. Find <UiLabel name={m.settings_citation_engine_name()} />, then select <UiLabel name={m.settings_citation_engine_install()} />.

    Wait until the row says that Pandoc is installed. The engine formats citations, references, and the exported document.

  </Step>
  <Step>
    ### Insert the citation

    Open a Markdown note in Live Preview. Type `[@`, then type part of the item's title or citation key. A list of matching Zotero items opens below the cursor.

    ![A thesis paragraph in Obsidian ending in "[@ten", with the suggestion list below showing "Ten Simple Rules for Better Figures" by Rougier et al. (2014)](/img/tutorial/write-and-export-insert-citation.webp)

    Select the item and press `Enter`. ZotLit inserts a citation such as:

    ```md
    Recent work reaches a similar conclusion [@doe2024].
    ```

    Move the cursor away from the citation. ZotLit replaces the source with a formatted citation in Live Preview.

  </Step>
  <Step>
    ### Review the reference

    Open the command palette and run:

    <Command name={m.command_open_references_view_name()} />

    The <UiLabel name={m.references_view_name()} /> Sidebar shows the formatted bibliography entry for your citation.

    ![The paragraph now ends in the formatted citation "(Rougier et al. 2014)", and the References Sidebar on the right lists the full bibliography entry for the paper](/img/tutorial/write-and-export-references-sidebar.webp)

  </Step>
  <Step>
    ### Preview the citation

    Hover over the formatted citation in Live Preview. The <UiLabel name={m.settings_citation_hover_action_popover()} /> shows the complete bibliography entry.

    ![A popover below the citation "(Rougier et al. 2014)" showing the complete bibliography entry for Ten Simple Rules for Better Figures](/img/tutorial/write-and-export-citation-popover.webp)

    The default hover settings show this popover without a modifier key in Live Preview.

  </Step>
  <Step>
    ### Copy the bibliography

    In the <UiLabel name={m.references_view_name()} /> Sidebar toolbar, select <UiLabel name={m.references_copy_bibliography()} />. Paste it into a text editor or word processor.

    ZotLit places rich text and plain text on the clipboard. The destination uses the representation it supports.

  </Step>
  <Step>
    ### Export a Word document

    Keep the note active. Open the command palette and run:

    <Command name={m.command_pandoc_export_name()} />

    Leave <UiLabel name={m.pandoc_export_format_name()} /> set to <UiLabel name={m.pandoc_export_format_docx()} />. The <UiLabel name={m.pandoc_export_style_name()} /> row shows the style ZotLit will use. The line below it says where that style comes from. Leave the style as it is.

    <UiLabel name={m.pandoc_export_destination_name()} /> starts next to your note. To save the document somewhere else, select <UiLabel name={m.pandoc_export_destination_browse()} />. Then select <UiLabel name={m.pandoc_export_confirm()} />.

    ![The Export with citations dialog set to Word document, with the citation style Default (Chicago author-date) and the line "Your vault settings set this style."](/img/tutorial/write-and-export-export-dialog.webp)

    When the export finishes, a notice names the file and the citation style it used. Open the resulting `.docx` file. It contains your formatted citation and a bibliography.

  </Step>
</Steps>

You now have one Markdown source that works in Obsidian and produces a cited Word document.

<Callout type="info" title="Your Markdown stays portable">
  ZotLit leaves `[@doe2024]` in the note. Live Preview formats it for reading,
  and export creates the bibliography in the output file.
</Callout>
