在 Obsidian 中使用模板工作台视图，修改第一篇文献笔记中的标注 callout。本教程紧接[创建第一篇文献笔记](/docs/tutorial/first-note)。

<Callout type="info" title="准备工作">
  请使用[第一篇教程](/docs/tutorial/first-note)中创建的文献笔记。
  该笔记需要至少包含一条来自 Zotero PDF 的批注。如果尚无批注，请先在 Zotero
  中添加一条高亮，并在继续前更新文献笔记。
</Callout>

## 修改 callout 类型

内置的标注格式使用 `[!note]` 作为 Obsidian callout 类型。您将把它修改为 `[!quote]`。

<Steps>
  <Step>
    ### 打开模板工作台视图

    在 Obsidian 中打开该文献笔记。运行命令 <Command name={m.command_customize_note_template_name()} />。

    ZotLit 会在新窗口中打开此笔记所使用的模板文档，并选择对应的论文用于预览。当您自定义内置模板时，ZotLit 会在您的模板文件夹中保存一份可编辑的副本。即使您未做更改直接关闭窗口，该副本也会保留。

    阅读编辑器上方的共享模板说明：在此模板更新时，所做的修改会影响使用该模板的每一篇笔记。确认您的笔记名称显示在 <UiLabel name={m.template_workbench_update_this_note()} /> 旁边。

  </Step>
  <Step>
    ### 打开标注格式

    选择 <UiLabel name={m.workbench_tab_annotation()} /> 标签页。编辑器将显示用于单条标注的格式。预览区域会在 <UiLabel name={m.workbench_annotation_example()} /> 下显示论文中的一条标注。如需显示其他标注，请选择编辑器顶部的 <UiLabel name={m.workbench_choose_annotation()} />。

    如需查看该格式的简要说明，可打开标注操作说明旁边的 <UiLabel name={m.workbench_help()} />。

  </Step>
  <Step>
    ### 修改 callout 类型

    在标注格式中找到 `[!note]` 并将其改为 `[!quote]`。

    ZotLit 会自动保存模板文档。检查预览中同一条标注现在是否已经显示在 quote 类型的 callout 中。在您主动更新之前，文献笔记仍会保持先前的内容。

    ![打开了标注标签页的模板工作台窗口。编辑器中的 callout 行现在使用 quote 类型，右侧预览在标题为 Page 1 的引用 callout 中显示第一条高亮](/img/tutorial/customize-template-workbench-quote.webp)

  </Step>
  <Step>
    ### 更新文献笔记

    在工作台中，选择笔记名称旁边的 <UiLabel name={m.template_workbench_update_this_note()} />。等待提示显示该笔记已更新的通知，然后打开该笔记。

    笔记中的批注现在已改用 quote callout。您在受管区域之外书写的内容完好保留。

    ![位于 Annotations 标题下的笔记 rougier2014，每条高亮现在均显示在带有引号图标、标题为 Page 1 的引用 callout 中](/img/tutorial/customize-template-note-quote.webp)

  </Step>
</Steps>

## 添加高亮颜色

模板字段可插入来自 Zotero 的数据。您将把标注的 `colorName` 字段添加到 callout 标题中。

<Steps>
  <Step>
    ### 返回标注格式

    在文献笔记中运行 <Command name={m.command_customize_note_template_name()} />。选择 <UiLabel name={m.workbench_tab_annotation()} /> 标签页。

  </Step>
  <Step>
    ### 插入颜色字段

    将光标移动到 callout 标题行的末尾（`{% endif %}` 之后）。输入一个逗号和一个空格，然后输入 `{{` 打开模板字段补全列表。在您选定字段前，工作台会报告语法问题，选定字段就位后该提示会自动消除。

    选择 `colorName`。该行现在包含：

    ```liquid
    [!quote] Page {% if zt.pageLabel %}{{ zt | file_link: zt.pageLabel | default: zt.pageLabel }}{% endif %}, {{ zt.colorName }}
    ```

  </Step>
  <Step>
    ### 检查预览

    预览标题末尾现在会显示标注的高亮颜色，例如 `Page 1, yellow`。选择 <UiLabel name={m.workbench_choose_annotation()} /> 并选取其他标注以检查其对应颜色。

  </Step>
  <Step>
    ### 再次更新笔记

    选择笔记名称旁边的 <UiLabel name={m.template_workbench_update_this_note()} />。当 ZotLit 报告更新完成后，打开笔记。每个标注 callout 的标题现在都会包含其高亮颜色，如 `Page 1, yellow`。

    ![带有 quote callout 的笔记 rougier2014，标题分别为 Page 1, yellow，随后是 Page 1, green 与 Page 1, purple](/img/tutorial/customize-template-note-color.webp)

  </Step>
</Steps>

## 恢复内置配置方案

若要从默认配置方案中清除这些修改，请打开 <SettingsPath />。在 <UiLabel name={m.settings_profile_document_name()} /> 所在行选择 <UiLabel name={m.settings_profile_document_restore()} />，然后点击 <UiLabel name={m.settings_profile_document_restore_action()} /> 确认。

ZotLit 会将自定义配置方案文档移动到 Obsidian 配置的废纸篓中。在文献笔记中运行 <Command name={m.command_update_note_name()} />，即可使用内置配置方案对其重新渲染。
