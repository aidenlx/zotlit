借助 Obsidian 中的 Template Workbench View（模板工作台视图），修改你第一篇文献笔记中的批注标注框（Callout）。本教程承接自[创建你的第一篇文献笔记](/docs/tutorial/first-note)。

<Callout type="info" title="开始之前">
  请使用[第一篇教程](/docs/tutorial/first-note)中创建的文献笔记。 笔记所属的
  Zotero PDF 需要包含至少一条批注。如果没有，请先在 Zotero
  中添加一段高亮并更新该文献笔记后再继续。
</Callout>

## 修改标注框类型

内置的批注格式使用 `[!note]` 作为 Obsidian 标注框类型。你将把它修改为 `[!quote]`。

<Steps>
  <Step>
    ### 打开模板工作台视图

    在 Obsidian 中打开文献笔记。运行 <Command name={m.command_customize_note_template_name()} />。

    ZotLit 会在新窗口中打开该笔记所使用的模板文档，并自动选择对应的文献以供预览。当你自定义内置模板时，ZotLit 会在你的模板文件夹中保存一份可编辑副本。即使你未做修改就关闭窗口，该副本也会保留。

    请阅读编辑器上方的共享模板说明：当你对模板进行编辑后，所有使用该模板的笔记在下次更新时都会同步发生变化。确认你的笔记名称出现在 <UiLabel name={m.template_workbench_update_this_note()} /> 旁边。

  </Step>
  <Step>
    ### 打开批注格式

    选择 <UiLabel name={m.workbench_tab_annotation()} /> 标签页。编辑器将展示单条批注的格式模板。右侧预览区在 <UiLabel name={m.workbench_annotation_example()} /> 下展示来自你论文中的一条批注。如需查看其他批注，请选择编辑器顶部的 <UiLabel name={m.workbench_choose_annotation()} />。

    如需查看格式的简要说明，可打开批注指南旁边的 <UiLabel name={m.workbench_help()} />。

  </Step>
  <Step>
    ### 修改标注框类型

    在批注格式中找到 `[!note]` 并将其改为 `[!quote]`。

    ZotLit 会自动保存模板文档。检查预览区中的同一条批注是否已经转换为引用（quote）标注框。在主动更新之前，你的文献笔记正文仍会保持原有内容。

    ![模板工作台窗口，已打开“批注”标签页。编辑器中的标注框行已改为 quote 类型，右侧预览以标题为 Page 1 的引用标注框显示第一处高亮](/img/tutorial/customize-template-workbench-quote.webp)

  </Step>
  <Step>
    ### 更新文献笔记

    在工作台中，点击笔记名称旁的 <UiLabel name={m.template_workbench_update_this_note()} />。等待提示显示已更新笔记名称后，打开该笔记。

    笔记中的批注现已全部使用引用标注框。你在托管区域之外撰写的内容保持不变。

    ![Annotations 标题下的 rougier2014 笔记，每处高亮均显示为带有引号图标且标题为 Page 1 的引用标注框](/img/tutorial/customize-template-note-quote.webp)

  </Step>
</Steps>

## 添加高亮颜色

模板字段用于插入来自 Zotero 的数据。你将把批注的 `colorName` 字段添加到标注框标题中。

<Steps>
  <Step>
    ### 返回批注格式

    在文献笔记中运行 <Command name={m.command_customize_note_template_name()} />。选择 <UiLabel name={m.workbench_tab_annotation()} /> 标签页。

  </Step>
  <Step>
    ### 插入颜色字段

    将光标置于标注框标题行的末尾，即 `{% endif %}` 之后。输入一个逗号和一个空格，然后输入 `{{` 打开模板字段候选列表。在选定字段之前，工作台会提示语法问题；一旦补全字段，提示即会自动消除。

    选择 `colorName`。该行现在变为：

    ```liquid
    [!quote] Page {% if zt.pageLabel %}{{ zt | file_link: zt.pageLabel | default: zt.pageLabel }}{% endif %}, {{ zt.colorName }}
    ```

  </Step>
  <Step>
    ### 检查预览

    预览标题现已在末尾附带批注的高亮颜色，例如 `Page 1, yellow`。点击 <UiLabel name={m.workbench_choose_annotation()} /> 并挑选其他批注以检查其颜色效果。

  </Step>
  <Step>
    ### 再次更新笔记

    点击笔记名称旁的 <UiLabel name={m.template_workbench_update_this_note()} />。在 ZotLit 提示更新完成后，打开笔记。每条批注的标注框标题现在都包含了其对应的高亮颜色，例如 `Page 1, yellow`。

    ![包含引用标注框的 rougier2014 笔记，标题依次为 Page 1, yellow、Page 1, green、Page 1, purple](/img/tutorial/customize-template-note-color.webp)

  </Step>
</Steps>

## 恢复内置配置方案

若要从默认配置方案中撤销这些修改，请打开 <SettingsPath />。在 <UiLabel name={m.settings_profile_document_name()} /> 行上选择 <UiLabel name={m.settings_profile_document_restore()} />，然后点击 <UiLabel name={m.settings_profile_document_restore_action()} /> 进行确认。

ZotLit 会将自定义配置方案文档移至 Obsidian 配置的废纸篓。在文献笔记中运行 <Command name={m.command_update_note_name()} />，即可重新按内置配置方案进行渲染。
