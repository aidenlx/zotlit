ZotLit 直接从 Zotero 数据库读取文库数据。浏览和阅读只需访问数据库即可：文库视图、搜索以及在 Obsidian 中打开 PDF，均可在 Zotero 关闭且未安装 Zotero 插件的情况下正常工作。ZotLit Companion（Zotero 插件）可让最新更改随时可用，并将 Zotero 操作连接到 Obsidian。实时更新则提供了可选的第三种连接方式。

ZotLit 支持 Zotero 9 及更高版本。要从 Obsidian 保存标注更改，需要 Zotero 10 或更高版本。在 Zotero 9 下，你可以阅读 PDF 及其标注，但无法对其进行编辑。

## 读取 Zotero 数据库 [#reading-the-zotero-database]

Zotero 运行时可能会将最新更改保存在单独的数据库文件中。ZotLit 通过读取模式访问文库，且不会干扰 Zotero 的正常运行。

默认设置 <UiLabel name={m.settings_db_read_mode_auto()} /> 会选择当前环境下的最佳模式。在 macOS 和 Linux 上，它会尝试使用 <UiLabel name={m.settings_db_read_mode_reflink()} />。<UiLabel name={m.settings_db_read_mode_auto()} /> 会在 APFS、Btrfs 以及启用了 reflink 的 XFS 文件系统上使用克隆。在 Windows 和其他文件系统（例如 ext4）上，<UiLabel name={m.settings_db_read_mode_auto()} /> 会自动回退到 <UiLabel name={m.settings_db_read_mode_immutable()} />。你可以在“设置”中覆盖此选项。

<UiLabel name={m.settings_db_read_mode_reflink()} />
能够快速创建轻量的数据库快照。它可以读取最新编辑，也是
<UiLabel name={m.settings_db_read_mode_auto()} /> 在支持克隆的 macOS 或 Linux
文件系统上优先采用的模式。

<UiLabel name={m.settings_db_read_mode_immutable()} />
直接读取数据库文件而无需创建副本。它是
<UiLabel name={m.settings_db_read_mode_auto()} />
在克隆不可用时使用的模式。此模式仅读取主数据库文件。在 Zotero
将更改写入主文件之前，最新编辑可能会一直保留在独立的预写式日志中。

Companion 会通过将最新更改写入主数据库文件来保持其最新状态。其 <UiLabel name={m["zotero.prefs_wal_checkpoint.label"]()} /> 设置默认已启用。这一数据库检查点机制无需[实时更新](/docs/how-to/set-up-live-updates)即可生效。

<UiLabel name={m.settings_db_read_mode_copy()} />
适用于所有文件系统并能读取最新编辑。它每次都会复制整个数据库，因此速度较慢且占用更多磁盘空间，在大型
Zotero 文库中尤为明显。
<UiLabel name={m.settings_db_read_mode_auto()} />
从不自动选择此模式；仅在其他模式均不可用时手动选用。

有关完整选项列表和说明，请参见[设置参考](/docs/reference/settings)。

### 针对每台设备的路径解析 [#per-device-path-resolution]

配置文件目录和数据目录是随电脑不同的绝对文件系统路径。ZotLit 会按设备分别解析它们：在每台机器上，它会自动检测默认的 Zotero 配置文件（来自 `profiles.ini`）和数据目录。如果 Zotero 位于非默认路径，只需在该设备上设置设备覆盖。该覆盖设置保存在本地（按仓库、按设备隔离），绝不会通过仓库同步，因此一台电脑上的路径不会覆盖另一台电脑。

详细步骤请参阅[在多台设备上使用 ZotLit](/docs/how-to/sync-across-devices)。

## ZotLit Companion [#zotlit-companion]

Companion 在 Zotero 内部添加了右键菜单操作。这些操作可用于打开、更新和导入笔记，以及在 Obsidian 中打开条目的 PDF。Companion 还可以向 Obsidian 推送实时事件。

Companion 为 ZotLit 保持 Zotero 主数据库文件处于最新状态。Zotero 使用预写式日志（WAL）在将最新更改写入主文件前进行暂存。Companion 会在 Zotero 更新文库后通知其将这些更改写入主文件。此行为默认启用，且无需服务器即可工作。

Companion 不会在后台运行服务器。其右键菜单操作通过构建 `obsidian://zotlit/...` 协议链接并交给操作系统，由操作系统将其传递给 Obsidian。即使 Obsidian 中未启用任何服务器或网络监听器，该功能也能正常工作。

## 协议链接与实时更新的区别 [#protocol-links-versus-live-updates]

ZotLit 在 Zotero 和 Obsidian 之间使用两种传输机制。它们服务于不同目的，并可独立运行。

### 协议链接（无需服务器） [#protocol-links-no-server-required]

在 Zotero 中右键点击某个条目并选择 ZotLit 操作（打开笔记、更新笔记、导入、打开 PDF）时，Companion 会构建一个 `obsidian://zotlit/...` URL 并打开它。Obsidian 接收到该 URL 后，由 ZotLit 执行相应操作。

安装 ZotLit 和 Companion 后，协议链接即可开箱即用。它们携带有来源标识符，因此 ZotLit 只会处理来自预期的 Zotero 安装的链接。

<Callout type="info" title="批量操作与 URL 长度限制">
  批量操作（在 Zotero 中选中多个条目）可能会超出 URL
  长度限制。发生这种情况时，Companion 会回退为向 ZotLit 服务器发送 HTTP
  请求。如果未启用服务器，Zotero
  会弹出提示，建议你启用服务器或减少选中的条目数量。
</Callout>

### 实时更新（需要服务器） [#live-updates-server-required]

实时更新是一个推送通道。当你在 Zotero PDF 阅读器中阅读和做标注时，Companion 会向 Obsidian 发送 HTTP 通知，驱动标注视图的跟随阅读器模式。在 Companion 完成对主数据库文件的写入后，还会发送一个不含负载的信号通知 ZotLit 刷新，以便更改立即可见。

将这些更改写入主文件的数据库检查点机制独立于实时更新运行。实时更新仅增加了通知 ZotLit 何时刷新的信号。

实时更新需要启用两项内容：

- **在 Obsidian 中**：启用 ZotLit 服务器（默认监听本地端口 9091 的 HTTP 服务），并开启 <UiLabel name={m.settings_live_updates_enabled_name()} />。
- **在 Zotero 中**：启用 Companion 的通知选项，并指向相同的地址。

两端均携带来源标识符和协议版本。服务器会丢弃来自未识别 Zotero 安装的请求（来源不匹配），并拒绝协议版本不兼容的请求。

<Callout type="info" title="默认关闭">
  Obsidian 服务器和 Companion
  的通知偏好设置默认均处于禁用状态。无需开启它们，协议链接即可处理所有右键菜单操作。仅在需要来自
  Zotero 的实时推送时才启用实时更新。
</Callout>

## 将标注更改保存到 Zotero [#saving-annotation-changes-to-zotero]

数据库连接仅支持只读。在 Obsidian 中编辑标注时，如果 Zotero 正在运行，ZotLit 会将更改发送给 Zotero。Zotero 会像在自身阅读器中创建标注一样保存它，因此更改会同步到你的 Zotero 文库中。

ZotLit 通过 Zotero 本地 API 发送这些更改，这是 Zotero 为同一台电脑上的其他应用程序提供的连接接口。需要满足两个条件：

- **在 Zotero 中**：在**设置 > 高级**（Settings > Advanced）下，开启**允许本计算机上的其他应用程序与 Zotero 通信**（Allow other applications on this computer to communicate with Zotero）。
- **用户授权**：首次允许编辑时，Zotero 会弹出授权对话框。选择一次**总是允许**（Always Allow）。ZotLit 仅为当前设备上的当前仓库保存此授权，因此在每台电脑上的每个仓库只需授权一次。

该连接不使用协议链接或 ZotLit 服务器。具体步骤请参阅[在 Obsidian 中编辑 PDF 标注](/docs/how-to/edit-pdf-annotations)。

## 各部分如何协同工作 [#how-the-pieces-fit-together]

ZotLit 可以在 Zotero 关闭时读取数据库，这已完全满足浏览和阅读的需求。在 Zotero 中安装 Companion 可在数据更改后保持其最新，特别是在 ZotLit 以 <UiLabel name={m.settings_db_read_mode_immutable()} /> 模式读取时。协议链接和实时更新同样依赖于 Companion。[保持 Zotero 与 Obsidian 同步](/docs/how-to/keep-zotero-and-obsidian-in-sync)详细介绍了完整的配置流程。
