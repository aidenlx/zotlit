本页面详细记录了所有 `obsidian://zotlit/*` 自定义协议链接动作。这些深度链接允许配套插件 ZotLit Companion 以及自动化脚本、系统启动器等外部工具直接在 Obsidian 中触发特定的 ZotLit 操作。

## 通用参数

每个协议链接都必须携带 `source-id` 参数：一个 8 位的十六进制字符串，用于标识生成该链接的 Zotero 安装实例。ZotLit 会严密校验并拒绝任何 `source-id` 与当前连接数据库不匹配的外部链接。

如果 Zotero 数据库尚未完成加载，ZotLit 会提示 <UiLabel name={m.notice_protocol_db_unavailable()} />。

## 目标打开位置 [#pane-type]

有四个动作会在您眼前打开窗口界面：`open`、`update`、`explore` 以及 `open-attachment`。它们均支持可选的 `paneType` 参数，书写形式遵循 [Obsidian 原生 URI 规范](https://help.obsidian.md/Extending+Obsidian/Obsidian+URI)：

| 参数取值 | 执行结果                                   |
| -------- | ------------------------------------------ |
| `tab`    | 在新标签页中打开。                         |
| `split`  | 在新分栏窗格组中打开。                     |
| `window` | 在独立的弹出浮动窗口中打开（仅限桌面端）。 |

```
obsidian://zotlit/open?item=<id>&source-id=<hash>&paneType=tab
```

如果省略此参数，则沿用各动作的默认习惯：`open`、`update` 与 `open-attachment` 会直接替换上一个活动标签页，而 `explore` 则复用侧边栏中已有的模板数据浏览器。传入这三者之外的值会提示 <UiLabel name={m.notice_protocol_invalid()} /> 并终止执行。

ZotLit Companion 会自动为其在 Zotero 右键菜单中生成的链接注入该参数。在 Zotero 首选项的 <UiLabel name={m["zotero.prefs_pane_label"]()} /> 面板下的 <UiLabel name={m["zotero.prefs_open_section"]()} /> 区域中，<UiLabel name={m["zotero.prefs_pane_type"]()} /> 可配置打开目标。默认的 <UiLabel name={m["zotero.prefs_pane_type_active.label"]()} /> 会在链接中省略该参数。

## 支持的动作

### open

打开指定 Zotero 条目现有的文献笔记，若尚不存在则自动创建。

```
obsidian://zotlit/open?item=<id>&source-id=<hash>
```

| 参数名      | 数据类型     | 是否必填 | 详细描述                                                                         |
| ----------- | ------------ | -------- | -------------------------------------------------------------------------------- |
| `item`      | 整数         | 是       | Zotero 条目 ID                                                                   |
| `source-id` | 8 位十六进制 | 是       | Zotero 安装实例标识符                                                            |
| `profile`   | 12 位 ID     | 否       | 指定用于创建或更新该笔记的配置方案 ID。                                          |
| `paneType`  | 分栏类型取值 | 否       | 笔记打开的目标位置：`tab`、`split` 或 `window`。详见[目标打开位置](#pane-type)。 |

`profile` 参数指定了动作解析笔记时所采用的配置方案。若笔记尚未创建，将使用该配置方案进行创建。若笔记已存在，则保持该笔记已绑定的原有配置方案不变；若传入了不同的配置方案，系统仅会汇报现有配置方案，不作任何改动。

该取值为 12 位的字母或数字组合，即其[配置方案文档](/docs/reference/templates/profile-document)中声明的 `id`，而非显示标签。若省略此参数，则按常规规则解析配置方案。传入未知的 ID 会弹出提示通知并终止操作。

### update

使用当前 Zotero 数据重新渲染文献笔记。

```
obsidian://zotlit/update?item=<id>&source-id=<hash>
```

| 参数名      | 数据类型             | 是否必填 | 详细描述                                                                                 |
| ----------- | -------------------- | -------- | ---------------------------------------------------------------------------------------- |
| `item`      | 整数                 | 是       | Zotero 条目 ID                                                                           |
| `source-id` | 8 位十六进制         | 是       | Zotero 安装实例标识符                                                                    |
| `scope`     | `full` 或 `metadata` | 否       | 更新范围。默认值为 `full`（frontmatter 和正文受管区域）。`metadata` 仅更新 frontmatter。 |
| `profile`   | 12 位 ID             | 否       | 用于创建或更新笔记的配置方案，以配置方案 ID 指定。                                       |
| `paneType`  | 窗格类型             | 否       | 笔记打开的位置：`tab`、`split` 或 `window`。详见[目标打开位置](#pane-type)。             |

`profile` 指定该条目使用的配置方案。更新使用笔记已记录的配置方案。如果链接指定了不同的配置方案，系统会报告笔记保留的原配置方案，并跳过更新。如果该条目尚无笔记，则使用指定的配置方案创建笔记。

该值为 12 位字母或数字，即[配置方案文档](/docs/reference/templates/profile-document)声明的 `id`。未知 ID 会触发提示并终止操作。

---

### update-many

批量更新多篇文献笔记，并打开可交互的确认与进度窗口。

```
obsidian://zotlit/update-many?items=<id,id,...>&source-id=<hash>
```

| 参数名      | 数据类型             | 是否必填 | 详细描述                                   |
| ----------- | -------------------- | -------- | ------------------------------------------ |
| `items`     | 逗号分隔的整数       | 是       | Zotero 条目 ID（自动去重；允许末尾有逗号） |
| `source-id` | 8 位十六进制         | 是       | Zotero 安装实例标识符                      |
| `scope`     | `full` 或 `metadata` | 否       | 默认值为 `full`                            |
| `profile`   | 12 位 ID             | 否       | 此批次创建笔记时使用的配置方案。           |

`profile` 是此批次指定的配套配置方案。此批次新建的每篇笔记均使用该方案。已有笔记保留各自的配置方案；批次会报告这些笔记已保留，而不重新渲染。该值为 12 位字母或数字，即[配置方案文档](/docs/reference/templates/profile-document)声明的 `id`。未知 ID 会触发提示并终止整批操作。

<Callout type="info">
  如果批次过大，无法放入 URL，ZotLit 还提供 `PUT {host}
  /literature-notes`，在请求体中接收相同参数（包括 `profile`），并通过
  `source-id` 请求头校验数据源。
</Callout>

---

### import-note

将单篇 Zotero 笔记（或某条目的子笔记）导入仓库。

```
obsidian://zotlit/import-note?item=<id>&mode=<mode>&source-id=<hash>
```

| 参数名      | 数据类型          | 是否必填 | 详细描述                                        |
| ----------- | ----------------- | -------- | ----------------------------------------------- |
| `item`      | 整数              | 是       | Zotero 条目 ID                                  |
| `mode`      | `note` 或 `child` | 是       | `note` 导入独立笔记；`child` 导入父条目的子笔记 |
| `source-id` | 8 位十六进制      | 是       | Zotero 安装实例标识符                           |

---

### import-notes

批量导入多篇 Zotero 笔记。

```
obsidian://zotlit/import-notes?items=<id,id,...>&mode=<mode>&source-id=<hash>
```

| 参数名      | 数据类型          | 是否必填 | 详细描述                                   |
| ----------- | ----------------- | -------- | ------------------------------------------ |
| `items`     | 逗号分隔的整数    | 是       | Zotero 条目 ID（自动去重；允许末尾有逗号） |
| `mode`      | `note` 或 `child` | 是       | 导入模式                                   |
| `source-id` | 8 位十六进制      | 是       | Zotero 安装实例标识符                      |

<Callout type="info">
  如果批次过大，无法放入 URL，ZotLit 还提供 `PUT {host}/zotero-notes`，
  在请求体中接收相同参数，并通过 `source-id` 请求头校验数据源。
</Callout>

---

### update-all [#update-all]

为一个文献库中的每个条目创建或更新文献笔记，也可将范围限定为一个分类。打开与 `update-many` 相同的批量确认窗口。

```
obsidian://zotlit/update-all?source-id=<hash>&library=<groupID>&collection=<key>
```

| 参数名       | 数据类型     | 是否必填 | 详细描述                                                               |
| ------------ | ------------ | -------- | ---------------------------------------------------------------------- |
| `source-id`  | 8 位十六进制 | 是       | Zotero 安装实例标识符                                                  |
| `library`    | 整数         | 否       | 目标文献库的 Zotero 群组 ID。省略或设为 `0` 时，目标为**我的文献库**。 |
| `collection` | 8 位键       | 否       | 目标文献库中的分类键。覆盖该分类及其全部子分类；省略时覆盖整个文献库。 |

---

### import-all-notes [#import-all-notes]

导入一个文献库中所有常规条目的子笔记及所有独立笔记，也可将范围限定为一个分类。打开与 `import-notes` 相同的批量确认窗口。此动作收集两种笔记，因此没有 `mode` 参数。

```
obsidian://zotlit/import-all-notes?source-id=<hash>&library=<groupID>&collection=<key>
```

| 参数名       | 数据类型     | 是否必填 | 详细描述                                                               |
| ------------ | ------------ | -------- | ---------------------------------------------------------------------- |
| `source-id`  | 8 位十六进制 | 是       | Zotero 安装实例标识符                                                  |
| `library`    | 整数         | 否       | 目标文献库的 Zotero 群组 ID。省略或设为 `0` 时，目标为**我的文献库**。 |
| `collection` | 8 位键       | 否       | 目标文献库中的分类键。覆盖该分类及其全部子分类；省略时覆盖整个文献库。 |

#### 精确指定目标 [#exact-target]

对这两个动作，`library` 都会精确指定目标。不论您的[文献库作用域](/docs/reference/settings#library-scope)包含哪些文献库，ZotLit 都只操作指定的文献库，因此链接也适用于您从未选入作用域的文献库。同一个分类键可能存在于两个文献库中；`library` 决定链接指向哪一个。

省略 `library` 的链接仍以**我的文献库**为目标，与以往版本一致。旧版 ZotLit 写入的永久链接因此保留原意。

以下两种情况会在写入任何笔记前终止操作：

- 此 Zotero 数据库已不包含指定的 `library`，显示 <UiLabel name={m.batch_all_library_unavailable()} />。
- 目标文献库不包含指定的 `collection`，显示 <UiLabel name={m.notice_collection_not_found()} />。

Obsidian 命令面板提供相同的两项操作，但不指定精确目标，而是覆盖文献库作用域中的每个可用文献库。请参阅[命令](/docs/reference/commands)。

### explore

打开模板数据浏览器，并定位到指定条目。

```
obsidian://zotlit/explore?item=<id>&source-id=<hash>
```

| 参数名       | 数据类型     | 是否必填 | 详细描述                                                                       |
| ------------ | ------------ | -------- | ------------------------------------------------------------------------------ |
| `item`       | 整数         | 是       | Zotero 条目 ID                                                                 |
| `source-id`  | 8 位十六进制 | 是       | Zotero 安装实例标识符                                                          |
| `annotation` | 8 位键       | 否       | Zotero 批注键（字符集：`23456789A-NP-Z`）。提供后，浏览器会定位到该批注。      |
| `paneType`   | 窗格类型     | 否       | 浏览器打开的位置：`tab`、`split` 或 `window`。详见[目标打开位置](#pane-type)。 |

---

### open-attachment [#open-attachment]

在 Obsidian 自带的 PDF 阅读器中打开 Zotero PDF 附件。

```
obsidian://zotlit/open-attachment?item=<id>&source-id=<hash>
```

| 参数名      | 数据类型     | 是否必填 | 详细描述                                                                     |
| ----------- | ------------ | -------- | ---------------------------------------------------------------------------- |
| `item`      | 整数         | 是       | Zotero 条目 ID，可指向 PDF 附件或带有 PDF 附件的常规条目                     |
| `source-id` | 8 位十六进制 | 是       | Zotero 安装实例标识符                                                        |
| `paneType`  | 窗格类型     | 否       | PDF 打开的位置：`tab`、`split` 或 `window`。详见[目标打开位置](#pane-type)。 |

`item` 可直接指定附件，也可指定其所属的常规条目；ZotLit 会辨别目标类型并据此查找 PDF。只有一个 PDF 时直接打开，有多个时则显示按文件名列出的选择器。

此动作仅提供 PDF 附件，跳过 EPUB、网页快照及其他文件类型。条目没有 PDF 时显示 <UiLabel name={m.notice_no_pdf_attachment()} />；PDF 文件已不在磁盘上时显示 <UiLabel name={m.notice_pdf_file_missing()} />。这两种情况都不会改用 Zotero 自带的阅读器。

无论文件位于仓库内还是 Zotero 的存储文件夹中，均可打开。

## 动作概览 [#action-summary]

| 动作               | 单条目 | 批量 | scope 参数 | mode 参数 | library 参数 | profile 参数 | paneType 参数 |
| ------------------ | :----: | :--: | :--------: | :-------: | :----------: | :----------: | :-----------: |
| `open`             |   是   |  —   |     —      |     —     |      —       |      是      |      是       |
| `update`           |   是   |  —   |     是     |     —     |      —       |      是      |      是       |
| `update-many`      |   —    |  是  |     是     |     —     |      —       |      是      |       —       |
| `import-note`      |   是   |  —   |     —      |    是     |      —       |      —       |       —       |
| `import-notes`     |   —    |  是  |     —      |    是     |      —       |      —       |       —       |
| `update-all`       |   —    |  是  |     —      |     —     |      是      |      —       |       —       |
| `import-all-notes` |   —    |  是  |     —      |     —     |      是      |      —       |       —       |
| `explore`          |   是   |  —   |     —      |     —     |      —       |      —       |      是       |
| `open-attachment`  |   是   |  —   |     —      |     —     |      —       |      —       |      是       |

`profile` 用于文献笔记动作 `open`、`update` 和 `update-many`；对应的 `PUT {host}/literature-notes` 请求体也可携带此参数。笔记导入动作不接受该参数。`paneType` 用于会打开界面的动作 `open`、`update`、`explore` 和 `open-attachment`。其他动作最终只显示提示或确认窗口，不打开窗格，因此不接受该参数。
