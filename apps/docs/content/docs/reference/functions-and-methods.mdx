This reference lists every function, method, and property of the [Filter Expression](/docs/concepts/how-zotlit-query-works#steps) language. You write Filter Expressions in the filters and formulas of a [query file](/docs/reference/query-file-format) and in a [Profile Match](/docs/reference/templates/profile-match).

Each signature shows the parameters and the type of the result. A parameter marked `?` can be left out, and `...` takes any number of arguments. A result can also be null when data is missing.

## Global functions [#functions]

A global function is called by its name, such as `today()`.

| Signature                                         | Description                                                                                                                                                                 |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `if(condition: any, then: any, else?: any) → any` | The `then` value when the condition is truthy, otherwise the `else` value or null; only the selected branch is evaluated.                                                   |
| `number(value: any) → number`                     | The value as a number: a text read as a decimal number, a boolean as 1 or 0, and a date as its Unix time in milliseconds; a text that is not a number gives an Error Value. |
| `min(...values: number \| null) → number`         | The smallest number among the arguments, or null when no argument is a number.                                                                                              |
| `max(...values: number \| null) → number`         | The largest number among the arguments, or null when no argument is a number.                                                                                               |
| `now() → date`                                    | The instant of the Query Clock as a date with a time, the same for every call in one query.                                                                                 |
| `today() → date`                                  | The calendar day of the Query Clock in the query time zone, as a date.                                                                                                      |
| `date(text: string \| date) → date`               | The text read as a date, or a date unchanged; a text that is not a date gives an Error Value.                                                                               |
| `duration(text: string) → duration`               | The text read as a duration, such as `"7d"` or `"PT1H30M"`; a text that is not a duration gives an Error Value.                                                             |
| `list(value: any) → list`                         | The value as a list: a list unchanged, null as the empty list, and any other value as a list of that one element.                                                           |

## Methods [#methods]

A method is called on a value, such as `title.lower()`. Each group lists the methods of one value type.

### Methods of every value [#any-methods]

| Signature                                                                                                                                               | Description                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `any.toString() → string`                                                                                                                               | The value as text.                                                                                                            |
| `any.isType(type: "any" \| "null" \| "boolean" \| "record" \| "number" \| "string" \| "list" \| "date" \| "duration" \| "regexp" \| "error") → boolean` | Whether the value has the named value type; `any` names every type.                                                           |
| `any.isTruthy() → boolean`                                                                                                                              | Whether the value is truthy: false for null, false, 0, the empty text, the empty list, an empty duration, and an Error Value. |

### Null methods [#null-methods]

| Signature                  | Description          |
| -------------------------- | -------------------- |
| `null.isEmpty() → boolean` | True: null is empty. |

### List methods [#list-methods]

| Signature                                          | Description                                                                                                                                                                        |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `list.isEmpty() → boolean`                         | Whether the list has no elements.                                                                                                                                                  |
| `list.contains(value: any) → boolean`              | Whether the list has an element equal to `value`.                                                                                                                                  |
| `list.containsAny(...values: any) → boolean`       | Whether the list has an element equal to at least one of the values, or of the elements of a single list argument.                                                                 |
| `list.containsAll(...values: any) → boolean`       | Whether the list has an element equal to each of the values, or to each element of a single list argument.                                                                         |
| `list.flat() → list`                               | The list with each element that is a list replaced by its elements, one level deep.                                                                                                |
| `list.join(separator: string) → string`            | The elements of the list as text joined by `separator`, with null as the empty text.                                                                                               |
| `list.reverse() → list`                            | The list with its elements in reverse order.                                                                                                                                       |
| `list.slice(start: number, end?: number) → list`   | The elements of the list from index `start` up to, not including, `end`; a negative index counts from the end.                                                                     |
| `list.sort() → list`                               | The list in ascending order: numbers by value, texts in the Item Query collation, dates by their start, false before true, and elements of different types grouped by type.        |
| `list.unique() → list`                             | The list with only the first of each group of equal elements.                                                                                                                      |
| `list.filter(expression: any) → list`              | The elements of the list for which the expression, with `value` and `index` bound, is truthy. The expression can use `value` and `index`.                                          |
| `list.map(expression: any) → list`                 | The list of the results of the expression for each element, with `value` and `index` bound. The expression can use `value` and `index`.                                            |
| `list.reduce(expression: any, initial: any) → any` | The result of the expression run on each element in turn, with `acc` bound to the previous result and starting from `initial`. The expression can use `value`, `index`, and `acc`. |
| `list.within(path: string) → boolean`              | Whether the list of Collection paths holds the Collection at `path` or a Collection below it.                                                                                      |

## Properties [#properties]

### String properties [#string-properties]

| Signature                | Description                                  |
| ------------------------ | -------------------------------------------- |
| `string.length → number` | The number of UTF-16 code units in the text. |

### List properties [#list-properties]

| Signature              | Description                         |
| ---------------------- | ----------------------------------- |
| `list.length → number` | The number of elements in the list. |

### Date properties [#date-properties]

| Signature                   | Description                                                                      |
| --------------------------- | -------------------------------------------------------------------------------- |
| `date.year → number`        | The year of the date in the query time zone.                                     |
| `date.month → number`       | The month of the date from 1 to 12, or null for a date of only a year.           |
| `date.day → number`         | The day of the month of the date, or null for a date without a day.              |
| `date.hour → number`        | The hour of the date from 0 to 23 in the query time zone, 0 for a calendar date. |
| `date.minute → number`      | The minute of the date in the query time zone, 0 for a calendar date.            |
| `date.second → number`      | The second of the date in the query time zone, 0 for a calendar date.            |
| `date.millisecond → number` | The millisecond of the date in the query time zone, 0 for a calendar date.       |
| `date.timestamp → number`   | The Unix time of the start of the date in milliseconds.                          |
