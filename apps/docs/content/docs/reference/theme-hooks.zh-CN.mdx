本参考手册列出了 ZotLit 提供的公开 CSS 样式类名：引文类名及其激活生效规则、PDF 阅读器类名以及模板编辑器类名。同时还列出了在图谱视图中为 ZotLit 节点和引文连线着色的自定义 CSS 变量属性。

## 样式类名清单 [#hooks]

| 类名                                   | 语义说明                                                                                                       |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `zt-citation`                          | 由 ZotLit 负责渲染呈现或提供交互导航跳转的引文元素。                                                           |
| `zt-citation-key`                      | 原始文献引用标识（citation key），或由字面量标识语法生成的格式化引文。                                         |
| `zt-citation-key-pending`              | 正在等待首次文献引用标识解析快照的文献引用标识。该元素同时包含 `zt-citation-key`。                             |
| `zt-citation-key-unresolved`           | 无法在文献库中解析的标识键，或所有标识均无法解析的格式化引文。该元素同时包含 `zt-citation-key`。               |
| `zt-citation-key-partially-unresolved` | 同时包含已成功解析和无法解析标识键的格式化引文。该元素同时包含 `zt-citation-key`。                             |
| `zt-citation-key-ambiguous`            | 匹配到多个 Zotero 条目的歧义标识键，或包含歧义键且不含未解析键的格式化引文。该元素同时包含 `zt-citation-key`。 |
| `zt-literature-note-link`              | 由文献笔记双链链接或引文组合序列（Citation Run）生成的格式化引文。                                             |
| `zt-entry-serial`                      | 格式化引文内部的条目序号元素，以及在引文悬停浮窗中为每个被引条目所在行标明的序号。                             |

格式化引文同时还会携带其来源类型的专属类名：字面量引文簇包含 `zt-citation` 与 `zt-citation-key`；由文献笔记双链构成的引文组合序列则包含 `zt-citation` 与 `zt-literature-note-link`。

## 支持的 Obsidian 视图 [#views]

当满足激活条件时，这些类名可出现在源码模式、实时预览以及阅读视图中。

| 视图类型 | Pandoc 字面量引文源码                                    | 文献笔记双链                       |
| -------- | -------------------------------------------------------- | ---------------------------------- |
| 源码模式 | 当开启标识导航时，标记处于活跃状态的源码。               | 使用 Obsidian 原生的链接排版表面。 |
| 实时预览 | 为导航标记活跃的原始源码，并为格式化排版标记格式化引文。 | 为格式化排版标记格式化引文。       |
| 阅读视图 | 当 ZotLit 提供导航或格式化排版时标记活跃文本。           | 为格式化排版标记格式化引文。       |

CodeMirror 底层可能会将一段源码范围拆分为多个连续的 DOM 元素。ZotLit 确保每个公开类名的语义一致性与激活规则稳定，但不保证具体的底层 DOM 标签类型、嵌套深度、元素数量，亦不保证 Obsidian 或 CodeMirror 自带的原生私有类名。

## 激活生效条件 [#activation]

ZotLit 仅在同时满足以下两个条件时才会注入公开类名：

1. 该引文来源归属于当前活动笔记的文档引文集（Document Citation Set）。
2. ZotLit 正在为该引文来源提供格式化渲染或交互导航支持。

`zt-citation-key` 及其状态类标识处于活跃状态的 Pandoc 字面量引文来源。<UiLabel name={m.settings_citation_pandoc_citations_name()} /> 决定是否将其纳入引文集。<UiLabel name={m.settings_citation_show_formatted_name()} /> 与 <UiLabel name={m.settings_citation_open_as_links_name()} /> 分别控制可激活这些类名的两项功能。

`zt-literature-note-link` 标识处于活跃状态的双链引文来源。<UiLabel name={m.settings_citation_wikilink_citations_name()} /> 决定是否将其纳入引文集。当 <UiLabel name={m.settings_citation_show_formatted_name()} /> 为其提供渲染时，ZotLit 应用此类名。开启 <UiLabel name={m.settings_citation_open_as_links_name()} /> 后，Obsidian 提供双链导航；关闭时，普通点击已渲染的双链引文会在实时预览中将光标置于链接源码中，在阅读视图中则无操作，而 Mod+点击仍会打开笔记。

一个文献引用标识只表示一种解析状态。在首个文献引用标识解析快照就绪前，它带有 `zt-citation-key-pending`。匹配多个 Zotero 条目的键在源码模式、实时预览和阅读视图中均带有 `zt-citation-key-ambiguous`。引文簇中，未解析键的优先级高于歧义键：同时包含两者的引文簇带有 `zt-citation-key-unresolved`；如果还包含已解析键，则带有 `zt-citation-key-partially-unresolved`，且不带歧义类名。

带别名的链接、标题链接、块链接、嵌入、未解析的目标以及格式不正确的引文片段均不属于可渲染的引文集，ZotLit 不为其添加公开引文类名。

如果两项适用功能均未启用，引文来源也不会带有公开的 ZotLit 类名。内部引文索引本身不会激活类名。

`zt-citation` 仅在 ZotLit 渲染引文或为其提供文献引用标识导航时出现。

`zt-entry-serial` 出现在已渲染引文中承载条目序号的元素上。仅当所选引文与参考文献样式将引文写为脚注时，ZotLit 才会添加此类名，因为 Obsidian 的各个视图都无法显示这类脚注。此时，ZotLit 改为显示每篇被引文献在参考文献侧边栏中的位置：每篇文献对应一个数字，以逗号分隔；没有生成参考文献条目的文献显示 `⚠`。作者-年份制或数字制等将引文写入正文的样式不会激活此类名。

此类名还会出现在这类引文的 <UiLabel name={m.settings_citation_hover_action_popover()} /> 中，用于为每个被引条目的按钮行标注序号。如果某篇文献没有生成参考文献条目，此处同样显示 `⚠`。

## 默认外观 [#defaults]

已解析的文献引用标识使用 Obsidian 的 `--link-*` 变量。完全未解析的文献引用标识使用对应的 `--link-unresolved-*` 变量。

ZotLit 不为待解析的文献引用标识提供默认样式。在首个解析快照就绪前，它们保持所在视图的中性外观。

ZotLit 不为 `zt-citation-key-partially-unresolved` 添加整体样式，因此部分解析的结果保持其中已解析文献的外观。ZotLit 也不为原生文献笔记双链添加样式。

歧义文献引用标识保留已解析链接的颜色，同时使用 `--link-unresolved-decoration-*` 变量，既显示该键可以跳转，又表明它匹配多个条目。<UiLabel name={m.settings_citation_hover_action_popover()} /> 会列出候选条目。

ZotLit 也不为 `zt-entry-serial` 添加样式。序号在引文中显示为上标文本，在 <UiLabel name={m.settings_citation_hover_action_popover()} /> 中显示为普通标签，其外观由主题决定。

## 图谱视图颜色 [#graph]

图谱与局部图谱视图使用画布绘制，因此 ZotLit 通过自定义属性而非类名设置节点和连线的颜色。ZotLit 从 `body` 读取这些属性，请在 `body` 上设置。在视图自身（例如 `.graph-view`）上设置不会生效。

| 自定义属性                         | 含义                                             |
| ---------------------------------- | ------------------------------------------------ |
| `--zt-graph-literature-note-color` | 新建文献笔记分组的初始颜色。                     |
| `--zt-graph-cited-work-node-color` | 仓库中没有对应文献笔记的被引文献节点的填充颜色。 |
| `--zt-graph-citation-link-color`   | 引文连线的颜色。                                 |

ZotLit 接受应用本身支持的所有颜色语法，包括 `oklch()` 和 `color-mix()`。

### 默认外观 [#graph-defaults]

文献笔记使用原生节点颜色。新建文献笔记分组使用 ZotLit 橙色：浅色模式为 `#E8622C`，深色模式为 `#F0793F`。通过图谱按钮或引文图谱命令创建分组时，ZotLit 会读取 `--zt-graph-literature-note-color`。

切换主题时，已有分组保留已保存的颜色。移除分组后，其中节点重新采用其余原生分组及原生颜色。

没有对应文献笔记的被引文献使用 `--text-faint`，除非匹配某个原生颜色分组。引文连线默认使用原生颜色。开启 <UiLabel name={m.graph_option_color_citation_links_name()} /> 后，会应用 `--zt-graph-citation-link-color`，其默认值为 `--color-purple`。

当指针停在连线任一端的节点上时，连线保留 Obsidian 自带的高亮颜色。

```css
body.theme-light {
  --zt-graph-literature-note-color: #e8622c;
}

body.theme-dark {
  --zt-graph-literature-note-color: #f0793f;
}

body {
  --zt-graph-cited-work-node-color: oklch(0.6 0.02 250);
  --zt-graph-citation-link-color: var(--color-cyan);
}
```

## PDF 阅读器样式类名 [#pdf-reader]

Obsidian PDF 阅读器通过覆盖层显示 Zotero 附件的批注，并提供用于创建和编辑批注的工具栏与弹窗。ZotLit 基于 Obsidian 自带的工具栏和浮窗组件绘制这些界面。

| 类名                                  | 标记对象                                                                                       |
| ------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `zt-pdf-annotation-overlay`           | ZotLit 用于绘制 Zotero 批注的 SVG，每个已渲染的 PDF 页面各有一个。                             |
| `zt-pdf-annotation-mark`              | 覆盖层中的一个批注标记。                                                                       |
| `zt-pdf-annotation-highlight`         | 高亮批注标记的填充矩形。                                                                       |
| `zt-pdf-annotation-selection-outline` | 围绕所选批注标记合并后的轮廓绘制的边线。                                                       |
| `zt-pdf-annotation-handle`            | 开启编辑时，在所选批注标记上绘制的一个调整手柄。                                               |
| `zt-pdf-annotation-note-icon`         | 便笺批注标记中用于绘制图标的分组。                                                             |
| `zt-pdf-annotation-note-fill`         | 便笺批注标记图标的主体。                                                                       |
| `zt-pdf-annotation-note-crease`       | 便笺批注图标右下角折角的两条折线。仅描边，没有自身填充。                                       |
| `zt-pdf-text-draft`                   | 在页面上输入自由文本批注的文本框，直到保存后的标记替代它。                                     |
| `zt-pdf-capability`                   | 阅读器工具栏中的编辑状态指示，仅在 ZotLit 等待 Zotero 或处于冷却期时显示。                     |
| `zt-pdf-creation-toolbar`             | 阅读器右侧工具栏槽位中的创建工具栏，也容纳编辑状态指示。                                       |
| `zt-pdf-tool`                         | 工具栏中的一个工具：启用开关与打开颜色菜单的箭头组成一个分体按钮。工具待用时带有 `is-active`。 |
| `zt-pdf-mark-popup`                   | 基于 Obsidian 自带悬停浮窗的标记弹窗，两种模式均使用此类名。                                   |
| `zt-pdf-comment-sheet`                | 标记弹窗在操作行下方打开的评论面板，两种模式均使用此类名。                                     |

### 批注标记 [#pdf-annotation-marks]

每当 PDF.js 渲染一页，ZotLit 都会重建该页的 `zt-pdf-annotation-overlay`，并为每条批注绘制一个 `zt-pdf-annotation-mark`：高亮使用填充矩形（`zt-pdf-annotation-highlight`），下划线使用线条，便笺使用 lucide 风格的图标（`zt-pdf-annotation-note-icon`，内含 `zt-pdf-annotation-note-fill` 和 `zt-pdf-annotation-note-crease`），图像区域使用描边矩形，墨迹使用路径，自由文本批注使用文本。覆盖层不接收指针输入，因此其下方的原生文本选择、PDF 链接及阅读器工具栏仍可正常使用。

每个标记都带有 `data-zotero-annotation-type`（值为 `highlight`、`underline`、`note`、`image`、`ink` 或 `text`）以及 `data-zotero-annotation-key`，即该批注的 Zotero 标识符。标记弹窗正在操作的标记还带有 Obsidian 自带的 `is-selected`；覆盖层在其上方绘制 `zt-pdf-annotation-selection-outline`，紧贴标记自身的矩形区域，或紧贴墨迹笔画。

开启编辑后，所选图像区域的轮廓上方还会显示八个 `zt-pdf-annotation-handle` 方形手柄。每个手柄的 `data-zt-grip` 指明它移动的边缘（`tl`、`t`、`tr`、`r`、`br`、`b`、`bl` 或 `l`；其中 `t` 是页面在未旋转的存储状态下的顶部），`data-zt-cursor` 指明显示的光标。图像标记自身带有 `data-zt-grip="body"` 和 `data-zt-cursor="move"`。所选墨迹标记在略大于笔画范围的矩形四角显示手柄（`tl`、`tr`、`br`、`bl`），其自身也带有 `data-zt-grip="body"`。所选高亮或下划线显示两条窄条：首行起始边缘的 `data-zt-grip="start"` 和末行结束边缘的 `data-zt-grip="end"`；若引文跨页，结束手柄位于下一页。高亮或下划线标记自身不带 `data-zt-grip`。手柄以及图像或墨迹主体接收指针输入，按住它们可移动标记或调整大小，而不是选择文本。在高亮或下划线主体上按下仍会选择文本。

### 编辑状态指示 [#pdf-capability]

`zt-pdf-capability` 位于创建工具栏内，仅在两种状态下显示：Zotero 权限对话框打开时显示 <UiLabel name={m.capability_authorizing()} />；Zotero 暂时拒绝新的权限请求时显示 <UiLabel name={m.capability_cooldown()} />。其他状态下工具栏不显示此指示。

状态指示是一行图标和状态标签，不是按钮，点击无操作。冷却期间还会显示剩余秒数。两种状态均带有 `data-zt-capability-tone="busy"`，等待 Zotero 时还带有 `aria-busy="true"`。

如需授权 ZotLit 编辑，请参阅[在 Obsidian 中编辑 PDF 批注](/docs/how-to/edit-pdf-annotations#before-you-edit)。

### 创建工具栏 [#pdf-creation-toolbar]

`zt-pdf-creation-toolbar` 容纳创建和管理批注标记的控件。最前方的 <UiLabel name={m.pdf_toolbar_tools()} /> 分组为 ZotLit 支持写入的每种批注提供一个工具，目前包括 <UiLabel name={m.pdf_toolbar_highlight()} />、<UiLabel name={m.pdf_toolbar_underline()} />、<UiLabel name={m.pdf_toolbar_note()} />、<UiLabel name={m.pdf_toolbar_text()} />、<UiLabel name={m.pdf_toolbar_image()} /> 和 <UiLabel name={m.pdf_toolbar_ink()} />。每个工具由两个共用容器的 `clickable-icon` 组成分体按钮：一半是将工具设为待用状态的开关，`data-zt-tool` 为 `highlight`、`underline`、`note`、`text`、`image` 或 `ink`；另一半是打开颜色菜单的箭头，使用相同值加上 `-color`，例如 `note-color`。两半各有独立的悬停效果。一次只能有一个工具处于待用状态；再次选择该工具会取消待用状态。无论工具是否待用，都可通过箭头打开颜色菜单。分组外还有显示或隐藏批注标记的开关（<UiLabel name={m.pdf_toolbar_show_marks()} /> 或 <UiLabel name={m.pdf_toolbar_hide_marks()} />，`data-zt-tool="visibility"`）。

每个工具的颜色选择都会跨 PDF 和会话保留。

暂时无法写入的控件仍留在工具栏中，带有 `aria-disabled`，并在提示文本中说明原因。

<UiLabel name={m.pdf_toolbar_ink()} /> 处于待用状态时，PDF 视图容器带有空值的
`data-zt-inking`。ZotLit
在此属性下的样式规则禁用页面触摸平移，使手指动作改为绘画。

### 标记弹窗与评论面板 [#pdf-mark-popup]

`zt-pdf-mark-popup` 是显示在所选批注标记或新选文本上方的弹窗，其中每个控件都带有 `data-zt-verb`。

对于所选标记，弹窗提供 <UiLabel name={m.annot_view_card_color()} />、<UiLabel name={m.annot_view_card_add_tags()} /> 或 <UiLabel name={m.annot_view_card_edit_tags()} />、<UiLabel name={m.annot_view_menu_copy_text()} />、<UiLabel name={m.annot_view_menu_delete()} />，以及 <UiLabel name={m.pdf_mark_popup_reveal()} />，对应的 `data-zt-verb` 值为 `color`、`tags`、`copy`、`delete` 和 `reveal`。多个标记重叠时，还会增加逐个切换控件 `data-zt-verb="stack"`。操作行下方的评论字段为 `zt-annot-comment-field`；没有评论时显示 <UiLabel name={m.annot_view_card_comment_placeholder()} />。选择评论会在原位置打开 `zt-pdf-comment-sheet`。

对于新选文本，操作行提供 <UiLabel name={m.pdf_toolbar_highlight()} /> 和 <UiLabel name={m.pdf_toolbar_underline()} />（`data-zt-verb` 为 `highlight` 或 `underline`）；任意工具最近使用的四种颜色，不足时按 Zotero 调色板顺序补齐（`data-zt-verb` 为 `color-1` 至 `color-8`，按颜色在调色板中的位置编号，每项为一个实心圆点）；<UiLabel name={m.annot_view_card_add_comment()} />（`data-zt-verb="comment"`）；以及 <UiLabel name={m.pdf_create_popup_copy()} />（`data-zt-verb="copy"`）。选择 <UiLabel name={m.annot_view_card_add_comment()} /> 会在操作行下方打开 `zt-pdf-comment-sheet`。

暂时无法写入的控件会保留位置并呈禁用状态，在提示文本中说明原因。复制和定位操作不写入数据，因此始终可用。

### 默认外观 [#pdf-defaults]

高亮标记与页面混合显示：浅色主题采用 40% 不透明度及 `multiply` 混合，深色主题采用 30% 不透明度及 `plus-lighter` 混合。便笺图标以批注自身颜色绘制 1.4px 细线，主体使用相同颜色、22% 不透明度填充。所选标记保留自身颜色，并用 `--text-accent` 细线沿合并后的轮廓描边。

创建工具栏以 flex 横排布局控件，沿用 Obsidian 的工具栏间距。待用工具保留批注颜色，而不采用 Obsidian 强调色的 `is-active` 填充。工具开关使用该工具的颜色，让工具栏直接显示各工具的绘制颜色；旁边的箭头不着色，图标尺寸小一级，因为它代表菜单而非颜色。`zt-pdf-tool` 是整个按钮容器，负责圆角并将两个半区裁剪在圆角内；两半相接处的内边距减半，使其形成一个紧凑控件。两半均保留 Obsidian 原生悬停效果，各自高亮。待用工具的容器带有 `is-active`，两个半区同时使用 `--background-modifier-active-hover` 填充；与 Obsidian 中其他已激活的 `clickable-icon` 一样，指针移入时保持该填充，不进一步变亮。仅开关通过 `aria-pressed` 报告状态。编辑状态指示的图标与标签使用弱化文本色，其他颜色由 Obsidian 和主题决定。

标记弹窗按操作行所需宽度调整大小，覆盖 Obsidian 默认的悬停浮窗尺寸。评论面板与上方操作行同宽，且最小宽度为 12em。

```css
.zt-pdf-annotation-mark[data-zotero-annotation-type="highlight"] {
  mix-blend-mode: normal;
}

.zt-pdf-capability[data-zt-capability-tone="busy"] {
  color: var(--text-accent);
}

.zt-pdf-mark-popup [data-zt-verb="delete"] {
  color: var(--text-error);
}
```

这些类名、数据属性值与默认样式构成 ZotLit PDF 阅读器公开的主题接口约定，DOM 结构仍属于内部实现。

## 批注视图样式类名 [#annot-view]

批注视图在阅读器旁列出 Zotero 附件的批注，并带有自己的工具栏。菜单使用 Obsidian 原生菜单，主题可通过 `menu` 设置样式。标签筛选器和颜色筛选器使用选择弹窗，主题可通过 `zt-chooser` 和 `zt-chooser-trigger` 设置样式。

| 类名                     | 标记对象                                                               |
| ------------------------ | ---------------------------------------------------------------------- |
| `zt-annot-conflict`      | 批注卡片存在写入冲突时显示的面板。                                     |
| `zt-annot-draft`         | 批注卡片或标记弹窗在 Zotero 尚未保存评论、引用文本或标签时显示的面板。 |
| `zt-annot-comment-field` | 可选择后编辑的评论字段，显示于单独选中的卡片和标记弹窗中。             |
| `zt-annot-lock`          | 已锁定批注的卡片标题区中的锁图标。                                     |
| `zt-chooser`             | 标签或颜色筛选器打开的选择弹窗。                                       |
| `zt-chooser-trigger`     | 选择弹窗所依附的控件。                                                 |

若卡片的最后一次编辑遇到 Zotero 中更新的值，或 Zotero 始终未回应其创建请求，卡片会显示 `zt-annot-conflict`。它说明发生的情况、显示两个值，并提供解决冲突的操作。

当编辑内容等待 <UiLabel name={m.annot_view_comment_save()} />、<UiLabel name={m.annot_view_text_save()} /> 或 <UiLabel name={m.annot_view_tags_save()} /> 时，会显示 `zt-annot-draft`，例如保存失败后，或编辑尚未结束时编辑功能被停止。它显示未保存的评论、引用文本或标签，说明等待原因，并提供保存或放弃操作。

`zt-annot-comment-field` 仅标记单独选中的卡片上的评论，不出现在其他卡片上。选择它会在原位置打开评论编辑器。没有评论时显示 <UiLabel name={m.annot_view_card_comment_placeholder()} />。ZotLit 无法编辑该批注时，它带有 `data-blocked`。标记弹窗也使用同一类名，详见[标记弹窗与评论面板](#pdf-mark-popup)。

对于 Zotero 阅读器不允许修改的批注（例如从 PDF 文件导入的批注），卡片标题区会显示 `zt-annot-lock`。提示文本和无障碍名称均说明原因。被锁定状态禁止的修改控件呈灰色。

`zt-chooser` 标记可筛选多选控件打开的定位浮窗。它使用原生浮窗，而非 Obsidian 菜单，因此打开时可由 `:popover-open` 匹配，`menu` 则不会匹配。外观来自 `--menu-background`、`--menu-border-color`、`--menu-border-width`、`--menu-corner-shape`、`--menu-padding`、`--menu-radius` 和 `--menu-shadow`，因此修改菜单配色的主题也可通过这些变量影响它。

`zt-chooser-trigger` 标记弹窗所依附的控件。该控件是 `<button>`，因为浮窗调用属性要求使用按钮。弹窗打开时，控件带有 `aria-expanded` 和 `data-open`；其 Obsidian 按钮样式已撤销，因此主题应通过此类名而非 `button` 设置样式。

这些类名与数据属性值构成 ZotLit 批注视图公开的主题接口约定，DOM 结构仍属于内部实现。

## 模板编辑器样式类名 [#template-editor]

模板工作台视图通过同一组类名，为所有包含模板代码的窗格设置 frontmatter 样式，以及模板源码和 Markdown 标记的颜色：包括笔记正文、批注格式、属性表达式、笔记名称，以及源码模式中的整个文件。本网站的模板工作台也输出相同类名。

Liquid 语法单元在 YAML 值、Markdown 行内代码和代码块中保留自身颜色。Eta 高亮覆盖标签分隔符。Markdown 提示会标记笔记与批注正文中的标题、列表和引用，保持正常文本字号与字重。

| 类名                               | 含义                                                   |
| ---------------------------------- | ------------------------------------------------------ |
| `zt-template-editor`               | 容纳一个模板编辑器窗格的元素。                         |
| `zt-template-delimiter`            | 用于开始或结束标签或输出的分隔符：`{{`、`{%-`、`<%=`。 |
| `zt-template-keyword`              | 标签名或关键字：`if`、`for`、`endbq`、`in`。           |
| `zt-template-variable`             | 变量或根节点名称：`zt`、`it`。                         |
| `zt-template-property`             | 点号后的属性名，或 JSON 键。                           |
| `zt-template-filter`               | Liquid 过滤器或函数调用：`map`、`note_links`。         |
| `zt-template-string`               | 字符串字面量。                                         |
| `zt-template-value`                | 数字、布尔值或 null。                                  |
| `zt-template-operator`             | 运算符：`.`、`>`、`\|`。                               |
| `zt-template-punctuation`          | 其他标点：`,`、`:`、括号。                             |
| `zt-template-comment`              | 模板注释文本。                                         |
| `zt-template-invalid`              | 解析器不接受的源码。                                   |
| `zt-template-frontmatter`          | frontmatter 行，包括起止边界。                         |
| `zt-template-markdown-marker`      | 正文中的 Markdown 标题、列表或引用标记。               |
| `zt-template-markdown-list-marker` | Markdown 列表标记上的附加类名。                        |
| `zt-template-hover`                | 解释指针下方语法单元的浮窗，仅在 Obsidian 中使用。     |

### 默认外观 [#template-defaults]

颜色通过 `zt-template-editor` 上的自定义属性设置，每类语法单元对应一个 `--zt-template-<token>` 属性。分隔符、关键字和运算符使用 `--text-accent`；过滤器使用 `--color-blue`；变量与属性使用 `--text-normal`；字符串、值及标点使用 `--text-muted`；注释使用 `--text-faint` 并呈斜体；无效源码使用 `--text-error`。悬停浮窗使用 Obsidian 自带的 `hover-popover`，按文本内容调整大小。

Frontmatter 使用 `--text-muted`，其中的模板语法单元保留自身颜色。标题与引用标记使用 `--text-faint`，列表标记使用 `--list-marker-color`。这些样式仅改变颜色。模板工作台视图的所有窗格均保留现有的等宽字体、代码字号、间距和背景。

在编辑器类名上设置自定义属性，可同时改变所有窗格中同类语法单元的颜色；也可直接为语法单元类名设置样式：

```css
.zt-template-editor {
  --zt-template-keyword: var(--color-purple);
  --zt-template-filter: var(--color-cyan);
}

.zt-template-comment {
  font-style: normal;
}
```

## CSS 示例 [#examples]

使用直接的类选择器即可覆盖 ZotLit 低优先级的默认样式，无需 `!important`。

```css
.zt-citation-key {
  color: var(--link-color);
}

.zt-citation-key.zt-citation-key-unresolved {
  color: var(--link-unresolved-color);
  opacity: var(--link-unresolved-opacity);
}

.zt-literature-note-link {
  text-decoration-line: underline;
}

.zt-entry-serial {
  color: var(--text-muted);
}
```

使用组合选择器区分渲染结果和原始源码：

```css
.zt-citation.zt-citation-key {
  font-style: italic;
}

.zt-citation.zt-literature-note-link {
  font-style: normal;
}
```

这些类名、含义和激活规则构成 ZotLit 公开的主题接口约定，DOM 结构仍属于内部实现。
