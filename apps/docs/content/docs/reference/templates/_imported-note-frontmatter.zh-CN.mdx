每个导入的子笔记文件都包含四个 frontmatter 字段：

| 字段              | 说明                                                                                                        |
| ----------------- | ----------------------------------------------------------------------------------------------------------- |
| `date`            | 笔记添加到 Zotero 的时间。带时区偏移量、精确到秒的本地日期时间（例如 `2025-03-15T10:30:00-04:00`）          |
| `zotero-note-key` | 将导入文件与 Zotero 笔记精准对应的标识键。对于群组文献库，包含群组文献库标识符（`KEYgGROUPID`）             |
| `zotero-lastmod`  | 源笔记的 `dateModified` 时间戳（格式同 `date`）。批量重新导入时据此跳过未修改的笔记                         |
| `zotlit-profile`  | 执行导入的配置方案名称与 12 位 ID。仅当由非默认配置方案执行导入时才会写入，并与其他系统字段一样受到系统保留 |
