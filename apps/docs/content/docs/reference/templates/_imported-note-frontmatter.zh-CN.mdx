导入的每个子笔记 Markdown 文件都包含以下四个 frontmatter 属性字段：

| 字段              | 说明                                                                                                    |
| ----------------- | ------------------------------------------------------------------------------------------------------- |
| `date`            | 该笔记添加到 Zotero 的时间。带有秒级精度时区偏移的本地日期时间（例如 `2025-03-15T10:30:00-04:00`）      |
| `zotero-note-key` | 将导入文件匹配至 Zotero 笔记的唯一标识键。对于群组文献库，包含群组文献库标识符（`KEYgGROUPID`）         |
| `zotero-lastmod`  | 源笔记的 `dateModified` 修改时间戳（格式同 `date`）。用于批量重新导入时跳过未修改的笔记                 |
| `zotlit-profile`  | 执行该次导入的配置方案名称及 12 位 ID。仅当使用非默认配置方案导入时写入，且像其他系统键一样受到保护保留 |
