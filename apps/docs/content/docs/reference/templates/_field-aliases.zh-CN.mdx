这三个字段提供了借鉴自 CSL 的别名。无论是别名还是 Zotero 规范字段名均可正常使用：

| 属性                | Zotero 规范字段名  | 说明                                        |
| ------------------- | ------------------ | ------------------------------------------- |
| `zt.abstract`       | `abstractNote`     | `zt.abstract` 与 `zt.abstractNote` 均可使用 |
| `zt.containerTitle` | `publicationTitle` | 两个名称均可使用                            |
| `zt.citekey`        | `citationKey`      | `zt.citekey` 与 `zt.citationKey` 均可使用   |
