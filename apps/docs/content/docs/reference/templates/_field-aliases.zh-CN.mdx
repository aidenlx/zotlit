有三个字段支持借鉴自 CSL 的重命名字段别名。别名与 Zotero 原生规范名称均可正常生效：

| 属性                | Zotero 规范名称    | 说明                                        |
| ------------------- | ------------------ | ------------------------------------------- |
| `zt.abstract`       | `abstractNote`     | `zt.abstract` 与 `zt.abstractNote` 均可生效 |
| `zt.containerTitle` | `publicationTitle` | 两个名称均可生效                            |
| `zt.citekey`        | `citationKey`      | `zt.citekey` 与 `zt.citationKey` 均可生效   |
