---
title: "Theme hooks"
description: "Public CSS classes for styling ZotLit citation keys, rendered citations, and Literature Note links across Obsidian views."
---

ZotLit adds public CSS classes to citation keys, rendered citations, and Literature Note links. Themes and CSS snippets can use these classes without depending on ZotLit or Obsidian DOM structure.

## Hooks [#hooks]

| Class                                  | Meaning                                                                                                                                 |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `zt-citation`                          | A formatted Citation rendered by ZotLit.                                                                                                |
| `zt-citation-key`                      | A raw citation key, or a rendered Citation produced from literal citation key syntax.                                                   |
| `zt-citation-key-unresolved`           | A citation key that does not resolve, or a rendered Citation in which no citation key resolves. The element also has `zt-citation-key`. |
| `zt-citation-key-partially-unresolved` | A rendered Citation containing both resolved and unresolved citation keys. The element also has `zt-citation-key`.                      |
| `zt-literature-note-link`              | A resolved internal link to a Literature Note, or a rendered Citation produced from a Literature Note link or Citation Run.             |

A rendered Citation also has the class for its source. A literal Citation Cluster has `zt-citation` and `zt-citation-key`. A Citation Run made from Literature Note links has `zt-citation` and `zt-literature-note-link`.

## Supported views [#views]

The hooks are available in Source mode, Live Preview, and Reading view.

| View         | Citation key hook                                                   | Literature Note link hook                                          |
| ------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Source mode  | Marks the literal citation key source.                              | Marks the internal-link source.                                    |
| Live Preview | Marks raw source while it is visible, and marks rendered Citations. | Marks native links, Citation Display Text, and rendered Citations. |
| Reading view | Marks citation keys and rendered Citations.                         | Marks native links, Citation Display Text, and rendered Citations. |

CodeMirror can split one source range across multiple elements. ZotLit guarantees the meaning and activation of each class. It does not guarantee the element type, nesting, number of elements, or native Obsidian and CodeMirror classes.

## Activation [#activation]

`zt-citation-key` and its state classes are active while both **Citation key indexing** and **Citation key styling** are on.

`zt-literature-note-link` applies to every resolved, non-embed internal link whose target is a Literature Note. It does not depend on **Wikilink citations** or **Show wikilink citations as citation text**. It includes:

- Plain and aliased links.
- Links to a heading or block in a Literature Note.
- `[[#Heading]]` and `[[#^block]]` inside a Literature Note.

The class does not apply to embeds, unresolved internal links, or self-subpath links outside a Literature Note.

`zt-citation` appears only when ZotLit renders formatted Citation output.

## Default appearance [#defaults]

Resolved citation keys use Obsidian's `--link-*` variables. Fully unresolved citation keys use the corresponding `--link-unresolved-*` variables.

ZotLit adds no aggregate style for `zt-citation-key-partially-unresolved`. A partial result therefore keeps the appearance of its resolved works. ZotLit also adds no style to an ordinary `zt-literature-note-link`; the native internal-link appearance remains active.

## CSS examples [#examples]

Use a direct class selector to override ZotLit's low-specificity defaults. `!important` is not required.

```css
.zt-citation-key {
  color: var(--link-color);
}

.zt-citation-key.zt-citation-key-unresolved {
  color: var(--link-unresolved-color);
  opacity: var(--link-unresolved-opacity);
}

.zt-literature-note-link {
  text-decoration-line: underline;
}
```

Use combined selectors to distinguish rendered output from raw source:

```css
.zt-citation.zt-citation-key {
  font-style: italic;
}

.zt-citation.zt-literature-note-link {
  font-style: normal;
}
```

These class names, meanings, and activation rules are ZotLit's public theme contract. DOM structure remains private.
