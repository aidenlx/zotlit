## 全文库更新 [#library-wide-update]

<Command name={m.command_update_all_notes_name()} />

| 入口点   | 详情                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 命令面板 | 始终可用                                                                                                                                     |
| Zotero   | 右键点击文库或分类 > <UiLabel name={m["zotero.menu_submenu.label"]()} /> > <UiLabel name={m["zotero.menu_collection_update_all.label"]()} /> |

Zotero 入口将批量操作范围限制在你右键点击的行：文库涵盖其中的每个条目，分类涵盖该分类及其子分类。该目标是精确指定的，因此无论该行是否在你的文库范围内均会执行。

## 文献笔记快速切换 [#quick-switcher]

<Command name={m.command_open_lit_note_name()} />

打开弹窗以搜索[文库范围](/docs/reference/settings#library-scope)内的所有文库，并跳转到（或创建）对应的文献笔记。

| 入口点   | 详情     |
| -------- | -------- |
| 命令面板 | 始终可用 |

搜索结果支持 5 种快捷键组合，列在弹窗底部：

| 快捷键                                             | 结果                                                      |
| -------------------------------------------------- | --------------------------------------------------------- |
| `Enter`                                            | 打开文献笔记；若不存在则先创建。                          |
| `Ctrl+Enter`（macOS 上为 `Cmd+Enter`）             | 同上，但在新分栏中打开。                                  |
| `Shift+Enter`                                      | 在 Obsidian 的 PDF 阅读器中打开该条目的 PDF，不打开笔记。 |
| `Ctrl+Shift+Enter`（macOS 上为 `Cmd+Shift+Enter`） | 同上，但在新分栏中打开。                                  |
| `Alt+Enter`（macOS 上为 `Option+Enter`）           | 在[文库视图](#library-view)中显示该条目。                 |

`Alt+Enter` 会在条目的第一个分类中（若不属于任何分类则在其文库中）打开文库视图，并选中其所在行。它会清除视图中的搜索并关闭阅读状态筛选，确保该行不会被隐藏。当条目超出视图 1000 篇文献的限制时，不会选中任何条目并会显示相应提示。

两个 PDF 快捷键会对选中的结果执行 <UiLabel name={m.command_open_pdf_name()} />，该命令列在[文献笔记操作](#literature-note-actions)下。

### 引文搜索如何对文献排序 [#citation-search-order]

两个入口点均会同时搜索[文库范围](/docs/reference/settings#library-scope)内的所有文库，并按统一的相关度排序。当有多个文库提供结果时，每个建议项都会标明条目所属的文库。若范围内只有一个文库，则省略该标签。

在输入搜索词之前，两个列表都会将当前笔记中已引用的文献排在最前。每个分组按“最近活动时间”倒序排列（最新的排在前面）。这与[文库视图中的 <UiLabel name={m.library_view_recent()} />](/docs/how-to/use-library-view#recent) 顺序一致。

键入搜索内容时，两个列表均按相关度对所有结果进行排序。

当前笔记已引用的文献无论是否进行搜索，都会显示 <UiLabel name={m.citation_suggester_cited_in_note()} /> 标签。

### 建议器触发方式与查询语法 [#suggester-queries]

在编辑器中键入 `[@`（或 `【@`）时会打开引文建议器。下拉菜单中会显示来自 Zotero 文库的条目。

启用 <UiLabel name={m.settings_citation_at_trigger_name()} /> 后，在单词边界键入 `@` 也会起到相同的作用。单词中间的 `@`（例如电子邮件地址中）会被忽略。

`@` 查询会在遇到第一个空格时结束。如需在搜索中加入空格，请用 `_` 代替：例如 `@machine_learning` 可搜索 “machine learning”。方括号触发查询（`[@`）支持直接输入真实空格。

弹窗中没有末尾 `/` 的快捷方式；在此处只能通过 `Shift+Enter` 请求替代引文。

- `alt` 形式可通过两者的 `Shift+Enter` 获取，或通过建议器查询末尾的 `/` 获取。在不按 `Shift` 的情况下末尾的 `/` 优先，并且 `/` 会从搜索词中剥离。

#### “被引用”侧边栏 [#cited-by]

<UiLabel name={m.cited_by_view_name()} />
侧边栏会跟随活动文献笔记。它按来源笔记对引用出现的位置进行分组，并在周围文本的上下文中显示该引用。

使用侧边栏工具栏可缩小范围和整理结果：

- <UiLabel name={m.cited_by_show_search_filter()} />
  ：按来源笔记路径或显示的引用上下文进行筛选。
- <UiLabel name={m.cited_by_show_more_context()} />
  ：将每个结果从紧凑摘录展开为其所在的完整 Markdown 块。
- <UiLabel name={m.cited_by_change_sort_order()} />
  ：按文件名、修改时间或创建时间对来源笔记进行双向排序。
- <UiLabel name={m.cited_by_collapse_results()} />
  ：折叠或展开可见的来源笔记分组。

选择引用摘录可在对应的出现位置打开其来源笔记。选择分组上的 <UiLabel name={m.cited_by_open_source()} /> 可直接打开笔记而不定位到特定出现位置。在 Windows 或 Linux 上按住 Ctrl，或在 macOS 上按住 Command，可在另一分栏中打开。

<Command name={m.command_open_pdf_name()} />

### 跟随模式 [#follow-modes]

| 模式                                                      | 行为                                                           |
| --------------------------------------------------------- | -------------------------------------------------------------- |
| <UiLabel name={m.annot_view_mode_active_tab()} />（默认） | 跟随当前活动标签页：文献笔记对应的条目，或 Zotero PDF 的附件。 |
| <UiLabel name={m.annot_view_mode_zotero_reader()} />      | 跟随 Zotero 阅读器中打开的附件。需要开启实时更新。             |
| <UiLabel name={m.annot_view_mode_pinned()} />             | 固定在你选定的单个条目上，并记住其附件。                       |

如需切换，请打开视图顶部的菜单（带有向下箭头的条目标题）；其第一个分组标题为 <UiLabel name={m.annot_view_header_menu_label()} />。视图面板菜单中也提供相同的 3 个切换选项，且各自拥有独立的命令。

视图会保持你选择的模式，直到切换为其他模式。当数据源无法响应时，视图会就地显示提示而非自动替你切换。

<UiLabel name={m.annot_view_mode_zotero_reader()} />
需要开启实时更新，它能将阅读器的位置从 Zotero 传递到
Obsidian。在实时更新关闭时，视图会在列表位置显示
<UiLabel name={m.annot_view_enable_live_updates()} />
。参见[设置实时更新](/docs/how-to/set-up-live-updates)。

在 Zotero 中关闭阅读器后，屏幕上会保留最后一个附件，并显示 <UiLabel name={m.annot_view_reader_closed()} />。

从 Zotero PDF 标签页执行固定操作会解除该标签页对附件的独占，以便在保持固定的同时在该条目的各个附件之间切换。

选择 <UiLabel name={m.annot_view_mode_unpin()} /> 可返回固定之前的模式。

Zotero 中没有所属父条目的 PDF 无法被固定；菜单不会为其提供固定选项。

### 附件选择器 [#attachments]

当条目拥有多个附件时，工具栏下方的选择器会显示屏幕当前展示的附件名称及其标注数量，并按条目记住你的选择。

Zotero PDF 标签页和 Zotero 阅读器各自会自行选择附件，因此当其中之一生效时选择器会暂停生效。

如需在 Obsidian 中阅读当前屏幕上的附件，请打开视图顶部的菜单，然后选择 <UiLabel name={m.command_open_pdf_name()} />。视图面板菜单中也包含相同条目。当 Obsidian PDF 标签页已显示该附件时不会显示。

### 锁定的标注 [#locked]

卡片页码旁的锁图标表示 ZotLit 无法更改该标注。指向该图标可查看原因。例如，该标注是由 Zotero 从 PDF 文件中导入的，或是群组文库的其他成员创建的。关于锁定标注仍可执行的操作，请参见[如何在 Obsidian 中编辑 PDF 标注](/docs/how-to/edit-pdf-annotations)。

### 插入到笔记 [#insert]

ZotLit 会使用标注条目对应文献笔记的[配置方案](/docs/reference/templates/how-templates-work#profiles)，若该条目没有笔记则使用默认配置方案。等待期间进行的编辑会使插入位置随文本一起移动。按 Escape 可取消挂起的插入。插入完成后，执行一次撤销即可移除插入的内容。

## 查询 CLI [#query-cli]

查询 CLI 为 Agent 和脚本提供读取文献、文件和阅读标记的能力。通过一条 `zotlit:query` 命令并搭配 `from` 选择查询数据集。[ZotLit 查询工作原理](/docs/reference/how-queries-work#zotlit-query)详细解释了数据集、筛选器和分组。

| 命令                      | 参数                                                                                                                        | 结果                                          |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `zotlit:query`            | `from`, `filter`, `fields`, `formulas`, `sort`, `group`, `limit`, `library`, `output`, `id`, `this-item`, `this-attachment` | 每个匹配的条目、附件或标注对应一个查询结果行  |
| `zotlit:query-schema`     | `from`                                                                                                                      | 架构 URL、源自定义字段、数据集字段及默认值    |
| `zotlit:query-values`     | `kind`, `library`, `match`, `limit`                                                                                         | 各文库的精确分类路径或标签名称                |
| `zotlit:query-guide`      | `topic`                                                                                                                     | 单个主题的说明，省略 `topic` 时输出完整指南   |
| `zotlit:annotation-image` | `key`                                                                                                                       | 图片或手绘标注的本地 PNG 路径、格式和来源信息 |
| `zotlit:query-cancel`     | `id`                                                                                                                        | ZotLit 是否找到指定查询并请求了取消           |

`zotlit:query` 支持以下参数：

| 参数              | 值                                                                                                                                                                     |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from`            | `items`、`attachments` 或 `annotations`。默认为 `items`。                                                                                                              |
| `filter`          | 针对选定数据集及其关联记录的筛选表达式。                                                                                                                               |
| `fields`          | 逗号分隔的投影路径列表或 JSON 数组。`fields=[]` 仅返回身份标识行。                                                                                                     |
| `formulas`        | 从公式名称到筛选表达式的 JSON 对象。在 `fields`、`filter` 或其他公式中以 `formula.<name>` 读取公式。参见[使用公式计算值](/docs/how-to/query-zotero-library#formulas)。 |
| `sort`            | 逗号分隔的列表或 `{ "field", "direction" }` 对象的 JSON 数组。使用 `-field` 表示降序，使用 `field` 或 `+field` 表示升序。                                              |
| `group`           | 单个标量投影路径，或包含单个 `[]` 的路径（如 `tags[].name`）。结果为每个值包含一个分组。                                                                               |
| `limit`           | 正整数或 `all`。默认为 100。在分组查询中，限制应用于每个分组内部。                                                                                                     |
| `library`         | `personal`、`group:<groupID>`、逗号分隔列表、JSON 数组或 `all`。默认值来自文库范围设置。                                                                               |
| `output`          | 用于写入完整 JSON 结果的新绝对文件路径。                                                                                                                               |
| `id`              | 供 `zotlit:query-cancel` 使用的查询 ID。                                                                                                                               |
| `this-item`       | 条目的索引标识符（Indexed Key）。筛选器将其作为 `this.item` 读取。参见[查询上下文](#query-context)。                                                                   |
| `this-attachment` | 附件的索引标识符。筛选器将其作为 `this.attachment` 读取。参见[查询上下文](#query-context)。                                                                            |

ZotLit 会在引号和括号之外的逗号处拆分 `fields` 和 `sort`。

### 查询数据集 [#query-datasets]

选择代表单行结果的数据集：

| `from` 值     | 单行代表       | 数据集内容                                         | 关联记录                              |
| ------------- | -------------- | -------------------------------------------------- | ------------------------------------- |
| `items`       | 一篇文献       | 回收站之外的顶层条目                               | `attachments`、`annotations`、`notes` |
| `attachments` | 一个文件或 URL | 回收站之外的顶层条目的非回收站附件                 | `item`、`annotations`                 |
| `annotations` | 一个阅读标记   | 回收站之外的顶层条目的非回收站附件上的非回收站标注 | `item`、`attachment`                  |

独立附件不在这些数据集之内。关联列表包含来自同一数据集全集的记录。在筛选器中使用列表方法，在投影路径中使用显式的 `[]`。

`notes` 列出回收站之外的条目子笔记，按笔记标识符排序。笔记记录包含 `indexedKey`、`key`、`title`、`dateAdded`、`dateModified`、`library` 及其所属的父 `item`。没有数据集将笔记作为行来读取。以下查询查找含有子笔记的文献并列出笔记标题：

```bash
obsidian zotlit:query filter='!notes.isEmpty()' fields='title,notes[].title'
```

例如，以下查询查找在此计算机上没有可被 ZotLit 打开的 PDF 的文献：

```bash
obsidian zotlit:query filter='attachments.filter(value.contentType == "application/pdf" && value.exists).isEmpty()' fields=title,citationKey
```

当每个文件必须单独成行时，请从 Attachments 出发。以下查询查找缺失的链接文件：

```bash
obsidian zotlit:query from=attachments filter='linkMode == "linked_file" && !exists' fields=item.title,path
```

在筛选器中通过索引标识符（Indexed Key）选择记录。行记录使用 `indexedKey`，其所属父条目使用 `item.indexedKey`，标注所属的父附件使用 `attachment.indexedKey`。超出目标文库范围的标识符会产生查询警告，但目标文库保持不变。

### 查询上下文 [#query-context]

`this-item` 和 `this-attachment` 用于设置查询的“查询上下文”：即筛选器作为 `this.item` 和 `this.attachment` 读取的条目和附件。查询文件和查询块会根据显示它们的笔记设置相同的上下文。参见[`this`：笔记对应的文献](/docs/reference/how-queries-work#this)。

| 数据集        | 绑定条目的记录                       | 绑定附件的记录                             |
| ------------- | ------------------------------------ | ------------------------------------------ |
| `items`       | `indexedKey == this.item.indexedKey` |                                            |
| `attachments` | `item == this.item`                  | `indexedKey == this.attachment.indexedKey` |
| `annotations` | `item == this.item`                  | `attachment == this.attachment`            |

```bash
obsidian zotlit:query from=annotations filter='item == this.item' this-item=ABCD2345 limit=all
```

若筛选器在未提供对应参数的情况下读取 `this.item` 或 `this.attachment`，会失败并报错 `unbound-context`。

### 投影与分组 [#projection-and-grouping]

类似于 `attachments[].path` 的路径会为每个附件返回一个值。它会保持源顺序，并将 `null` 保留在其原始位置。完整的关联记录包含固定的摘要信息：

| 记录               | 摘要字段                                                           |
| ------------------ | ------------------------------------------------------------------ |
| 条目（Item）       | `indexedKey`, `title`, `citationKey`                               |
| 附件（Attachment） | `indexedKey`, `title`, `contentType`, `linkMode`, `path`, `exists` |
| 标注（Annotation） | `indexedKey`, `type`, `text`, `comment`, `pageLabel`, `pageIndex`  |
| 笔记（Note）       | `indexedKey`, `title`                                              |

`group` 接受单个标量路径。以下命令按 `fileType`（值为 `pdf`、`epub`、`web` 或 `other`）统计附件：

```bash
obsidian zotlit:query from=attachments group=fileType
```

每个分组包含 `value`、`count` 和 `rows`。`count` 是应用每组限制之前的匹配数。`totalCount` 统计所有匹配的记录数，`returnedCount` 统计跨所有分组返回的行总数。

包含单个 `[]` 的路径会按列表的每个元素进行分组。以下命令统计每个标签下的文献数：

```bash
obsidian zotlit:query group='tags[].name' fields='[]' limit=1
```

文献会根据其拥有的每个标签分别加入对应分组，没有标签的文献则归入 `null` 分组。分组可能重叠，因此各分组数量相加可能大于 `totalCount`。使用 `collections[]` 可按分类统计文献，使用 `attachments[].fileType` 可按文件类型统计文献。

以下命令为每篇文献返回最新的 3 个标注标记：

```bash
obsidian zotlit:query from=annotations group=item.indexedKey sort=-dateModified limit=3 fields=text,item.title
```

### 分类与标签值 [#query-values]

`zotlit:query-values` 列出筛选器完全匹配的名称。在按分类或标签筛选之前可先运行此命令。

| 参数      | 值                                                               |
| --------- | ---------------------------------------------------------------- |
| `kind`    | `collections` 或 `tags`。必填。                                  |
| `library` | `personal`、`group:<groupID>` 或 `all`。默认值来自文库范围设置。 |
| `match`   | 保留包含此文本的名称（忽略大小写）。                             |
| `limit`   | 正整数或 `all`，应用于每个文库。默认为 100。                     |

分类值为以 `/` 连接的完整路径，包括空分类。标签值为 `{ name, type }`，其中 `type` 为 `manual`、`auto` 或 `unknown`。每个文库会报告其 `library` 选择器、`name`、`values`、`totalCount`、`returnedCount` 和 `truncated`。

```bash
obsidian zotlit:query-values kind=collections match=thesis
```

在 `collections.contains` 或 `collections.within` 中指定的分类路径若不存在于任何目标文库中，会产生 `unknown-collection` 查询警告。其 `suggestions` 会列出最接近的路径，并在其他文库包含该路径时提供 `library` 值。

### 架构、指南与结果 [#schema-guide-and-results]

统一的 `query.schema.json` 目录包含 `datasets.items`、`datasets.attachments` 和 `datasets.annotations`。它还包含共享的函数、方法、属性和类型。`zotlit:query-schema` 按数据集返回目录 URL、源自定义字段以及默认值。添加 `from=items`、`from=attachments` 或 `from=annotations` 可缩小实时响应范围。

`zotlit:query-guide` 接受 `datasets`、`filter`、`fields`、`sort`、`group`、`results`、`schema`、`values` 或 `cancel` 作为主题参数。省略 `topic` 则输出完整指南。

查询结果遵循 CLI 契约版本 3（CLI Contract version 3）。JSON 外层包含 `command: "zotlit:query"`；`request.from` 标明数据集，`request.library` 标明其文库。顶层的 `libraries` 字段描述了 ZotLit 读取的文库。

在报告空结果前请先查看 `warnings`。发生失败时，请阅读 `diagnostic.report` 并按照其最终的恢复操作指引进行处理。

每个附件行均包含该附件及其父条目的索引标识符。每个标注行还包含其所属父附件的索引标识符。标注的默认值包括 `pageLabel`、`pageIndex`、`hasExcerptImage`、附件详情、条目标题和文献引用标识。若需要原始几何坐标，请在 `fields` 中请求 `position`。当 `attachment.exists` 为 true 时，可读取 `attachment.path` 以打开源文档。

当 `hasExcerptImage` 为 true 时，可将标注索引标识符作为 `key` 传递给 `zotlit:annotation-image`。该命令将返回文件路径而非图片原始字节。

`zotlit-query` Agent Skill 在构建查询前会先读取 `zotlit:query-guide` 和 `zotlit:query-schema`。参见[向 AI Agent 提问](/docs/how-to/query-zotero-library#agent)。

## 模板工作台 CLI [#template-workbench-cli]

模板工作台向 Obsidian CLI 注册了专有命令，主要供 Agent 和脚本使用而非命令面板。目前有 5 个命令可用：

- `zotlit:template-inspect`：检查单个模板文档并验证其保存的源码是否为最新。
- `zotlit:template-check`：检查每个配置方案的所有已保存组件。
- `zotlit:template-status`：报告仓库的工作台状态。
- `zotlit:template-data`：返回单个根节点的模板数据。
- `zotlit:template-guide`：输出工作台指南。

早期的架构、渲染、源码及托管属性命令已废弃。这些命令仍保留注册，但会返回 `COMMAND_RETIRED` 诊断信息。

有关所有命令（可用与废弃）、选项标志及诊断信息的详情，请参见[模板工作台 CLI](/docs/reference/template-workbench-cli)；有关核心概念请参见[模板工作台](/docs/reference/template-workbench-cli)。
