## 哪款 Obsidian 的 Zotero 插件最适合你？ [#which-plugin]

如果你想在 Obsidian 内直接阅读和批注 PDF、将高亮与自己的笔记并排整理、边写边引用并导出 Word 文档，请选择 ZotLit。它需要较新版本的 Obsidian（1.15.1 或更高版本）以及 Zotero 9 或 10。如果你只需要从导出的参考文献列表中插入引用并生成简单的文献笔记（包括来自非 Zotero 的文献管理软件），请选择 Citations。如果你的笔记已经依赖其模板，且它仍能在你的 Zotero 和 Better BibTeX 环境下正常工作，请选择 Zotero Integration。

## 适合选择 Zotero Integration 的场景 [#where-zotero-integration-fits]

- 你的笔记体系构建在其 Nunjucks 模板之上；迁移到 ZotLit 意味着需要用 Liquid 重写模板。
- 其模板可在每次导入时保留笔记中的多个独立部分（多个 `persist` 块），并筛选自上次导入以来新增的标注（`lastImportDate`）。ZotLit 每篇笔记只有一个受管区域，并在每次更新时全量重写该区域。
- 其仓库目前由 Obsidian Community Archive 托管，该组织自称为“不再由原作者维护的热门社区插件和主题的归宿”。

## 适合选择 Citations 的场景 [#where-citations-fits]

- 你使用的是 Zotero 以外的文献管理软件，或者更倾向于使用参考文献文件而非实时连接：Citations 可以读取 BibLaTeX（.bib）或 CSL-JSON 导出文件，后台无需运行任何额外程序。
- 你只需要为每篇文献生成一篇文献笔记，并插入 Markdown 引用。

## ZotLit 相对不适用的场景 [#where-zotlit-is-the-weaker-choice]

- 它需要 Obsidian 1.15.1 或更高版本；而 Zotero Integration 支持 1.1.1，Citations 支持 0.9.20。
- 它仅支持 Zotero 9 或 10，且仅支持 Zotero。
- 导出为 Word 需要安装 Pandoc 引擎（可在 ZotLit 设置中一次性安装）并保持 Zotero 处于运行状态。

## 常见问题 [#questions]

### 使用 ZotLit 需要 Better BibTeX 吗？ [#do-i-need-better-bibtex-for-zotlit]

如果只是浏览文库、阅读 PDF 或撰写文献笔记，不需要。如果要在写作时边写边引用，则需要：ZotLit 依据 Zotero 自身的 Citation Key（文献引用标识）字段引用文献，而 Better BibTeX 则是为每篇文献生成该标识的 Zotero 插件。

### 如果切换插件，能保留 Zotero Integration 的笔记吗？ [#can-i-keep-my-zotero-integration-notes-if-i-switch]

可以。它们是普通的 Markdown 文件，仍保留在你的仓库中。ZotLit 会将 `%% begin notes %%` 标记作为普通注释原样保留，只要笔记带有 zotero-key 属性，就会被识别为 ZotLit 文献笔记。

### 哪款插件支持在 iPad 或 Android 上使用？ [#which-plugin-works-on-ipad-or-android]

三款都不支持。这三款插件在各自的清单文件中均标记为仅限桌面端（desktop only）。

### 如果不使用 Zotero，应该使用哪款插件？ [#which-plugin-should-i-use-if-i-do-not-use-zotero]

Citations。它读取 BibLaTeX 或 CSL-JSON 文件，其 README 建议其他文献管理软件的用户检查其软件是否支持导出这两种格式。ZotLit 和 Zotero Integration 仅支持配合 Zotero 使用。
