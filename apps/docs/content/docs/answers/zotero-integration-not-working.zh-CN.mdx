Zotero Integration 需要 Zotero 保持运行并安装 Better BibTeX 插件，请对照下表排查出现的提示信息。"No citation found" 来自另一个插件 Pandoc Reference List，而不是 Zotero Integration。

ZotLit 的开发者并不维护 Zotero Integration。本页内容仅汇总了 Zotero Integration 自身 README、文档、源代码和问题追踪器中给出的排查建议，核对时间为 2026 年 11 月 11 日。

## 用户反馈：选择文献后“没有任何反应” [#user-reports-nothing-happens-after-you-pick-a-paper]

以下步骤整理自 2026 年 Zotero Integration 问题追踪器中的用户反馈，而非维护者的官方建议。用户反映打开选择器后未创建任何笔记。其他用户验证有效的两种解决方法：

- 条目的 Citation Key 为空：在 Zotero 中选中相应条目，右键点击，打开 Better BibTeX，重新生成文献引用标识（Issue #469）。
- Zotero 更新后失效：在 Zotero 中更新 Better BibTeX 并重启 Zotero（Issue #463 与 #481）。

## Zotero 8、9 和 10 [#zotero-8-9-and-10]

Zotero Integration 的 README 和文档未注明适用的 Zotero 版本。其最后一个版本是 2024 年 8 月 11 日发布的 3.2.1。其代码仓库目前由 Obsidian Community Archive 托管，该归档库定位为“原作者已无法继续维护的热门社区插件与主题的存放空间”。

## 在 ZotLit 中完成同样的工作 [#doing-the-same-job-in-zotlit]

- 连接 Zotero：ZotLit 直接读取 Zotero 数据库。连接不依赖 Better BibTeX，浏览、搜索和阅读时无需打开 Zotero。
- 导入高亮：高亮和评论保存在文献笔记的特定托管区域内。更新时仅会重写该部分；托管区域之外自行撰写的内容原样保留。
- 插入引用：在笔记中输入 `[@` 即可选择文献。
- 模板系统：ZotLit 使用 Liquid；Zotero Integration 使用 Nunjucks。迁移指南中提供了两者语法的对应表。
- 现有笔记：全部为标准的 Markdown 文件，完整保存在你的仓库中。

## 迁移前，确认你的 Zotero 版本 [#before-you-switch-check-your-zotero-version]

- ZotLit 支持读取 Zotero 9 和 Zotero 10。
- 可选安装的 ZotLit Companion 插件支持 Zotero 9 和 10。
- 在 Obsidian 中编辑高亮需要使用 Zotero 10。
- ZotLit 需要 Obsidian 1.15.1 或更高版本，且安装包版本不低于 1.13.4。
- 若使用的是 Zotero 8 或更早版本，请在安装 ZotLit 前先升级 Zotero。

## 常见问题 [#questions]

### 为什么 Obsidian 提示 "No citation found"？ [#why-does-obsidian-say-no-citation-found]

该提示来自 Pandoc Reference List 插件，它会为笔记中的每个文献引用标识显示对应的参考文献。其 README 要求使用 Pandoc 2.11 或更高版本并配置参考文献文件路径，请在其设置中检查这两项。

### Zotero Integration 支持 Zotero 9 或 10 吗？ [#does-zotero-integration-work-with-zotero-9-or-10]

其 README 和文档未说明支持哪些 Zotero 版本，其最新版本为 2024 年 8 月 11 日发布的 3.2.1。在其问题追踪器中，部分用户反馈在更新 Better BibTeX 并重启 Zotero 后可以在 Zotero 9 上使用。另有用户报告在 Zotero 9.0.4 和 Zotero 10 测试版上无任何错误提示直接失效。

### 迁移到 ZotLit 会改动我现有的笔记吗？ [#will-switching-to-zotlit-change-my-existing-notes]

不会。你的 Zotero Integration 笔记是纯 Markdown 文件，会原样保留在仓库中。笔记中的 `%% begin notes %%` 标记会作为注释保留，ZotLit 会忽略它们。

### 使用 ZotLit 需要 Better BibTeX 吗？ [#do-i-need-better-bibtex-for-zotlit]

如果只是浏览文库、阅读 PDF 或撰写文献笔记，不需要。若要在写作时插入引用，则需要：ZotLit 通过 Zotero 自身的文献引用标识（Citation Key）字段来引用文献，而 Better BibTeX 正是为每篇文献生成该标识的 Zotero 插件。
