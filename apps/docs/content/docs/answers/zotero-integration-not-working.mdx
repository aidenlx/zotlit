Zotero Integration needs Zotero running with the Better BibTeX add-on installed, so match the message you see to the table below. "No citation found" is a message from a different plugin, Pandoc Reference List, not from Zotero Integration.

ZotLit's authors do not maintain Zotero Integration. This page gives only the checks that Zotero Integration's own README, documentation, source code and issue tracker give, checked on 11 November 2026.

## User reports: "Nothing happens" after you pick a paper

These steps come from user reports in Zotero Integration's issue tracker in 2026, not from maintainer advice. Users reported that the picker opens and no note is created. Two fixes other users said worked for them:

- An item with an empty Citation Key: in Zotero, select the items, right-click, open Better BibTeX, and regenerate the citation key (issue #469).
- After a Zotero update: update Better BibTeX in Zotero and restart Zotero (issues #463 and #481).

## Zotero 8, 9 and 10

Zotero Integration's README and documentation state no Zotero version. Its last release is 3.2.1, 11 August 2024. Its repository is held by the Obsidian Community Archive, which describes itself as "a landing space for popular community plugins and themes which can no longer be taken care of by their creators".

## Doing the same job in ZotLit

- Connecting to Zotero: ZotLit reads Zotero's database. The connection does not go through Better BibTeX, and Zotero can stay closed while you browse, search and read.
- Importing highlights: highlights and comments go into a marked part of the literature note, the managed region. An update rewrites only that part; your own writing outside it stays as it was.
- Inserting a citation: type `[@` in a note and pick the paper.
- Templates: ZotLit uses Liquid; Zotero Integration uses Nunjucks. The migration guide has a table that maps one to the other.
- Your existing notes: they are ordinary Markdown files and stay in your vault.

## Before you switch, check your Zotero version

- ZotLit reads Zotero 9 and Zotero 10.
- ZotLit Companion, the optional Zotero add-on, installs on Zotero 9 and 10.
- Editing highlights from Obsidian needs Zotero 10.
- ZotLit needs Obsidian 1.14.5 or later, with installer 1.13.4 or later.
- On Zotero 8 or earlier, update Zotero before you install ZotLit.

## Questions [#questions]

### Why does Obsidian say "No citation found"?

That message comes from the Pandoc Reference List plugin, which shows a reference for each citation key in a note. Its README asks for Pandoc 2.11 or later and a path to a bibliography file, so check both in its settings.

### Does Zotero Integration work with Zotero 9 or 10?

Its README and documentation do not state which Zotero versions it supports, and its last release is 3.2.1 from 11 August 2024. In its issue tracker, some users report it working with Zotero 9 after they updated Better BibTeX and restarted Zotero. Others report failures with no error message on Zotero 9.0.4 and on a Zotero 10 beta.

### Will switching to ZotLit change my existing notes?

No. Your Zotero Integration notes are Markdown files and stay in your vault as they are. Their `%% begin notes %%` markers stay as comments that ZotLit ignores.

### Do I need Better BibTeX for ZotLit?

Not to browse your library, read PDFs or write literature notes. To cite as you write, yes: ZotLit cites a paper by the key in Zotero's own Citation Key field, and Better BibTeX is the Zotero add-on that gives every paper that key.
