ZotLit Skill 能够帮助 Agent 在单个仓库内编辑并测试模板，以及配置托管 frontmatter 属性模板。

## 开始之前

你需要准备：

- Node.js 18 或更高版本。
- Obsidian 桌面端 1.14.2 或更高版本。
- 已加载 ZotLit 的已打开仓库。
- 按照 [Obsidian 命令行指南](https://obsidian.md/help/cli)启用 Obsidian CLI。

<Callout type="warn" title="Agent 数据访问说明">
  你所选择的 Agent 能够接收由 Template Workbench CLI 返回的 Zotero
  元数据与批注全文。Agent 本身的数据处理政策均适用。
</Callout>

## 安装 Skill

<Steps>
  <Step>
    ### 打开仓库文件夹

    在仓库根目录下打开终端（包含 `.obsidian` 文件夹的目录）。

  </Step>
  <Step>
    ### 启动安装程序

    运行：

    ```bash
    npx skills@latest add https://zotlit.aidenlx.site/
    ```

  </Step>
  <Step>
    ### 选择仓库与 Agent

    选择 **Project** 范围以将 Skill 安装到当前仓库。勾选你在该仓库中使用的每个 Agent：Claude Code、Codex 或 pi。

    选择推荐的符号链接（symlink）安装方式。

  </Step>
  <Step>
    ### 跳过额外 Skill

    如果安装程序推荐安装 `find-skills`，请选择 **No**。该 Skill 与 ZotLit 无关。

  </Step>
</Steps>

## 验证安装

从仓库文件夹启动选定的 Agent 之一。发送以下请求：

> Use the ZotLit skill to check my current template setup. Do not change any files.

Agent 应当会调用 Template Workbench CLI，并报告当前活跃仓库及模板配置情况。你的模板文件将保持不变。

## 发起你的第一个模板调整请求

用自然语言描述你期望的效果。例如：

> Use the ZotLit skill to add Zotero tags below the title in my literature notes. Show me the rendered result before you finish.

Agent 会检查当前模板与相关 Zotero 数据，随后在内存中编辑仓库模板并测试渲染出的 Markdown 效果。
