ZotLit Skill 能帮助智能体（Agent）在单个仓库中编辑并测试模板，以及配置受管 frontmatter 字段模板。

## 准备工作

您需要：

- Node.js 18 或更高版本。
- Obsidian 桌面端 1.14.2 或更高版本。
- 打开一个已加载 ZotLit 的 Obsidian 仓库。
- 按照 [Obsidian CLI 指南](https://obsidian.md/help/cli)启用 Obsidian CLI。

<Callout type="warn" title="智能体数据访问权限">
  您选择的智能体可以接收由模板工作台 CLI 返回的 Zotero
  元数据和标注文本。智能体自身的数据处理政策将适用。
</Callout>

## 安装 Skill

<Steps>
  <Step>
    ### 打开仓库根目录

    在仓库根目录下打开终端。该目录包含 `.obsidian` 文件夹。

  </Step>
  <Step>
    ### 启动安装程序

    运行：

    ```bash
    npx skills@latest add https://zotlit.aidenlx.site/
    ```

  </Step>
  <Step>
    ### 选择仓库范围与智能体

    选择 **Project** 范围以将 Skill 安装到当前仓库中。选择您在该仓库中使用的每个智能体：Claude Code、Codex 或 pi。

    选择推荐的符号链接（symlink）安装方式。

  </Step>
  <Step>
    ### 跳过额外 Skill

    如果安装程序推荐安装 `find-skills`，请选择 **No**。该 Skill 与 ZotLit 无关。

  </Step>
</Steps>

## 验证安装

从仓库根目录启动已配置的智能体之一。发送此提示：

> 使用 ZotLit Skill 检查我当前的模板配置。不要更改任何文件。

智能体应当调用模板工作台 CLI，并汇报当前活跃的仓库与模板配置情况。您的模板文件将保持不变。

## 首次尝试模板请求

用自然语言描述您想要的效果。例如：

> 使用 ZotLit Skill，在我的文献笔记标题下方添加 Zotero 标签。在完成之前先向我展示渲染结果。

智能体将检查当前模板和相关的 Zotero 数据，随后编辑仓库中的模板并在内存中测试渲染生成的 Markdown。
