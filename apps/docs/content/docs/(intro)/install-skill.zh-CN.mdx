通过 ZotLit skills，Claude Code、Codex 或 pi 等智能体可以在同一仓库中处理你的 Zotero 文库与文献笔记。你只需使用自然语言提问，智能体就会代你执行 ZotLit 的各项命令。

一次安装即可提供四项 skill。根据你的工作需求选择安装：

| Skill              | 对你的研究所起的作用                                                                           | 示例请求                                 | 了解更多                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------- |
| `zotlit-template`  | 创建、编辑并测试塑造文献笔记的模板，并解释模板错误。                                           | “在我的笔记标题下方添加 Zotero 标签。”   | [Template Workbench CLI](/docs/reference/template-workbench-cli)           |
| `zotlit-query`     | 搜索你的 Zotero 文献、文件和标注，用于文献综述、阅读计划以及查找缺失或损坏的 PDF。             | “我的毕业论文分类中有哪些文献没有 PDF？” | [查询 Zotero 文库](/docs/how-to/query-zotero-library)                      |
| `zotlit-citations` | 查找哪些笔记引用了某篇文献、某篇笔记引用了什么内容、标注在哪里被使用，以及排查引用失效的原因。 | “我的哪些笔记引用了 Smith 2020？”        | [检查与排查参考文献问题](/docs/how-to/review-copy-troubleshoot-references) |
| `zotlit-pandoc`    | 为你的手稿配置、刷新并运行原生 Pandoc 工作流，并诊断导出问题。                                 | “为我的章节草稿配置原生 Pandoc 导出。”   | [使用原生 Pandoc 导出](/docs/how-to/export-with-native-pandoc)             |

## 开始之前 [#before-you-start]

你需要准备：

- Node.js 22.20 或更高版本，用于运行安装程序。
- Obsidian 桌面端 1.15.1 或更高版本。
- 一个已打开且已加载 ZotLit 的仓库。
- 按照 [Obsidian CLI 指南](https://obsidian.md/help/cli)启用的 Obsidian CLI。
- 仅针对 `zotlit-pandoc`：电脑上已安装 [Pandoc](https://pandoc.org/installing.html) 命令行程序。

<Callout type="warn" title="智能体数据访问权限">
  你选择的智能体可以接收 ZotLit 命令返回的内容：Zotero
  元数据、标注文本、笔记中引用文献的位置以及文件路径。适用该智能体自身的数据处理政策。
</Callout>

## 安装 skills [#install-the-skills]

<Steps>
  <Step>
    ### 打开仓库文件夹 [#open-the-vault-folder]

    在仓库根目录下打开终端。这是包含 `.obsidian` 文件夹的目录。

  </Step>
  <Step>
    ### 启动安装程序 [#start-the-installer]

    运行：

    ```bash
    npx skills@latest add https://zotlit.aidenlx.site/
    ```

  </Step>
  <Step>
    ### 选择 skills [#select-the-skills]

    安装程序会列出这四项 ZotLit skills。按空格键勾选所需的每一项 skill，然后按回车键。你可以四项全部选择。

  </Step>
  <Step>
    ### 选择仓库与智能体 [#select-the-vault-and-agents]

    选择你在该仓库中使用的智能体：Claude Code、Codex 或 pi。选择 **Project** 范围，将 skills 安装在当前仓库中。

    如果安装程序询问安装方式，选择推荐的软链接（symlink）方式。确认摘要信息以完成安装。

  </Step>
  <Step>
    ### 跳过额外推荐的 skill [#decline-the-extra-skill]

    如果安装程序推荐安装 `find-skills`，选择 **No**。该 skill 与 ZotLit 无关。

  </Step>
</Steps>

## 验证安装 [#verify-the-installation]

从仓库文件夹中启动所选的某一个智能体。发送以下请求：

> 告诉我你拥有哪些 ZotLit skills，然后检查 ZotLit 是否在此仓库中正常响应。请不要更改任何文件。

智能体应当说出你安装的 ZotLit skills 名称，并列出 Obsidian 为该仓库报告的 ZotLit 命令。你的文件不会受到任何修改。

## 发送你的第一批请求 [#make-your-first-requests]

用平实的语言描述你期望的结果。如果智能体选错了 skill，指明对应的 skill 名称即可。例如：

- **模板：**“使用 ZotLit template skill，在我的文献笔记标题下方添加 Zotero 标签。完成前向我展示渲染结果。”
- **文库查询：**“使用 ZotLit query skill 列出我的毕业论文分类中所有没有 PDF 的文献，按年份分组。”
- **引用：**“使用 ZotLit citations skill 找出所有引用了 Smith 2020 的笔记，并显示每次引用所在的上下文句子。”
- **Pandoc：**“使用 ZotLit Pandoc skill 为我的章节草稿配置原生 Pandoc 导出，然后将第 1 章转换为 Word。”

模板 skill 会对照真实的 Zotero 条目校验每次编辑，并汇报其验证过的输出结果。Pandoc skill 在替换已有输出文件前会先行询问。
