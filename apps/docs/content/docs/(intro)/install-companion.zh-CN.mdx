ZotLit Companion（Zotero 侧扩展组件）确保 Zotero 的最新更改能够实时供 ZotLit 读取。它是 ZotLit 官方支持工作流中必不可少的一部分。

## 保持数据库文件最新

Companion 默认启用 <UiLabel name={m["zotero.prefs_wal_checkpoint.label"]()} />。当你更新文献笔记时，此项设置能让 ZotLit 读取到 Zotero 中的最新改动。请在 <UiLabel name={m["zotero.prefs_pane_label"]()} /> 面板的 <UiLabel name={m["zotero.prefs_database_section"]()} /> 区域中保持该选项启用。

此数据库设置无需开启实时更新即可生效。右键菜单的基础交互动作也可通过协议链接直接使用，无需额外设置。

## 关于实时更新

实时更新（Live updates）能将 Zotero 文献库中的变更实时推送到 Obsidian。这需要开启 Companion 的通知设置以及 Obsidian 中的 ZotLit 本地服务。

实时更新为可选功能。即使未开启实时更新，Companion 依然能够确保数据库文件保持最新状态。

关于实时更新的配置步骤，请参阅[设置实时更新](/docs/how-to/set-up-live-updates)。
