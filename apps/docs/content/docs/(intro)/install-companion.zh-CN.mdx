ZotLit Companion 是一个 Zotero 插件，能让 ZotLit 及时读取 Zotero 的最新更改，并在 Zotero 的菜单中添加 ZotLit 操作。不安装该插件，ZotLit 也能浏览和阅读文库。如需决定是否需要安装，请参阅[让 Zotero 与 Obsidian 保持同步](/docs/how-to/keep-zotero-and-obsidian-in-sync)。

## 保持数据库文件最新 [#keep-the-database-file-current]

Companion 默认启用 <UiLabel name={m["zotero.prefs_wal_checkpoint.label"]()} />。此设置让 ZotLit 在更新文献笔记时能够读取 Zotero 的最新更改。请在 <UiLabel name={m["zotero.prefs_pane_label"]()} /> 面板的 <UiLabel name={m["zotero.prefs_database_section"]()} /> 分节下保持其开启状态。

即使未启用实时更新，此数据库设置也能正常生效。基础右键菜单操作也可通过协议链接直接运行，无需额外设置。

## 关于实时更新 [#about-live-updates]

实时更新将 Zotero 文库中的更改推送到 Obsidian。这需要配置 Companion 的通知设置以及 Obsidian 中的 ZotLit 服务器。

实时更新是可选功能。即使关闭实时更新，Companion 也会保持数据库文件为最新状态。

有关实时更新的配置步骤，请参阅[设置实时更新](/docs/how-to/set-up-live-updates)。
