ZotLit Companion（Zotero 端的必备插件）保持 Zotero 中的最新更改能即时供 ZotLit 读取。在每一个受支持的 ZotLit 环境中，Companion 都是不可或缺的一部分。

## 安装插件

## 保持数据库文件即时更新

Companion 默认启用 <UiLabel name={m["zotero.prefs_wal_checkpoint.label"]()} />。此设置使 ZotLit 在您更新文献笔记时能即时读取 Zotero 的最新更改。请在 <UiLabel name={m["zotero.prefs_pane_label"]()} /> 面板的 <UiLabel name={m["zotero.prefs_database_section"]()} /> 区域下保持此项启用。

该数据库设置在未开启即时同步更新（live updates）的情况下也可正常工作。右键菜单的基础操作亦可通过协议链接运作，无需额外配置。

## 关于即时同步更新

即时同步更新会将更改从 Zotero 文献库推送到 Obsidian。这需要开启 Companion 的通知设置以及 Obsidian 中的 ZotLit 本地服务器。

即时同步更新是可选的。即使关闭即时同步更新，Companion 也会保持数据库文件的时效性。

有关即时同步更新的设置，请参阅[配置即时同步更新](/docs/how-to/set-up-live-updates)。
