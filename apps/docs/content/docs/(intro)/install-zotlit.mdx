ZotLit is a desktop-only Obsidian plugin. It runs on Windows, macOS, and Linux; mobile is not supported.

<Callout type="warn" title="Update the Obsidian installer first">
  ZotLit needs Obsidian 1.13.4 or newer, and your **installer version** must also be 1.13.4 or newer. Obsidian's in-app update does not replace the installer. Check yours in **Settings > About**, then read [how to update the Obsidian installer](/docs/how-to/update-obsidian-installer). If the installer is older, ZotLit does not load.
</Callout>

## Install the plugin

<Tabs items={["Stable", "Pre-release"]} updateAnchor>
  <Tab id="stable" value="Stable">
    <VersionLedger app="obsidian" channel="stable" />

    You can find ZotLit in the Obsidian community plugin directory: [View ZotLit](https://community.obsidian.md/plugins/zotlit).

    <Steps>
      <Step>
        ### Open the plugin listing

        Click the link above, or open **Settings > Community plugins** in Obsidian, select **Browse**, and search for "ZotLit". You can also use this deep link:

        <ActionLink href="obsidian://show-plugin?id=zotlit" kind="obsidian">Show ZotLit in Obsidian</ActionLink>
      </Step>
      <Step>
        ### Install and enable

        Click **Install**, then **Enable**.
      </Step>
    </Steps>

  </Tab>
  <Tab id="pre-release" value="Pre-release">
    <VersionLedger app="obsidian" channel="pre-release" />

    BRAT (Beta Reviewers Auto-update Tester) is an Obsidian plugin that installs and auto-updates pre-releases from GitHub. Use BRAT if you want to test upcoming changes before they reach the community directory.

    <Steps>
      <Step>
        ### Install BRAT

        Open BRAT in the Obsidian plugin directory:

        <ActionLink href="obsidian://show-plugin?id=obsidian42-brat" kind="obsidian">Install BRAT</ActionLink>

        Enable it after installation. If you already have BRAT installed, skip to the next step.
      </Step>
      <Step>
        ### Add ZotLit as a beta plugin

        Click the link below to add ZotLit to BRAT automatically:

        <ActionLink href="obsidian://brat?plugin=aidenlx/zotlit" kind="obsidian">Add ZotLit to BRAT</ActionLink>

        Alternatively, open the command palette, run **BRAT: Add a beta plugin**, and enter `aidenlx/zotlit`.
      </Step>
      <Step>
        ### Enable ZotLit

        Go to **Settings > Community plugins** and enable **ZotLit**. You may need to refresh the plugin list first.

        BRAT keeps ZotLit up to date as new pre-releases ship. You do not need to reinstall manually.
      </Step>
    </Steps>

  </Tab>
</Tabs>
