## 灵感来源

为 ZotLit 提供启发与灵感的开源项目：

- [BibNotes Formatter](https://github.com/stefanopagliari/bibnotes)
- [obsidian-citation](https://github.com/hans/obsidian-citation-plugin)
- [obsidian-zotero-integration](https://github.com/mgmeyers/obsidian-zotero-integration)
- [zotero-plugin-scaffold](https://github.com/zotero-plugin-dev/zotero-plugin-scaffold): Zotero 开发工具热重载工作流
- [obsidian-pandoc-reference-list](https://github.com/mgmeyers/obsidian-pandoc-reference-list)
- [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus): PDF 标注交互
- [ZotFlow](https://github.com/duanxianpi/zotflow): 在 Obsidian 中内置 Zotero PDF 阅读器

## 教程作者

在官方文档发布前，为 ZotLit v1 撰写过社区教程的创作者：

- [@FeralFlora](https://github.com/FeralFlora): [ZotLit template walkthrough](https://forum.obsidian.md/t/zotlit-previously-obsidian-zotero-import-templates/56901) (Obsidian 官方论坛)
- [@MichaTarlton](https://github.com/MichaTarlton): [Beginner's set up for AidenLX's Zotero Integration Plugin](https://gist.github.com/MichaTarlton/67c24bfe65bb4cc2c6158e67363a4b45) (Gist)

## 贡献者

其建议或方案已在 v2 中落地的贡献者。在多数情况下，原 Pull Request 已关闭，其构想在 v2 重构期间重新实现。

- [Ascarshen](https://github.com/Ascarshen) ([#459](https://github.com/aidenlx/zotlit/pull/459)): 支持 Zotero 8 并稳定文献引用标识处理（已合并到 v1）
- [DanielRunningen](https://github.com/DanielRunningen) ([#353](https://github.com/aidenlx/zotlit/pull/353), [#351](https://github.com/aidenlx/zotlit/pull/351)): 完整日期解析以及文献笔记的批量创建/更新
- [OliverDudgeon](https://github.com/OliverDudgeon) ([#433](https://github.com/aidenlx/zotlit/pull/433)): 模板中的关联条目与关系支持
- [theotheo](https://github.com/theotheo) ([#296](https://github.com/aidenlx/zotlit/pull/296)): 通过在文件名中允许 `/` 指定子目录路径
- [Tisen-Ray](https://github.com/Tisen-Ray) ([#466](https://github.com/aidenlx/zotlit/pull/466)): 支持 Zotero 9
- [yukiizumi3](https://github.com/yukiizumi3) ([#464](https://github.com/aidenlx/zotlit/pull/464)): 自定义 Zotero 列以显示各条目的 Obsidian 笔记状态
