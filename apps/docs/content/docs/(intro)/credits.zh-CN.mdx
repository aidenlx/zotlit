## 贡献者 [#contributors]

其提案在 v2 中得以实现的贡献者。大多数情况下，原始 Pull Request 虽已关闭，但其想法在 v2 重写期间得到了重新实现。

- [Ascarshen](https://github.com/Ascarshen)（[#459](https://github.com/aidenlx/zotlit/pull/459)）：支持 Zotero 8 并提升文献引用标识处理的稳定性（已合并至 v1）
- [DanielRunningen](https://github.com/DanielRunningen)（[#353](https://github.com/aidenlx/zotlit/pull/353)、[#351](https://github.com/aidenlx/zotlit/pull/351)）：完整日期解析以及批量创建/更新文献笔记
- [OliverDudgeon](https://github.com/OliverDudgeon)（[#433](https://github.com/aidenlx/zotlit/pull/433)）：模板中的相关条目与关联关系
- [theotheo](https://github.com/theotheo)（[#296](https://github.com/aidenlx/zotlit/pull/296)）：支持在文件名中使用 `/` 指定目录以进行文件夹路由
- [Tisen-Ray](https://github.com/Tisen-Ray)（[#466](https://github.com/aidenlx/zotlit/pull/466)）：支持 Zotero 9
- [yukiizumi3](https://github.com/yukiizumi3)（[#464](https://github.com/aidenlx/zotlit/pull/464)）：自定义 Zotero 列，用于显示各条目在 Obsidian 中的笔记状态
