## 灵感来源

为 ZotLit 带来灵感的设计与开源项目。

- [BibNotes Formatter](https://github.com/stefanopagliari/bibnotes)
- [obsidian-citation](https://github.com/hans/obsidian-citation-plugin)
- [obsidian-zotero-integration](https://github.com/mgmeyers/obsidian-zotero-integration)
- [zotero-plugin-scaffold](https://github.com/zotero-plugin-dev/zotero-plugin-scaffold)：Zotero 开发工具热重载工作流
- [obsidian-pandoc-reference-list](https://github.com/mgmeyers/obsidian-pandoc-reference-list)
- [PDF++](https://github.com/RyotaUshio/obsidian-pdf-plus)：PDF 标注交互
- [ZotFlow](https://github.com/duanxianpi/zotflow)：Obsidian 内嵌 Zotero PDF 阅读器

## 教程作者

在官方文档建立之前为 ZotLit v1 编写社区教程的热心学者与用户。

- [@FeralFlora](https://github.com/FeralFlora)：[ZotLit template walkthrough](https://forum.obsidian.md/t/zotlit-previously-obsidian-zotero-import-templates/56901)（Obsidian 官方论坛）
- [@MichaTarlton](https://github.com/MichaTarlton)：[Beginner's set up for AidenLX's Zotero Integration Plugin](https://gist.github.com/MichaTarlton/67c24bfe65bb4cc2c6158e67363a4b45)（GitHub Gist）

## 贡献者

贡献的建议与方案在 v2 中落地的贡献者。大部分原始 Pull Request 在 v2 全面重写期间关闭并在重构中重新实现。

- [Ascarshen](https://github.com/Ascarshen)（[#459](https://github.com/aidenlx/zotlit/pull/459)）：支持 Zotero 8 并稳定文献引用标识处理（已合并至 v1）
- [DanielRunningen](https://github.com/DanielRunningen)（[#353](https://github.com/aidenlx/zotlit/pull/353)、[#351](https://github.com/aidenlx/zotlit/pull/351)）：完整日期解析与文献笔记批量创建/更新
- [OliverDudgeon](https://github.com/OliverDudgeon)（[#433](https://github.com/aidenlx/zotlit/pull/433)）：模板中的关联条目与关系
- [theotheo](https://github.com/theotheo)（[#296](https://github.com/aidenlx/zotlit/pull/296)）：支持在文件名中使用 `/` 指定文件夹分类路由
- [Tisen-Ray](https://github.com/Tisen-Ray)（[#466](https://github.com/aidenlx/zotlit/pull/466)）：Zotero 9 兼容支持
- [yukiizumi3](https://github.com/yukiizumi3)（[#464](https://github.com/aidenlx/zotlit/pull/464)）：展示每个条目 Obsidian 笔记状态的自定义 Zotero 数据列
