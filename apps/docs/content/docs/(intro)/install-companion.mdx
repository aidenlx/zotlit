The companion is a Zotero add-on that lets ZotLit communicate with your library. It requires **Zotero 9** or later.

## Install the add-on

<Tabs items={["Stable", "Pre-release"]} updateAnchor>
  <Tab id="stable" value="Stable">
    <VersionLedger app="zotero" channel="stable" />

    <Steps>
      <Step>
        ### Download the `.xpi` file

        Download the latest companion asset directly:

        <XpiDownload channel="stable" />

        If you are using Firefox, you should right click the link and choose `Save Link As...`

        Prefer to pick manually? Find latest companion release from [ZotLit releases page](https://github.com/aidenlx/zotlit/releases) that starts with `zt-`.

      </Step>
      <Step>
        ### Install in Zotero

        In Zotero, open **Tools > Add-ons**. Click the gear menu and select **Install Add-on From File...**. Choose the `.xpi` file you downloaded, then confirm when prompted.

      </Step>
      <Step>
        ### Confirm the installation

        After installing, a **ZotLit** pane should appear in Zotero's settings.

        You do not need to configure anything here right now. The next section explains when this matters.

      </Step>
    </Steps>

  </Tab>

## Keep the database file current

The companion enables **Keep the database file up to date for Obsidian** by default. This setting lets ZotLit read recent Zotero changes when you update a literature note. Keep it enabled under the **Database** section of the ZotLit pane.

This database setting works without live updates. Basic context-menu actions also work through protocol links with no extra setup.

## About live updates

Live updates push changes from your Zotero library to Obsidian. They require the companion's notification setting and the ZotLit server in Obsidian.

The setup for live updates is covered in [Set up live updates](/docs/how-to/set-up-live-updates).
