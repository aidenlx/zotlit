ZotLit brings your Zotero library into Obsidian. ZotLit Companion, the Zotero add-on, keeps recent Zotero changes available to ZotLit.

<Callout type="warn" title="Coming from v1?">
  v2 is a major upgrade with breaking changes. Your existing literature notes
  and custom templates do not carry over unchanged: notes lose incremental
  updates until re-created, and custom Eta templates need rework. Read [Migrate
  from v1](/docs/how-to/migrate-from-v1) before upgrading.
</Callout>

## Start here

Follow these steps in order. Better BibTeX is optional and recommended for citation workflows.

<Steps>
  <Step>
    ### Install ZotLit

    [Install and enable ZotLit in Obsidian.](/docs/install-zotlit)

  </Step>
  <Step>
    ### Install ZotLit Companion

    [Install the required add-on in Zotero.](/docs/install-companion)

  </Step>
  <Step>
    ### Install Better BibTeX (recommended)

    [Install Better BibTeX](https://retorque.re/zotero-better-bibtex/installation/) for stable [citation keys](https://retorque.re/zotero-better-bibtex/citing/) and [automatic bibliography updates](https://retorque.re/zotero-better-bibtex/exporting/auto/).

    ZotLit also supports Zotero-native citation keys and manual bibliography exports.

  </Step>
  <Step>
    ### Create your first literature note

    [Create a note from an item in your Zotero library.](/docs/tutorial/first-note)

  </Step>
</Steps>
