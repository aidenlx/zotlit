import { Check, Fix, Step } from "@/components/learn/lesson-mdx";
import { Command } from "@/components/command";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

<Step n={1}>

Review your draft. Remove any lines meant only for you, such as a to-do list, because everything in the note goes into the Word file.

<Check>The draft contains only what you want to send to your supervisor.</Check>

</Step>

<Step n={2}>

With the draft open, press Ctrl+P (Cmd+P on a Mac) and run <Command inline name={m.command_pandoc_export_name()} />.

<Check>
  The dialog <UiLabel name={m.pandoc_export_title()} /> opens, and{" "}
  <UiLabel name={m.pandoc_export_format_name()} /> is set to{" "}
  <UiLabel name={m.pandoc_export_format_docx()} />.
</Check>

</Step>

<Step n={3}>

Open <UiLabel name={m.pandoc_export_style_name()} /> and choose the style your supervisor or journal asks for, such as **APA Style 7th edition**. The note does not change; this style applies to this export only.

<Check>
  The line under the setting reads{" "}
  <UiLabel
    name={m.pandoc_export_style_changed({
      style: "Default (Chicago author-date)",
    })}
  />
</Check>

<Fix title="The style is not in the list">
  The list shows the styles installed in Zotero. Install the style in Zotero,
  then open the dialog again.
</Fix>

</Step>

<Step n={4}>

Select <UiLabel name={m.pandoc_export_confirm()} />. ZotLit creates the Word file and places the reference list after the last line under the heading **References** without you having to write one.

<Check>
  After a few seconds, the notice appears:{" "}
  <UiLabel
    name={m.notice_pandoc_export_done({
      file: "Chapter 3 - Presenting the results.docx",
      style: "APA Style 7th edition",
    })}
  />
</Check>

</Step>

<Step n={5}>

The Word file sits in the same folder as your draft, with the same name. Obsidian's file list does not show Word files, so open that folder in Finder (Mac) or File Explorer (Windows), and open the file.

<Check>
  Each citation is formatted, for example **(Sandve et al., 2013, p. 2)**, and a
  **References** list at the end has one entry for each paper cited.
</Check>

</Step>
