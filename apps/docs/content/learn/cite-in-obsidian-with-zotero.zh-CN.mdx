import { Check, Fix, Step } from "@/components/learn/lesson-mdx";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

<Step n={1}>

在**设置**（Settings）> **ZotLit** > <UiLabel name={m.settings_page_citations()} /> 中，选择 <UiLabel name={m.settings_citation_engine_name()} /> 旁边的 <UiLabel name={m.settings_citation_engine_install()} />。

<Check>
  该行显示{" "}
  <UiLabel
    name={m.settings_citation_engine_status_installed({ version: "3.10" })}
  />{" "}
  （版本号可以更高）。
</Check>

</Step>

<Step n={2}>

在你的草稿中（此处为 `Chapter 3 - Presenting the results`），放置光标并键入 `[@` 以及你文库中的作者名，例如 `[@sandve`。

<Check>
  引文菜单随即打开，显示你的文献（此处为 **Sandve et al. (2013), PLOS
  Computational Biology, 9(10), e1003285**）。
</Check>

<Fix title="文献不在列表中">
  没有文献引用标识的文献无法被引用。在 Zotero 中安装 Better
  BibTeX，即可为每篇文献生成引用标识。
</Fix>

</Step>

<Step n={3}>

按 Enter 选择文献。

<Check>草稿在光标处显示文献的文献引用标识（此处为 `[@sandve2013]`）。</Check>

</Step>

<Step n={4}>

在右方括号前键入 `, p. 2`，然后将光标移开。

<Check>
  引文现在显示为作者、年份和页码，此处为 **(Sandve et al. 2013, 2)**。
</Check>

<Fix title="仍显示为 [@sandve2013, p. 2]">请完成步骤 1 中的引擎安装。</Fix>

</Step>

<Step n={5}>

将指针悬停在格式化引文上。

<Check>预览卡片随即打开，显示文献的完整参考文献（此处为 Sandve 2013）。</Check>

</Step>

<Step n={6}>

在草稿旁边打开 PDF。将侧边栏中高亮的页码标签（例如 **p. 2**）拖入草稿中。

<Check>
  草稿中显示一个标题为 **Page 2** 的引用块，包含高亮文本、引文和笔记。
</Check>

</Step>
