import { Check, Fix, Step } from "@/components/learn/lesson-mdx";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

<Step n={1}>

在 <UiLabel name={m.library_view_name()} /> 中，选择第 1 课中的论文（此处为 Sandve et al. 2013），然后在卡片上点击 <UiLabel name={m.library_view_menu_open_pdf()} />。

<Check>
  PDF 打开，标注工具呈暗淡状态，侧边栏显示{" "}
  <UiLabel name={m.annot_view_header_following_active_tab()} /> ·{" "}
  <UiLabel name={m.annot_view_header_reading_only()} />。
</Check>

</Step>

<Step n={2}>

点击侧边栏标题，然后点击 <UiLabel name={m.capability_enable_editing()} />。切换到 Zotero，在对话框中选择 **Always Allow**。

<Check>
  返回 Obsidian，会弹出提示：{" "}
  <UiLabel name={m.notice_zotero_editing_enabled()} /> 工具栏变为彩色。
</Check>

<Fix title="工具仍呈暗淡状态">重新执行此步骤并选择 **Always Allow**。</Fix>

</Step>

<Step n={3}>

在 PDF 中拖动光标选划一句话。

<Check>
  选中文本下方会出现一个工具栏，包含{" "}
  <UiLabel name={m.pdf_toolbar_highlight()} />、{" "}
  <UiLabel name={m.pdf_toolbar_underline()} />
  、四种颜色以及 <UiLabel name={m.annot_view_card_add_comment()} />。
</Check>

</Step>

<Step n={4}>

点击 <UiLabel name={m.annot_view_card_add_comment()} />，输入自己的评论，然后点击 <UiLabel name={m.pdf_toolbar_highlight()} />。

<Check>选中文本变为黄色，侧边栏会出现一张显示页码、摘录和评论的卡片。</Check>

</Step>

<Step n={5}>

切换到 Zotero 并打开同一份 PDF。

<Check>Zotero 中的 PDF 显示了相同的黄色高亮和评论。</Check>

</Step>

<Step n={6}>

在 Obsidian 中打开该论文的笔记。

<Check>**Annotations** 分节下显示了该高亮的新卡片。</Check>

</Step>
