import { Check, Step } from "@/components/learn/lesson-mdx";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

<Step n={1}>

在 <UiLabel name={m.library_view_name()} /> 中，选择你的一个分类（例如 `Reproducibility`），然后点击 <UiLabel name={m.annot_view_save_as_query_file()} />（列表右上角带加号的页面图标）。输入你自选的文件夹（例如 `Thesis`），然后选择 <UiLabel name={m.annot_view_save_action()} />。

<Check>
  对话框会显示根据你的文件夹和分类创建的文件（此处为{" "}
  <UiLabel
    name={m.annot_view_save_file({ file: "Thesis/Reproducibility.zotquery" })}
  />
  ），并且该文件会在新标签页中打开并列出你的文献。
</Check>

</Step>

<Step n={2}>

点击左上方的 <UiLabel name={m.query_view_views()} />，然后点击该行末尾的箭头（<UiLabel name={m.query_view_configure_view()} />）。将 <UiLabel name={m.query_view_layout()} /> 设置为 <UiLabel name={m.query_view_layout_table()} />。

<Check>
  文献以表格行呈现，列包括 **条目类型**、**标题**、**修改日期** 以及{" "}
  <UiLabel name={m.query_view_table_literature_note()} />。
</Check>

</Step>

<Step n={3}>

点击 <UiLabel name={m.query_view_properties()} /> 并取消勾选 **条目类型** 与 **修改日期**。依次输入并选择各项：输入 `year` 选择 **年份**，输入 `publication` 选择 **出版物**，输入 `creators` 选择 <UiLabel name={m.query_view_properties_add({ name: "creators" })} />。

<Check>
  当前显示的列为 **标题**、{" "}
  <UiLabel name={m.query_view_table_literature_note()} />
  、**年份**、**出版物** 和 **创建者**。
</Check>

</Step>

<Step n={4}>

点击 <UiLabel name={m.query_view_properties()} />，输入 `rating`，然后选择 <UiLabel name={m.query_view_properties_add_vault({ name: "rating" })} />。在新列下方的每个单元格中输入评分（例如 `5`）并按 Enter。

<Check>
  列 **rating (note)** 会显示你的评分，且输入评分时会显示{" "}
  <UiLabel name={m.notice_created_note()} />
</Check>

</Step>

<Step n={5}>

点击 <UiLabel name={m.query_view_sort()} /> > <UiLabel name={m.query_view_sort_add()} />，将第一个框设为 <UiLabel name={m.query_view_property_date()} />，第二个框设为 <UiLabel name={m.query_view_sort_old_new()} />。

<Check>表格中的文献按日期从旧到新排序显示。</Check>

</Step>

<Step n={6}>

点击结果数量（例如 <UiLabel name={m.query_view_results({ count: 4 })} />），然后点击 <UiLabel name={m.query_view_copy()} />。将表格粘贴到你的草稿中。

<Check>表格出现在草稿中，并保留所有列。</Check>

</Step>
