import { Check, Fix, Step } from "@/components/learn/lesson-mdx";
import { UiLabel } from "@/components/ui-label";
import { m } from "@/paraglide/messages.js";

<Step n={1}>

在 <UiLabel name={m.library_view_name()} /> 中，选择 <UiLabel name={m.annot_view_save_as_query_file()} />（列表右上角的页面加号图标）。输入 `Reading plan` 作为名称并选择 <UiLabel name={m.annot_view_save_action()} />。

<Check>`Reading plan` 文件会在新标签页中打开，列出你的文献。</Check>

</Step>

<Step n={2}>

选择左上方的 <UiLabel name={m.query_view_views()} />，然后点击该行末尾的箭头（<UiLabel name={m.query_view_configure_view()} />）。将 <UiLabel name={m.query_view_layout()} /> 设置为 <UiLabel name={m.query_view_layout_table()} />。

<Check>你的文献将作为表格的行显示。</Check>

</Step>

<Step n={3}>

选择 <UiLabel name={m.query_view_properties()} />，输入 `reading-status`，然后选择 <UiLabel name={m.query_view_properties_add_vault({ name: "reading-status" })} />。

<Check>
  会出现一列名为 **reading-status (note)** 的列，未关联笔记的文献显示{" "}
  <UiLabel name={m.query_view_vault_no_note()} />。
</Check>

<Fix title="列标题没有包含“(note)”">
  选择 <UiLabel name={m.query_view_properties()} />
  ，取消选中该复选框，然后选择{" "}
  <UiLabel
    name={m.query_view_properties_add_vault({ name: "reading-status" })}
  />
  。
</Fix>

</Step>

<Step n={4}>

选择某篇文献的阅读状态单元格，输入 `to-read`，然后按 Enter。

<Check>
  出现提示：
  <UiLabel name={m.notice_created_note()} /> 单元格显示 `to-read`。
</Check>

</Step>

<Step n={5}>

将另一篇文献标记为 `reading`，已读完的文献标记为 `done`。

<Check>输入时，单元格会推荐你之前使用过的状态。各行现已显示相应状态。</Check>

</Step>

<Step n={6}>

选择 <UiLabel name={m.query_view_filter()} />，将第一个框设置为 **reading-status (note)**，第二个框设置为 **是**，在第三个框中输入 `to-read`。

<Check>表格中将仅显示标记为 `to-read` 的文献。</Check>

</Step>
