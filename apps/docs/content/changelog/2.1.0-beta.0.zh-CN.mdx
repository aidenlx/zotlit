## 版本亮点

![实时预览中将文献笔记双链渲染为格式化引文簇，右侧参考文献侧边栏展示对应的参考文献列表条目](/img/changelog/wikilink-citation-runs.webp)

### 参考文献侧边栏（References Sidebar）

新增的侧边栏视图会将当前活动笔记中包含的引文汇总为排版精美的参考文献列表。每个条目均展示其引文编号以及所选 CSL 样式格式化的文本，并提供一键打开文献笔记、在 Zotero 中定位该条目或打开对应 PDF 附件的操作按钮。点击条目文本即可在编辑器中依次循环跳转换读正文中的各处引用。

### 正文引文格式化渲染

字面量引文簇（例如 `[see @wang2020, p. 3; @lee2019]`）现在在实时预览与阅读视图中均能够自动呈现为格式化文本。

指向文献笔记的双链链接同样可以作为引文进行渲染，并与字面量引文共享相同的格式化排版和连续编号机制。在**设置 > ZotLit > 引文**中开启**双链引文（Wikilink citations）**即可启用该特性（默认处于关闭状态）。

引文渲染同样支持通过 Pandoc 将其格式化为您从 Zotero 已安装样式中选定的 CSL 样式（在**设置 > ZotLit > 引文**中配置）。

### 导出包含引文的笔记

新增命令 **ZotLit: 导出包含引文的笔记**，支持将当前活动的 Markdown 笔记转换为附带格式化参考文献列表的 DOCX 或 HTML 文档。在导出对话框中可自由选择输出格式、CSL 引文样式以及目标保存路径。引文直接从笔记自身的链接中解析，无需在外部安装独立的 Pandoc。详情参阅[如何导出包含引文的笔记](/docs/how-to/export-note-with-citations)。

这项功能尚未最终定型，但您已可以通过该命令进行试用。

## 新增功能

### 文献引用标识导航与样式支持

编辑器中识别出的文献引用标识被赋予了链接交互样式。未解析的标识（即 Zotero 中找不到对应条目）与已解析的标识在视觉上有明显的区分。点击文献引用标识可直接打开其对应的文献笔记，鼠标悬停即可查看页面预览。

在阅读视图中渲染的引文同样具备交互导航能力：点击单篇文献引文可直接打开文献笔记；点击多篇引文则会弹出一个包含所引全部文献的菜单供您选择。详见[正文引文渲染与导航机制](/docs/concepts/how-citekey-links-work)。

该功能可通过**设置 > ZotLit > 引文**中的**将 Pandoc 引文作为链接打开**进行开关。

### 直接从 Zotero 解析文献引用标识

文献引用标识现在严格对照 Zotero 原生的文献引用标识字段进行解析，不再依赖笔记自身的 frontmatter 属性。旧版的**文献引用标识属性**配置项现已废弃并完成自动迁移。

### CSL 引文样式选择

参考文献侧边栏与正文引文渲染会统一采用您从 Zotero 已安装样式中选定的 CSL 样式。样式选择器位于**设置 > ZotLit > 引文**。留空或选用了已删除的样式会自动安全回退至系统默认样式。

### 原生 Pandoc CLI 工作流

支持在 Obsidian 外部通过独立安装的原生 Pandoc 转换笔记，同时将文献笔记双链正确转换为学术引文。引文设置页面中的<UiLabel name={m.settings_citation_pandoc_files_save()} />操作会生成与当前插件版本匹配的 Lua 过滤器（`zotlit-cite.lua`）与 Pandoc 默认配置文件（`zotlit.yaml`）。Lua 过滤器通过新增的 `zotlit:resolve` 命令，将每个双链解析为对应的文献引用标识；支持 Obsidian 命令行接口的 CLI 工具（例如 `obsidian-cli`）可以调用该命令。

另有两条配套命令支持此工作流：`zotlit:pandoc-files` 以 JSON 形式返回集成文件对，`zotlit:pandoc-guide` 打印配置与排错指南。新增的 `zotlit-pandoc` skill 能够引导 AI 智能体完成同一工作流：配置、刷新、运行原生导出，以及诊断失败的运行。

### 主题开发支持

- 编辑器与阅读视图中的各引文 DOM 元素均开放了公开的 CSS 类名接口，详细记录在[主题样式类名参考](/docs/reference/theme-hooks)中。主题作者可针对已解析、未解析、待解析及渲染态引文进行专属定制美化。
