## 亮点 [#highlights]

![在实时预览中渲染为格式化引用群的文献笔记 Wiki 链接引用，参考文献侧边栏显示匹配的参考文献条目](/img/changelog/wikilink-citation-runs.webp)

### 参考文献侧边栏 [#references-sidebar]

全新的侧边栏视图将当前活动笔记中的引用列为格式化的参考文献列表。每个条目均显示参考文献编号以及采用所选 CSL 样式排版的格式化文本，并提供打开文献笔记、在 Zotero 中打开条目或打开关联 PDF 的操作。点击条目文本可在编辑器中逐个浏览该引用的出现位置。

### 文内引用渲染 [#in-text-citation-rendering]

字面引用群（例如 `[see @wang2020, p. 3; @lee2019]`）现已在**实时预览**（Live Preview）和**阅读视图**（Reading view）中显示为格式化文本。

文献笔记 Wiki 链接也可以渲染为引用，与字面引用共享相同的格式化显示和编号规则。你可以在**设置**（Settings）> **ZotLit** > **引文**中开启 **Wiki 链接引用**——此功能默认关闭。

引文渲染还支持使用 Pandoc，按你在 Zotero 已安装样式中选取的 CSL 样式进行排版（在**设置** > **ZotLit** > **引文**中设置）。

### 导出带引文的笔记 [#export-a-note-with-citations]

新增命令 **ZotLit: 导出带引文的笔记**，可将当前 Markdown 笔记转换为包含格式化参考文献列表的 DOCX 或 HTML 文档。在导出对话框中选择输出格式、CSL 样式和保存目标。引用会直接从笔记自身的链接中解析；无需在外部安装 Pandoc。参见[如何导出带引文的笔记](/docs/how-to/export-note-with-citations)。

此功能尚未最终定型，但该命令已可供测试。

## 新增内容 [#whats-new]

### 文献引用标识导航与样式 [#citation-key-navigation-and-styling]

编辑器中识别出的文献引用标识现在会呈现为链接样式。未解析的文献引用标识（即在 Zotero 中未指代任何条目的标识）在外观上与已解析的标识有明显区别。点击文献引用标识可打开其文献笔记，悬停则可查看页面预览。

阅读视图中渲染的引用同样支持导航：点击单个引用的标识会打开文献笔记，点击多引用的标识则会打开列出每篇被引文献的菜单。参见[文内引用渲染与导航的工作原理](/docs/reference/citation-links)。

如需关闭此功能，可在**设置** > **ZotLit** > **引文**中关闭**将 Pandoc 引用作为链接打开**。

### 从 Zotero 解析文献引用标识 [#citation-key-resolution-from-zotero]

文献引用标识现在根据 Zotero 原生的文献引用标识进行解析，不再依赖属性。**文献引用标识属性**设置项已弃用并已自动迁移。

### CSL 样式选择 [#csl-style-selection]

参考文献侧边栏与文内引用渲染均采用你从 Zotero 已安装样式中选取的 CSL 样式。样式选择器位于**设置** > **ZotLit** > **引文**中。若未设置或选择的样式已被移除，将自动回退到默认样式。

### 原生 Pandoc CLI 工作流 [#native-pandoc-cli-workflow]

支持在 Obsidian 外部使用独立安装的 Pandoc 转换笔记，文献笔记 Wiki 链接会自动转换为引用。引文设置页面中的**保存集成文件**操作会写入适配当前安装插件版本的 Lua 过滤器（`zotlit-cite.lua`）和 Pandoc 默认配置文件（`zotlit.yaml`）；Lua 过滤器通过全新的 `zotlit:resolve` 命令将每个 Wiki 链接解析为其文献引用标识，该命令可通过支持 Obsidian 命令行界面的 CLI 工具（例如 `obsidian-cli`）调用。

另有两个命令支持此工作流：`zotlit:pandoc-files` 以 JSON 格式返回集成文件对，`zotlit:pandoc-guide` 输出配置与故障排除指南。全新的 `zotlit-pandoc` 技能可引导 AI Agent 完成整个工作流：配置、刷新、运行原生导出以及诊断失败的运行。

### 主题支持 [#theme-support]

- 编辑器和阅读视图界面的引用元素均已提供 CSS 类，详见[主题钩子参考](/docs/reference/theme-hooks)。主题作者可以针对已解析、未解析、等待中以及已渲染的引用状态自定义样式。
