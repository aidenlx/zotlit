这是 v2.1 引文工作流的首个稳定版本：包含参考文献侧边栏、文内引用渲染、引用弹出框和被引用侧边栏，同时支持 Zotero 10 和多文库范围。以下内容汇总了自 beta.3 以来的主要更新；如需了解完整介绍，请阅读[发布博文](/blog/v2.1-release)。

## 自 beta.3 以来的新增内容 [#whats-new-since-beta3]

### Pandoc 引擎性能 [#pandoc-engine-performance]

内置 Pandoc 引擎的加载速度提升了约三倍：中位加载时间从 291 ms 降至 97 ms，且不再出现伴随每次加载的 JavaScript 内存瞬时激增。如果缓存的引擎二进制文件损坏，ZotLit 现在能够检测到并将其清除，重新提示安装。

### 彩色笔记导入高亮 [#colored-note-import-highlights]

**设置 › 导入笔记**下的新增自选设置项**使用彩色高亮语法**，可将从 Zotero 笔记导入的高亮转换为基于 emoji 的彩色高亮语法。该功能支持六种高亮颜色。若高亮使用了不受支持的颜色，或者文本可能破坏该语法结构，则仍保留为 HTML。无论采用哪种方式，标注反向链接都会予以保留。

## 自 beta.3 以来的问题修复 [#bug-fixes-since-beta3]

- 修复了关于数据库读取模式回退的重复提示。ZotLit 现在会引导你安装 Companion 或进行陈旧数据排障，而不再反复显示通知。
- 修复了在运行多个 Zotero 实例时，Pandoc 导出连接到错误的 Zotero HTTP 端口的问题。现在端口会根据当前活动的配置文件正确解析。
