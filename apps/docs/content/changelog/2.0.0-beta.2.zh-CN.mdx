## 破坏性变更

### 引文插入文本自动单行规范化规整

插入笔记的正文引文文本现在会自动消除多余空白并规整收拢为单行行内文本。编辑器会在插入内容后自动留出一个空格，以便光标就绪直接继续后续打字。有意生成多行引文输出的自定义模板在插入时将被自动扁平化为单行文本。

在行内引文建议下拉框中按下 Shift+Enter 现在会选择备用引文格式，与命令面板弹窗的交互行为保持一致。

## 新增功能

### 单个 @ 触发引文插入

新增的按需开启设置项允许您直接键入单个 `@` 唤起引文建议下拉框，无需输入默认的 `[@` 触发前缀。由于 `@` 查询没有后括号作为闭合界限，可用下划线代替空格（例如 `@cognitive_load`）。可在引文设置区域中将其开启。详见[插入引文](/docs/how-to/insert-citations)。

### 富文本标注卡片

标注视图中的标注卡片现在支持渲染带行内样式（加粗、斜体、下标、上标）的正文摘录，并通过与文献笔记相同的 Markdown 渲染流水线展示评注内容。卡片中看到的效果与笔记模板生成的内容完全一致。评注中的双链链接能够正常关联文献笔记并在工作区中顺利打开。

### 其他改进

- Zotero 配套插件 ZotLit Companion 中的右键菜单标签现在明确使用“文献笔记（Literature Note）”替代原本模糊的“笔记”，并遵循 Zotero 原生菜单的英文大写规范。

## 问题修复

- 修复了在标注模板中，即便 `zt.parentItem.title` 正常，`zt.parentItem.authorsShort` 与 `zt.parentItem.authors` 仍旧渲染为空的问题。现在这些字段均能正确解析，且 `zt.parentItem.backlink` 与 `zt.parentItem.weblink` 也已完整补齐。
- 修复了对尚无文献笔记的条目执行“仅更新元数据”操作时，意外使用模板创建了完整笔记的错误。现在仅更新元数据的操作会如规范所述，安全跳过尚无现有笔记的条目。
