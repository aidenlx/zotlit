## What's New

### Your citations in the graph view

Obsidian's graph view now draws your citations ([discussion #965](https://github.com/aidenlx/zotlit/discussions/965)). Each note gains an edge to every work it cites, so Literature Notes stop floating unconnected and two notes that cite the same paper meet at that paper's node.

A work you cite but have no Literature Note for still appears, as a dimmed Cited Work Node labeled with the citation key. Select it to create its Literature Note from your template, right-click it to open the item in Zotero or copy its key, and hover it to read the formatted entry. Once the note exists, a key that matches one Zotero item trades its dimmed node for the note node, with the same edges. A key that matches several items stays ambiguous, so its Cited Work Node remains.

Literature Notes, Cited Work Nodes, and citation edges each take their own color, which follows your theme and dark mode. Your own color groups still win, and a one-press <UiLabel name={m.graph_citations_add_literature_notes_group()} /> button in the graph's Groups section colors every Literature Note without writing a search query.

Four new rows in the graph controls panel decide what each graph draws: <UiLabel name={m.graph_option_pandoc_citations_name()} />, <UiLabel name={m.graph_option_wikilink_citations_name()} />, <UiLabel name={m.graph_option_citation_connected_only_name()} />, and <UiLabel name={m.graph_option_color_citation_links_name()} />. They persist and reset like the native rows.

Two commands, <Command inline name={m.command_open_citation_graph_name()} /> and <Command inline name={m.command_open_local_citation_graph_name()} />, open the graph set for reading as a research map: citations on, every node except your Literature Notes, cited works, and the notes that cite them hidden, arrows on, and the literature notes group added. A global graph keeps one set of options for the whole vault, so the first command saves that arrangement as your graph settings; **Restore default settings** returns the graph to Obsidian's defaults.

Everything native keeps working across citation edges: search, depth, incoming and outgoing links, following the active note, and **Existing files only** to hide the cited works.

The whole feature has one switch, <UiLabel name={m.settings_citation_graph_name()} />, under <SettingsPath page={m.settings_page_citations()} />. Turn it off and every graph goes back to exactly what Obsidian drew before. [Explore citations in the graph view](/docs/how-to/explore-citations-in-graph) is the full guide.
