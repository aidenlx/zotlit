## 破坏性变更

### 单设备独立的 Zotero 路径配置

Zotero 配置文件与数据目录路径现已改为单设备独立存储。如果您在多台电脑间同步仓库，一台设备的 Zotero 路径将绝不会覆盖另一台设备。未配置的路径代表自动侦测；在某台机器上手动指定的路径仅会在该机器上生效。

若插件在某台新设备上找不到您的 Zotero 数据库，欢迎视图会弹出通知引导您进行路径定位。详见[在多台设备上同步使用](/docs/how-to/sync-across-devices)。

如果您此前设置过自定义的 Zotero 配置文件或数据目录路径，在更新后需要在每台对应设备上重新指定一次，原有的同步历史值不再迁移。

## 新增功能

### `zt.weblink` 模板字段

新增的模板变量 `zt.weblink` 提供了条目在 Zotero Web 端文库的网页访问 URL（例如 `https://www.zotero.org/yourname/items/ABC123`），与原有的 `zt.backlink` 桌面端深度链接形成互补。该字段可在主条目以及 `zt.relatedItems` 的各条目上访问（从未同步过云端账户的条目除外）。详见[模板数据参考](/docs/reference/templates/data)。

## 问题修复

- 修复了标注视图未能跟随在独立新窗口（而非主窗口标签页）中打开的 Zotero 阅读器的问题。此前仅追踪标签页阅读器，现在独立阅读器窗口在获得焦点时同样能被准确捕捉。
- 修复了当 Obsidian 窗口处于后台或被遮挡时，批量导入和索引构建速度大幅变慢的问题。
