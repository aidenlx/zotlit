## 新增内容 [#whats-new]

### 欢迎视图 [#welcome-view]

全新安装和升级后会显示首次运行引导界面。其中提供实时的设置时间线，包含 Zotero 连接状态、笔记文件夹选择器、首篇笔记搜索，以及指向文档和社区的快捷链接。

设置选项卡上的资源快捷栏（发行说明、文档、帮助）现已在 Obsidian 1.13 及更早版本中可用。

### 标注视图：搜索与筛选 [#annotation-view-search-and-filter]

标注视图新增的搜索栏支持匹配文本、评论、标签和页码。包含颜色色块、首个标签胶囊和内嵌标签抽屉的筛选栏，让你无需切换到 Zotero 即可缩小标注范围。卡片默认折叠以便快速浏览，视图还预留了状态栏间距，确保列表底部绝不会被遮挡。

完整工作流请参阅[使用标注视图](/docs/how-to/use-annotation-view)。

![Obsidian 中的文献笔记，打开了标注视图，显示搜索、颜色与标签筛选以及 Zotero 条目的标注卡片](/img/blog/annotation-view.webp)

### Zotero 中的笔记状态列 [#note-status-column-in-zotero]

ZotLit Companion（Zotero 插件）现在会显示一个额外列，标明哪些条目在 Obsidian 中已有对应的文献笔记。这让你无需离开 Zotero 即可对笔记覆盖情况一目了然。

### v2 文档网站 [#v2-documentation-site]

[文档网站](/docs)与此版本同步上线，涵盖全部功能：[教程](/learn/connect-zotero-to-obsidian)、[操作指南](/docs)、[概念说明](/docs/reference)，以及涵盖设置、命令、协议链接和模板语法的[参考手册](/docs/reference)。

新指南：[屏蔽 Zotero 的安全提示](/docs/how-to/suppress-zotero-security-prompt)、[收集调试日志](/docs/how-to/collect-debug-logs)，以及重写的[从 v1 迁移](/docs/how-to/migrate-from-v1)。
