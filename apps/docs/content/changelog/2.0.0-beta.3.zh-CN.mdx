## 新增内容 [#whats-new]

### 初步支持简体中文 [#initial-chinese-simplified-language-support]

本插件现已提供简体中文语言包供下载。打开设置中的 **语言包** 区域即可安装。

### 附件上的 `backlink` 字段 [#backlink-field-on-attachments]

`zt.attachments` 和 `zt.parentAttachment` 中的每个附件现在都提供了 `backlink` 字段。它包含一个用于在 Zotero 阅读器中打开该附件的 `zotero://open/...` 深度链接。这补充了主条目上原有的 `backlink`。参见[模板数据参考](/docs/reference/templates/data)。

### 其他改进 [#other-improvements]

- 在低于 1.13.0 且缺少内置确认 API 的 Obsidian 版本上，确认对话框现已能正常显示。
