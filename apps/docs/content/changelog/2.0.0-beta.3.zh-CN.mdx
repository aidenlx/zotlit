## 新增功能

### 初步引入简体中文界面语言支持

插件现已提供简体中文作为可下载的语言包（Language Pack）。打开设置中的**语言包**区域即可一键安装。

### 附件对象新增 `backlink` 字段

`zt.attachments` 以及 `zt.parentAttachment` 中的每个附件现在均暴露了 `backlink` 字段。它包含形如 `zotero://open/...` 的深度链接，可直接在 Zotero 原生阅读器中打开该附件。这与主条目上原有的 `backlink` 形成了完备互补。详见[模板数据参考](/docs/reference/templates/data)。

### 其他改进

- 在没有内置原生确认 API 的低于 1.13.0 的老版本 Obsidian 上，二次确认弹窗现在也能正常排版展示。
