# Unload

Unload closes the plugin's runtime Scope and every layer Scope under it. The close stops every pending run, and code outside Effect sees that stop in one of two shapes. The reviewer checks each part below.

- **Every run stops.** A bridge run lives in the bridge's Scope (`lib/effect-bridge.ts`, `bridgeOver`): `effectBridge(runtime)` uses the runtime's Scope, `scopedBridge` the layer's. At unload, `runPromise` rejects with an `AbortError` (`lib/abort-error.ts`), and `runPromiseExit` resolves with an interrupt-only Exit, which `valueOr` or `settleAtEdge` (`lib/signal-edge.ts`) maps to the caller's released answer.
- **A waiting caller stays silent.** A caller that awaits a run treats the unload's `AbortError` as no outcome: no notice, no log. `toast` (`lib/toast.ts`) and the notifier's `reportProgress` / `reportOutcome` (`lib/notifier.ts`) already pass over it; other code tests it with `AbortError.test`. A fire-and-forget call on an edge handle's Promise member adds `.catch(passAborted)` (`lib/abort-error.ts`).
- **A call fired and forgotten** from a DOM, editor or observer callback runs through `bridge.runAndForget`: unload stops it quietly, and any other failure stays an unhandled rejection, so the service or the caller handles that failure.
- **A write finishes its step.** A write step that an interrupt would leave half-done (a created note before its stamp, a template conversion, a settings save) is an `Effect.uninterruptible` region in its service, so the Scope close waits for that step and no longer: the `write` of `template/service.ts`, `owned(…, true)` in `profile/service.ts`, `flush` in `settings/service.ts` (`CODING_STANDARDS.md` → Interruption gives its test).
- **A captured runner is scoped.** A service that keeps a runner for later callbacks builds it on a Scope: the layer's `FiberSet.runtime` (`protocol/register.ts`), or `scopedBridge` (`citekey-reading/service.ts`); a plain adapter uses `effectBridge(runtime)`. This holds for every service, `citation-index/plain.ts` included: a run over a captured context (`Effect.runPromiseWith(context)`) has no Scope, so unload leaves it running. A runner that must outlive the writes it serves uses a Scope forked before the writes' Scope, so the close waits for the writes first.
