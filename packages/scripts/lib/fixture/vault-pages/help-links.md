# Help links

Each case opens a documentation page from ZotLit. The browser opens the page in a new tab with no redirect.

Run state: the default `configured` Fixture Vault, built with `pnpm fixture`, with Obsidian open on it. Zotero need not run for these cases. In this state the setup is complete, so the Library View shows no Welcome banner until the first case asks for it.

## Getting started tile

1. Run **ZotLit: Open welcome view**. The Library View opens with the Welcome banner above the paper list.
2. In the Help links in the banner, select **Getting started**.

Expected: the Welcome banner shows its Help links. The browser opens `https://zotlit.aidenlx.site/learn`, the page of the tutorial course. Its first lesson is "Connect Zotero to Obsidian and write a literature note". The tile's subtitle reads "Set up ZotLit and write your first note".

## Browse docs

1. Open **Settings → ZotLit**.
2. In the resources section at the top, find **Documentation** and select **Browse docs**.

Expected: the browser opens `https://zotlit.aidenlx.site/docs`, the documentation home. The row keeps its name "Documentation" and its description "Guides and reference for setting up and using ZotLit."

## Pandoc citation workflow

1. Open **Settings → ZotLit → Citations**.
2. In the **Native Pandoc workflow** group, find **Pandoc citation workflow** and select **Open guide**.

Expected: the browser opens `https://zotlit.aidenlx.site/docs/how-to/pandoc-citation-workflow` and the address stays on that path.
