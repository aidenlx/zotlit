# Seminar talk: mapping a research field

Twenty-minute talk for the methods seminar. The argument: a field can be mapped from its references, and the map changes what we read next.

## Outline

1. **The problem.** The record grows faster than any reader can follow. Bush said so in 1945 [@bushAsWeMayThink1945].
2. **References as data.** The citation index makes every reference a link that can be followed forward [@garfieldCitationIndexes1955].
3. **Finding clusters.** Co-citation groups papers that later authors read together [@smallCoCitationScientific1973].
4. **Ranking by links.** PageRank and hubs and authorities reuse the same idea on the web [@brinAnatomyLargeScale1998; @kleinbergAuthoritativeSources1999].
5. **Drawing the map.** Overview first, then zoom and filter, then details on demand [@shneidermanEyesHaveIt1996].
6. **Living with the map.** A map is a tool for thought only if the researcher can change it while reading [@matuschakTransformativeTools2019].
