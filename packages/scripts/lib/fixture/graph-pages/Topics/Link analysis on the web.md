# Link analysis on the web

The web is a hypertext in Nelson's sense, documents that point to one another [@nelsonComplexInformation1965]. Its links are much like citations, and the first good search engines used them that way.

## Two algorithms from bibliometrics

PageRank gives a page a high rank when pages of high rank link to it [@brinAnatomyLargeScale1998]. The idea is a weighted citation count, close to the journal rankings that Garfield proposed [@garfieldCitationAnalysisTool1972].

Kleinberg separates two roles. A hub is a page that links to many good authorities, and an authority is a page that many good hubs link to [@kleinbergAuthoritativeSources1999, p. 604]. He relates the method directly to co-citation [@smallCoCitationScientific1973] and bibliographic coupling [@kesslerBibliographicCoupling1963].

## Links with meaning

A citation or a link says that two documents are related, not how. The semantic web proposal adds machine-readable meaning to links, so that software can act on the relation [@bernersLeeSemanticWeb2001].
