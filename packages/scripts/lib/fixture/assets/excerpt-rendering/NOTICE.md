# Excerpt rendering acceptance PDFs

These files are generated by `generate.ts` in this directory. They contain no
third-party document content and use ZotLit's AGPL-3.0-or-later license.

`excerpt-rendering.pdf` has six pages. It covers page rotations 0, 90, 180,
and 270; a nonzero CropBox; UserUnit 2; an embedded Type3 font with a ToUnicode
CMap for `测试`; explicit native Text and AcroForm Widget appearance streams;
optional content; the maximum pixel budget; and the maximum dimension. Its
color blocks, glyphs, appearance streams, and ink paths give the acceptance
tests independent pixel oracles.

`corrupt.pdf` has a broken cross-reference offset. `encrypted.pdf` declares a
Standard security handler and requires a password. Both define a stable
unavailable outcome.

Regenerate the files from the repository root:

```sh
node packages/scripts/lib/fixture/assets/excerpt-rendering/generate.ts
```
