# Fixture asset for an External Annotation

The file in this directory is original ZotLit content, hand-generated by
`generate.ts` in this directory. It carries ZotLit's AGPL-3.0-or-later
license, unlike the third-party PDFs in the sibling asset directories.

`generate.ts` writes raw PDF bytes directly (classic xref table, uncompressed
content stream, Standard-14 `Times-Roman`, no embedded font file) and is
byte-deterministic: no random ids, no `/CreationDate`, and a fixed `/M`.
Regenerate with:

```
node lib/fixture/assets/external-annotation/generate.ts
```

## Files

- `external-annotation.pdf`: one page, `MediaBox [0 0 612 792]`, with two
  lines of text. A `/Highlight` annotation with `/QuadPoints` covers the
  first line, "Another PDF reader highlighted this sentence.", and carries
  the comment "Noted in another PDF reader." It has no Zotero key, as a
  highlight that another PDF reader saves. SHA-256:
  `376a4662e2648db8271e583a3603bad06b137107153b556133a2588280216e54`.

## Verified import

Measured against the managed Zotero 10.0 on 2026-09-26: `Zotero.Reader.open`
on the Fixture Attachment `EXTPDF25` imports one Annotation with
`annotationIsExternal` true, the Quoted Text of the first line, the comment
above, colour `#ffd400`, and page label `1`.
