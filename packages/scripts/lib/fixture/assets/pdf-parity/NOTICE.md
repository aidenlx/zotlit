# Fixture assets for Sort Index / Page Label parity

The files in this directory are original ZotLit content, hand-generated by
`generate.ts` in this directory. They carry ZotLit's AGPL-3.0-or-later
license, unlike the third-party PDFs in the sibling asset directories.

`generate.ts` writes raw PDF bytes through the shared `../pdf-writer.ts`
(classic xref table, uncompressed content streams, Standard-14 `Times-Roman` —
no embedded font file) and is byte-deterministic: no timestamps, no random ids, no `/CreationDate`.
Regenerate with:

```
node lib/fixture/assets/pdf-parity/generate.ts
```

## Files

- `pdf-parity-layout.pdf` — one page, `MediaBox [0 0 612 792]`, that enters
  the rotation, ligature, and multi-column branches of Zotero's PDF
  line-grouping algorithm (`core/module/structure.js` in Zotero's pinned
  pdf.js): two text columns (left at x≈60, right at x≈330), a 90-degree
  rotated block (text matrix `0 1 -1 0 tx ty`) near x≈560, and a ligature
  line under the left column rendered through a font resource with
  `/Encoding << /Differences [ 1 /fi 2 /fl ] >>`. SHA-256:
  `3839ce157abd250ab19d57d18855e72a45eaf9a70bdd207981600ca48b67a4db`.

- `pdf-parity-scanned.pdf` — one page, `MediaBox [0 0 612 792]`, whose only
  content is a full-page `DeviceGray` image XObject with no `BT`/`Tj`/`TJ`
  operators, so text extraction yields an empty character array (a scanned
  page with no text layer). SHA-256:
  `dac746f7dee4aaf961bb8a3764611d088264cbb25ea55314914940d1ffcbbf04`.

## Verified branch coverage

Measured against Zotero's pinned pdf.js (`core/module/structure.js`,
`getStructuredChars`) on the raw `chars` records pdf.js's `getTextContent()`
attaches to each text item:

- `pdf-parity-layout.pdf`: `getStructuredChars` returns 616 characters; 104
  carry `rotation === 90`; the ligature line yields two 2-character records
  (`c: "fi"`, `u: "ﬁ"` and `c: "fl"`, `u: "ﬂ"`); character x
  positions cluster around both columns (≈60–240 for the left column and its
  ligature line, ≈330–500 for the right column) plus the rotated block
  (≈550–590).
- `pdf-parity-scanned.pdf`: `getTextContent()` yields zero text items and
  `getStructuredChars([])` returns `[]`.
