Template Workbench at every width

Throwaway prototype. Three ways to fit Fields, the template editor, and Preview into one narrow place: a small browser window, a narrow Obsidian leaf in a wide window, or Obsidian on a phone. Each variant runs live in two frames. Variant D is the chosen design; drag its leaf width from 320 to 1400 px to see each layout step. Use the scenario buttons to see where a problem or a field insertion takes the reader. The grey box under each frame shows the facts the layout keeps.
